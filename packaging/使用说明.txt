Travelogue Studio · 使用说明（绿色便携版）
========================================

1. 系统要求
   - Windows 10 / 11（64 位）
   - 建议使用 Chrome 或 Edge 打开 Studio 页面

2. 如何打开
   - 解压本压缩包到任意文件夹（路径尽量短，可含中文）
   - 双击 TravelogueStudio.exe
   - 浏览器会自动打开 Studio；请勿关闭该程序窗口所在的后台进程

3. 第一次怎么用
   - 在首页点「试用示例相册」，或选择你自己的照片文件夹
   - 按界面提示完成导入 → 预览 → 保存长图

4. 长图
   - 在预览中选择「保存长图」
   - 若本机未安装高清长图组件，会自动使用兼容模式保存 PNG
   - 保存成功后可用「在文件夹中显示」找到文件，再发到微信

5. 我的数据在哪（本绿色版）
   - 与 TravelogueStudio.exe 同级的 trips\ 目录
   - 日志在同级 logs\ 目录（反馈问题时可附带）

6. 若 Windows 拦截
   - 请先核对邀请来源与 SHA256SUMS
   - 确认无误后，按系统提示选择「更多信息 → 仍要运行」

7. 如何退出
   - 在 Studio「导入偏好 / 设置」中点「退出 Studio」
   - 或在预览页 Dock 点「退出」
   - 退出后本机服务停止；浏览器标签可手动关闭

8. 反馈
   - 唯一入口见同目录 gate-a\SUPPORT-SOP.md（或随邀请消息附带的说明）
   - 请填写 gate-a\反馈表：版本、Windows、是否完成找文件、是否同意附日志
   - 发送日志前请先征得你的同意；不要上传含隐私的整本相册

版本号见同目录 VERSION.txt。
