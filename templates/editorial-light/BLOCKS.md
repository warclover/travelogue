# Editorial Light · 块清单 v0.1

> 线框文件：`wireframe.html`（浏览器打开即可预览结构）  
> 机器可读规则：`manifest.json`

## 页面总览（自上而下）

```
┌─────────────────────────────────────┐
│ ① cover-hero          全屏封面      │
├─────────────────────────────────────┤
│ ② trip-meta           行程元信息    │
│ ③ hook-line           一句话钩子    │
│ ④ toc-jump            章节目录(可选)│
├─────────────────────────────────────┤
│ ⑤–⑭ 章节区 × 3–7                  │
│     chapter-* + figure-* + …        │
├─────────────────────────────────────┤
│ ⑮ map-overview        路线概览(可选)│
│ ⑯ epilogue            收尾          │
│ ⑰ footer-cta          页脚          │
└─────────────────────────────────────┘
```

## 块定义

### ① `cover-hero`

| 项 | 约束 |
|----|------|
| 用途 | 首屏 3 秒：标题 + 封面图 |
| 媒体 | 1 张图（横图优先；竖图 center-crop） |
| 文案 | `title` ≤24 字；`subtitle` 可选 ≤40 字 |
| 布局 | 100vh（移动）/ min-height 85vh（桌面）；底部渐变遮罩 |
| 禁止 | 正文段落、视频、多图轮播 |

**线框标注**：`[COVER IMAGE]` + `[TITLE]` + `[SUBTITLE?]`

---

### ② `trip-meta`

| 项 | 约束 |
|----|------|
| 用途 | 快速建立时空上下文 |
| 字段 | `dates` · `places`（2–4 个）· `companions?` · `days?` |
| 布局 | 封面下第一屏；单行或两行点分隔 |
| 示例 | `2025.04.02–04.06 · 京都 · 5 天 · 两人` |

---

### ③ `hook-line`

| 项 | 约束 |
|----|------|
| 用途 | 分享钩子，不是摘要作文 |
| 文案 | 1 行 ≤56 字；可来自用户语音原话精简 |
| 样式 | 略大于正文；可选左边框/引号装饰 |
| 禁止 | 超过 2 行、列表、链接 |

---

### ④ `toc-jump`（可选）

| 项 | 约束 |
|----|------|
| 用途 | 章节 ≥5 时显示；锚点跳转 |
| 内容 | 章标题列表，水平滚动 chips |
| 显示条件 | `chapters.length >= 5` |
| P0 | 可省略，线框保留占位 |

---

### ⑤ `chapter-header`

| 项 | 约束 |
|----|------|
| 用途 | 章节锚点与节奏切换 |
| 字段 | `index`（01/02…）· `title` ≤16 字 · `place?` |
| 布局 | 章顶留白 64–96px；序号小号 + 标题 H2 |
| 命名 | 意象/地点，避免纯「Day1」除非徒步日记 |

---

### ⑥ `chapter-intro`

| 项 | 约束 |
|----|------|
| 用途 | 章导语，定调 |
| 文案 | ≤280 字，2–4 句 |
| 可选 | `mood` 标签：惊喜 / 疲惫 / 踩雷（最多 1 个） |

---

### ⑦ `figure-single`

| 项 | 约束 |
|----|------|
| 用途 | 单张强调（锚点图） |
| 媒体 | 1 图 + `caption?` ≤40 字 |
| 布局 | 全宽出血或版心内全宽；竖图 max-width 85% 居中 |
| 比例 | 容器 `aspect-ratio` 防 CLS |

---

### ⑧ `figure-duo`

| 项 | 约束 |
|----|------|
| 用途 | 两图对照、并列 moment |
| 媒体 | 2 图，caption 可选（整组 1 条） |
| 布局 | 移动：上下堆叠；≥640px：1:1 两列，gap 12px |
| 选图 | 横图优先；避免 1 横 1 竖极端反差 |

---

### ⑨ `figure-trio`

| 项 | 约束 |
|----|------|
| 用途 | 杂志经典 1 大 2 小 |
| 媒体 | 3 图；第 1 张为「主图」 |
| 布局 | 移动：上大下二小；桌面：左大右二小栈 |
| 限制 | 每章最多 1 次 trio |

---

### ⑩ `figure-scroll`

| 项 | 约束 |
|----|------|
| 用途 | 同场景连拍、美食 série |
| 媒体 | 3–5 图横滑 |
| 布局 | `overflow-x: auto`，snap 可选；图宽 ~72vw |
| JS | P0 可纯 CSS scroll；增强 snap 可后加 |
| 限制 | 全页最多 2 次 |

---

### ⑪ `quote-pull`

| 项 | 约束 |
|----|------|
| 用途 | 人味、用户原话、章内金句 |
| 文案 | ≤120 字；优先语音转写原文 |
| 布局 | 版心内缩进 + 左边线或大号引号 |
| 全页 | 0–3 处 |

---

### ⑫ `video-loop`

| 项 | 约束 |
|----|------|
| 用途 | 短视频 moment（非完整 vlog） |
| 媒体 | 1 clip；3–8s；静音循环 autoplay |
| 比例 | 9:16 或 4:5；max-height 70vh |
| UI | poster + 角标「轻触开声」 |
| 限制 | 每章 ≤1；不得作封面；全页 ≤3 |

---

### ⑬ `divider-place`

| 项 | 约束 |
|----|------|
| 用途 | 跨城/跨天视觉分隔 |
| 字段 | `placeName` · `date?` · 可选静态地图缩略 |
| 布局 | 全宽细线 + 居中地名 + 少量留白 |
| 禁止 | 每章都用（会碎） |

---

### ⑭ `timeline-bridge`（可选）

| 项 | 约束 |
|----|------|
| 用途 | 同一天相邻两章之间的轻连接 |
| 文案 | 一行，如 `午后 · 从祇园步行至鸭川` |
| 显示 | 仅 `sameDayAsPrevious === true` |

---

### ⑮ `map-overview`（可选）

| 项 | 约束 |
|----|------|
| 用途 | 全 trip 路线感（非精确 GPS） |
| 媒体 | 1 张静态路线图或点状示意图 |
| 隐私 | 城市级/景点级，无家庭住址精度 |
| P0 | 线框占位即可 |

---

### ⑯ `epilogue`

| 项 | 约束 |
|----|------|
| 用途 | 情绪收束 |
| 文案 | 1–3 句；可含「若再去」一句 |
| 布局 | 居中窄栏；章后大留白 |

---

### ⑰ `footer-cta`

| 项 | 约束 |
|----|------|
| 用途 | 作者信息 + 二次创作入口（后期） |
| 字段 | `author?` · `createdAt` · `cta?` |
| P0 | 仅版权行 + 生成日期 |

---

## 章节 Pattern（Agent 选用）

| Pattern ID | 适用场景 | Block 序列 |
|------------|----------|------------|
| `opening-moment` | 开篇 / 抵达 | header → intro → single → duo |
| `place-day` | 一地一日 | divider? → header → intro → trio → scroll |
| `highlight-clip` | 有短视频的高光 | header → video-loop → quote → single |
| `quiet-close` | 末章收尾 | intro → single → quote |

**规则**：Agent 为每章指定 `patternId` + 填充媒体槽位；渲染器按序展开，不得自由拼装未在 manifest 登记的序列。

## 响应式断点

| 断点 | 变化 |
|------|------|
| `<640px` | 单列；duo/trio 堆叠；scroll 横滑 |
| `≥640px` | duo/trio 分栏生效 |
| `≥1024px` | 可选 sticky `toc-jump`；标题字号 +1 级 |
