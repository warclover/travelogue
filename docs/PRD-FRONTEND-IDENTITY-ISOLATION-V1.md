> **定位**
>
> DPI 已经把装配 / CSS / Writer 分家。PFM / PFO / PIS 已经把作品集做成独立主路径，并用折叠 + 副句把六种「降级」。现网仍容易误导：**折叠不等于看不见，副句也救不了「出现在这本书的设置列表里」**。
>
> 本主题 **只给作品集加面**。游记精修 / 导出保持现网。作品集默认面 = 这本书此刻是作品集；对面的能力还在，但必须走过河，而且会被告知「那不是这本书」。
>
> **一句话目标**：游记精修 / 导出零改；作品集另挂独立精修面与导出面。作品集默认面只出现作品集的词和控件；要发社交图，必须换过河面。
>
> **产品铁律**
>
> 1. **作品集默认态必须藏干净。** 看见的设置 = 这本书此刻是作品集。游记的词和控件不得出现在作品集默认面，包括折叠组。  
> 2. **过河是一次性动作，不叫设置。** 作品集用户仍可出小红书；那是另一趟导出，不是这本书的导出模式。  
> 3. **不废 D-PFM-10。** 改判的是落点：从「导出设置里的折叠分组」挪到「成功面 / 一次性过河」。与当初「默认折叠、不与主产物平铺」同一意图，折叠还是会误导。  
> 4. **点法对齐继续（PFO）。** 过河之后的社交面板，点法与游记导出一致：选平台 → 确定 → Task Dock → 成功面。**复用游记点法，不改游记那份面板。**  
> 5. **游记精修冻结。** 成册类型两卡、成册风格、杂志名、确认文案本波零改。改身份形态只在**作品集精修新面**上改：书名 + 厚度 +「想改做成一本游记？」；二次确认沿用现网 `/edition`。  
> 6. **页数芯片挂在作品集精修新面上。** 游记精修不本波改挂载逻辑（现网点作品集卡才出芯片，保持）。  
> 7. **不在 `dock.js` 铺 `is_portfolio`。** 仍走 S-09：`journalDockLogic` / `portfolioDockLogic` 各吐一套面板 spec。禁止「同一面板、CSS 隐藏对面」。禁止做成一张面板里的「游记 \| 作品集」两个 tab。  
> 8. **游记印刷跨页不是作品集泄漏。** 对游记用户，那是游记自己的印刷出口。作品集侧的印刷跨页只出现在过河面，且不得与「这一本」并列。  
> 9. **加法，不改游记。** 此次实现**不得**影响游记管线的精修与导出：功能、文案、DOM、偏好钥、点法都零回归。新 HTML / 新文案只进作品集 spec。游记快照红则整 PR 打回（**BLK-FXI-01**）。  
> 10. **精修与导出跟身份联动，互斥。** 导入时选游记或作品集，这本书的精修面和导出面一起跟那次选择走，**不会同时出现两套**。线框并排只是对照。过河（F2）不是第二种身份，不改精修面。

## 1. 问题

### 1.1 根因

一个共享壳、两套身份，用**折叠和文案副句**做隔离。

- 折叠不等于看不见。  
- 副句救不了「出现在设置列表里」。  
- 用户会把列表里的每一项当成「这本书本来就有这些模式」。

后端管线已经隔离。本波只收**作品集侧**仍把游记设置摆进同一块导出 / 精修的误导。游记精修里的成册类型两卡是已知次要泄漏，**冻结，不本波改**。

### 1.2 现网对照（as-is · 2026-08-26）

| 场景 | 现网第一眼 | 用户会以为 |
|------|------------|------------|
| 作品集打开导出 ▾ | 主区「这一本 / 页图」；折叠里仍是游记六平台 +「印刷跨页（现网画册）」。面板标题仍叫「导出」。实现：`wrapPortfolioSocialGroupHtml` + `portfolioExportPopoverSpec().title = "导出"` | 这些也是作品集的导出模式 |
| 游记打开精修「这本」 | 「成册类型」两卡 +「成册风格」+ 杂志名（现网 `mountEditionControls`） | **本波不改。** 已知：人可能以为这本游记也有作品集页数档。后继另收 |
| 作品集打开精修「这本」 | 与游记共用同一张「成册类型」表；再叠页数芯片 | 这本作品集也能调游记气质 / 成册风格 |
| 游记封面 / Sheet | 共享壳写「杂志名」；作品集侧 PIS 已切「书名」 | W2 只切作品集残留混写；游记标签不强制改 |
| 导出偏好 | 单钥 `travelogue.studio.longshotExportPrefs` | 在作品集里点过社交，会写回游记的 `wechat_chat` |

书架菜单已经按身份切（「保存长图」/「导出作品集」）。预览 ▾ **比书架更杂**，这是合同缺口。

### 1.3 不是问题

| 不是 | 为什么 |
|------|--------|
| 作品集用户永远不能出小红书 | D-PFM-10 已签「换种分享」。错的是把它当成这本书的设置 |
| 游记用户不能印跨页 | 对游记，`album_spread` 是自己的印刷出口 |
| 精修不能改身份 | 能力保留。游记侧继续现网两卡；作品集侧改为独立面底下一句问话 |
| 管线要再分一次叉 | 装配 / Writer 已隔离；本波只给作品集加看见的面 |
| 游记精修 / 导出要重画 | **不要。** 那是现网 GA，本波冻结 |

## 2. 目标与非目标

### 2.1 目标

| ID | 目标 |
|----|------|
| **G-FXI-01** | 作品集导出默认面 **只** 出现作品集主产物（这一本、页图；以后 PDF 也只在这里）。六种、长图密度、按章/一整张、小红书张数 **不在此面**（含不得进折叠） |
| **G-FXI-02** | 作品集仍能发微信/小红书：默认面与成功面同一句「想发到微信或小红书？」→ 换到 F2。顶上先说「这不是在导出作品集」。主钮改称「导出长图」。导完回到 F1，Dock 主钮仍是「导出作品集」，不写回作品集偏好 |
| **G-FXI-03** | **游记精修冻结。** 功能、文案、DOM 与现网一致（成册类型两卡、成册风格、杂志名）。隔离方式 = `edition=journal` 继续走现网 `mountEditionControls`；`edition=portfolio` **另挂**作品集精修 spec。禁止同一张「成册类型」表服务两套管线 |
| **G-FXI-04** | **新增**作品集精修面：只出现书名 + 厚度 +「想改做成一本游记？」。无疏密、无杂志名、无六平台、无「成册类型」两卡。二次确认沿用 `/edition`；D-PFM-24 作品集侧可改口为人话 |
| **G-FXI-05** | 作品集精修新面挂页数芯片。不要求本波清空游记精修里现网预挂的 hidden 芯片 |
| **G-FXI-06** | 作品集新面说「书名」「导出作品集」。游记导出 / 精修用词 **不强制改**（守现网快照） |
| **G-FXI-07** | 导出偏好分钥。作品集默认面不得把 `wechat_chat` 写入游记钥 |
| **G-FXI-08** | 预览 ▾ 的杂度 **不得高于** 书架菜单 |
| **G-FXI-09** | 工程：`dock.js` 零新增 `is_portfolio`；两套 spec；禁止 CSS 隐藏对面控件 |
| **G-FXI-10** | 精修面与导出面跟 `edition` 联动、互斥。游记 trip 只挂游记精修 + 游记导出；作品集 trip 只挂作品集精修 + 作品集导出。禁止同屏两套 |

| ID | 非目标 | 理由 |
|----|--------|------|
| **N-FXI-01** | 从作品集能力上删除社交导出 | 守 D-PFM-10 能力；只改落点 |
| **N-FXI-02** | 把游记六平台从游记导出默认面拿走 | 那是游记自己的产品（守 D-PFM-11 的导出半句） |
| **N-FXI-03** | 把游记「画册印刷」当成作品集泄漏而隐藏 | 游记用户的印刷出口 |
| **N-FXI-04** | 在 `dock.js` / `chapters.py` / `journal-screens.css` 铺身份分支 | DPI S-09 / 双管线铁律 |
| **N-FXI-05** | 同一面板 DOM 里挂齐两套管线、用 `hidden` / CSS 藏 | 隐藏控件仍进 Tab、进文案、进偏好 |

| **N-FXI-08** | 重开 PIS 同夹双本 / 票根 / 成册页 X / 选脸 | 用词表可续切，算法不重开 |
| **N-FXI-09** | 把作品集设成 Studio 默认身份 | 守 D-PFM-02 |
| **N-FXI-10** | `portfolio_pages` 进社交批量多选 | 守 N-PFM-15 |
| **N-FXI-11** | 过河时改 `edition` 或静默重排这本书 | 过河 ≠ 改身份 |

| **N-FXI-14** | 本波重写游记精修身份区，或退役游记侧「成册类型」两卡 | 游记冻结。两卡泄漏后继另收 |

### 2.3 成功标准（产品可验）

| 场景 | 通过 |
|------|------|
| 打开一本作品集，点导出 ▾，**不**点任何链 | 只看见这一本、页图；看不见六平台名、看不见长图密度、看不见「换种分享」折叠 |
| 同上，点「想发到微信或小红书？」 | 整面换成「发到哪儿」；顶上能读到「这不是在导出作品集」；主钮改称「导出长图」；导完回到 F1，Dock 仍是「导出作品集」 |
| 打开一本游记，开精修 | 与改前一致：成册类型、成册风格、杂志名都在（AC-FXI-06） |

## 4. 原则与过河地图

### 4.0 身份联动（D-FXI-07 · 2026-08-26 产品确认）

导入向导选「这次做：游记」或「作品集」，写入 `edition`。之后这本书的**精修面和导出面一起跟这个身份走**，互斥，**不会同时出现两套**。

| 导入时选 | 打开精修 | 打开导出 ▾ | Dock 主钮 |
|----------|----------|------------|-----------|
| 游记 | 现网游记精修（冻结） | 现网六平台 | 导出长图 |
| 作品集 | F3 作品集精修 | F1 作品集导出 | 导出作品集 |

- 线框把两套管线**并排放**，只为对照，不是同一本书的 UI。  
- 后来在精修里改身份（游记两卡 / 作品集「想改做成一本游记？」）并确认重排后，**精修和导出一起换成新身份**，仍互斥。  
- F2 过河：仍是作品集这本书，精修面不变，Dock 主钮仍是「导出作品集」。过河不是第二种身份。

### 4.1 唯一原则

> 游记精修 / 导出保持现网。作品集默认面只出现作品集的词和控件。要过河，必须换一块面，并说清楚「这不是这本书」。  
> 精修与导出跟这本书的身份联动，互斥，不同时出现。

### 4.2 入口地图

| 入口 | 做什么 | 不做什么 |
|------|--------|----------|
| 作品集精修里的「想改做成一本游记？」 | 换身份，重排**这本书** | 不当成日常设置；不走游记那张成册类型表 |
| 游记精修里的成册类型两卡 | **现网能力，本波冻结** | 不重画、不改口 |
| 导出成功后 / 默认面底下一句「想发到微信或小红书？」 | 用同一批照片，走游记 Writer | 不把六平台写进作品集设置；不改 Dock 主钮；不写回作品集偏好；不改 `edition` |

不允许的第三处：作品集导出默认面里的折叠分组、作品集精修里的「社交模式」设置、一张面板里的「游记 \| 作品集」tab。

### 4.3 状态（导出）

| 状态 | 含义 | 面板 |
|------|------|------|
| `portfolio_export_default` | 作品集，未过河 | F1 默认面 |
| `portfolio_social_crossing` | 作品集会话内过河 | F2 过河面 |
| `journal_export_default` | 游记 | 现网六平台（零改） |

关闭过河面（导完、点返回、点遮罩）→ 回到 `portfolio_export_default`。  
刷新预览 / 换 trip → 不得停留在过河面。

### 4.4 状态（精修身份）

| 状态 | 默认面 |
|------|--------|
| `edition=journal` | **现网精修**（成册类型 + 成册风格 + 杂志名）。本波不新开 spec |
| `edition=portfolio` | F3：改这本作品集 · 书名 · 厚度 · 问句「想改做成一本游记？」；无疏密、无成册类型两卡 |

关旗：游记不挂身份区（现网 `shouldMountEditionType`）；存量作品集仍挂「改为游记重排」（现网旗关横幅保留）。作品集开旗时挂 **F3 新面**，不挂 `mountEditionControls` 那张表。
