> **定位说明**
>
> - Phase 11 不是做“更多文案”，而是做“更少但更准”的文案。
> - 文案从“导语主叙事”降级为“章级点缀”，坚持一句话、弱存在感、可随时隐藏。
> - 目标是提升成片质感与情绪引导，不抢照片主角地位。

## 1. 背景与问题陈述

### 1.1 当前问题

现状（代码与配置）存在以下矛盾：

| 问题 | 现状 | 影响 |
|------|------|------|
| **文案角色过重** | 现有 narrate 以 `hook/lead/caption/epilogue` 为主，默认策略偏“填槽” | 用户感知“AI 在说教/解释照片” |
| **视觉证据不足** | 现有 brief 依赖结构化信息，缺少更强视觉事实抽取层 | 容易泛化、空话、导游词 |
| **缺少候选重排** | 单次生成 + 校验重试，缺少多候选优选 | 稳定性差，章节间质量波动明显 |
| **控制粒度不够精细** | 可一键隐藏文案已具备，但没有“只保留轻点缀”策略 | 用户要么全看，要么全关，中间态弱 |

### 1.2 用户诉求（本次需求）

1. 根据用户照片自动生成文案；
2. 每章只要一句话；
3. 句长不超过 30 字；
4. 作为点缀，不喧宾夺主，不画蛇添足；
5. 继续支持用户一键隐藏文案。

### 1.3 核心判断（产品共识）

> 文案优化难点不在“会不会写”，而在“是否知道用户当时的情绪与关注点”。
>
> 仅靠照片与通用提示词，模型往往只能输出“合理但不属于用户”的句子。
> 因此 P11 采用「自动生成 + 最小意图注入」路线：不给用户增加写作负担，但给模型提供必要锚点，降低“靠蒙”。

## 2. 目标与非目标

### 2.1 产品目标

| ID | 目标 | 衡量方式 |
|----|------|----------|
| **G-P11-01** | 每章生成 1 句点缀文案，长度 <=30 字 | schema + validator 强约束 |
| **G-P11-02** | 文案“弱存在感”，不抢图 | 人工盲评：≥80% 样本被判定“点到即止” |
| **G-P11-03** | 准确贴合本章照片内容 | 章级事实一致性评测通过率 ≥90% |
| **G-P11-04** | 保留现有一键隐藏能力 | `copy-toggle` / `photos-only` 行为无回归 |
| **G-P11-05** | 可灰度可回滚 | 配置开关 1 次关闭可回退到 Phase 10 行为 |
| **G-P11-06** | 降低“靠蒙”比例 | 启用意图锚点的章节中，人工判定“贴合本人感受”提升 |

### 2.2 非目标

- 不做长段落故事生成；
- 不新增用户手写文案编辑器大改（沿用现有编辑机制）；
- 不做跨章连贯小说式叙事；
- 不在本 Phase 引入重型模型训练平台（先做推理链路优化）。

## 3. 已拍板决策（D-P11）

| ID | 决策 | 结论 |
|----|------|------|
| **D-P11-01** | 文案单位 | **章级单句**（`decorLine`），每章最多一条 |
| **D-P11-02** | 字数上限 | **30 字**（中文字符计） |
| **D-P11-03** | 生成风格 | “轻描淡写、事实优先、情绪点到即止” |
| **D-P11-04** | 展示策略 | 默认展示 `decorLine`；保留一键隐藏文案与纯照片 |
| **D-P11-05** | 技术路线 | 两阶段生成：事实归纳 -> 单句生成；多候选重排 |
| **D-P11-06** | 失败兜底 | 失败时允许空文案（不强行凑句） |
| **D-P11-07** | 兼容策略 | 不破坏现有 `lead/caption` 字段，P11 仅新增轻文案通道 |
| **D-P11-08** | 意图输入方式 | 采用“最小输入”：情绪（单选）+ 关注点（单选）+ 一句念头（可选） |
| **D-P11-09** | 输入负担上限 | 默认最多 2 次点击 + 可选短句，不要求长文本 |
| **D-P11-10** | 生成优先级 | 用户意图 > 章节事实 > 通用风格模板 |

## 4. 方案调研结论与选型

### 4.1 候选路径

| 路径 | 描述 | 优点 | 风险 |
|------|------|------|------|
| **A. 仅优化提示词** | 继续单次 LLM，改 prompt | 成本低 | 提升有限，波动仍大 |
| **B. 两阶段 + 重排（推荐）** | 先做章级事实，再生多候选单句并重排 | 提升稳定性与可控性 | 工程复杂度中等 |
| **C. 端到端换 VLM 大模型** | 直接用多模态模型产最终文案 | 上限高 | 计算/延迟/集成成本高 |

### 4.2 P11 选型

采用 **B 路径**：

1. 复用现有 `trip/chapter/assets/tags/memoryAnchors/voiceExcerpt`；
2. 增加章级事实摘要（不直接给用户展示）；
3. 单句生成 K 个候选（建议 K=3）；
4. 基于规则分 + 一致性分重排；
5. 输出最终 `decorLine` 或空字符串。

并追加意图锚点机制（P11.1）：

6. 若用户提供“情绪/关注点/一句念头”，则进入同一重排链路并提升对应权重；
7. 无锚点时保持保守生成策略，低置信度直接留空。

## 5. 功能规格

### 5.1 产物定义：章级点缀文案（decorLine）

| 项 | 规格 |
|----|------|
| 字段 | `chapters[].decorLine` |
| 类型 | `string`（可空） |
| 长度 | `0..30` |
| 数量 | 每章最多 1 条 |
| 默认策略 | 可空；质量不足则不输出 |

### 5.2 内容约束（硬规则）

1. 单句，不分段，不换行；
2. 禁止解释照片“意义”、禁止说教；
3. 禁止“综上所述/值得一提/令人难忘”等 AI 套话；
4. 不复述章节标题，不重复已有 lead；
5. 避免强情绪词堆砌与感叹号泛滥。

### 5.3 生成流程（P11 核心）

```text
chapter assets/tags/anchors/voice
 + optional chapter intent hints
        ↓
[Step 1] chapter_facts 提取（事实短列表）
        ↓
[Step 2] 单句候选生成（K=3，融合意图锚点）
        ↓
[Step 3] 候选重排（长度/禁用词/重复度/事实一致性）
        ↓
输出 decorLine（或空）
```

### 5.4 评分与重排规则（MVP）

总分 = `0.4 * factual + 0.25 * brevity + 0.2 * anti_generic + 0.15 * style_fit`

- `factual`：是否命中本章 tags/anchors/时间地点信号；
- `brevity`：越接近 18~26 字越优，超过 30 直接淘汰；
- `anti_generic`：模板味、空话比例惩罚；
- `style_fit`：tone 与整体语气一致（relaxed/documentary）。

当存在用户意图锚点时，启用加权版本：

总分 = `0.32 * factual + 0.2 * brevity + 0.16 * anti_generic + 0.12 * style_fit + 0.2 * intent_fit`

- `intent_fit`：候选是否匹配用户选择的情绪与关注点，是否合理吸收“一句念头”。

### 5.5 最小用户意图输入（P11.1）

为降低“靠蒙”，在不打断主流程的前提下新增可选轻交互：

1. **情绪（单选）**：`松弛 / 热闹 / 赶路 / 意外 / 仪式感 / 平静`
2. **关注点（单选）**：`人 / 地方 / 食物 / 关系 / 自我感受`
3. **一句念头（可选）**：建议 10~20 字，最多 30 字

交互原则：

- 默认折叠，用户不填也可继续；
- 每章最多一次设置，支持“应用到后续章节”；
- 输入是“锚点”不是“命令”，生成仍受真实性与长度约束。

### 5.6 展示与隐藏

沿用现有前端机制（`copy-toggle.js`）：

- 用户点击“隐藏导语/显示导语”仍生效；
- “纯照片”模式仍隐藏所有文案，包括 `decorLine`；
- session 级记忆行为保持不变。

## 8. UX 规范（轻文案）

### 8.1 视觉层级

- 字号低于章节标题，接近辅助信息级；
- 不独占大面积空间；
- 与图片之间保持“留白感”，不压图。

### 8.2 交互

- 不新增开关负担，沿用已有两个入口：
  - 隐藏/显示导语；
  - 纯照片模式。
- 新增“可选意图锚点”轻交互，不要求必填，不阻塞导出流程。

### 8.3 编辑与覆盖

- 用户手动编辑 `decorLine` 后，`edited=true` 保护继续生效；
- regenerate 默认不覆盖用户编辑字段。

## 12. 灰度发布与回滚

### 12.1 灰度阶段

| 阶段 | 范围 | 门槛 |
|------|------|------|
| **G0** | 离线 fixture + 盲评样本 | AC-P11-01/02/06 |
| **G1** | 内测 10% trip | hide_rate 无显著恶化 |
| **G2** | 内测 50% trip | 盲评达标 |
| **G3** | 全量开启 | 连续 7 天无告警 |

### 12.2 回滚策略

一键关闭：

```yaml
narrative:
  decor_line_enabled: false
```

关闭后系统忽略 `decorLine` 生成与渲染，保留历史字段不删除。

## 14. 风险与缓解

| 风险 | 影响 | 缓解 |
|------|------|------|
| 句子仍“AI 味” | 用户继续关闭文案 | 多候选重排 + anti_generic 权重提升 |
| 过度追求短句导致空洞 | 体验平淡 | 允许空输出，宁缺毋滥 |
| 与现有 lead/caption 冲突 | 信息重复 | validator 增加重复惩罚 |
| 渲染占位破坏版式 | 视觉回归 | 轻样式 + 回归截图测试 |
| 用户嫌新增输入麻烦 | 意图锚点使用率低 | 默认可跳过、应用到后续章节、两次点击完成 |
