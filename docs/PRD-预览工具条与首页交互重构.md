> **定位**
>
> - 解决「首页几次升级后前端架构已乱、预览工具条交互/功能分类/布局不合理」的问题。
> - 核心论点：**工具条不是功能陈列架，而是当前任务的遥控器**。让 80% 分享者只看到「读 → 保存长图」；让 20% 编辑者在明确的「编辑模式」里获得完整工作台（对齐 PRD-PHASE5 §1.4 Tier 0 / Tier 2 分层）。
> - 三阶段推进：**P0 快赢**（纯布局/文案，不动架构）→ **P1 模式化改造**（信息架构重组）→ **P2 架构治理**（模块拆分 + 单一状态源）。P2 与 P1 并行，避免在旧单体上继续堆功能。

## 1. 背景与问题

### 1.1 现状结构

- 首页：`studio-home-v2.html` + `homepage-v2/` 模块群（Bento 首屏 + 工作台 Bench + 书架）。
- 预览页：Python 渲染的静态 `index.html`，由 `studio_chrome.py` 响应时注入 `preview-toolbar.js/css` 形成 Studio 顶栏；页内另有 `screenplay-toolbar` / `longshot-toolbar`（Studio 态被 CSS 隐藏）。
- 两页整页跳转，前端状态互不共享。

## 3. 用户分层（继承 PRD-PHASE5 §1.4）

| Persona | 占比 | 预览页任务 | 本 PRD 对应形态 |
|---------|------|-----------|----------------|
| **分享者** | ~80% | 扫一眼验货 → 保存长图 → 发微信 | **阅读模式**（默认）：干净正文 + 保存长图主 CTA |
| **编辑者** | ~20% | 改文案/精选/结构/模板 → 重排版 → 再导出 | **编辑模式**：完整工作台 + 暂存修改状态栏 |

## 4. 总体信息架构（P1 目标态）

### 4.1 预览页顶栏三段式

```
┌──────────────────────────────────────────────────────────────────────────┐
│ ← 返回   华农油菜花 · 31张   │  [阅读] [编辑] [▶放映]  │  [保存长图] [▾] [⋯] [▴] │
│ └── 左：导航+身份 ──────────┘  └── 中：模式切换 ──────┘  └── 右：模式动作 ─────┘ │
└──────────────────────────────────────────────────────────────────────────┘
```

| 段 | 内容 | 规则 |
|----|------|------|
| 左 | `← 返回` + 画册标题 + 元信息（张数/模板来源，tertiary 小字） | 恒定，所有模式相同；返回永远在最左 |
| 中 | `阅读 / 编辑 / 放映` 三态 seg | 恒定；放映点击即全屏（非驻留态，退出回到此前模式） |
| 右 | 当前模式的动作区 | 随模式切换内容，见 §4.2 |

### 4.2 三模式动作区

| 模式 | 右侧动作区 | 正文表现 |
|------|-----------|---------|
| **阅读**（默认） | `保存长图`（主 CTA·琥珀填充）+ `导出设置 ▾` + `⋯` + `▴收起` | 无任何编辑 overlay（隐藏 ★ / 媒资 select / plate meta）；等同 `reader_immersive` |
| **编辑** | `应用排版`（有暂存修改时为主 CTA，否则 ghost 置灰）+ `编辑工具 ▾`（感受锚点 / 结构分章 / 模板 / 同框）+ `⋯` + `▴收起` | 显示 ★ 精选、媒资改判 overlay；底部常驻暂存状态栏（§6.3）；等同 `studio_preview` |
| **放映** | （进入即全屏，无动作区） | screenplay 全屏；启动浮层提供「从头放映 / 仅放映精选」二选 |

### 4.3 「⋯」系统菜单（所有模式一致）

```
⋯
├─ ✨ 生成杂志感文案        （LLM 可用时显示）
├─ ──────────────
├─ 在文件夹中显示
├─ 导出 zip（自行托管）
├─ ──────────────
└─ 收起工具栏
```

规则：同组分隔线聚类；编辑类条目（感受锚点/结构分章/模板）**移出**本菜单归入编辑模式；「放映精选」移入放映启动浮层；条件项不可用时整组隐藏不留洞。

### 4.4 首页 Bench 目标态

```
┌─ Bench ──────────────────────────────────────────────────┐
│ [最近一本 · 卡片(封面+标题+继续按钮)]  [开始制作我的游记 →]  [⚙] │
└──────────────────────────────────────────────────────────┘
```

- 「示例作品/最近一本」Tab、「继续上次」「查看最近」合并为**一张「最近一本」卡片**（无作品时显示示例作品卡片，标「示例」角标）；「查看最近」职能由书架区承担。
- 配色（10 项）与高级选项（聚类/视觉/G1/排版评分）移入右上角 `⚙ 设置` popover。

## 5. P0 · 快赢（不动架构，纯 DOM/CSS/文案）

> 工期量级：1–2 天。全部改动限于 `preview-toolbar.js` 的 DOM 模板字符串与 `preview-toolbar.css`，不拆文件、不改状态逻辑。

### 5.1 R-P0-01 · 返回左置 + 画册标题

- `← 返回` 移到顶栏最左；其后显示画册标题（取 `document.title` 或 entry API 的 `title`）+ 张数 tertiary 小字。
- 收起条（collapsed-strip）同步：`返回` 在左，`显示工具栏` 在右。

### 5.2 R-P0-02 · 控件三段式分区

- 现有控件按「左：返回+标题 / 中：阅读视图·编辑预览 seg + ▶全屏放映 / 右：保存长图区 + 文件夹 + ⋯ + ▴」重新排布，段间 `margin` 分隔（≥24px）+ 1px 竖线。
- 「保存长图」升级为唯一 primary 样式（琥珀填充加重、高度 36px），其余全部 ghost；meta 文案「按章 · 2×…」前加标签「导出设置：」并与 caret 合并为一个可点击区域。

### 5.3 R-P0-03 · 文案 chips 收进导出设置 popover

- 删除 `longshot-preview-row` 独立行；「纯照片/完整文案」「图注」「导语」三项并入点击 `▾` 弹出的导出选项 popover，与「按章/完整」「2×/3×」同面板分组展示：

```
导出设置 ▾
├─ 内容    (•) 完整文案   ( ) 纯照片
├─ 图注    [开/关]     导语 [显/隐]    （纯照片时置灰）
├─ 范围    (•) 按章     ( ) 完整一张
└─ 清晰度  (•) 2×       ( ) 3×
```

- popover 底部实时刷新摘要行（即原 meta 文案）。

### 5.4 R-P0-04 · 词汇修订

| 现文案 | 新文案 | 理由 |
|--------|--------|------|
| 阅读视图 / 编辑预览 | **阅读 / 编辑** | 去掉冗余的「视图/预览」，二字对仗 |
| ▶ 全屏放映 | ▶ 放映 | 段内更紧凑；title 保留「全屏逐屏放映」 |
| 文件夹 | **在文件夹中显示** | 与长图结果抽屉内现有按钮文案统一 |
| ⋯（更多编辑） | ⋯（aria-label：更多操作） | 菜单不止编辑 |
| 按章 · 2× · 完整文案 | 导出设置：按章 · 2× · 完整文案 | 标明语义 |
| 有编辑尚未应用排版 | 已暂存修改 · 应用排版后生效 | 因果可读 |

### 5.5 R-P0-05 · 「⋯」菜单加分组

- 按 §4.3 顺序重排并插入 `<hr role="separator">`；本阶段编辑类条目暂留菜单内（P1 才迁移），但归入「编辑」分组置于 AI 组之后。

### 5.6 R-P0-06 · 防误点

- 「▴ 收起」与「← 返回」不再相邻（返回已左置）；收起条上的「显示工具栏」按钮加 `aria-expanded` 与更高对比底色（现状已有，验证保留）。

## 6. P1 · 模式化改造（信息架构重组）

> 工期量级：1–2 周。§11 形态决议已拍板，可直接实施；依赖 P2 的模块拆分先行或同步（§7）。

### 6.1 R-P1-01 · 三模式落地

- 顶栏中段 seg 改为 `阅读 / 编辑 / ▶放映` 三项；模式驻留态写入 store + localStorage（`travelogue.studio.previewMode`）。
- **阅读**：`reader_immersive` profile；隐藏全部编辑 overlay（★、媒资 select、G1 banner 改为编辑模式内呈现；阅读模式下若存在 `structure_draft` 仅显示一条不可操作的提示 pill「章节结构待确认 → 去编辑」）。
- **编辑**：`studio_preview` profile；显示编辑 overlay；右侧动作区切换为 §4.2 编辑组。
- **放映**：保留 seg 位但为非驻留态（O-3 已拍板）——点击即启动 screenplay（有精选时先弹「从头放映 / 仅放映精选」浮层）；退出后回到此前模式。`?share=1` 态不受影响（继续极简顶栏）。

### 6.2 R-P1-02 · 编辑工具归拢

- 「编辑感受与锚点」「结构与分章」「旅行主角·同框」「模板选择」从 ⋯ 菜单/一级栏移入编辑模式的 `编辑工具 ▾` 下拉（O-1 已拍板：下拉形态；左侧 rail 留待编辑功能增多后另案）。
- 模板 pill 从一级栏移除；模板信息并入左段元信息 tertiary 文案；模板切换入口在编辑工具内。

### 6.3 R-P1-03 · 暂存修改状态栏

- 编辑模式底部常驻状态条（替代现 pending-row）：

```
┌────────────────────────────────────────────────────────┐
│ 已暂存 3 处修改（精选 ×2 · 媒资 ×1） · 应用排版后生效   [查看明细] [应用排版] │
└────────────────────────────────────────────────────────┘
```

- 无暂存时状态条**隐藏**（O-2 已拍板）；应用排版成功后短暂 toast「已应用」再隐藏。「查看明细」展开列表并支持单项撤销（撤销 = 反向 PATCH）。
- ★ / 媒资改判点击后立即在状态条 +1 并短促高亮，建立「标记 → 计数 → 应用」因果链。
- 布局 CSS 过期（`layoutCssStale`）并入同一状态条文案，不再单独一行。

### 6.4 R-P1-04 · 抽屉与浮层归位

- 长图结果抽屉固定从**右侧**滑出（不再从工具条下方推挤正文）；G1 结构 banner 移入编辑模式正文顶部（非工具条子行）。
- 工具条高度恒定为单行 56px（阅读/编辑相同），消除 `syncToolbarHeight` 的动态推挤（B-10）。

### 6.5 R-P1-05 · 首页 Bench 减负

- 按 §4.4 实施：「最近一本」卡片合并三个「最近」概念；配色 + 高级选项迁入 `⚙ 设置` popover（右上角固定位）。
- 配色裁剪（O-4 已拍板）：⚙ 内默认只露 **5 项常用**（清新浅蓝 / 经典深色 / 暖阳珊瑚 / 森系薄荷 / 夜航蓝调），其余 5 项收入「更多配色」二级展开；用户当前已选主题若在后 5 项，仍正常驻留显示。
- 涉及模块：`bento-tabs.js`（移除 Tab）、`shelf-actions-logic.js`（复用 resume 逻辑）、`theme.js` / `advanced-options.js`（挂载点迁移）。

### 6.6 R-P1-06 · 精细制作表单分步

- Import Sheet「精细制作」拆两步：
  - **步骤 2a 基本**：名称 / 地点 / 日期 / 写给编辑的一句话；
  - **步骤 2b 进阶**（默认折叠 details）：见闻、计划文件、精选/素材目录、版面密度、模板。
- 徽章文案随步进更新（「步骤 2 / 2 · 补充信息（可选）」）。
