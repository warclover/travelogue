Import Sheet v2 · 懒人版 / 专业版 双 Tab

需求理解：用户点「开始制作我的游记」→ 弹出本 Sheet（可与系统选文件夹并行或紧接）。 默认 懒人版（80% · 长图快享）；专业版（20% · 高质量卷轴/旅伴分享）收纳全部 Intent 字段。

  • 线框仅交互与信息架构；视觉对齐 studio-home-v2 深色 Sheet。
  • 字段映射见各场景下方「设计说明」callout。
  • Windows 原生文件夹选择器会阻塞浏览器——实际实现建议：先开 Sheet → 用户点选夹 → 系统对话框 → 返回后填充路径（见流程图）。

建议交互时序（讨论稿）

用户点首页 CTA「开始制作我的游记」
    │
    ├─→ ① 立即弹出 Import Sheet（默认 Tab = 懒人版）
    │
    └─→ ② 用户点「选择照片文件夹」→ 系统 pick-folder（Sheet 保持打开，按钮 disabled）
            │
            ├─ 取消 → 回到 Sheet，可改 Tab / 关闭
            └─ 选定 → 路径写入 Sheet 顶栏「已选文件夹」→ 懒人版可直接「开始制作」
                      专业版可继续填表 → 「开始制作（专业）」

Scenario 1 · 默认首屏

制作我的游记

选文件夹 · 自动出稿 · 照片留在本机

只需选一个文件夹，分章、排版、配文全自动。适合微信群发长图。

相册里若有「精选」和「素材」子文件夹，封面会优先用精选（建议 8–20 张）。

🔒 照片仅在本地处理 · 无需注册 · 不会上传云端

S1 设计要点

懒人版不出现任何输入框，降低 80% 用户认知负担。 主按钮即 pick-folder。精选/素材说明保留一行常显 hint（Phase 5 唯一值得教的准备动作）。

Scenario 2 · 选夹后 · 一键开跑

制作我的游记

懒人版 · 已选文件夹

✓ D:\Photos\Kyoto2025 更换

杂志名将使用文件夹名「Kyoto2025」。想改名？切换到专业版。

S2 设计要点

懒人路径目标 ≤2 次点击（选夹 + 开始制作）。 杂志名默认 basename，不在懒人版暴露输入框；提供「切换到专业版改名」的轻提示即可。

影响文案语气与章节重点，不是写完整游记正文。

行程单仅用于本地分章，不会公开发布。

④ 成稿偏好 （可选）

懒人版默认直奔长图；专业版用户更常需要验货卷轴。

预计 3–8 分钟 · 可关闭 Sheet，制作在后台继续

S3 字段映射（与现有 trip.json）

游记名称 → intent.title · 地点 → intent.places · 写给编辑 → userNotes · plan 文件 → intent.travelPlan · 精选/素材 → intent.folders + ingest 双源。 日期范围、旅途见闻为线框新增，需 PRD/ schema 扩展或暂映射到 planText。

Scenario 4 · Tab 切换规则

懒人版 ⇄ 专业版

规则 行为
默认 Tab 懒人版；sessionStorage 记住上次选择（专业用户回访）
已填专业字段后切懒人 保留已填数据不丢失；懒人版「开始制作」仍携带 Intent
未选夹切 Tab 允许；专业版字段可预填，但「开始制作」disabled 直到选夹
Import 中 Sheet 不可打开；与现 v2 状态机一致
文案调性 懒人版强调「快 · 长图 · 微信」；专业版强调「贴旅程 · 卷轴 · 旅伴」；均避免突出「AI」

与 80/20 用户模型对齐

懒人版（80%）                    专业版（20%）
─────────────────────────────────────────────────
选文件夹                         选文件夹 + 基本信息
  ↓                                ↓
开始制作（0 表单）               照片组织 + 编辑偏好 + plan
  ↓                                ↓
等待 → 长图 CTA 为主             等待 → 卷轴预览 + 长图
