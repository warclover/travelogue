维度 方案 A · 改进 方案 B · 全新
解决的核心问题 IS-01～06：滚动、噪音、无验货、桌面空间 心智升级：从「填表导入」到「启动创作」
快速用户路径 选夹 → 开始（2 次点击） 选夹/拖入 → 开始（同样 2 次，仪式感更强）
模式语义 快速分享 vs 精细制作（制作深度） 长图 vs 卷轴（交付物）+ 偏好可选
工程风险 低 · flag 已有 · 下游零侵入 中高 · 需重做 IA/文案/部分埋点语义
工期（估） 约 10～12 工作日（含进阶折叠） 约 3～4 周（含拖放、示意、意图卡）
适合若… 要尽快提升转化、灰度稳妥、复用 v3 PRD 愿投入重塑入口体验、强化品牌差异
建议策略 先 A.1 后 B：先推全 Wizard v3 + A.1 P0/P1（见 A.1 规格）验证漏斗； 再把「交付物示意 / 拖放 / 偏好后置」作为 v4 演进，而不是一次赌全新。 若品牌叙事优先、可接受更长周期，可直接立 B 为下一代入口。
