## 问题与目标

### 要解决的问题

现网已经会把照片装进一页（聚类定幕、拼图选脸装填），但**不会按一本书来编排**。页数跟着「有多少合格窗」走，不是「这本要 8 页还是 16 页」。缺的不是第 48 张拼图脸，而是上面那一层：**成册**——先开口径，再给每页派任务（开篇、大图、疏密、收束），最后才轮到拼图在任务里干活。

同时，模板这边也撑不住成册。旧脸库身份不诚实（名和槽对不上）、没有数据包、封面 / 封底 / 中间页 / 成册混在一张平铺表里。开发者改版式只能手翻 YAML 或手输地址，**没有一个日常入口，把「这本书用哪些角色、哪一页换哪张同族脸」当成可编排、可预演、可关旗回退的工作。**

不能靠两种偷懒来补：一是把小本乘 2 冒充大本；二是把 47 套全重画、引擎换代。拼图朝向硬门、供给感知、裁切失败链已经还过债，推倒会把旧 trip 再燃一遍。画册导出仍是另一条舞台（`card-*` / ECC），本波不能假装「已经和 Web 共用一页」。

### 要实现的目标

默认仍然零步出册。版式由 **模板 + 成册系列 + 照片清单** 决定，不再由运行时发明页序或槽位拓扑。

做成三件事：

1. **成册先开口。** 档位按页（一屏一页，左侧胶装）。先做 8 / 16 页 × 疏正密，金样 20 页正。系列只写角色，不锁死某一张脸；换同族脸不必重排整本。非 4 的倍数页靠档，不升新 SKU。
2. **页型小而诚实。** 正式页型必须带数据包、身份名实相符；旧脸进历史归档，旧 trip 永可渲染。封面封底只登记现有书衣，不另造一套。一套目录里不同页可以有不同的**优先槽比**；照片适应页，页不适应照片（D-U-17）。
3. **一个开发者后台，干日常的事。** 五入口分柜（正式页型 / 试验页型 / 历史归档 / 封面封底 / 成册系列）；编排器可视化改系列并写回仓库 YAML。首页底栏「版式」进这套已落地功能，方便反复调效果。关编排旗，Web 回到现网贪心，画册卡序不因本旗改变。

引擎继续当登记处和编译器，不当第四套选图算法，也不对 C 端开放「把照片拖进槽」。V1 先服务 Web 预览；画册要吃系列，另立合同。

条款与边界见 §1 / §2；版本账见 §8。

## 2. 目标 / 非目标 / 边界

### 2.1 目标

问题与目标的叙述以**文首**为准，此处不另写一套。落地时对照下列可勾项（细则见冻结决策与附录）：

1. 成册先开口：页数是意图，不是「有多少合格窗就有多少页」。  
2. 正式页型小、身份诚实、准入一条漏斗。  
3. 系列只写角色，不锁死脸 ID；换同族脸不必重排整本。  
4. 四种对象一个后台、分柜、同构身份字段。  
5. 已画示意图全部升为附录 A 数据包；角色都有现网顶岗脸（附录 B）。

### 2.2 非目标

- 重写 MCS / CardGrouper / Curate  
- 运行时发明页或槽位拓扑  
- 默认打开 MSA；不借「混用优先比」重开槽位自适应  
- 按文件夹照片比例多数票复制两套成册模板  
- `spread-*`、骑缝禁区、出血 / 页码 / 成品毫米  
- 把 `card-*` 与 `page-*` 合成一个 registry  
- 对 C 端开放自由画框  
- 用加脸或切碎聚类冒充杂志感

### 2.3 与相邻主题

| 主题 | 它管 | TSU 管 | 禁止 |
|------|------|--------|------|
| **Curate / 分镜** | 谁和谁一幕 | 只读组；补角色标签供匹配 | 分镜选 `page-*` 或排页序 |
| **MCS / TPC / MTSO** | 窗内选脸、装填、朝向硬门；比例软靠档可吃 `slots[].aspect` | 数据包写死优先比；漏斗形态不变 | 把 MCS 写进模板引擎包；按比例硬拆窗口 |
| **MSA** | 轨道自适应（默认 off；盲评未过） | 只消费写死的槽比 | 为混用优先比默认打开 MSA |
| **EDC** | 页纲领 `program`、裁切得体 | 成册序列与四种对象资产面 | 两套 program 枚举；把 EDC 编译塞进引擎包 |
| **ABE / CAL / CAD** | 书衣选片、题字工艺 | 登记封面/封底 SKU | 平行封面库；成册生成题字 |
| **AEL** | 画册试验床、角色匹配探针 | 正式 `page-*` 库与系列 | 把试验床几何当活目录 |
| **ECC / ADR-021** | 画册/小红书 3:4 卡 + 两卡 gutter | V1 **不改**画册渲染；系列页序若要下发画册须另立编译合同 | 把 D-U-09 写成「已经共用 `page-*`」 |
| **ADR-020** | `narrativeRole` | TSU `program` **映射**其上（§3.5） | 第三套主编词 |

EDC 的 `program` 枚举与 TSU 页任务共用：`opener | hero | mosaic | grid | breath | journal | peak`。TSU 不另开一套主编词。映射以 [EDC §6.2.1](./PRD-EDITORIAL-COMPILER-V1.md) 为权威，本 PRD §3.5 只引用。

### 2.4 双舞台 As-Is / To-Be（D-U-09）

| | Web 预览 | 画册导出 `album_spread` |
|--|----------|-------------------------|
| **As-Is** | LTE `screen-*` + `MOSAIC_*` 统一窗；页数≈合格窗数 | ECC `card-*` 3:4 + 两卡 gutter；书衣 ABE |
| **V1 To-Be** | 系列先开口；中间页从活目录 `page-*` 选（W1 可用 `screen-*` 顶岗） | **仍走 ECC**。系列不自动改卡几何 |

## 3. 三算法与四种对象

### 3.1 层间合同（单向）

| 层 | 输出（下游只读） | 禁止 |
|----|------------------|------|
| 聚类 / 分镜 | 组：`assetIds[]`、场景、角色倾向 | 不选脸、不排页序、不按长宽比拆组 |
| 成册 | 页序列：`role` + `program` + 槽数带 + 密度 | 不改组边界、不裁切、不发明几何、不按相册比例换系列库 |
| 拼图 | 在「页槽数带 ∩ 组朝向」内选脸装填；可按数据包 `slots[].aspect` **软靠档** | 不改页序、不拆组/合并组、**不改写死的槽比** |

只在 **匹配器** 见面（包落点 D-U-15）。派不上按顺序降级，写成接口而不是散文：

1. 换同纲领兄弟角色 / 同族脸（含**不同优先比**的 `faceHint`，不改该脸槽比）  
2. 消耗系列里写明的 flex 位  
3. 靠档少一页或丢低优先级页（D-U-11）  

匹配器**不得**为了装下而改全书页数、放松朝向硬门、或按单张照片改槽比。不许拼图改成册页序。对不上优先比：D-U-10 留白，或走到第 1 步换兄弟脸。

### 3.2 谁先开口

```
N 张照片 + 档位 P（或自动靠档）
  → 成册选出系列（封面 + 中间序列 + 封底）
  → 分镜给出组
  → 匹配器：组 → 页（槽数带 + 纲领；可读优先比以便换兄弟脸）
  → 拼图：族内选脸（比例软靠档）、按写死槽比装填、D-U-10 裁切
```

### 3.3 四种对象

| 对象 | 是什么 | 谁读 | 图标 |
|------|--------|------|------|
| 封面 | 单页；舞台可与内页不同 | 书衣 / CAL | 按该脸数据包 |
| 封底 | 同上 | 书衣 | 同上 |
| 中间页 | `page-*` 拼图脸 | 拼图 | 槽标 + 几何微缩 |
| 成册 | **序列**，不是脸 | 成册 | 整本密度条 |

统一管理 = 同一套身份 / 状态 / 图标 / CRUD。kind 不同，校验不同。系列文件引用页 id；页文件不反向包含系列。

### 3.4 引擎五条能力（收紧）

1. 增删改查 + 五态；正式页型 / 试验页型 / 历史归档分柜。  
2. 使用说明与图标 = 数据包投影；LLM 只润色，不准入。  
3. 成册拖拉拽；统计按 **纲领 / 家族**，不按具体 id。  
4. 类型含封面、封底、中间页、成册。  
5. 先对开发者开放；用户将来只改编排序列。

### 3.5 匹配器落点与 `program` 映射

**包**：`travelogue/layout_engine/editorial_series/`（实现时可同级改名，不得改边界）。职责：选系列、组→页、flex/靠档。可读数据包 `slots[].aspect`，**只**为换同族 `faceHint`。不改槽几何、不裁切、不发明拓扑、不按相册多数票选库。

**禁止 import 方向**：`layout_templates` 与 `mosaic`（MCS）不得反向依赖本包。本包可读数据包字段与系列 YAML；选型核仍由 MCS 在槽数带内完成，并**消费优先比作软分**（现网 hero `targetDisplayAspect` 同构）。硬门仍是朝向 + 槽数带。

**`program` ↔ `narrativeRole`**（引用 EDC §6.2.1，禁止第三枚举）：

| `program` | 典型 `narrativeRole` |
|-----------|----------------------|
| `opener` | 新族或暂 `plate` + 前缀（EDC W0） |
| `hero` | `hero_single` |
| `mosaic` | `mosaic_hero` / `mosaic_flat` |

| `breath` | `breath` |

## 4. 数据包、图标、角色、档位

字段合同、裁切三条、`page-3-port` 范例见设计理由 §5；**已画脸的完整数据包以附录 A 为准**。

图标两级（账徽 `3P` / `2L1P` + 几何微缩）见设计理由 §6。竖红横蓝；从 YAML 生成 SVG。

系列只写角色。角色权威表见附录 B。画布拖角色，脸只换 `faceHint`。

档位：`4 / 8 / 12 / 16 / 20 / 24 / 28 / 32` 页 × 疏/正/密。禁止小本×2。`photo_span` 必须与 `pages × PPC` 闭合。

邻页软规则（胶装打开时会同时看见）：禁止相邻双密网；禁止 opener 后立刻 opener；closer 不得出现在中段。

#### 4.1 槽优先比（D-U-17）

人会按内容裁成各种长宽比，节奏来自 **不同页用不同窗口**，不是整本先投票再换一套家具，也不是槽跟着单张照片变形。

| 页的任务 | 优先槽比 | 说明 |
|----------|----------|------|
| 英雄 / 高潮 | 横 16:9 或 3:2 | 冲击；3:2 吃相机原图 |
| 画心 / 呼吸 | 横 4:3 | 纸边、印刷感 |
| 双竖 / 三竖 | 竖 3:4 | 不要默认 9:16 满幅条 |
| 方图 | 1:1 | 单独页或明确方槽 |

同一页不要并排多种横比。对不上优先比的照片走 D-U-10（留白或换同朝向兄弟脸），不改拓扑、不默默切坏主体。智能裁剪只在**已写死的槽**里滑动取景，不决定槽比。

### 5.2 前端与界面范围（V1 必修）

模板引擎的资产面一半是界面。没有治理台和编排器，数据包、四种对象、成册序列落不成日常工作流。本节是架构升级的一部分，不是后补皮肤。

#### 5.2.0 界面用词

治理台与编排器**只使用下表左列**。过程稿旧称可出现在设计理由 / 七席纪要，不得再画进界面。

| 界面用词 | 旧称 | 指什么 |
|----------|------|--------|
| **正式页型** | 活目录 | 带数据包、可供新册选用的 `page-*` |
| **试验页型** | 观察室 | 有假说与到期日、未转正 |
| **历史归档** | 博物馆 | 旧 `screen-*`；只读兼容，新册不可选 |
| **封面封底** | 书衣柜 | 登记 V6 / CAL / ABE，不重画题字或选片 |
| **成册系列** | 成册柜 | 页序配方，不是一张脸 |
| **暂用旧版** | 顶岗 | W1 用现网 `screen-*` 代替尚未入库的目标页型 |
| **弹性位** | flex | 系列里可被匹配器改写的页 |
| **翻开相邻页** | 本缝 | 胶装打开时同时看见的左右两页；**不是**跨页单位 |
| **槽标** | 账徽 | `3P` / `2L1P` 角标 |
| **名实不符** | 撒谎 id | 名称槽数与实际不符 |
| **更换版式** | 换脸 | 只改 `faceHint`，不重排页序 |
| **非标准页数** | 非档 | 不是 4 的倍数档；须标「按 16 页靠档」 |

**权限**：沿用 `template_admin`。先对开发者开放。C 端用户自定义成册不在 V1（只预留 YAML 可导出）。

**权威**：系列 YAML 是唯一真相。画布是 YAML 的可视化编辑器。保存 = 写文件 + 校验；刷新 = 从文件重读。禁止只存在于浏览器里的幽灵页序。
