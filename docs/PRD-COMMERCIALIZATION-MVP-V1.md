> **定位**
>
> 本 PRD 定义 Travelogue **首轮可验证付费闭环**的最小完备集：本地安装软件 + 买断许可 + 离线友好激活，用真实付款证明一类用户愿意为官方桌面版付费。  
> 目标不是建成完整商店/账号/订阅平台，而是完成路线图 **COM-001 → S2（真实付费 ≥3）** 所需的产品与运营合同。
>
> **一句话目标**：非开发者能免费做出可发群的第一篇；愿意付费者可一次买断解锁正式导出权益，并在离线环境继续使用。
>
> **与既有张力的处置**
>
> | 既有口径 | 本 MVP 处置 |
> |----------|-------------|
> | 章程 / 营销「零订阅、无强制云」 | **保留**：不做订阅、不做强制联网激活 |
> | 营销「零付费墙」 | **修订为实验口径**：Community 仍可完成主路径；正式无水印/无限导出为买断权益（见 LEG-CMZ-01） |
> | 「许可证待定」 | **阻塞公开售卖**：Gate C 售卖前必须冻结 EULA + 对外文案（LEG-001） |
> | 海外 Pack / 年费假设 | **后置**：不在本 MVP 落地支付；不引入年费主模式 |

## 1. 背景与问题

### 1.1 现状

| 层 | 现状 | 缺口 |
|----|------|------|
| **产品** | Windows 本地 Studio；导入→策展→预览→长图主链可用 | 无付费分层、无许可态 |
| **分发** | 便携 zip（Gate A）+ Setup（Gate B/C 门禁） | 许可/定价文案未冻结；不宜公开售卖 |
| **商业证据** | 评估与路线图已写买断假设 | 尚无真实非关联付款 |
| **工程** | 无激活码 / 许可文件 / 收款集成 | 需最小授权面，且不破坏本地优先 |
| **法务** | README「许可证待定」 | EULA、退款、设备数未定 |

### 1.2 问题陈述（P-CMZ-*）

| ID | 问题 | 严重度 |
|----|------|--------|
| **P-CMZ-01** | 无单一主商业模式，无法设计首轮真实付款实验 | 阻塞 |
| **P-CMZ-02** | 若做成「必须联网激活」，与安装器铁律与隐私叙事冲突 | 严重 |
| **P-CMZ-03** | 若做成「打开即锁死」，会伤害首篇完成率（北极星） | 严重 |
| **P-CMZ-04** | 许可与「永久免费 / MIT」文案冲突，公开售卖有法律与信任风险 | 阻塞 |
| **P-CMZ-05** | 三档以上 SKU + 账号体系会使 MVP 膨胀，延误证据 | 中等 |

### 1.3 成功定义（商业发现期）

本 MVP **成功** = 同时满足：

1. 至少 **3** 笔真实付款，其中 **≥2** 笔来自非关联用户（对齐路线图 S2）；
2. 付费用户在激活后可 **离线** 完成至少一次正式导出；
3. 免费用户仍可在无指导情况下完成「可发群」主路径（允许水印或次数限制）；
4. 对外口径与 EULA / 安装器文案一致，无「永久免费」与「售卖 Pro」并存。

**不等于成功**：激活系统很完善但无人付款；或付款靠熟人但主路径被付费墙打断。

## 2. 目标与非目标

### 2.1 目标（In Scope）

| ID | 目标 |
|----|------|
| **G-CMZ-01** | 确立 **单一主模式**：个人桌面买断（Perpetual License） |
| **G-CMZ-02** | 定义 **两档**：Community（免费）+ Desktop License（买断） |
| **G-CMZ-03** | 定义 **离线友好** 激活：激活码或许可文件，本地验签；可选联网兑换 |
| **G-CMZ-04** | 用 **导出权益墙**（非启动墙）做转化，保护首篇完成率 |
| **G-CMZ-05** | 打通最小运营闭环：定价页文案 → 收款 → 发码 → 激活 → 支持/退款规则 |
| **G-CMZ-06** | 冻结 LEG 边界：EULA 草案、设备数、大版本政策、退款 |

### 2.2 非目标（Out of Scope · 本 V1）

| 不做 | 理由 |
|------|------|
| 强制年订阅 / 月订阅 | 旅行低频；章程与商业评估明确不建议首年 |
| 必须联网激活 / 每次启动校验 | 违反安装器铁律与本地优先 |
| 完整账号体系、云同步、多租户 | 章程非目标 |
| 应用商店 IAP、macOS/Linux 售卖 | 分发未就绪 |
| 模板商城、广告、印刷履约主业 | 首年不依赖 |
| Creator Pro 全量能力（品牌模板库、批量、工作室席位） | 第二轮；本轮最多预留 entitlement 位 |
| 自动化大规模防破解 / 加壳 | 成本高、口碑差；MVP 只挡随手分享 |
| 海外 Stripe/IAP 闭环 | 见海外 Pack；本 MVP 以国内买断实验为主 |
| 开源协议最终决议的全部细节 | 只需「可售卖边界」最低冻结（见 OQ） |

### 2.3 产品铁律（继承并加一条）

1. **本地优先不变** — 照片与行程数据默认不上传。  
2. **无强制账号** — 买断不强制注册；邮箱仅用于交付许可（运营侧）。  
3. **无强制联网激活** — 激活后离线可用。  
4. **首篇可完成** — Community 必须能走出「愿意发群」路径。  
5. **不借商业化开云能力面** — 不借机做云渲染付费墙（与营销 M4 旧设想切割）。  
6. **（新增）转化靠权益，不靠惊吓** — 禁止启动即全屏锁死；引导出现在「正式导出」决策点。

## 3. 商业模式（拍板）

### 3.1 主模式

```text
Windows 桌面本地软件
  → Community 免费下载/使用（有导出限制）
  → 一次买断 Desktop License
  → 离线许可（激活码 / .lic）
  → 当前大版本永久使用；下一大版本另议（半价或新购）
```

**卖的是什么**

- 官方发行版使用权（签名安装包优先）  
- 正式导出权益（去水印、解除次数/分辨率墙）  
- 基础支持与小版本更新（补丁）  

**不卖什么（本轮）**

- 云空间、算力包、订阅席位、模板商城 SKU

### 3.2 辅助模式（可选、不进工程 MVP）

| 模式 | 用途 | 本轮工程 |
|------|------|----------|
| 人工策展 / 代制作服务 | 付款不足时的情景 B（路线图） | 不进客户端 |
| 赞助码 / 早鸟码 | 种子用户感谢与小样本收款 | 可用同一激活通道手工发码 |

### 3.3 决策记录（D-CMZ-*）

| ID | 决策 | 说明 |
|----|------|------|
| **D-CMZ-01** | 主模式 = **个人买断** | 对齐商业评估基准情景 |
| **D-CMZ-02** | SKU 数 ≤ **2**（Free + License） | 满足 COM-001「最多 3 个报价」，本轮再收紧 |
| **D-CMZ-03** | 转化点 = **正式导出**，不是启动 | 保护首篇北极星 |
| **D-CMZ-04** | 激活 = **本地验签许可**；联网兑换可选 | 禁止必须联网 |
| **D-CMZ-05** | 设备绑定软限制：默认 **2 台** 活跃设备 | 换机走重置，不绑死主板 |
| **D-CMZ-06** | 防破解目标 = 挡「激活码群分享」 | 不做军工级 DRM |
| **D-CMZ-07** | 价格为 **实验锚点**，以真实付款改价 | 见 §4 |

## 4. 档位与定价

### 4.1 两档定义

| 档位 | 内部代号 | 目标用户 | 核心交付 | 实验锚点价格 |
|------|----------|----------|----------|-------------|
| **Community** | `tier=free` | 种子、尝鲜、一年一两次旅行者 | 完整导入/策展/预览；受限正式导出 | **¥0** |
| **Desktop License** | `tier=licensed` | 摄影爱好者、在意成品质感的旅行者 | Community 全部 + 正式导出权益 + 官方支持口径 | **¥129**（区间 ¥99～149） |

> Creator Pro（¥199～299：品牌模板/水印自定义/批量）**不在本 MVP 售卖**，但 entitlement schema 预留 `features.creator_pro` 布尔位，避免二轮重做激活格式。

### 4.2 Desktop License 含什么 / 不含什么

| 含 | 不含（本轮） |
|----|--------------|
| 当前大版本（如 1.x）永久使用 | 自动免费升到 2.x |
| 补丁与缺陷修复更新 | 云同步、账号协作 |
| 最多 2 台设备同时激活 | 无限设备、公司席位 |
| 去水印正式长图 / HTML 导出（按 §5） | 工作室定制模板服务 |
| 邮件支持（最佳努力，SLA 不作承诺） | 7×24 人工支持 |

### 4.3 价格实验规则

| 规则 | 合同 |
|------|------|
| 首轮锚点 | **¥129** |
| 允许测试 | 早鸟 ¥99（限量 N≤20）或邀请码 |
| 改价触发 | 连续 10 次合格演示后付费率 &lt;10% → 检讨价值锚，而非先加功能 |
| 禁止 | 未验证前对外承诺「永久 ¥99」或「终身全版本免费升级」 |

### 4.4 成本粗算（用于 COM-001，非对外）

| 项 | 备注 |
|----|------|
| 收款手续费 | 按通道 0.6%～3% |
| 签名证书 / 域名 / 邮箱 | 按年摊销 |
| 支持时间 | 邮件答疑；超时则缩支持范围 |
| 边际成本 | 本地计算为主，接近零（无云推理捆绑） |

## 5. 试用与功能墙

### 5.1 原则

- **预览永不收费**：书架、精修、卷轴预览对 Free 全开。  
- **墙在「带走正式交付物」**：用户已看见价值后再转化。  
- **禁止**：启动激活码墙、导入张数恐吓式限制（可作为软提示，不作硬拒）。  

### 5.2 Community（Free）权益

| 能力 | Free | Licensed |
|------|:----:|:--------:|
| 安装便携版 / 安装包 | ✅ | ✅ |
| 导入照片、策展、分章、选封面 | ✅ | ✅ |
| 卷轴预览与精修 | ✅ | ✅ |
| Demo 相册完整体验 | ✅ | ✅ |
| 导出带品牌水印的长图 PNG | ✅（见次数） | ✅ 无水印 |
| 导出无水印长图 PNG | ❌ | ✅ |
| 高清长图轨（若环境可用） | ❌ 或限 1 次 | ✅ |
| HTML / zip 高级导出 | 限 1 次或带水印 | ✅ |
| LLM / AI 写作表面 | **仍受 NAS 合同**（默认隐藏）；本 MVP **不**把 AI 当作付费锚 | 同左 |

### 5.3 次数与水印合同（拍板草案）

| ID | 规则 |
|----|------|
| **R-CMZ-01** | Free：**终身累计 3 次**「正式导出成功」（长图或 HTML/zip 合计）；第 4 次起必须激活或仅允许预览 |
| **R-CMZ-02** | Free 导出 PNG **必须带**不可去的品牌角标/底栏水印（文案：「由 Travelogue 制作」+ 获取正式版提示，不遮挡主体内容区超过 8% 高度） |
| **R-CMZ-03** | Licensed：无限次、无强制水印；用户可选手动署名 |
| **R-CMZ-04** | 计数器存在本地许可状态旁；允许用户查看剩余次数；**禁止**用遥测上传计数（除非未来另开同意型遥测主题） |
| **R-CMZ-05** | 重装不重置次数的「强防刷」**不做**；接受少量重装滥用，优先体验 |

### 5.4 转化文案触点（最小 UI）

仅以下触点允许出现付费引导（其余界面保持干净）：

1. 导出菜单 / 导出成功后的「去除水印」次级按钮  
2. 第 3 次导出成功后的一次性说明  
3. 设置页底部「许可证」一行（状态：未激活 / 已激活 / 剩余次数）  
4. 帮助页「购买与激活」短节  

禁止：首页大横幅、每次启动弹窗、预览页贴片广告。

## 6. 许可与激活技术

### 6.1 推荐形态（拍板）

**主路径：离线激活码 → 本地许可文件**

```text
用户付款
  → 运营系统生成 license_key（或 .lic 文件）
  → 用户在 Studio「设置 → 许可证」粘贴 key
  → 客户端用内置公钥验签
  → 写入本机 license.json（安装版：%LOCALAPPDATA%\Travelogue\；便携：exe 旁）
  → 此后离线可用
```

**可选增强（非阻塞）：** 官网「用订单号兑换」一次联网，下载已签名 `.lic`（仍本地验签）。

### 6.2 许可载荷（逻辑字段）

```json
{
  "license_id": "lic_...",
  "product": "travelogue-desktop",
  "tier": "licensed",
  "features": {
    "export_unwatermarked": true,
    "export_unlimited": true,
    "export_hq": true,
    "creator_pro": false
  },
  "seats": 2,
  "issued_at": "2026-07-23T00:00:00Z",
  "valid_until": null,
  "major_version_max": 1,
  "customer_ref": "optional-opaque"
}
```

- `valid_until=null` 表示买断（当前 major）。  
- 签名算法建议：**Ed25519**（实现简单、体积小）。  
- key 形态：`XXXX-XXXX-XXXX-XXXX` 人读串 **或** 短 JWT-like；MVP 二选一，推荐 **签名 blob 的 Base32 分段**。

### 6.3 设备与换机

| 规则 | 合同 |
|------|------|
| 绑定 | 许可文件可含 `device_hash`（机器名+磁盘ID 等哈希，**不上传原始硬件序列到公网日志**） |
| 活跃数 | ≤ 2；第 3 台激活时提示「停用一台」 |
| MVP 简化 | 若无服务端：允许同一 key 在 2 台写入本地许可；超限仅靠诚信 + 日后服务端黑名单 |
| 换机 | 邮件支持「重置许可」；人工处理即可（付费用户 &lt;50 前不建自助门户） |

### 6.4 明确禁止的技术路径

- 每次启动 HTTPS 心跳失败则锁软件  
- 内核驱动级保护、商业强壳  
- 把行程照片或 `trip.json` 加密绑架为 DRM  

### 6.5 安全与诚信分层

| 层 | MVP 做法 |
|----|----------|
| 随手转发激活码 | 签名 + 订单台账；发现滥用则吊销（吊销列表可随小版本更新打包，非实时） |
| 破解去水印 | 接受存在；靠更新与正版权益竞争 |
| 源码树开发者 | `tier=dev` 或环境变量绕过，**不得**进入发行包 |

## 7. 最小产品面变更

### 7.1 客户端（必须）

| 项 | 说明 | 优先级 |
|----|------|:------:|
| 许可状态模块 | 读/写 license；暴露 `get_entitlements()` | P0 |
| 导出门控 | 长图 / HTML/zip 应用 R-CMZ-01～03 | P0 |
| 水印渲染 | Free 正式导出固定水印 | P0 |
| 设置「许可证」页 | 粘贴激活、显示状态、剩余次数 | P0 |
| 便携版与安装版同逻辑 | 许可路径随数据根走 | P0 |
| 开发者旁路 | 仅非 frozen 或显式 build flag | P0 |

### 7.2 客户端（明确不做）

- 登录注册 UI  
- 应用内支付 SDK  
- 自动在线升级商店  
- 付费解锁 AI 开关（与 NAS 解耦） |

### 7.3 分发与文案（必须）

| 项 | 说明 |
|----|------|
| 安装器 / 便携说明 | 写明 Community / License 差异；删除「永久免费」冲突句 |
| 官网或单页定价 | 一页说清价格、含什么、设备数、退款 |
| README / 营销 | 执行 LEG-CMZ-01 口径冻结 |

### 7.4 运营侧（必须，可半自动）

| 项 | MVP 做法 |
|----|----------|
| 收款 | 微信/支付宝个人收款码或小商店 **或** 第三方（Lemon 等）；**不**自建支付中台 |

## 8. 运营闭环（从下载到支持）

### 8.1 用户旅程

```text
发现产品 → 下载 Community → 用自己的照片完成预览
  → 导出第 1～3 次（含水印）→ 感知价值
  → 打开定价说明 → 付款
  → 收到激活码邮件/消息 → 设置页激活
  → 无水印导出 → 发群
```

### 8.2 退款与售后（对外草案）

| 条款 | 草案 |
|------|------|
| 退款窗口 | 购买后 **7 日**内，且正式无水印导出成功次数 **= 0** |
| 不退 | 已无水印导出成功；或超过 7 日 |
| 换机 | 邮件申请，年重置 ≤ 3 次（人工） |
| 兼容 | Windows 10/11 x64；不承诺虚拟机/精简版系统 |

### 8.3 隐私

- 激活不要求上传照片。  
- 可选联网兑换仅传 `license_key` / 订单号与最小设备哈希。  
- 本地 `license.json` 不含用户相册路径。

## 9. 里程碑与门禁

| 里程碑 | 交付 | Go 标准 |
|--------|------|---------|
| **M0 口径冻结** | EULA 草案 + 对外文案去冲突（LEG-CMZ-01） | 无「永久免费」与售卖并存；评审签字 |
| **M1 许可技术** | 验签 + 本地许可 + 导出门控 + 水印 + 设置页 | 单测绿；frozen 包手测激活/离线导出 |
| **M2 运营闭环** | 定价页 + 收款 + 发码脚本/台账 + 支持邮箱 | 团队自买 1 笔跑通 |
| **M3 证据** | 邀请 10～20 人；收集付款 | **≥3** 笔真实付款（≥2 非关联）|

### 9.1 与安装器 Gate 的关系

| 安装器 | 商业化 |
|--------|--------|
| Gate A 便携外测 | 可无付款，仅埋「导出受限」说明（或尚未开门控） |
| Gate B 邀请安装包 | **可**开始 M2 内部购码 |
| Gate C 签名公开 | **必须** M0 已完成；否则禁止公开售卖 CTA |

### 9.2 No-Go

- 主路径被激活墙打断，首篇完成率明显下降 → 撤回启动墙，回到导出墙。  
- 连续合格演示付费率极低且访谈归因是「不需要正式导出」→ 改价值锚（服务/代制作），不先堆 Pro 功能。  
- 许可冲突文案未清 → 禁止公开收款链接。
