## 1. 项目愿景

> **把智能体做成「旅行记忆的编辑」，而不是「旅行内容的工厂」。**

用户上传旅行中的照片与少量短视频，经智能策展与短文案填槽，输出 **可预览的杂志风 HTML 游记** 与 **微信长图 PNG**（Phase 2 主分享物）；zip 与小程序鉴权 HTML 为进阶选项。交付物归用户所有，默认本地处理。

---

## 2. 问题与机会

| 现状 | 机会 |
|------|------|
| 相册乱序、重复、难讲故事 | 自动分章、去重、选封面 |
| 手写游记易拖延 | 20 分钟内得到可改草稿 |
| 通用 AI 写作流水账、与版式脱节 | 固定模板 + Agent 只填 `trip.json` |
| Vlog 工具重视频、博客平台重托管 | **照片 + 可选短视频 → 可分享 HTML 游记包** 缝隙 |

---

## 3. 项目目标（MVP）

| ID | 目标 | 成功信号 |
|----|------|----------|
| O1 | **可用**：从本地文件夹到可预览 HTML | 技术闭环跑通 |
| O2 | **好用**：种子用户 20 分钟内愿导出 | 3 次真实旅行平均时长 |
| O3 | **愿分享**：输出物可发给非开发者朋友 | ≥2 篇实际发出 |
| O4 | **稳定**：同数据重渲染版式一致 | 回归测试通过 |
| O5 | **可演进**：数据模型支撑后续托管分享 | `trip.json` v0.2 + schema |

---

## 4. 范围边界

### 4.1 In Scope（本项目做）

- 本地导入照片（≤250）与短视频（≤3）  
- EXIF / 分章策展 / 短文案生成 / 语音转写精简  
- 唯一模板 **`visual-journal`**（有声视觉相册）  
- 轻量 HTML（相对路径资源）+ zip 离线包 + 9:16 封面图（`preview.jpg`）  
- Agent 0 语义标签 + G1 记忆锚点（见 [adr/001](./adr/001-delivery-and-media.md)）  
- 3+1 Agent 流水线（见 `AGENT-ARCHITECTURE.md`）与 G1/G3 人工闸口  
- P0：CLI / 脚本；**Phase 2：Studio 工作台 + 服务端长图（微信群分享主路径）**  
- P1：轻量 zip 高级导出、PyInstaller exe  
- P3：小程序鉴权 HTML  

### 4.2 Out of Scope（本项目不做）

- 应用商店、账号体系、云同步、协作编辑  
- 多模板商城、自定义 CSS、评论与信息流  
- 完整 Vlog 剪辑时间线、长视频托管  
- 精确 GPS 公开展示、实时地图动画  
- SEO 站点、付费订阅、大规模运营

## 5. 干系人与用户

| 角色 | 诉求 |
|------|------|
| **项目发起人（P0）** | 自用验证、快速迭代、文档可支撑实现 |

---

## 7. 核心原则（不可妥协）

1. **模板优先**：版式由模板与 manifest 决定，Agent 不直出 HTML。  
2. **先结构后文案**：章节确认（G1）后再叙事生成。  
3. **本地优先**：默认不上传用户 trip；API Key 仅本地配置。  
4. **隐私默认正确**：导出剥离精确 GPS；发布前确认。  
5. **人类在环**：用户可删图、改字、调序、补语音。

## 8. 成功标准与退出条件

### 8.1 MVP 完成（Go）

满足 `ACCEPTANCE.md` 中 **AC-01～AC-07** 全部通过（含微信群长图 AC-07）。

### 8.2 继续投入（P1）

- 至少 1 次非开发者正向反馈  
- 分享路径（zip 或静态托管）在微信内可读  

### 8.3 暂停或 pivot

- 3 次真实 trip 均无法在 30 分钟内得到「愿导出」结果  
- 模板/渲染稳定性无法保证（同 JSON 多次渲染不一致）

## 11. 决策记录（已拍板）

| 决策 | 结论 |
|------|------|
| 模板 | `visual-journal` v0.2.1，退役 `editorial-light` 为参考 |
| 断点 | 768px（48rem）；手机 9:16 深色 overlay，Web 16:9 浅色 |
| 交付形态 | **zip 包为主**；MVP 不做 Base64 单文件 HTML（ADR-001） |
| Agent 模型 | 0 ingest + 可选视觉标签；1 规则为主；2 LLM 填槽；3 零 LLM 渲染 |
| 数据版本 | `trip.json` **0.2** |
| 首版 UI | CLI + 脚本（Tauri 可延后） |
| 封面 | MVP：Pillow 固定版式 9:16 |
