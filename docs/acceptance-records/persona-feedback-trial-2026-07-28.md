### U2 · 近郊周末党

- **喜欢**：参数人话（L1/L2/L6）。
- **吐槽**：无。

### U3 · 空态首访
- 路径：390px gate；首页「开始制作我的游记」。

- 路径：书架 12 本；契约 P5 PASS；东澳岛 stale 徽标。

### U5 · 轻度编辑

## 6. 建议下一波（按反馈票数）

1. **P0** SFP migrate / entry 打开后：**同步 rewrite 或 re-render `index.html` 章标题**；禁止面板净、卷轴脏（E1）。补回归：打开京都示例断言无 `· 三`。
2. **P0** 导入 humanize：拒绝/改写扩展名式题名（`JPG`/`PNG`/`DCIM`）；剥离书架可见的纯数字前缀（`005…`）；导入完成强制「确认杂志名」当噪声命中（E2）。
3. **P1** 图注策略：空优于「旅行照片」；禁止把「日期 · 杂志名」灌进可见 caption/alt 主文（E3）。
4. **P1** 同日多段章名：在时段之外争取地点/场景钩子；第三段避免回到「光秃日期」让读者联想序号（E5）。
5. **P2** stale 徽标互斥文案：一张卡只留一个主状态词（E6）；窄屏打开时自动关设置 dialog（E8）。
6. **P2** 拼贴可见性：狗粮 cohort 下提高实验 mosaic 命中，或预览旁路「版式多样」说明（E7）。
7. **产品债** 写作增强：若 NAS 坚持 L0 隐藏，首页/预览需诚实空态「未开启写作增强」而非假装没有能力（E4）。
