## 2. 总评（给决策者的一句话）

> **六席一致：W0「读者面零破绽」方向正确、证据扎实、应尽快做；但 PRD 有三类硬伤必须先修——① 它是第三个认领同一底线的文档（FST → SFC → 本 PRD），却没诊断「合同为什么没兑现」（答案：存量册未重渲 + 存量数据未清洗，不是缺代码）；② W1 两个核心决策（AI 重写章名、改名直达锚点）分别违反 Chapter Naming 铁律和指向不存在的 UI 落点；③ W2 紧凑档立项证据建立在对合成占位册的误诊上。修完 10 条合并 Must-Fix 回写 v0.2.0 后转 Go。**

**联席互证的两个关键翻案**：

1. **UX-4 与 VIS-2 对冲后自动化解**：用户体验席要求「页脚署名仅首尾屏」提前到 W1；视觉席像素核验证明「每屏重复小字」真凶是**图注题名复读**（归 W0 D-SFI-01），品牌署名本来只在尾部出现一次。结论：把「复读图注抑制 + 空渐变带不渲染」钉死在 W0，UX-4 诉求即被满足，无需动署名频次。
2. **ARCH-1 与 PROD-1 同根**：架构实测封面/书架/FirstSuccess 同源代码早已上线（SFC 已合入），试用踩到的脏名是**渲染产物过期**——这正是产品席「不诊断根因就重新认领」批评的实锤。本 PRD 的 W0 主活应从「写同源代码」改为「存量册批量重渲/迁移 + 回归断言」。
