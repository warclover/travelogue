## 3. 分角色意见摘要

### 3.1 架构

| 态度 | 要点 |
|------|------|
| ✅ 赞成 | Fixpack 定位清晰；M1 止血可独立切拍；R5.1 外置正确 |
| ⚠️ **D1 修订** | **禁止**把平台选择写入 `PATCH /trips/{id}/intent`（该端点是叙事字段）。应走 `trip.output` / 专用输出设置，并由服务端 `resolve_output_recipe` 裁决；前端只同步 CTA |
| ⚠️ **D2 反对原案** | `displayTitle` 已是防噪展示投影，不可对存量无条件用 `title` 覆写。须区分「用户改名后的旧缓存」与「目录噪声清洗」 |
| ✅ D3/D5/D6 | 赞成推荐案（D5 建议与 M14 成功态叠加） |
| 🔧 D4 | 修订后赞成：资源可验 + 能力开关；无小程序则删二维码位 |
| ⚠️ 风险 | 长图按章 PNG→JPG 中途切换导致混扩展名；须 **job 启动前** 定整批格式或全量重捕 |

### 3.2 算法 / 版式

| 态度 | 要点 |
|------|------|
| ✅ R1.1 | 后端已有 `platform=poster_bric` → BRIC 旁路与 `screens[]` 指纹校验；须让确认后的 platform 成为主按钮请求唯一来源，且 **服务端复核** |
| ⚠️ R1.4 | 禁止「改扩展名装 JPG」；一次导出一次格式决策 + 原子提交；海报固定 PNG 合同不得被「默认 JPG」覆盖 |
| ⚠️ R2.1 | 用户显式改名：`title` SSOT + 同步同值 `displayTitle`；读取仍走 `resolve_display_title()` fallback；**不触发** cover asset/style/scoring 重选，仅重渲染 + 长标题溢出回归 |
| 🅿️ R5.1 | **Park**：全局 sticky / 压缩间隙会伤 breath/snap/长图切分；若单独立项须先做 `anchorGapPx` 诊断 |
| 🚫 本包勿碰 | TPC mix、mosaic 候选、BRIC 选片参数、cover scoring |

### 3.3 测试 / 质量

| 态度 | 要点 |
|------|------|
| ✅ 赞成 | 现有 Node / pytest / Playwright 金字塔可承接；部分 QR/海报/指纹测试可复用 |
| ⚠️ AC 冲突 | AC-05/06「首次加载回写」vs 风险表「预览只内存、保存才落盘」——必须二选一写死 |
| ⚠️ AC-13 | 「真实导出 **或** 改文案」二选一不可作门禁；须先拍板唯一行为 |
| ⚠️ M1 门禁 | 须跨四层：payload · job · 产物 · `screens[]`；禁止「只看按钮文案变了」假绿 |
| 🔧 环境 | 每例注入 `gcs_poster_bric`、临时 `trips_dir`、`_free_port()`；勿依赖本机 8766 / `config.yaml` |
| 🔧 flaky | 导出/5s 提示用 mock job + 可注入计时器，禁固定 sleep |

### 3.4 用户体验

| 态度 | 要点 |
|------|------|
| ✅ 赞成 | P0 直接阻断核心任务；范围克制；改名一致性减不确定感 |
| ⚠️ D1 | 须定义「选择中 / 已确认 / 取消不提交 / 失败不切换」状态机 |
| ⚠️ D5 | 8s Toast **不足**作成功终点；复用 M14 Task Dock / 书架「分享图已就绪」作稳定载体，Toast 仅即时提示 |
| ⚠️ R4.1 | 开工前冻结一种：「真实发起导出」或「改文案」 |
| 🔧 | 「一句话」回车须兼容中文 IME 组合态；AC-01 补至少一个非海报平台反向回归 |

### 3.5 UI / UX

| 态度 | 要点 |
|------|------|
| ✅ 赞成 | sticky 操作条是矮窗正确解；双标题源消除可修手机封面割裂；破图不可接受 |
| ⚠️ D3 | 须补焦点陷阱、Esc、背景滚动锁定；`<560px` 全屏 Sheet 规格 |
| ⚠️ D1 | 主按钮文案切换须规定宽度/换行/loading，防布局跳动 |
| ⚠️ D5 | Toast 与 Task Dock / 移动提示须写层级与互斥 |
| 🔧 | 版式差异 tip 的 localStorage 键须版本化；手机 toast 写 safe-area |

### 3.6 典型用户

| 角色切片 | 态度 |
|----------|------|
| 纯小白 | 支持修「保存长图」名实不符 + 示例先报错 |
| 普通旅行者 | **强支持**改名全链同步与「一句话」反馈 |
| 分享达人 | **强支持** D1/D3/D5；「选了海报却出长图」= 信任破坏 |
| 手机端用户 | 修破图与旧名；**拒绝**用失效二维码假装有小程序 |

额外诉求：设置入口也要显示「当前将导出什么」；「在文件夹中显示」旁补「已保存到此游记文件夹」；海报卡补一句用途/张数预期。
