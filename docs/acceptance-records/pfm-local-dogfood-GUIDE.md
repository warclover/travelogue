## 1. 一键配置

把样例片段合并进项目根 `config.yaml`（gitignore），**重启 Studio**。

```yaml
studio:
  portfolio_pipeline:
    enabled: true
    homepage_entry: false
```

关旗对照：把 `enabled` 改回 `false`，导入两击、Dock「导出长图」、LVP 两卡须与现网相同。

## 2. 三册语料

现网目录：`magazine-{8,12,16,20,28}-standard`（24 页因容量退化未入库）。芯片带「N 页 · 约 M 张」。

| 册 | kept 张数 | 看什么 |
|----|-----------|--------|
| **短** | 不足 **27** | 作品集卡置灰；知情继续后可做 8 页 |
| **金样** | 约 50 | 自动应落 16 页；无溢出角标；盲评主样本 |
| **长** | 超过 81 | 自动落 28 页；角标「本册收录 N / M 张」+「改用游记（全收）」 |

同一相册各做一本**游记**作对照臂（隐藏来源后再打分）。

建议沿用 LVP 三册：`demo-d6697c8dca` / `demo-2025` / `demo-49cbe46479`。张数不够就换本地实册，不要用合成九宫格墙当金样。

## 4. 盲评怎么拍

成对、打乱、隐藏来源。每册两套全视窗（或封面 + 3 张正文 + 封底）：

| 臂 | 拍什么 | 给评委的标签 |
|----|--------|--------------|
| 游记 | 现网卷轴 | A 或 B（随机） |
| 作品集 | 同一相册的 16 页杂志卷轴 | 另一侧 |

评分表三问见模板。不要口头问「哪本是作品集」。

**门槛（建议，产品可改）**：金样册三问「作品集 ≥ 游记」至少两问成立；短册不计入胜负，只记「知情继续是否可接受」。未过门 → **不**开 `homepage_entry`。

## 5. 明确不要做

- 不要把 `folio-8` / `folio-24` 拷进运行时目录凑芯片
- 不要用微信群竖条当「像一本」的评分材料
- 不要改游记 Dock / LVP / Wait Tips 六张字面
