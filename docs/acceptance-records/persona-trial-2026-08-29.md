## 3. 流程走查摘要

### 3.1 首页与导入（U1 / U2）

- Bento 大屏预览 + 右侧微信长图对照，第一眼像成品，不是空工作台。
- 向导主路径清楚：「选择照片文件夹」∥「试用《斯里兰卡见闻录》」；选夹帮助（50–100 张、子夹、格式、先传到电脑）人话够用。
- 作品集向导标题换成「制作一本作品集」，但**没有示例试用**，新用户无法零摩擦试第二形态。
- 回访主 CTA 被最近一本作品集占据（「继续制作《珠海东澳岛一日游》」），「选择照片文件夹 / 做一本作品集 / 新建画册」四处入口并行，截取型会停一下。
- 书架票根露出 `NO.20266695`、`XDAJDY8E` 一类编码；多本角标「长图需更新」。
- 首页「版式」直达 `/templates-admin`（模板治理 · kill-switch / 审计 / 覆盖率），普通用户不该落到工程台。

### 3.2 游记预览与精修（U3 / U4 / U9）

- `demo-album` 封面杂志感强，封面导语「赤道边的风…」有内容；**正文三章只有日期名，章导语空**。
- 精修「封面」Tab（照片 / 版式 / 杂志名 / 生成字体）完整，能改名。
- 停在封面时点「页面」：只得到「封面在『封面』里换」三钮跳转，像死胡同。
- 「画册」Tab 写「智能生成请用顶栏『AI』」「在 AI 中打开」，**顶栏没有 AI 按钮**（只有返回 / 调整 / 长图 / 设置 / ⋯）。
- 关精修后曾弹出「AI 文案已就绪，可为这本重新生成文案」——本机开了 AI 面故合法，但对「只想改个名字」的轻度编辑是岔路。
- 辑封可见：「使用你的照片装帧 · 未生成风景。标题为程序化字库合成，非 AI 绘图」。接收方会读到工程免责。

### 3.3 导出（U3 · FTT 主链）

- 点「长图」弹出「这趟精选了 14 张，你想怎么发？」：微信群（推荐）/ 朋友圈连读。文案人话。
- 弹层叠在奶油封面上看起来几乎融进去（全页截图难辨），缺足够遮罩/对比。
- 确认后出现「正在导出长图 / 按原图清晰度生成 / 可去干别的」。
- **切到作品集标签再回来：进度条消失，没有「已导出 N 张」成功主句，也没有「在文件夹中显示」主动作**；本机未找到对应 PNG。完工定义（导出成功 + 找到交付物）本轮未闭环。

### 3.4 作品集（U5 / U6）

- 珠海封面精致；Dock 正确换成「导出作品集」，无微信三意图倒计时。
- 角标：「编排没排满，有 28 张没放进这本。」详情：`文件夹 121 张 · 放进这本的有 89 张 · 大约用上 117 张`。三数对不上（121−89=32，不是 28；117 与 89 并列费解）。摄影用户会以为丢片。

### 3.5 设置 / 帮助 / 手机（U7 / U8）

- 设置：外观、行程识别、存储 2.12 GB · 引用相册，可用。
- 本机 AI 面开启，故「模型API 配置 · 已连接通义百炼」可见——**正式默认包应按 NAS 隐藏**；即使狗粮机，「打开 Dev 面板」也不该出现在普通设置里。
- 帮助目录覆盖选夹 / 发群 / 封面 / 作品集页数；「怎么把长图发到微信群」四步清楚。一条偏工程：「分段或多平台时，以成功态发群指引为准」。
- 390×844 闸门生效：「请在电脑浏览器打开 Studio」+ 复制地址 + 小程序即将上线。符合现行合同；手机用户本趟做不了。
