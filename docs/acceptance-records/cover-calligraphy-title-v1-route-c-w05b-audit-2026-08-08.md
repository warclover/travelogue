## 分类定义

| 标签 | 含义 |
|------|------|
| `glyph_wrong` | 画面字形相对期望主标题有缺字 / 错字 / 增字 / 标点缺失 |
| `ocr_false_reject` | 人眼判断画面与期望一致（或仅书法连笔可辨），OCR 回读却不一致 |
| `ambiguous` | 连笔过甚或人眼也无法稳定判定某一笔画是否为目标字 |

## 对优化方案的含义

1. **主矛盾是扩散字形保真**，不是 OCR 门禁过严——重试与 Prompt v2 是正确主杠杆。
2. **不放松 D-CAL-19**：假阴性占比低；误放行错字贴纸的产品成本远高于偶尔回退路线 B。
3. **风险规则值得做**：标点（#18）、叠字（#23）可直接短路路线 B，省 15～28s 白等；不提升「被允许尝试」子集的内在正确率。
4. **重试有理论空间**：`glyph_wrong` 中含非确定性（#0 拾光）；但失败也可能高度相关，必须以 E1 Spike 实测「≤1 次重试后通过率」。
