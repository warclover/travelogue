## 2. 总评（一句话）

> **方向正确且与「一次做成」战略一致（主路径零分章打扰 + Dock 选修「分章」+ 配色 A）；阻塞不在要不要做，而在三处合同未钉死——① D-PCU-01 覆盖矩阵（精细制作 / kept_n≥10 / 实验开关）② D-PCU-02 自动锁定须改状态机而非只藏 UI ③ F5 分章工作台 MVP 与窄屏 Dock 溢出未冻结。另：线框多数 F 帧仍画旧墨绿金渐变，与已拍板 Scheme A 脱节，开工易抄错。**

**表决**：七席均为 **Conditional Go**（典型用户对主路径偏 **Go**）。

| 角色 | 表决 | 备注 |
|------|------|------|
| 产品 | Conditional Go | 先冻结覆盖矩阵与实验开关行为 |
| UI / UX | Conditional Go | Scheme A 贯彻到全帧；窄屏/触控门闸 |
| 典型用户 | Go（主路径）/ Conditional（B 路径） | 怕找不到分章 / 误点；文案「应用并锁定」易混 |
| 交互 | Conditional Go | F5 MVP + ATTACH 不计入 2 层 chrome |
| 前端 | Conditional Go | 忌「只藏横幅」；须改 `g1Pending` 默认 |
| 算法 / 版式 | Conditional Go | 质量样例集可并行，不挡 UI 但挡夸口 |
| 测试 | Conditional Go | AC-PCU-01～10；厘清与 AC-SFC-09 |

**是否可立即编码**：**是**（产品已同意 D-PCU-07～12）。开 `feat/preview-chrome-unify-v1`；实现同期完成 MF-05～07。

## 3. 分角色意见摘要

### 3.1 产品

| 态度 | 要点 |
|------|------|
| ✅ | 80/15/5 分流可执行；杀四层 chrome 对症；D-PCU-05/06 写死覆盖与视觉 |
| ⚠️ | 「首次生成一律不打扰」与 SFC「精细制作除外 / ≥10 可 G1」边界未闭环 |
| ⚠️ | D-PCU-02 是管线语义，不是纯 UI |

### 3.2 UI / UX

| 态度 | 要点 |
|------|------|
| ✅ | 主路径成品感；D-STAT⊂Dock；Scheme A 方向对 |
| ⚠️ **M1** | F1–F7 仍大量旧墨绿+金渐变；实现须以 ⑨ `dock--ink` token 为准 |
| ⚠️ **M2** | 分章激活态用旧金色洗边 → 抬成第二强调，违反唯一 CTA |
| ⚠️ **M3** | 「应用并锁定」与「创建即已锁定」语义冲突 |
| ⚠️ **M4–M5** | 窄屏 nowrap 必溢出；触控靶偏小 |
| ⚠️ | Scheme A 在天空/沙滩/雪景上 CTA 与状态字易洗白——验收须实景抽检 |

### 3.3 典型用户

| 态度 | 要点 |
|------|------|
| ✅ | F1 正是要的：看见就能带走 |
| ⚠️ | 「分章」旁「精修」可能误点；零提示时 B 用户可能找不到 |
| ⚠️ | 「应用并锁定」像重复考试 |

### 3.4 交互

| 态度 | 要点 |
|------|------|
| ✅ | Strip 只服务做事中反馈；分章出栈正确 |
| ⚠️ | F5 能力边界（拖拽？跳章？复用这本？）未冻 |
| ⚠️ | 须约定 Sheet/分章面板 = ATTACH，不计入 chrome≤2 |

### 3.5 前端

| 态度 | 要点 |
|------|------|
| ✅ | 落点：`dock.*` / `task-dock` / `shell` / `drawers` / tokens 清晰 |
| ⚠️ **高** | 只藏 UI 不改 pending → 幽灵拦截 |
| 🔧 | 建议：合同文档 → 状态机 → Kill+配色 → 分章入口+MVP → Strip 去 G1 → 窄屏 |

### 3.6 算法 / 版式

| 态度 | 要点 |
|------|------|
| ✅ | 与 SFC「用默认质量换信任」同构 |
| ⚠️ | 跳过面扩大 → 坏分章直达导出；需无确认样例回归（可并行） |

### 3.7 测试

| 态度 | 要点 |
|------|------|
| ✅ | Kill 列表利于负向断言 |
| 🔧 | AC-PCU-01～10（见 §6）；AC-PCU-07 须与 AC-SFC-09 对齐产品答疑 |

## 4. 强烈共识（无需再议）

1. 主路径零主动分章打扰（D-PCU-01）

3. 配色方案 A 墨炭+香槟铜平涂 CTA（D-PCU-06）  
4. 杀：独立管道徽标 · 默认黄 G1 · Help FAB  
5. 精修保持更深一层，不主动展开

## 5. Must-Fix（开工前 · 产品须答 / 线框须补）

| ID | 项 | 责任 | 说明 |
|----|----|------|------|
| **MF-01** | **覆盖矩阵真值表** | 产品 | D-PCU-01 是否含：快速分享全部 / Sparse only / 精细制作 / `kept_n≥10` |
| **MF-02** | **自动锁定状态机** | 产品+前端 | 创建完成时 `g1Pending`/`structurePending`/`lock_structure` 权威语义；旧 pending trip 迁移；禁止「UI 可导、后端仍拦」 |
| **MF-03** | **实验开关单一行为** | 产品 | `g1ConfirmStructure` 开：恢复黄条？自动打开分章？仅标志？与「UI 不按主路径门闸」消歧 |
| **MF-04** | **F5 MVP 冻结** | 产品+交互 | 最低：explain + 完成/应用 + 重生；是否拖拽/跳章二选一写死 |
| **MF-05** | **窄屏 Dock 合同** | UI+前端 | &lt;720 / &lt;480 折叠或 overflow；触控 ≥40px；分章激活禁用金色 |
| **MF-06** | **PRD supersede 脚注** | 产品/文档 | Refine D-REF-09/18、SFC D-SFC-07、AC-REF-06、Dock 序 D-REF-02 |
| **MF-07** | **线框贯彻 Scheme A** | UI | 全 F 帧改 `dock--ink`；⑪ 文案去掉「选 A 或 B」；「应用并锁定」改写（见 SF-01） |
