## 分角色笔记

### 分享者
- 默认验货：`refine=off`，★ 不可见，不挡浏览。
- Dock 可见「返回 / 播放 / 精修」与长图入口；**不必**打开精修也能找导出。

### 轻度编辑（原 P0 受害方）
- 开精修：chip「精修中」+ Tab「这页/这本/导出」。
- Esc：一次性 tip「可在照片上点 ★ 标精选」；★ 全部可点。
- 点 ★ 后 Task Dock 有「更新版面」；因本 trip `longshotStale`，Dock 文案优先显示过期提示（V1 优先级栈，可接受）。
- 「完成」退出清晰，且 pending toast 不阻断。

### 重度编辑
- 「这本」净化成立；迁移 tip 出现一次。
- 手机封面折叠首次展开；「看封面」为主按钮。
- 「这页」承载章字段；说教不再刷屏。
- 导出首屏干净；更多工具折叠符合预期。

### 首次用户
- 封面空态：「收起面板，去画面上修改」+ 滚正文 + 去封面封底。
- 「完成」与「更新版面」分词成立。
