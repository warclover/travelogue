## 0. 会前宣读（主持人）

1. **切口**：PFM 把作品集装进运行时了。本场只评 **怎么走进来、怎么定厚度、怎么出门**。匹配器、换脸、系列 YAML 不重开。
2. **已拍（勿重开）**：默认仍是游记；主产物仍是「这一本 + 页图」；`portfolio_pages` 不进社交批量；引擎不读工坊；双管线隔离。
3. **本场必拍**：要不要推翻 PFM「导入不问页数」；六种还折不折叠；0.67 估可上版能不能见人；成功面能不能先导再看；加席 2026-08-20 那句「没看过照片让我猜页数」今天还算不算。
4. **加席说明**：典型用户不是狗粮工程师。他不知道 kept / stale / 档位容量。他只会问——我要不要猜一个数字、做完跟上次点哪个钮、少掉的照片去哪了、精修是不是必修课。他说「看不懂」，就是 Must-Fix。**本场加席意见优先于「和六种完全同一块面板」的工程师习惯。**

---

## 1. 总评（一句话）

> **八席一致 Conditional Go：主线对——作品集不该再绕精修才能出门，假「更新版面」必须先砍，张数必须说人话。** 但 v0.1.0 有七处按原文 Kickoff 会把普通用户丢回去、或和 PFM 加席已经否决过的体验撞车：（1）导入「页数芯片 8–36」在加席眼里仍是「让我猜一个我没见过的本有多厚」，推荐默认选中不够，必须改成一句人话规格、数字是系统的事；（2）三层 N/M/P/C 同时铺开会变成工程说明书，预览角标可以分层，向导上只许一句；（3）「六种不默认折叠」会重新打开 2026-08-20 加席的伤口——同一面板里两种「书」（作品集 vs 印刷跨页），习惯对齐的是**点法**不是**把六张卡重新平铺成同等选项**；（4）成功面主按钮直接导、预览变成次按钮，加席能接受「可以先导」，但不能接受「不让我翻一眼」——主次建议对调或并列同等，禁止倒计时自动导成作品集页图；（5）`M̂ = 0.67×N` 无语料校准，AC-PFO-04 会假绿；（6）W2 入口零线框（F9–F11 未画），按 PFM 纪律 W3 级界面不能无帧拆单；（7）「去精修」若旁边还写着产品口述的「逐页调整」，20% 用户会以为点进去能改每一页——PRD 正文禁止了，成功面文案没锁死。关 BLK 后升 v0.2；**W1 修闸门与人话张数可先开；W2 向导/成功面/导出面板必须等加席三条改判回写 + 线框 v1.2。**

### 2.1 加席原话（本场权重最高）

典型用户（160 张东澳式相册，只用过游记发群）：

1. **「系统推荐可以，让我选题不行。」**  
   「你们写推荐我听得懂：用我文件夹里这些照片，做成大约一本 32 页的。**点开始就行。** 下面一排 8、12、16……我没有参照，就会瞎点，或者不敢点。想改厚度，写成『换一本更厚/更薄的』再展开，不要一上来考试。」  
   → 否决 v0.1.0 §6.2「芯片默认摊开」的信息架构，**不否决**生成前定规格。

2. **「做完我想先翻一下。导出要跟上次一样好找。」**  
   「上次游记是做好了打开看看，再点导出长图。作品集如果做好了只能先导出、翻书变成小字，我会怕导错。两个按钮都可以大，**打开这一本不要比导出小一号。** 倒计时自动导我不要，万一导成印刷跨页怎么办。」  
   → 否决「成功面主=导出、打开=次/弱」的硬主次；要求并列或「打开」不弱于导出。

3. **「少了照片要一句人话。不要四个名词。」**  
   「『文件夹 160 张，这本用上大约 100 张，做成 32 页』我懂。『可上版 / 已排 / 容量 / 估计比』我不懂。生成完如果少了很多，就说『有几十张没放进这本，要的话用游记能全收』。」  

4. **「导出还是那个钮。不要又给我六本书选。」**  
   「习惯是：点导出 → 等 → 打开文件夹。里面默认就该是我刚做的这一本。小红书那些要有，但别跟这一本平起平坐。**印刷画册和作品集不要并排成两个一样大的『书』。**」  
   → 与 2026-08-20 SHD-PFM-06 同一伤口；否决 D-PFO-04 原文。

5. **「精修不是必修，也别写成能改每一页。」**  
   「不满意再进去可以。不要暗示我进去能一页页换图——现在没有，写了就是骗人。」

## 7. 与 PFM 2026-08-20 加席如何和解

| 8/20 原话 | 当时裁决 | 本场 |
|-----------|----------|------|
| 没看过照片不要让我猜 8 还是 24 | 否决导入芯片 | **改成：系统给一句规格，用户可以不猜就开始**；猜数字放进展开。不是回到「只准精修定页」 |
| 16 张 PNG 不知道发给谁 | 主产物 = 这一本 + 页图 | **保持**。成功面必须能打开这一本（BLK-03） |
| 180 张只上 96 没人说 | 溢出明示 | **保持**。向导/成功面改人话（BLK-02/05、SHD-04） |
| 作品集和印刷跨页分不清 | 六种折叠 + 副文 | **折叠的意图保留**；「点法对齐」≠ 再次平铺（BLK-04） |

结论：PFO 推翻的是「页数只能藏在精修」，**不是**推翻「不要让用户蒙页数」。v0.1.0 把这两件事写成了一件，本场拆开。
