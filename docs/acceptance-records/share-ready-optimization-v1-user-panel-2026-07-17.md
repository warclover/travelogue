## 2. 总评（给决策者的一句话）

> **六类用户一致：方案对准「敢发」，W0 三件事（真图、问怎么发、版心别漏工程话）必须先做；W1 的「发微信群」按钮文案与成功面发群指引是分享者过门条件；W2 文案润色重要但不挡先修信任。无用户要求本主题做海外 IG 或重做精修。**

**联席表决**：**Conditional Go**（6/6 用户席 + 主持附议）· 不新增阻塞 Kickoff 的 Must-Fix（跨职能 BLK 已回写）· 新增 **用户 Should-Fix（USR-*）** 建议合入编码前 PRD 脚注或 W1 验收。

## 4. 分角色意见摘要

### U1 · 极简分享者

| 态度 | 要点 |
|------|------|
| ✅ 赞成 F1 | 黑屏 = 不信任；真图样品是「值不值得下/打开」的第一关 |
| ✅ 赞成 F4 | 「长图」三个字太产品；要看到「发微信群」才知道终点 |
| ✅ 赞成 F5 | 文件存了不等于我会发；成功面停住 + 打开文件夹是刚需 |
| ⚠️ 担心 | 意图卡会不会挡到「我就想发群」的人？→ 主持说明：Sparse 不问；只有 10–30 张才问 |
| 📌 要求 | W1 未完成前，不要对外宣称「一键发群已闭环」 |
| ❌ 不要 | 首页堆设置、API、模板名 |

**剧本自评**：F1→F4→F5 能走完就愿意用；F2 与我无关（照片少）。

---

### U2 · 近郊周末党

| 态度 | 要点 |
|------|------|
| ✅ **强支持 F2** | 「系统直接导出」= 被冒犯；三选一文案清晰（发群 / 九宫格 / 连读） |
| ✅ 赞成 N=18 来自真实精选数 | 若写成 5 张会以为相册丢了 |
| ✅ **强支持 F3** | 改完图再导出，仍要能换分享方式；「重新导出」不能变成死命令 |
| ⚠️ 文案 | 「选择并导出」略硬；可接受；希望默认高亮「微信群 · 长图」 |
| 📌 要求 | 取消必须真的不导出（线框已写，验收要锁） |
| ❌ 不要 | 假九宫格；把连读叫做九宫格 |

**剧本自评**：F2/F3 是本场核心；不过门就不认主题完成。

---

### U3 · 空态首访用户

| 态度 | 要点 |
|------|------|
| ✅ 赞成 F1 | 第一眼必须像成品，不像开发者调试页 |
| ⚠️ 范围 | 示例相册、空态灰按钮、无 Key——应继续走 FTUE/L0，**本主题别再发明第三套首访故事** |
| 📌 要求 | 样品图旁「示例」标签保留，避免误以为是自己的相册 |
| ❌ 不要 | 首页解释 `kept_n`、DOM、recipe 等词（线框 F2 副文「非 DOM 估数」仅评审可见，产品面应隐藏） |

**USR-01（用户建议）**：产品面意图卡副文不要出现「kept_n / DOM」；仅显示「这趟精选了 N 张…」。

---

### U4 · 回访用户

| 态度 | 要点 |
|------|------|
| ✅ 赞成 F3 | stale 横幅 +「换种分享方式」符合「我改过东西」的心智 |
| ⚠️ 书架 | 主标题要人话；「模板已锁定」别抢镜（认 W2 / §3.6） |
| 📌 要求 | 书架一键导出若走默认发群，要有弱提示「想换九宫格可到预览里选」（对齐 D-OR-16，用户认可） |
| ❌ 不要 | 每次回访强制弹意图卡（会烦） |

---

### U5 · 轻度编辑者

| 态度 | 要点 |
|------|------|
| ✅ **强支持 F6** | 「雾底题签」「已省略封底」出现在封面 = 直接毁分享欲 |
| ✅ 赞成 | 精修面板里可以有解释；Share / 长图必须干净 |
| ⚠️ W2 | stub「关于…的1天」「N 张汇成」同样不敢发；同意放 W2，但希望编码时别忘记 |
| 📌 要求 | 改完标题/封面后的 stale 重导，走 F3 而不是静默旧图 |
| ❌ 不要 | 为了「敢发」砍掉精修入口 |

**剧本自评**：F6 不过 = 编辑者否决主题信任。

---

### U6 · 摄影向进阶用户

| 态度 | 要点 |
|------|------|
| ✅ 赞成优先级 | 先修分享断裂；章名「日期续」、地点「旅途」可 W2 |
| ✅ 赞成按章 | Narrative / ≥50 不要在本主题被削弱 |
| ⚠️ F5 进度 | 「按章 · 高清」次行可接受；不要用「打开浏览器」吓我 |
| 📌 要求 | 整卷二次确认保留（已有 OR 合同） |
| ❌ 不要 | 做成「发圈工具」品类；杂志预览仍要在 |

## 10. 给产品负责人的决议建议

1. **维持** Share-Ready **Conditional Go**，可按 IMPLEMENTATION 开编码 W0。  
2. **W0 不可妥协**：F1 真图 · F2/F3 意图同源 · F6 零泄漏。  
3. **W1 与分享者过门绑定**：F4「发微信群」+ F5 发群成功面（联合 FTUE）。  
4. **采纳 USR-01**：用户可见文案去工程词（实现时注意，无需再开大评审）。  
5. **主题「完成」对外宣布前**：安排 U1/U2/U5 真人复测（USR-06），Agent 联评不能替代。
