## 默认这一趟做了什么

选好旅行相册后，工具会在本机：

1. **整理行程**（有定位信息时按行程分段）  
2. **挑片并排成杂志页**  
3. **生成可预览的游记**，并可导出适合发群的竖版长图  

一般**不用改设置**即可导入、排版并导出纯照片长图。

## 默认不会做什么

- 不会默认打断你去「先确认章节」  
- 不会默认打开实验排版  
- 不会把照片上传到云端（默认留在本机）  
- 不会引导去配置写作引擎或 AI 文案（当前版本默认面已休眠）

## 常用设置（可选）

- **行程识别** / **场景分析**：影响怎么分段与合并同场景  
- **导入时复制源文件**：影响占不占磁盘  

实验选项在设置里默认折叠，日常成册请保持关闭。
