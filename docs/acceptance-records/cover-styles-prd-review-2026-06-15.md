## 核心议题

是否在 **不拆 DOM** 前提下，通过 3 套 Web 封面皮肤 + 创建时确定性分配，解决「首屏同质化」，且 **不破坏 Cover V4** 已交付能力。

---

## 全场共识

1. **问题判断成立** — 现网仅 `card-br`，演示与传播缺乏差异；技术路径（`data-cover-opening` + CSS）合理。  
2. **确定性哈希 + 写入 trip.json** 正确；禁止 render 时重随机是 **硬性要求**。  
3. **`card-br` 回归** 必须独立 AC；V4 测试不可被新样式稀释。  
4. **P0 仅 Web** 可接受，但须在 PRD 与 Studio 文案中 **明示** Mobile 不同步，避免用户困惑。  
5. **P0 无样式切换** 可上线，但须在 P0 验收中增加 **轻量告知**（见决议 R-05）。  
6. 两款新皮肤 **实施前须补高保真线框**（静态稿即可），不能仅凭 §4.3/4.4 文字描述开工。

## 分角色评审意见

### 产品

| 维度 | 意见 |
|------|------|
| **价值** | 支持立项；「连建三本看到三种」对演示有效（US-CSV-04）。 |
| **随机策略** | `tripId` 哈希可接受；建议 P1 尽快补 **手动切换**，降低「分到的款式不喜欢」流失。 |
| **权重** | 1:1:1 同意；若数据证明 `split-mat` 阅读性差，再调权重，不在 P0 阻塞。 |
| **缺口** | 缺 **成功指标**：建议 P0 至少记录 `coverOpeningStyle` 分布与 Share 打开率（telemetry 预留字段即可）。 |
| **风险** | 用户 **不知道** 自己被「随机分配」— 需最小告知，否则感知不到差异化价值。 |

### 用户体验研究

| 维度 | 意见 |
|------|------|
| **心智模型** | 用户预期「我的游记一种样子」；随机分配若 **无说明**，可能误解为 bug 或「为什么和别人的不一样」。 |
| **Web / Mobile 分裂** | 同一 trip 在电脑与手机封面不一致（P0）— 须在帮助文案或首次预览 Toast 一句解释，否则 **认知断裂**。 |
| **可发现性** | P0 无切换 = 用户无法修正；建议验收时做 **5 人走查**：分配后是否注意到版式差异、是否满意。 |
| **无障碍** | 深衬纸 + 白字（`split-mat`）需验 WCAG 对比度；浅底杂志款标题与背景对比亦需 AC。 |
| **建议** | 增加 **AC-CSV-43**：三种样式正文区对比度 ≥ 4.5:1（大文本 ≥ 3:1）。 |

### 视觉设计

| 维度 | 意见 |
|------|------|
| **系列感** | 三套皮肤不可像三个不同产品；须共用 **衬纸色、accent、圆角、阴影层级** 设计 token（可引用 `--folio-*` / `--accent-mobile`）。 |
| **`split-mat`** | §4.3「如 `#3d2b1f`」过粗；须改为 **设计 token 表**（衬纸浅/深、文案区底、分隔线）。右栏比例 58/42 可，但须验 **竖图封面** 在左栏不裁切主体。 |
| **`magazine-head`** | 参考图为 **居中杂志题 + 英文副标**；PRD 默认左对齐需 **二选一拍板**。标题区 `28–36vh` 范围过大，建议定死 **`max-height: 32vh`** + 最小摄影区 **≥ 58vh**。 |
| **字体** | 三套均用 HetangYuese 书名可接受；`magazine-head` 可考虑 title **略大一级** 以强化杂志感，hook 保持 UI 栈。 |
| **交付物** | P0 开工前须交付：`wireframes/cover-styles-v5-split-mat.html` + `wireframes/cover-styles-v5-magazine-head.html`（或 Figma 链接记入 PRD）。 |
| **Icon Dock** | `split-mat` / `magazine-head` 为浅底时，Dock 胶囊对比度须 **单独验**（现网 Dock 为深底场景优化）。 |

### UI/UX 设计

| 维度 | 意见 |
|------|------|
| **信息架构** | DOM 不变正确；`panel` 在 `magazine-head` 下置顶需验 **flex 顺序** 与 **书名点击热区** 不与其他控件重叠。 |
| **编辑体验** | 三种样式书名编辑（D-CSV-14）须统一：**输入框宽度随 panel 变**，禁止 `card-br` 宽而另两款窄导致截断体验不一致。 |
| **窄屏** | §10 提到 `<896px` 栈式回落，但 **无 AC** — 必须补 **AC-CSV-25/35** 或明确「P0 仅保证 ≥1024px」。 |
| **空状态** | hook 为空 AC 已有；**title 极短（1–2 字）** 时三款均须验 panel 最小宽，避免「林芝」贴边。 |
| **P1 切换** | 建议入口：**Sheet「排版」Tab** 顶部「封面版式」三选一缩略图；切换后 stale 提示。 |

### 前端实现

| 维度 | 意见 |
|------|------|
| **可行性** | 评估与 PRD 一致，约 3–5 人日合理（含测试）。 |
| **CSS 隔离** | 须强制 `data-cover-opening` 选择器前缀，避免 V4 规则泄漏到新皮肤。 |
| **`card-br` 默认** | `:not([data-cover-opening])` 与显式 `card-br` 双路径 OK；建议 V4 测试 fixture 显式写 `data-cover-opening="card-br"`。 |
| **长图** | AC 未覆盖 `longshot` 封面帧；建议 **AC-CSV-44**：三种样式 longshot 首屏截取无裁切异常。 |
| **Schema** | `meta.coverOpeningStyle` 位置同意；创建后 **禁止 curate 覆盖**。 |

### 内容策略

| 维度 | 意见 |
|------|------|
| **文案** | 不引入 Logo/英文装饰（非目标正确）；place 行在三款中 **语义一致**（地点 uppercase）。 |
| **气质** | `split-mat` 偏「画册商务」、`magazine-head` 偏「 editorial」、`card-br` 偏「旅行摄影」— 三款并列 OK，但 hook 长度上限应一致（2 行）。 |
