## 0. 会前宣读（主持人）

1. **切口**：临时库已经能设计、标星、编样例、真图试印。要定的是长期身份：独立工坊，还是并进现网。PRD 选前者，经升格包交给 TSU。  
2. **已拍（勿重开）**：机器隔离；词汇表统一；不抽共用模块；星不当 MCS 分数；试印不进 C 端；不接 `album_spread`；不把 5/7/9 槽塞进默认长图；现场不搬家。  
3. **勿重开**：47 套全重画、引擎换代、Mixbook 填图器、画框器、现网再造一套铺图台。  
4. **本场必拍**：W1 导出会不会把锁脸试刊送成正式金样；状态归谁标；创建最少几步；catalog / faces / roles 几份真相；导出和写入会不会看串；薄柜未建时能不能说升格闭环；B7 业主是产品还是运营。  
5. **加席说明**：项目运营是设计模板、标星、编成册、跑试印的人。本场他的否决权与产品同等——工具合同若只有建筑师能执行，算没写完。

## 1. 总评（一句话）

> **八席一致 Conditional Go：主线立得住——工坊回答好不好看、现网回答许不许可用、中间是升格包不是管道，比「整包并进 Studio」或「现网再做一套」都可验收、可关旗。但 v0.1.0 有七处按原文 Kickoff 会假绿或坑到运营：（1）W1 导出允许人表、atelier-only 推迟到 W2，运营会把 `folio-16-standard` 换个 id 交上去冒充 B7；（2）`reviewed` / `promote-ready` 写成产品标，日常使用者是运营，状态会停在 sketch；（3）AC-03 创建步骤少于 §7.1 真实步骤，按验收做会微缩不出现；（4）catalog / faces.js / roles.js / 映射表四份角色真相，W1 只对账前两份；（5）新 IA「写入 vs 导出」无线框，两钮会看串；（6）D-TDV-25 禁止假装闭环，W1 完成标志却含「升格可执行」，对外易说成已交给现网；（7）B7 仍派给产品，运营才握对照本，金样会继续空。关 BLK 后升 v0.2；W0 可继续改身份文案；W1 必须先让导出器自己会标「未准入脸 / 未收角色」，正式 id 禁止任何 `folio-*`。**
