## 0. 会前宣读（2 分钟）

1. **切口**：无 AI 面下「敢原样发」——去序号腔、去脏题名、去复读图注、章序可信、词表分层、浮层可点、小红书可抄标题话题。  
2. **不做**：恢复 AI 面、重做配方/意图卡、强制 lead、影楼/Vlog。  
3. **修订声明**：本主题 **拥有**「禁止 ·二/·三」；**硬化** SFC 展示名；**分层**而非废除 stale 三态；小红书文案包遵守 NAS 无 body。  
4. **喜欢项保护**：五目标导出、人话文件名、清晰度像素、长图紧凑、分章改名 — 本主题零行为回退。

---

## 1. 总评（一句话）

> **切口对准试用真断裂，根因树可裁决，排除 AI 正确。阻塞不在方向，而在：① 同日消歧「合并 vs 同名」未冻结；② 无线框挡门；③「可重排」字面与徽标层级缺 COPY/视觉合同；④ Chapter Naming / SFC 交叉脚注未落；⑤ W0 未纳入浮层互斥（狗粮已踩雷）。Must-Fix 回写后标 Conditional Go · Ready for W0 文档/线框。**

## 4. 分席意见摘要

### 4.1 产品

| 态度 | 要点 |
|------|------|
| ✅ | 铁律 1–6 可裁决；NAS 边界正确；反例附录防假绿 |
| 🔴 MF | OQ-01～04 **正文冻结**（见 §6） |
| 🔴 MF | Chapter Naming / SFC 增 **supersede 脚注**（序号腔、日期串 noise、stale L2） |
| 🔴 MF | FE-SFP-06（浮层互斥）**升入 W0**——试用已踩雷，不宜挂 W1 |
| ⚠️ | W0 含 BE-01/02/03 估点偏满；允许 W0a 章名+题名、W0b 图注，但退出标准仍绑 G-SFP-01～03 |
| 📌 | 主题完成仍绑真人 N≥5（对齐 FST/SFC 纪律） |

### 4.2 交互 / UI-UX

| 态度 | 要点 |
|------|------|
| ✅ | 浮层互斥优于只改 z-index；小红书「选中后一行」降噪正确 |
| 🔴 MF | **必须补线框** F1～F5（见 §7）后方可 W0 UI 合入 |
| 🔴 MF | 「可重排」徽标：**次级样式**（弱于分享图态）；tooltip COPY 冻结 |
| ⚠️ | 同名「5月27日」连读时依赖章号 01/02 —— 线框 F1 需画出仍可区分 |
| 📌 | 分章 × 命中区域 ≥ 44px；互斥后仍要防 toolbar caret 叠层 |

### 4.3 用户流程设计

| 态度 | 要点 |
|------|------|
| ✅ | 根因导向正确：改 SSOT 而非洗样片 |
| 🔴 MF | **打开册 migrate** 写进主路径：静默改 displayTitle/章名时 **不弹教学**，但预览标题变化须即时反映（无「旧缓存闪一下」） |
| 🔴 MF | 小红书主路径：**选中小红书 → 确定 → 可见「复制文案包」→ 再点金色导出**；成功面为第二入口（OQ-03） |
| ⚠️ | 弱桶合并会改变「按章导出」章数——「为什么这样分章」必须说「已合并同一天过短片段」 |
| 📌 | 用户手改章名后重导/刷新：继续 `titleOrigin=user` 保护（已有，验收加负例） |

### 4.4 用户体验

| 态度 | 要点 |
|------|------|
| ✅ | 空优于复读 / lead 空合法 —— 防止验收误杀 |
| ✅ | 三态分层，反对压成单一「分享图需更新」 |
| 🔴 MF | **同日默认允许同名日期**；合并仅弱桶（见 OQ-01）——乱合并比两个「5月27日」更伤「系统替我做主」感（U2/U5） |
| ⚠️ | 「可重排」仍略工程；必须 tooltip：「版式算法有更新，可点重新排版」 |
| 📌 | 空图注 +「带文字」导出：接受留白，禁止回填假句 |

### 4.5 视觉专家

| 态度 | 要点 |
|------|------|
| ✅ | 封面题名去掉数字日期链后，层次应回到「人名词 / 地点词」视觉重量 |
| 🔴 MF | 书架徽标：**同一封面最多 1 枚**；L1/L2 色阶区分（L1 警示感、L2 中性提示） |
| ⚠️ | 长图「带文字」但 caption 全空时，勿用灰色占位块冒充图注——直接不占行 |
| 📌 | 章名同名时，卷轴章头 **章号 + 日期** 双信号；禁止再加「（2）」工程后缀 |

### 4.6 典型用户

#### U1 · 极简分享者
- ✅ 强支持去「·三」、浮层可关。  
- ❌ 不关心「可重排」细节，只要别挡「发微信群」。  
- 📌 W0 必须包含互斥（曾点不到 ×）。

#### U4 · 回访
- ✅ 三态分层。  
- ⚠️ 「可重排」无解释会露出新问题 → tooltip 必做。  
- 📌 「分享图已就绪」保留。

#### U5 · 轻度编辑
- ✅ 改名保留；禁止静默覆盖手改。  
- ⚠️ 合并弱桶可接受，但要能在分章里看见结果并改名。  
- ❌ 不要为了净化再塞说明书腔。

#### U7 · 家庭组织者
- ✅ **强支持** D-SFP-03/04；书架与封面必须同一体面名。  
- 📌 回退名「地点 · 日期」可以，不要诗。

#### U8 · 职场晒旅
- ✅ **强支持** 禁序号腔；同事群零容忍。  
- 📌 图注空比复读题名体面。

#### B1 · 小红书列席
- ✅ title + `#旅行日记` + 地点话题可发。  
- ⚠️ UI 必须写明正文自填，否则以为坏了。  
- 📌 入口在导出前，不要只在成功后。

## 5. 全场共识

1. **方向正确**：净化读者面，不重开 AI，不重做配方。  
2. **根因级修复**：章名/题名/图注/章序必须改生成与解析 SSOT。  
3. **同名日期 > 乱合并**：弱桶才合并（OQ-01）。  
4. **浮层互斥进 W0**。  
5. **无线框不签 W0 UI**。  
6. **Agent 试用 ≠ 真人完成门**。  
7. **本轮只做评审/文档回写**；编码另排期。

## 6. OQ 拍板汇总（会中冻结）

| OQ | 决议 |
|----|------|
| **OQ-SFP-01** | **默认允许同名日期章名**（如两章皆「5月27日」）。**仅当**后续同日桶 `len(photos)≤2` 且无 daypart/segment 时合并入前桶。禁止用「·二/·三」消歧。 |
| **OQ-SFP-02** | V1 **不做**用户锁定章序；一律时间升序。精修拖拽若已存在：本主题不扩展；冲突时以时间序为准并在「为什么这样分章」说明（若现网无拖拽则无需额外 UI）。 |
| **OQ-SFP-03** | 小红书文案包：**仅在选中小红书后**于导出设置内显示一行「复制文案包」；成功面保留第二入口。不进五目标常驻列表。 |
| **OQ-SFP-04** | 「可重排」V1 **只改词 + tooltip**；一键 CTA 沿用现有「重新排版」，不新增第三按钮。 |
