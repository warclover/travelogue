## 0. 结论摘要

| 问题 | 结论 |
|------|------|
| **整体可行性** | **高（Conditional Feasible）** — 落点与现网 MCS/LTE/URO/Output Recipe 对齐；合同已冻结；主要风险在集成叠乘与 ordering 双轨，不在「从零发明算法」 |
| **全栈做完成本** | 开发约 **45–70 人日**；含算法/架构/QA/设计协作约 **70–110 人日**；日历约 **10–14 周**（1 开发主串行，GCS-B 可并行） |
| **最小有感包（MVP）** | 开发约 **18–28 人日** / 日历 **4–6 周**：共享守门 + MSR shadow→硬筛 + MGQ eligibility；GCS-B 可选并行 |
| **最大不确定项** | ① MSR↔`try_order_for_pattern` 双轨收敛；② 硬层叠乘导致 legacy 飙升回调；③ GCS 轨 A 轨道枚举工程量；④ 盲评组织成本（非编码） |
| **Go 建议** | **可 Kickoff LQS-P0**；W1 硬行为按纲领串行；全量默认开绑分主题盲评，勿一次性全开 |

## 1. 现网就绪度（可行性底座）

对照代码事实（2026-07-18）：

| 依赖能力 | 现状 | 对 LQS 含义 |
|----------|------|-------------|
| MCS `pick_best_window` / `score_candidate` | 现网权威 | MGQ/MSR 挂点清晰，**可行** |
| `generate_window_candidates_with_rejections` | 已有 | 硬筛插入点存在 |
| URO `usage_rules` | 模块齐全；`enabled` 可关 | MGQ **消费**即可，不重写引擎 |
| `validate_for_publish` / admission | 已有 | GCS-A 入轨可复用 |
| `slot_display_aspect` / 轨道几何 | 已有 | MGQ 面积口径可复用（BLK-09） |
| `_pick_alt_topk` / `replan_screen` | 已有 | MGQ 评分台候选源现成 |
| Output Recipe `EngineId` | 仅 `chapter_capture \| platform_segment \| photo_grid` | GCS-B **须扩**独立 engine/platform（已知、有界） |
| self-heal / legacy 硬过滤 | **存在绕过**（BLK-10） | 必须先修；属还债、难度中低 |
| SignatureIndex / `bric_compose` / eligibility DSL | **不存在** | 净新增；合同已钉，难度中 |
| 盲评 harness / 代表 trip | BQP/URO 可复用方向明确 | 组织成本 > 编码成本 |
| LSE / Hungarian | 冻结 / 默认 off | **降低**范围风险 |

**就绪度总判**：骨架 **70%+ 可复用**；净新工作集中在「硬筛接线、三 soft、签名索引、BRIC Writer、轨道工厂」五块，均有明确 API 合同。

## 4. 砍 scope 的成本包（决策用）

| 包 | 包含 | 开发人日 | 日历 | 用户可感知 | 建议 |
|----|------|----------|------|------------|------|
| **A · 还债+可见诊断** | P0 + MSR shadow | 5–8 | 1.5–2 周 | 低（内部看板） | **必做** |
| **B · 杂志硬层 MVP** | A + MGQ eligibility + MSR 硬筛 | **18–28** | **4–6 周** | 中高（少错页） | **推荐第一交付** |
| **C · 几何决胜** | B + MGQ soft | 22–34 | 5–7.5 周 | 高（主图更稳） | 紧随 B |
| **D · 旁路海报** | GCS-B（可与 B/C 并行） | +5–8 | +0～1.5 周（并行时） | 高（新交付） | **高 ROI 并行包** |
| **E · 扩库工厂** | GCS-A | +6–10 + 设计 | +2–2.5 周 | 中（中期 miss↓） | 宜在 MSR shadow 有空洞清单后 |
| **F · 标定闭环** | MGQ 评分台 + 盲评默认开 | +6–10 + 盲评 | +2–3 周 | 间接 | 默认开前置 |
| **G · 全栈** | A–F + MSR W2 可选 | 45–70 开发 | 10–14 周 | 完整 LQS | 完整纲领 |

**不建议砍**：P0 守门（否则后续全假绿）。  
**可延后**：page_group、caption replan、评分台线框、GCS-A hero 类、海报默认露出。

## 5. 可行性风险与成本上浮因子

| 风险 | 概率 | 成本上浮 | 缓解 |
|------|------|----------|------|
| MSR 硬筛后 legacy 飙升，反复回调 | 中 | +3–8 人日 | L3 保留；reject 看板；分开关 dogfood |
| `try_order` 双轨收敛慢于预期 | 中高 | +4–10 人日 | W2 迁移清单；新模板禁只加 Python |
| 硬层叠乘候选枯竭 | 中 | +2–5 人日 | 顺序写死；eligibility 不进 UNDO |
| GCS-A 轨道枚举比预想难 | 中 | +5–10 人日 | 先小 N；不合格丢弃；KPI=miss↓ |
| Recipe/导出门面接线拖尾 | 低中 | +1–3 人日 | 独立 engine 合同已冻 |
| 盲评排期拉长 | 中高 | 日历 +1–3 周 | 与编码解耦；flag 保持 off |
| 模板 role/mix 不适合派生签名 | 中 | +2–4 人日（修 YAML） | W0 shadow 尽早暴露 |

**上浮后全栈开发上界**：约 **55–80 人日**（仍可接受；非数量级失控）。

## 6. 分席可行性表决（模拟）

| 席位 | 可行性 | 成本观 | 一句话 |
|------|--------|--------|--------|
| **架构** | 高 | 可控 | 挂点清楚；成本在接线与纪律，不在新平台 |
| **开发** | 中高 | 45–70d 合理 | W2（MSR/GCS-A）偏紧；需防并行硬行为 |
| **算法** | 高 | soft/阈值已冻降试错 | 最大不确定是库覆盖与 bag 占比，非公式 |
| **测试** | 中高 | QA 16–27d 勿砍 | AC 可测；盲评是真实日历瓶颈 |
| **产品** | 高 | 先买包 B+D | MVP 即可讲故事；全栈可分期 |
| **设计 · SKU** | 中 | 工厂后仍要人工 sign-off | 空洞清单降低无效设计 |

**汇总**：**可落地**；推荐 **包 B（杂志硬层 MVP）+ 并行包 D（海报）** 作为第一投资单元，再进 C/E/F。

## 7. 与收益的匹配（是否值得这个成本）

对照 [影响评估](./layout-quality-stack-v1-impact-review-2026-07-18.md) §5：

| 投资 | 主要买到的收益层 | 性价比 |
|------|------------------|--------|
| P0 守门（3–5d） | 高置信·还债 | **极高** |
| 包 B 硬层 MVP（18–28d） | 中高置信·少错页 + 可解释 | **高** |
| GCS-B（5–8d） | 中置信·新交付 | **高**（旁路、风险隔离） |
| MGQ soft（+4–6d） | 中高置信·同窗更稳 | **中高**（依赖 B 已上） |
| GCS-A（+6–10d） | 中期天花板 | **中**（必须有空洞清单） |
| 评分台+盲评默认开 | 可迭代 / 发布资格 | **必要但偏组织成本** |

**不划算的投入**（相对本栈）：解冻 LSE、Hungarian 当主故事、BRIC 挂 legacy、三主题同周齐开硬筛。

## 8. 推荐排期（1 开发基线）

```text
周 1        LQS-P0 守门 + 开关 + 拆文
周 2        MSR shadow → 空洞清单 v0
周 3–4      MGQ eligibility + UR-01 消费
周 5–6      MSR 硬筛 + caption prefer
周 7        MGQ soft
周 5–7*     GCS-B 并行（若有插空/第二人力）
周 8–9      GCS-A（按空洞补 ≥3 experimental）
周 10–12    评分台 / 迁移清单 / 盲评与默认开决策
```

\* 无第二人力时：GCS-B 插在周 7 后、GCS-A 前（+1～1.5 周）。

**第一里程碑出口（约第 6 周）**：狗粮可开 MSR+eligibility；海报可 flag 狗粮；杂志 golden/LRG 绿；**尚未**默认开任何主题。
