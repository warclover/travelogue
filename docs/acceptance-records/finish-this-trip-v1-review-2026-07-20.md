## 1. 高度共识（建议直接采纳）

1. **战略收束正确**：不卖旅行 OS，卖「选相册 → 出游记 → 分享」；与 CHARTER §7.2 同向。  
2. **竞品不是 Notion**：行前/私人书架 Out of Scope；主战场是第三次快乐的成册与微信向分享。  
3. **波次大序正确**：漏斗（W0）→ 可信（W1/LTN A·B）→ 画册感（W2/LTN C·D）→ 第二趟与话术；HGM / 扩库后置。  
4. **纲领不重写相邻 PRD**：FTT 管目标、闸门、编排；字段合同归 FTUE / FST / Share / LTN。  
5. **成功面不教微信**：与 FST 同向；Dock「发微信群」= 交付终点语义，≠ 教程。  
6. **反产量 KPI**：禁止强制 mosaic / 张数 KPI；小集是正常输入，不是低配惩罚。  
7. **否决清单有效**：Planner、人生书架、排版工作台、强制 API 等默认 NO。  
8. **「愿意再做」不能替代行为回流**：访谈是佐证，14 日再次导入/新建 trip 才是回流。

## 4. 建设性增补（建议写入 v0.2 PRD）

### 4.1 完成状态分层（替代扁平 D-FTT-02）— BLK-FTT-01

```text
DraftReady          成稿可预览
→ ExportSucceeded   长图/交付物真实落盘且可打开
→ DeliveryLocated   用户已定位文件（打开位置）
→ ShareHandoff      非侵入确认：已发出 / 稍后分享 / 仅保存（可选）
```

| 宣布用语 | 最低证据 |
|----------|----------|
| 可生成 | DraftReady |
| 可导出 / 技术交付完成 | ExportSucceeded |
| 交付物可定位 | DeliveryLocated |
| **首趟完工（FTT 默认）** | **ExportSucceeded ∧ DeliveryLocated**（打开旧文件不算新导出等权） |
| 愿分享 / 分享交接 | ShareHandoff 有应答 |
| 防搁置 / 会再来 | 14 日内再次 InputSelected / 新建 trip（非口头意愿） |

> 原则不变：**不教微信**。ShareHandoff 是一键态度，不是发群教程。

### 4.2 事件字典与责任表 — BLK-FTT-02

须定义（名可调整，语义不可缺）：导入开始、生成成功/失败、导出成功、交付物打开、再做一趟曝光/点击、第二次导入；含分母、去重、失败码、归属 PRD。

### 4.3 流程状态机与搁置点强制节点 — BLK-FTT-03

W0 搁置点清单**强制覆盖**：首页意图 → 输入选择 → 导入校验 → 生成/中断恢复 → 双预览可发现 → 导出真实性 → 成功面可找回 → 第二趟冷启动。  
每节点：主 CTA、出口条件、失败模式、挂票归属。

### 4.4 UI 线框 F1–F8 — BLK-FTT-04

建议 `wireframes/finish-this-trip-v1-wireframe.html`：

| ID | 内容 | 挡门 |
|----|------|------|
| F1 | 空态首屏截取路径 | W0 |
| F2 | Import Sheet + 小集正向文案 | W3 前 |
| F3 | 成功面 FTT 挡门态（复用 FST） | W0 |
| F4 | 有作品·再做一趟一等入口 | W3 前 |
| F5 | 0→1 作品回首页时机 | W3 前 |
| F6 | 话术触点对照板 | W3 前 |
| F7 | 三模式双预览可发现性（挂 LTN） | W1 狗粮 |
| F8 | 搁置点审计页 | W0 |

**成功面所有权**：FST 唯一拥有字段合同；FTT 只做抽检挡门 + 回书架后第二趟。

### 4.5 第二趟「低承诺再开始」— BLK-FTT-05

- 最小入口 + 回流埋点可在 **W1 后并行**，不必等 W2 画册感。  
- 再做一趟 = 新建独立 trip 输入选择；不覆盖首趟；不进配置墙。  
- 与「继续精修」分流，避免旧作品召唤未完完美化。

### 4.6 轻控制合同 — BLK-FTT-06 / OQ-06

默认零步成稿；导出前允许：精选集顺序尊重、标题/日期校正、封面或首图确认、单张排除。  
**禁止**演化为多模板/逐步排版工作台（否决清单维持）。

### 4.7 狗粮脚本增补 — FLOW + UXR

在 §10.2 上增加：输入决策、等待观察、中断恢复、可控失败、导出文件真实性、成功面关闭后找回、示例→真实切换、隔时（≥24h）第二趟、状态分层记录、放弃节点归因；跨画像配额（截取 / 搁置 / 成册 × 小集 30–80 × 大库 150+）。

### 4.8 用户语言验收题（UXR）

1. 「从这里到发给朋友，还差几步？」→ 通过：0–1 步且说得出交付物。  
2. 「敢直接发微信群吗？为什么？」→ 归类不敢原因。  
3. 「这是照片堆，还是一趟游记？」  
4. 「下次旅行结束会不会再用？第一步做什么？」  
5. 「哪些你决定、哪些工具替你决定？」
