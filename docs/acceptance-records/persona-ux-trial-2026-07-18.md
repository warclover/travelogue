## 2. 一句话结论

> **排版与「按张数给分享方式」是本轮最强获得感；无 Key / stub 文案与文件夹名上封面，是最伤「敢不敢发」的吐槽。导入若触发视觉模型下载且进度为空，会被当成坏了。**

## 5. 分席试用纪要

### U1 · 极简分享者
- **路径**：导入「试用·周末短途」→ 预览 → CTA「导出长图 · 发微信群」可见。
- **喜欢**：终点文案清楚；卷轴可验货。
- **吐槽**：6 张仍要确认章节顺序（C6）；担心导入「没动静」（C3）。

### U2 · 近郊周末党
- **路径**：武大册（~23 精选）→「选择分享」。
- **喜欢**：意图卡三选项语义清楚（L3）。
- **吐槽**：题名「武大--米娜」难看（C2）；文案「白天，傍晚」不敢发（C1）。

### U3 · 空态首访
- **路径**：首页 hero →「开始制作」→「用示例照片试一次」。
- **喜欢**：双预览 + 示例入口（L4/L5）。
- **吐槽**：示例成片图注毁第一印象（C1）；若视觉分析开启则首跑极慢（C3）。

### U4 · 回访
- **路径**：书架见试用册与「示例 · 长图可更新」。
- **喜欢**：书架可继续；取消再导无空壳（L8/L9）。
- **吐槽**：「长图可更新」需二次解释（C4）。

### U5 · 轻度编辑
- **路径**：大册点「精修」→ 封面 Tab。
- **喜欢**：换封面、版式、恢复自动（L6）；行内可点改杂志名。
- **吐槽**：「媒资」词（C7）；章引「夜景，白天」要改到烦（C1）。

### U6 · 摄影进阶
- **路径**：129 张东澳岛册 →「按章导出长图」。
- **喜欢**：按章默认（L2）；版式杂志感（L1）。
- **吐槽**：封面文件夹名 + 说明书腔（C1/C2）。

### U7 · 家庭组织者
- **路径**：对照封面题名与书架展示名。
- **喜欢**：可手改杂志名。
- **吐槽**：默认把文件夹名推上封面仍会丢人（C2）。

### U8 · 职场晒旅
- **路径**：发群前审视分享面。
- **喜欢**：成片形态像杂志。
- **吐槽**：重复题名当图注 = 出糗风险（C1）；不要教微信操作（与 FST 一致，本轮成功面未强制教学）。

## 7. 建议下一波（产品优先级）

1. **P0** 无 Key 时：空着或极短中性句，禁止「竖幅 / 抬头看见 / 夜景，白天」类 stub 上分享面（C1）。
2. **P0** 封面/书架展示名：强化文件夹名 humanize（去 `--`、去序号尾巴）（C2）。
3. **P0** 导入忙碌态：任何 `running` 必须有可读阶段主句；视觉模型下载单独说明（C3）。
4. **P1** 「长图可更新」改人话或首次解释一次（C4）。
5. **P2** Sparse（1–9）默认跳过 G1 确认或降级为可忽略提示（C6）。
