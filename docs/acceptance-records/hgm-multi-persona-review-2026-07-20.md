## 1. 高度共识（建议直接采纳）

1. **方向对**：仅高光轻布展、非高光保持游记语法；优于全书装裱分级。  
2. **同纸面**：禁止默认黑匣/暗场、大相框、卡片阴影、缩轨换模板。  
3. **稀缺**：签名 ≤1；厅内高光严格配额；禁止连续高光。  
4. **选型门槛**：高光能力未完善前，不上完整轻布展（或仅签名 + 极弱气口）。  
5. **厅内高光必须来自 P23 池**（OQ-01）。  
6. **厅内默认无口号题签**（OQ-04）；签名可保留「决定性瞬间」。  
7. **凝视模式 V1 不做**（OQ-06）。  
8. **微信长图气口可略增、仍同纸面**（OQ-07）。  
9. **Studio 必须可解释 + 可换代表作**，否则布展像系统强加。

---

## 2. 主要担忧（跨角色重复出现）

| 担忧 | 谁强调 | 含义 |
|------|--------|------|
| 选错图还郑重布展 | 全员 | 比不做更伤；稀缺放大错误 |
| EXIF / 「决定性瞬间」矫情 | 家庭用户、部分摄影用户 | 家人看不懂；像广告或摄影课 |
| 黑底 EXIF 与同纸面冲突 | UI/UX、产品 | 现有实现可能已是「第二材质」 |
| 气口过弱白做 / 过强像 PPT | UX、UI/UX、家庭 | 需小样定 JND，忌拍脑袋 |
| 阅读态 vs 长图不一致 | 摄影用户 | 导出前要对齐观感 |

## 3. OQ-HGM 倾向汇总

| ID | 共识倾向 | 备注 |
|----|----------|------|
| **01** 必须来自池 | **必须** | 全员一致 |
| **02** 签名暗场 | **V1 默认否** | 可作实验开关 |
| **03** 气口数值 | **小样定标** | UI 基线提案：B≈L1×1.3，A≈L1×1.8；家庭侧宁小勿大 |
| **04** 厅内题签 | **默认无** | 家庭侧偏好「时间+地点」人话，非摄影口号 |
| **05** 选型弱先上样式 | **否 / 仅 A 极弱** | 产品：呈现强度 ∝ 选型置信度 |
| **06** 凝视模式 | **V1 不做** | 一致 |
| **07** 长图气口 | **略增 ×1.15–1.25** | 一致 |

## 4. 建设性增补（建议写入下一版 PRD）

| 来源 | 增补 |
|------|------|
| UX 研究 | 原则扩展为：选得对 → 放得对 → 看得重 → **认得出** → **信得过** |
| UX / 产品 | 配额双层：章上限 + 全书密度；小册全书展室态 ≤1；配额是上限不是 KPI |
| 产品 | 与 P23 气口预算冲突需显式 override；位置规则归编排层 |
| 产品 | MVP：Slice0 breath 修复 → Slice1 签名 A only → Slice2 厅内 B |
| UI/UX | 变量优先级：独屏 → 缓冲 → 气口 → EXIF(纸色) → 题签 |
| UI/UX | 三组小样矩阵：气口强度 / EXIF 家族 / A-B 档差 |
| 家庭用户 | 签名文案可用人话：「这次旅行最想留住的一张」+ Day·地点；EXIF 可进详情 |
| 摄影用户 | 导出前「阅读 / 微信长图」双预览，高光段并排确认 |

## 5. 建议的成功指标（收敛）

| 类型 | 指标 |
|------|------|
| **主指标** | 无角标盲指「被单独郑重对待」命中 moment/peak ≥ 70% |
| **守门** | 「仍像同一本游记」≥ 现版；「突兀」< 20% |
| **诊断** | 归因卡：「App 告诉我的」不宜过高；错误高光版不信任应显著升高 |

---

## 6. 建议下一轮讨论顺序

1. 是否认可 §1 共识写入 PRD 为「已倾向拍板」  
2. 签名文案：保留「决定性瞬间」还是增加/替换为人话选项  
3. EXIF：读者面默认纸色脚注 vs 折叠到详情（家庭向）  
4. MVP 是否同意「先签名 A，厅内 B gated」  
5. 是否立刻做静默小样（矩阵 1+2），仍不动生产默认  

---

## 7. 产品复核增补（选型 Gate）

第二位产品评审与首轮产品结论一致，并建议把下列 **Gate** 写进 PRD（未过则不加气口/缓冲，仅保留 P23 现状）：

满足其一才开完整轻布展：

1. Studio `momentExplain` 可对 top-3 给出可读理由；或  
2. 内测盲评「像旅途最好纪念之一」≥ 60%；或  
3. 用户已手动确认/换过签名 moment。

另建议：V1 以 **A 档为主**；B 档全书布展数可用绝对上限（如 ≤3）约束，百分比仅作监控。MVP 增量优先 **气口 + 缓冲**，独屏/EXIF/角标尽量复用 P23。
