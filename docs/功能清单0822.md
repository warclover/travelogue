# Travelogue 功能清单

**日期**：2026-08-22  
**依据**：仓库实际代码（CLI、`travelogue/`、`templates/studio/`、`templates/visual-journal/`、导出 writer）。不是 PRD 设想，也不是对外口径。  
**对外说明**：见 [项目说明手册.md](./项目说明手册.md)。本清单写「代码里有什么、默认开不开、从哪进、能干什么」。

**标记**

| 标记 | 含义 |
|------|------|
| **核心** | 默认路径「选相册 → 出游记 → 分享」缺了就不成立；或种子用户在 Windows 上完不成「本机成册、敢发长图」 |
| **默认开** | 种子 / 开发基线即可用，不必改配置 |
| **需开关** | 代码在，须 `config.yaml`、环境变量或用户操作才进主路径 |
| **CLI** | 命令行有，Studio 首页不一定露出 |
| **实验** | 有路由或模块，默认关或仅内测页 |
| **未实现** | 文档或类型里出现过，ingest / UI 没有这条路 |

**怎么判核心**：只看旅行者主路径，不看作品集、AI、多平台再分发、工程台、CLI 排障。多平台导出是亮点「做完再分发」，但不是第一次做完的必要条件，故不标核心。

### 核心功能一览

默认三步能走完，靠下面这些。表中对应行的标记带 **核心**。

| 步骤 | 核心能力 |
|------|----------|
| 打开 | Studio 工作台、本机浏览器、Windows 绿色包 |
| 选相册 | 选本地文件夹、系统选夹、常见成片 + HEIC、拦 RAW、复制源片、去重、`recommended` 挑片 |
| 出游记 | 规则 cull、时间地点分章、章标题、场景聚类、分镜收束、游记 Mosaic、自动封面 + 开场装帧、本地板书标题、stub 配文（导入不烧模型） |
| 先验货 | 大屏卷轴、异步作业、书架、精修、内联改字、纯照片/带文字 |
| 分享 | 长图阅读面、微信群竖版长图、客户端长图回退、在文件夹中显示 |
| 底线 | 无账号、默认 private、loopback、导出剥 EXIF |

## 1. 产品形态与入口

整套产品装在用户自己的电脑上。主入口是本机工作台，不是网站上传。

| 功能 | 作用 | 怎么进 | 标记 |
|------|------|--------|------|
| Studio 工作台 | 在本机起一个 HTTP 服务，用浏览器完成选相册、成册、预览、精修和导出。这是普通用户的主界面，不是命令行。 | `python -m travelogue studio`；exe 无参即 studio | 默认开 · **核心** |
| 浏览器打开本机页 | 启动后默认只听 `127.0.0.1`，并自动打开浏览器，避免用户去找端口。可用 `--no-open` 只起服务。 | `cmd_studio` | 默认开 · **核心** |
| 单实例 | 已经开着一份 Studio 时，再双击不会起第二个服务，而是打开已有地址，避免抢端口、两套数据。 | `desktop/single_instance.py` | 默认开 |
| 选文件夹再成册 | 启动时就能指定相册，或弹出 Windows 选夹对话框，省掉先开空工作台再点导入。 | `--pick-folder` / `--pick-folder-dialog` | 默认开（Win） |
| 内置示例相册 | 不带自己的照片也能走完一遍成册，用来验安装、看默认效果。 | `--demo-album` | 默认开 |
| 单 trip 预览服务 | 只预览已经做好的一本，带内联改字 API，适合开发对照 HTML，不是完整工坊。 | `travelogue serve` | CLI |
| LAN 绑定 | 允许局域网其它设备访问本机 Studio。必须带 token，且导入路径更严，防止把整盘相册暴露出去。 | `--allow-lan` | 需开关 |
| 开发双击脚本 | 给开发者一个 bat，设好本机相册信任旗后直接起 Studio，少敲命令。 | `scripts/start-studio.bat` | CLI |
| Windows 绿色包 | 用 PyInstaller 打成目录或 zip，用户不必先装 Python。便携模式把数据写在 exe 旁边。 | `packaging/` | 需打包 · **核心** |
| MSI / 商店安装器 | 代码里没有传统安装向导或商店上架流程。 | — | **未实现** |

## 2. 导入与媒体

把一趟旅行的底片变成 trip 工作区：扫描、拷贝、做衍生图、写 `trip.json`。

### 2.1 选源

| 功能 | 作用 | 标记 |
|------|------|------|
| 选本地相册文件夹 | 一次只做一趟。用户指一个目录，系统自己扫图，不用在网页里一张张上传。 | 默认开 · **核心** |
| Win32 原生选夹 | 在 Windows 上弹出系统文件夹对话框，比在浏览器里填路径更不容易选错盘。仅 loopback 开放，避免远程触发读盘。 | 默认开（Win） · **核心** |
| 导入前预览 | 导入前先看几张缩略图、大概张数和拍摄日期跨度，确认「就是这一趟」再开跑。 | 默认开 |
| 浏览器 multipart 上传 | 没有本机选夹时，也可以从网页把文件 POST 到 `uploads/`，再按普通相册 ingest。适合受限环境，不是主路径。 | 默认开 |
| 双源文件夹 | 允许「精选」和「素材」分开放。精选更容易上封面、少被 cull；素材用来填版。也能靠文件夹名字自动认。 | 默认开 |
| 路径白名单 | 默认只信 uploads、demo 和 trips 根下的路径。其它本地目录要信任旗，防止任意读盘。开发启动脚本会打开本机相册信任。 | 默认开 |
| LAN 导入 | 局域网模式下只收 uploads 和 demo，拒绝任意本机路径，降低「别人在同一 Wi-Fi 读你相册」的风险。 | 需 `--allow-lan` |

### 2.2 格式与闸口

| 功能 | 作用 | 标记 |
|------|------|------|
| JPG / JPEG / PNG / WebP / GIF / BMP | 主线只吃常见成片。这些后缀会被扫进 trip，再转成多档 WebP 供预览和导出。 | 默认开 · **核心** |
| HEIC / HEIF | 手机原图常见格式。装了 `pillow-heif` 就能读；没装会明确报错，而不是 silently 跳过。 | 默认开（有依赖） · **核心** |
| 拦 RAW | 相机原片体积大、预览链不稳，默认直接拒收。用户须先在相机软件里导出成片，避免半成品进册。 | 默认开（拦） · **核心** |
| 视频 mp4/mov | 下游个别模块认得 `type=video`，但扫文件夹时不会把视频当导入源。手册里的「可带少量视频」目前没有这条 ingest 路。 | **未实现文件夹导入** |
| 复制源片到 trip | 把原图拷进 `trip/source/`，之后预览不依赖用户乱移相册。关掉则更省盘，但源一挪册就缺图。 | 默认开 · **核心** |
| 最小张数 | 少于约 4 张不成册，避免空册或单张硬撑杂志结构。 | 默认开 |
| 上限约 250 张 | 防止一次吞进整库把内存和排版拖垮。舒服区间仍是大约 20～150 张。 | 默认开 |
| 内容去重 | 同一文件拷两份、连拍几乎一样的，用哈希和近似哈希收掉，减少「同一张连贴」。 | 默认开 · **核心** |
| 增量追加 | 已经做过的 trip 再补几张，不必整夹重来。 | CLI |
| 断点续跑 | 导入中途退出后，按检查点跳过已处理文件，从断点接着跑。 | 默认开 |
| 并行 embedding | 算视觉向量时开多进程，大相册更快。可关，便于排错。 | 需配置 |
| 从 source 重出 WebP | 衍生图坏了或尺寸策略变了，从 source 再导一版预览图，不用重新选夹。 | CLI |

### 2.3 保留策略（挑片）

决定「哪些照片有资格进册」，不是修图。

| 档位 | 作用 | 标记 |
|------|------|------|
| `recommended` | 默认策展：去掉明显废片和近重复，让成册更像杂志而不是相册倒出。 | **默认** · **核心** |
| `keep_bursts` | 仍做质量闸口，但连拍近重复留下。适合「同一动作要一组」的用法。 | 用户选 |
| `keep_all` | 几乎全收，包括低分图。只有用户显式选这一档才跳过低分硬丢，避免旧开关误开。 | 用户显式选 |
| 旧字段兼容 | 仍读 `photoCullEnabled` / `keepNearDuplicates`，但**不会**据此推断 keep_all，防止老客户端悄悄改成全留。 | 兼容 |

导入节奏还可以选 `quick_share`（快、敢发）或 `fine_craft`（可带布局密度，更磨一版）。

## 3. 策展：分章、选片、成册

主流程在 `curation/curate.py`：预检 → 分桶 → 建章 → 排版 compose → 收尾写回 `trip.json`。作用是把「一堆按时间排的文件」变成「可以翻的一本」。

### 3.1 筛选与聚类

| 功能 | 作用 | 标记 |
|------|------|------|
| 规则 cull | 用规则丢掉截图、缩略图、过糊、曝光极端和超额重复，把版面留给能看的成片。精选标记可以少被砍。 | 默认开 · **核心** |
| 精选豁免 | 用户标过 featured 的照片，cull 时更手下留情，避免把封面候选误删。 | 默认开 |
| 低分辨率硬丢 | 像素太低、放大必糊的图默认不进册。选「全部保留」时这条会放开。 | 默认开 |
| 审美 ML | 用 TopIQ 一类模型打「好不好看」。默认关，避免 CPU 重、结果难解释。 | 实验 |
| 地理 + 时间事件 | GPS 够密时，按位移和时间间隔合成「这一站」，比纯按小时切更像真实行程。GPS 不够就自动退回时间。 | 默认 `auto` |
| 场景聚类 | 用视觉向量把「同一处风景、同一桌饭」收成簇，后面分镜和拼版才知道哪些该待在一起。 | 默认 `run_aware` · **核心** |
| 反向地理编码 | 把经纬度变成可读地名，章标题可以写「科伦坡」而不是坐标。默认关，因为要出网。 | 需开关 |
| 分镜收束 | 同一动作连拍合成一组镜头，避免同一挥手拆成三屏。 | 默认开 · **核心** |
| 待处理资产 | 聚类缓存坏了或新图还没进簇时，用 CLI 补跑或清缓存，属于排障工具。 | CLI |

### 3.2 分章

| 功能 | 作用 | 标记 |
|------|------|------|
| 按时间地点切章 | 把一天或一站收成一章，读者按「傍晚 / 那家店 / 回程」翻，而不是 200 张平铺。 | 默认开 · **核心** |
| 章标题 | 用时间跨度和地点自动起名，先有可念的目录，再谈人改。 | 默认开 · **核心** |
| 章平衡 | 避免一章塞 80 张、下一章只剩 3 张，阅读节奏更匀。 | 默认开 |
| 叙事弧 | 用高峰、收束等弧线影响哪一章更「重」、beam 怎么排。要改配置才偏离默认。 | 需配置 |
| 算法档刷新 | 规则版本变了或结果过期时重跑 cull/聚类，避免旧决策钉死新算法。 | CLI / 自动 |

### 3.3 精选与高光

| 功能 | 作用 | 标记 |
|------|------|------|
| 用户标精选 | 告诉系统「这张更重要」：更易上封面、少被 cull，放映也可以只放精选。 | 默认开 |
| 升格 / 降级 / 恢复 | 在预览里把一张提进精选、踢出，或把被算法丢掉的 outlier 捞回来，不必重导入。 | 默认开 |
| Moment 策展 | 单独维护「值得停一下」的高光集合，给放映或封面池用。默认不是人人打开的入口。 | 需开关/行程 |
| 审美层偏好 | 记住用户更吃哪一档气质（例如更风光 / 更人物），下次选片往这边靠。 | 需开关 |
| CLI `tier` 组 | 命令行里挂了组名，但没有子命令。升格请走预览页 HTTP。 | **空实现** |

## 4. 双管线（游记 / 作品集）

同一套照片可以走两种「怎么做成一本」。两条管线独立迭代，禁止在非注册缝上写 `if is_portfolio`。

**游记**默认就有：快、按旅程分章、杂志屏（`screen-*`）、竖版长图按成屏几何拍。适合「这一趟做完、敢发群」。**核心。**

**作品集**是第二套：按官方杂志系列填 `page-*` 槽，页序更死、更像画册。父开关默认关，现网等于只有游记。失败会硬报，不会悄悄退回游记。

| 功能 | 作用 |
|------|------|
| 身份字段 | 缺省就是游记，不写 `edition`。作品集才持久化 `studio.edition=portfolio`，避免老 trip 被误标。 |
| 父开关 | 作品集整条链路（导入切身份、CLI `--edition`、Studio 切换）都看 `portfolio_pipeline.enabled`。关着时提示「此功能已关闭」。 |
| 成册引擎 | 游记 `compose_trip` 选 mosaic 屏；作品集 `compose_portfolio_trip` 选系列再填槽。两套规划器互不 import。 |
| 渲染 CSS | 游记吃 `journal-screens.css`，作品集吃 `portfolio-pages.css`，避免一套样式改坏另一套。 |
| 微信群导出 | 游记拍长图 HTML，保留杂志几何。作品集把 kept 照片竖拼（大约最多 24 张），不假装一页一页的长图。 |
| 页图导出 | 作品集可逐页渲成图再打 zip，给要「一页一张」的人。不进游记的多平台平铺勾选。 |
| Studio / CLI 切换 | 开着父开关时，可在工作台或 `curate --edition` 切换；作品集还能钉 4–48 页或交给 auto 靠档。 |
| 官方系列 | 8/12/16/20/28 页标准杂志，P0 常用 16 页。页数意图会靠到 catalog 真实容量；照片太少走稀疏组，够了再填充。 |

## 5. 布局与模板

### 5.1 游记屏（约 47 个 `screen-*.yaml`）

每一「屏」是卷轴里的一页杂志面：单图、双图、竖三列、五图拼版等。规划器按朝向和叙事角色挑选，再在章内用 beam 排顺序。

- **横图族**：一到多张横图铺满或分栏，适合风景和场面。
- **竖图族**：人像、招牌等竖构图，避免被裁成宽条。
- **混排**：一张竖压两张横等，用来讲「人 + 环境」。
- **Mosaic**：更密的拼版（约 18 个），一张屏里放下 4～6 张，仍保持主次。

| 功能 | 作用 | 标记 |
|------|------|------|
| Mosaic 规划 | 先为每个时间窗选合适模板，再在章内搜索更好的屏序，减少「三张横图连撞」或主次不清。 | **默认开** · **核心** |
| Layout beam 打分 | 给候选屏序打分（节奏、朝向、重复）。默认权重多为 0，等于还没把打分当主裁判。 | 需开关 |
| 单屏 replan | 只重排当前这一屏，不动整本结构。精修时改一张脏版最常用。 | 默认开 |
| 布局气质 | 用一句话换「更贴比例 / 更杂志」，不必暴露几十个内部开关。 | 默认开 |
| 拼贴 mediaClass 覆盖 | 人工指定某张是主图还是辅图，纠正算法看错角色。 | 需操作 |
| Template contract | 更严的模板合同路径，用来试验「规划必须服从 YAML」。默认仍走 legacy。 | 实验 |

### 5.2 作品集页（约 75 个 `page-*.yaml`）

每一页是画册上的一个固定槽位面（hero、对页、宫格、3 竖 2 横等），有左右、加宽、翻转变体。只给作品集 slot 匹配用，游记规划器不得引用，以免两套管线绑死。

### 5.3 工程模板台

给内部调模板和策略，不是旅行者主路径。

| 功能 | 作用 | 标记 |
|------|------|------|
| 模板管理 UI | 在浏览器里看、审、回滚 YAML 模板，减少改文件靠口头同步。 | 实验 |
| 模板 HTTP API | 注册、删除、审核、运行时元数据，给管理页和脚本用。 | 实验 |
| LSE 策略包 | 布局策略引擎的开关、权重、影子实验。用来试新打分，不直接给终端用户。 | 实验 |
| LTE / LSE CLI | 校验、导出、晋升模板或策略包，走 CI 和本地门禁。 | CLI |

## 6. 封面与装帧

让第一眼像「一本」而不是文件夹第一张。

| 功能 | 作用 | 标记 |
|------|------|------|
| 自动选封面图 | 综合好看程度、横竖是否适合封面框、是否精选，挑一张撑得住开场的图。 | 默认开 · **核心** |
| 开场风格 × 图联合选 | 同时选「这张图」和「这种开场皮肤」（约 10 款：压字、色带、叠页等），避免美图配错版式。 | 默认开 · **核心** |
| Web / 手机双封面 | 电脑封面可以偏宽，手机封面可以另选更适合竖框的一张，两边都好看。 | 默认开 |
| 封底 / bookends | 收束也有装帧（含更安静的 colophon），和封面成对，不像随便再贴一张。质量不够时允许降级，不挡出册。 | 默认开 |
| 换封面 / 封底候选 | 精修里换几张候选或恢复自动选择，不必整本重跑。 | 默认开 |
| 用户换 opening 皮肤 | 只换开场气质，分章和拼版保持不动。 | 默认开 |
| 书法 / 装帧标题 | 把标题做成可贴在封面上的 PNG，而不是系统字硬叠。 | 引擎默认开 |
| 路线 B 本地板书 | 没有云 Key 时，用本机字体和 PIL 画出可用标题，保证默认路径也能出「像一本」。 | 默认回退 · **核心** |
| 路线 C 万相手写 | 用通义万相生成更手写的标题，再用 OCR 核对是否写对。必须用户点「生成」，导入不会偷偷烧图。 | 需 Key + 手动 |
| CLI 生成标题艺术 | 开发或批处理时不打开 Studio 也能出标题图。 | CLI |

## 7. 文案

默认先有「能发」的句子，不把大模型当成完工前提。

| 功能 | 作用 | 标记 |
|------|------|------|
| 规则 stub 配文 | 用时间和地点拼出钩子、章导语、尾声、图注。不出网、不改像素，保证导入完就能翻。 | **默认** · **核心** |
| 导入不烧模型 | Studio 导入固定走 stub。有 Key 也不会在第一次成册时自动扣额度。 | 默认开 · **核心** |
| LLM 杂志句 | 用 DeepSeek 或百炼写出更像杂志的 JSON 文案，写入 meta、章 lead、图注，并做缓存。 | 需开关 + Key |
| Studio 生成文案 | 精修或 AI 面板里主动请求一次 LLM。Surface 没开或没 ping 通会 403。 | 需 AI Surface + Ready |
| 文案总闸 | 关掉后任何生成 copy 都不跑，只留用户自己写的字。用来做纯图册或排障。 | 默认开（生成允许） |
| 装饰行 LLM | 只给装帧上那一行短句走模型。默认关，避免开场变得很「AI」。 | 需开关 |
| 纯照片 / 带文字 | 一键藏掉钩子、导语、图注，导出也能出「只有照片」的长图。默认带文字。 | 默认 full · **核心** |
| 内联改字 | 在预览里点标题或句子就改，PATCH 回 trip。分享只读链上关掉，避免客人改你的本。 | draft 开 / share 关 · **核心** |
| 图注 | 单张说明可显示、可改、可选择导出带不带；并记下是用户写的、规则写的还是模型写的。 | 默认开 |
| 图注迁移 | 把旧结构里的图注搬到 assets 字段，升级老 trip。 | CLI |
| 叙事姿态条 | 看当前是「纯照片就能发」还是「可以升级杂志句」，再决定要不要打开 AI。 | 按 trip 状态 |

## 8. 阅读面

同一本 trip 渲出多种 HTML，屏序尽量同一套，换的是「怎么看」。

| 面 | 作用 | 标记 |
|----|------|------|
| 大屏卷轴 `index.html` | 给自己在电脑上翻的主交付：16:9 杂志风，带吸附滚动、呼吸动效和轻度装帧。 | 默认 draft 用 hybrid · **核心** |

| Share 只读链 | 带 `?share=1` 时去掉编辑条，只留保存长图，把预览当成只读成品。 | 链接触发 |
| 预览图 `preview.jpg` | 给书架或分享卡片一张封面缩略，不必打开整本 HTML。 | CLI |

打成分享 zip 时用少动效的 `performance` profile，别人打开更稳、更省电。

## 11. AI / 模型（代码接线）

AI 是可选项。默认路径是本机规则 + 本地标题，不依赖云。

| 能力 | 作用 | 标记 |
|------|------|------|
| AI Surface 总闸 | 总开关。关掉时，所有要烧模型的接口直接 403，设置页仍可先填 Key。环境变量可强制打开。 | **默认关** |
| Studio LLM 设置 | 只持久化百炼（DashScope）Key，写在本机 `secrets.json`。没有 Key 时一切按 stub。 | 默认无 Key |
| Ping 才算 Ready | 必须连通测试成功才算「能用模型」，避免填了假 Key 导入到一半才爆。 | 默认开（判定严） |
| DeepSeek | 命令行还能指定 DeepSeek 写文案或 ping。Studio 界面不保存 DeepSeek，避免两套 Key 打架。 | CLI |
| 百炼文案 | 在精修 / AI 面板里生成杂志句。导入阶段不会自动调用。 | 需 Surface + Ready |
| 万相标题 | 按用户点击生成手写风格封面字。 | 需 Key + 手动 |
| OCR 校验标题 | 生成后检查字是否写对，减少「好看但写错店名」。 | 随路线 C |
| 审美 MLLM 短名单 | 用视觉大模型给高光候选打分。默认关，贵且慢。 | **默认关** |
| Intent / 布局评审 agent | 给内部看「这本想做成啥、这版排得行不行」。不是旅行者必点按钮。 | **默认关** |
| AI Ops 管理页 | 看调用、解锁实验门。安装包默认藏起来。 | 需环境变量 |
| 本地 LLM 服务 | 没有「填 Ollama 地址就能用」的一等入口。所谓本地，指 stub 句子和标题路线 B。 | **未作为一等入口** |

## 12. 隐私、数据与本机

| 功能 | 作用 | 标记 |
|------|------|------|
| 默认 private | 新 trip 一出生就是私有，不会当成要公开的站点内容。 | 默认开 · **核心** |
| 导出剥 EXIF | 打出去的图去掉拍摄设备、GPS 等，降低「把家地址发给群」的风险。 | 默认开 · **核心** |
| CLI 导出确认 | 命令行走 export 必须显式确认隐私，防止脚本误把未审 trip 打成 zip。 | CLI |
| Studio 导出 | 工作台里视为用户已经在本机操作，内部带上确认，不再弹第二道旗标。 | 默认开 |
| 预览只绑 loopback | 单本预览服务拒绝非本机访问，避免同一网络的人打开你的草稿。 | 默认开 · **核心** |
| 用户数据目录 | 安装态数据集中在 `%LOCALAPPDATA%\Travelogue`；便携包则跟着 U 盘走，换电脑不丢。 | 默认开 |
| Key 本机 | 模型密钥只存在本机，并尽量收紧 Windows ACL，不进 trip、不进云。 | 默认开 |
| 无账号 / 无云相册 | 没有注册、没有把相册同步到服务器的 API。导入导出都打本地 trips 目录。 | 默认开 · **核心** |
| Surface 关时投影 | AI 总闸关掉时，配置接口少暴露 trips 路径和模型状态，减少误用面。 | 随 Surface 关 |

## 13. 命令行全表

给开发者和排障用。入口：`python -m travelogue`。

### 13.1 管线

| 命令 | 作用 |
|------|------|
| `ingest --from` | 只做导入：扫描、拷贝、衍生图。可增量、可关去重、可指定精选/素材夹。 |
| `curate` | 只做策展：分章、封面、排版。可指定游记/作品集，或跳过布局只出结构。 |
| `layout` | 结构不动，只重跑排版；需要的话再渲染 HTML。 |
| `lock structure\|copy` | 把结构和文案锁住，避免后续自动步骤覆盖人改的结果。结构锁可带封面。 |
| `narrate` | 单独跑配文。可选 stub 或真模型，可空跑、可强制重写。 |
| `run` | 按阶段连跑（从 ingest 到 export）。出包时必须确认隐私。 |
| `status` | 看这本跑到哪一步；加 `--g1` 看结构是否已确认。 |
| `validate` | 检查 trip.json 是否符合 schema / 清单，发版前自检。 |

### 13.2 渲染与导出

| 命令 | 作用 |
|------|------|
| `render` | 生成各阅读面 HTML。可出 draft 或 share，可选字体、纯图、阅读 profile。 |
| `studio` | 启动完整工作台。 |
| `serve` | 只服务一本的预览；可挂 Studio 壳，可选择是否重渲。 |
| `export` | 打分享 zip，必须确认隐私。 |
| `publish` | 锁定 → 配文 → 打 zip，一条龙发布。 |
| `export-longshot` | 出各平台长图；作品集必须写明 platform，避免默默用错几何。 |
| `export-pdf` | 出超长 PDF。 |
| `preview` | 出书架用的 `preview.jpg`。 |
| `title-art` | 单独生成装帧标题。 |
| `resolve-output-recipe` | 算出推荐出口，调试配方用。 |
| `migrate-captions` | 升级旧 trip 的图注字段。 |
| `longshot-smoke` | 用浏览器跑一遍长图，确认截图链没断。 |

### 13.3 其它组

| 命令 | 作用 |
|------|------|
| `quick` / `from-album` | 选一个夹子，自动 ingest→curate→render，最快看到一本。要发布仍须确认隐私。 |
| `trip new` / `trip list` | 建工作区、列出本机所有 trip。 |
| `demo` / `verify` / `golden` | 跑示例、核对产物、和金样 HTML 对比。 |
| `llm ping` | 测 DeepSeek 或百炼通不通。 |
| `media reexport` | 从 source 重出预览像素。 |
| `cluster *` | 重聚类、清缓存、补 pending，排障用。 |
| `tier` | 组在，命令不在。 |

另外还有模板引擎、策略引擎自己的 `python -m …cli`，只做校验和晋升，不成册。

## 14. Studio HTTP 路由（实现表）

鉴权：本机访问默认免 token；局域网必须带头或 cookie。  
静态页：`GET /` 首页，`/classic` 旧首页，`/__studio/*` 前端资源，`GET /{tripId}/…` 打开某一本并注入工具条。

这些路由的作用，是把上一节里的能力变成浏览器能调用的接口：选夹、开作业、改 trip、出文件。下面按组说明，不逐条重复参数。

**配置与 LLM**  
读改 `config.yaml`、弹系统选夹、看/清/重挂存储、查 LLM 是否 Ready、保存或删除百炼 Key、ping 连通。设置 Key 不必先开 AI Surface，真正写文案才要。

**作业与导入导出**  
问进度、取消、导入、导入前预览、读导出配方、请求 LLM 文案、服务端或客户端出长图、打 zip、在资源管理器里显示、退出进程。

**Trip**  
列出书架、读章结构、深链进某一本、看源是否还在、管 cohort 和意图、改 pipeline/模板、单屏重排、改一章文案意图、覆盖拼贴角色、读写高光与审美、预览 bento、管封面封底与标题艺术、手动触发 curate、换布局气质、切游记/作品集、收回文案埋点、删除一本。

**预览页内**  
`save-copy` 把点进去改的字写回；`promote-tier` 升格降级；`rerender` 只重出 HTML。在非 Studio 的 `serve` 上，这几条只许本机调用。

**实验台**  
模板与 LSE 的影子实验、AI Ops 摘要、解锁门、意图摘要、布局评审与采纳。默认不是旅行者菜单。

**遥测**  
`POST /__travelogue/studio-event` 收下工作台事件。

**capabilities** 告诉前端：能不能选夹、服务端长图在不在、有没有客户端回退、能不能退出 exe、AI Ops 页显不显。

## 15. 桌面打包细节

| 项 | 作用 |
|----|------|
| onedir exe | 一个 `TravelogueStudio.exe` 加 `_internal`，无控制台窗口，双击即工作台。 |
| 便携旗 | 旁边放 `portable.flag` 后，trips 和日志跟着软件走，适合 U 盘。 |

| 不打进包 | torch、Playwright、pytest 等太重或仅开发用；长图靠客户端回退。 |

## 16. 默认开关总表（GA / 种子基线）

这些开关决定「第一次打开像什么」。关着的不是没做，是默认不打扰。

| 开关 | 默认 | 作用一句话 |
|------|------|------------|
| 成册身份 | 游记 | 打开即做能发的旅行册，不先问作品集。 |
| 作品集管线 | **关** | 第二套管线代码在，现网先不露出。 |
| Mosaic | **开** | 游记按杂志屏拼，不是纯九宫格。 |
| Layout beam 打分 | **关** | 先用规划器出册，打分当实验。 |
| Cull | **开** | 默认帮你丢掉明显废片。 |
| photoKeepMode | **recommended** | 平衡「像一本」和「别删太狠」。 |
| 拒 RAW | **开** | 逼成片进册，保证预览链。 |
| 复制源片 | **开** | 册能离开原相册文件夹活着。 |
| 联合选封面 | **开** | 图和开场皮肤一起挑。 |
| 标题艺术引擎 | **开** | 至少能出本地板书标题；手写体要另点。 |
| 导入配文 | **stub** | 先有字，再谈模型。 |
| AI Surface | **关** | 默认不出现烧钱按钮。 |
| 审美 MLLM | **关** | 不在导入时打视觉大模型。 |
| Longshot 2.0 多平台 | **开** | 做完可再出朋友圈、小红书等。 |
| Output Recipe | **关** | 不自动替用户决定出口。 |
| Share zip 带长图脚本 | **开** | 别人打开 zip 也能存长图。 |
| 导出剥 EXIF | **开** | 发出去的图更干净。 |
| 反向地理编码 | **关** | 默认不出网换地名。 |
| Template contract | **关** | 模板实验合同不进主路径。 |

## 17. 手册有、代码没有（或弱于手册）

写清单时对过 [项目说明手册](./项目说明手册.md)，避免把口径当成实现。

| 手册说法 | 代码事实 |
|----------|----------|
| 少量短视频可以带 | **文件夹 ingest 不收视频**。其它模块对 `type=video` 有枝节，但选夹扫不到 mp4/mov。 |
| Windows 安装包 | 只有 onedir / zip，**无 MSI/Inno**。用户仍可双击 exe，只是没有安装向导。 |
| 作品集由你主动选 | 代码齐，**父开关默认关**。打开开关之前，界面上等于没有第二条成册。 |
| 可选杂志文案 | 代码齐，**导入不跑**。要 Surface、Key、用户点一下。 |
| 应用商店 / macOS | **未实现**。种子验证只把 Windows 本机包当主形态。 |
