## 1. 问题定义

当前自动产出在“可用”层面已达标，但“艺术气质”仍受限，主要表现为：

- 章节边界机械，旅程情绪起伏不明显
- 屏幕序列偏平，缺少张弛和留白
- 封面/章首更像“清晰图优先”而非“视觉叙事入口”
- 长段落视觉同质化，读者容易疲劳

---

## 2. 目标与非目标

### 2.1 目标（艺术优先）

| ID | 目标 | 衡量方式 |
|----|------|----------|
| **ART-P6-01** | 章节更有“故事段落感” | `event_boundary_f1` + 人工叙事评分双达标 |
| **ART-P6-02** | 读感更有节奏（密-疏、动-静交替） | `gravity_rhythm_score` 提升 ≥15% |
| **ART-P6-03** | 首屏与章首更有“杂志入口感” | 封面盲评胜率 ≥60% |
| **ART-P6-04** | 长卷阅读疲劳下降 | 连续同模板长度下降 ≥25% |
| **ART-P6-05** | 氛围屏插入更自然 | 呼吸屏“突兀感”负反馈 <10% |

### 2.2 非目标

- 不追求引入重型生成模型来“重绘照片”
- 不新增复杂人工编辑工作流
- 不牺牲 Phase 6 主路径稳定性与性能门禁

---

## 3. 影响最大的算法（优先级）

> 结论：艺术氛围的上限由“叙事分段 + 序列优化”决定，而不是单一视觉模型。

| 排名 | 算法能力 | 影响 | 说明 |
|------|----------|------|------|
| **1** | 叙事分段（Geo×Scene） | 极高 | 决定章节边界与高潮位置，是艺术叙事骨架 |
| **2** | 全局序列优化（节奏打分） | 极高 | 决定先后顺序、张弛关系、阅读流动性 |
| **3** | 封面/章首审美评分 | 高 | 决定第一眼“像杂志”还是“像相册” |
| **4** | 多样性选择（MMR） | 高 | 防止同质化，构建视觉变化 |
| **5** | 呼吸屏插入（节拍器） | 中高 | 形成停顿与转场，强化“卷轴呼吸感” |

---

## 4. 算法专项需求（可落地）

### 4.1 模块 A：叙事分段升级（最高优先）

| ID | 需求 | 验收 |
|----|------|------|
| **ART-A1** | Geo segment 后执行 scene-aware 子分段 | 城市内多景点误合并率下降 ≥20% |
| **ART-A2** | 分段结果输出“章节断点解释” | 预览 explain 可显示“时间/地点/场景”证据 |
| **ART-A3** | 异常输入 fail-open | 无 GPS/弱特征时回退现有稳定路径 |

### 4.2 模块 B：全局节奏优化

| ID | 需求 | 验收 |
|----|------|------|
| **ART-B1** | 引入跨屏重心连续性分 `gravity_balance` | `gravity_rhythm_score` 提升 ≥15% |
| **ART-B2** | 增加连续模板硬约束 | 同模板连续长度显著下降 |
| **ART-B3** | 英雄屏与网格屏交替约束 | 主观“节奏单调”反馈下降 |

### 4.3 模块 C：封面与章首审美

| ID | 需求 | 验收 |
|----|------|------|
| **ART-C1** | 构图规则分（三分法/主体偏移） | 封面盲评胜率 ≥60% |
| **ART-C2** | 色彩丰富度与叙事相关性联合 | 章首“主题不符”投诉下降 |
| **ART-C3** | Explain 输出“为什么选它” | 可解释理由 Top3 可读 |

### 4.4 模块 D：多样性与去同质化

| ID | 需求 | 验收 |
|----|------|------|
| **ART-D1** | longshot 采用 MMR 选屏 | `longshot_visual_variety` 提升 ≥15% |
| **ART-D2** | 色调/构图/版式三维去冗余 | 相似屏重复感下降 |

### 4.5 模块 E：呼吸屏节拍器

| ID | 需求 | 验收 |
|----|------|------|
| **ART-E1** | 呼吸屏间隔由固定改为“叙事弧驱动” | 高潮后停顿更自然 |
| **ART-E2** | 呼吸屏样式与前后文色调一致 | “突兀感”负反馈 <10% |

## 5. 评测体系（艺术专项）

### 5.1 客观指标

| 指标 | 目标 |
|------|------|
| `event_boundary_f1` | 提升 ≥10% |
| `gravity_rhythm_score` | 提升 ≥15% |
| `layout_repeat_streak` | 下降 ≥25% |
| `longshot_visual_variety` | 提升 ≥15% |

### 5.2 主观指标（必做）

| 指标 | 目标 |
|------|------|
| 封面偏好胜率 | ≥60% |
| 章节自然度评分 | ≥4.0/5 |
| 卷轴“艺术感”评分 | ≥4.0/5 |
| 呼吸屏突兀感负反馈 | <10% |

## 7. 风险与控制

| 风险 | 处理策略 |
|------|----------|
| 艺术优化导致性能回退 | 每波次设置性能门禁，超过阈值立即降级 |
| 规则过多导致“刻意感” | 先低权重灰度，保留人工盲评否决权 |
| 主观美学分歧大 | 用“盲评+客观指标”双轨决策 |
| 复杂度上升影响维护 | 模块化开关，默认可回退到 P5/P6 稳态 |
