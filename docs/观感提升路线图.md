## 1. 一句话结论

**差距不在「算法选型」，而在四个更底层的地方：① 对标能力大多默认关闭且未上量（已验证：全开仍几乎无观感提升）；② 架构是分层局部最优、没有全局编排；③ 优化的是代理指标而非感知质量；④ 上游选片和模板库才是天花板。**

换句话说：你以为在比「求解器」，典范们赢在 **选什么照片 + 用什么版式 + 谁来当裁判**。  
LSE 上量路线已在真实 trip 上证伪（见 [P17-LSE-处置建议 §2](./P17-LSE-处置建议.md#2-依据摘要)）；后续力气应从 **求解器调参** 转到 **选片 → 感知裁判 → 模板与硬约束 → 最后才是全局编排**。

## 2. 诊断摘要（为何开 LSE 救不了）

### 2.1 已验证：第一条优先级（开能力 / 上量）无效

| 证据 | 结论 |
|------|------|
| 真实 trip A/B：东澳岛系列 **0%** 屏变；川藏线对齐后 **~1.4%** | 成稿几乎不变 |
| 单能力消融：仅 `hungarian_assignment` 可单独复现 1 屏变化 | 其余 capability 为软乘子 |
| 并排 HTML 预览 | 肉眼无本质差异 |

能力**已接线**（`capabilityFlags` → mosaic/beam），但在 **garbage in + 规则网格 + 无感知裁判** 前提下，微调分数无法突破观感上限。

### 2.2 架构与目标函数（结构性上限）

| 层级 | 现状 | 典范做法 |
|------|------|----------|
| 编排 | 章内贪心 + 桶内 beam + 窗级 mosaic；无跨章联合最优 | 事件级 / 全相册级节奏曲线 |
| 优化目标 | `default.yaml` 手调加权和（aspect、sharpness、temporal…） | 感知美学模型或用户偏好闭环 |
| 编辑意图 | `editorial_hints` **只写 hint、不改 screens** | folio / breath / 留白为**硬规则** |
| 一致性 | tone 在 beam 与 mosaic look-back 两套实现 | 单一强制风格系统 |

### 2.3 与竞品逐行对照

| 来源 | 他们赢在哪 | 你的现状 | 根因 |
|------|------------|----------|------|
| Apple Memories | 选片 + 全局节奏 | highlight 关、beat=flat | 选片弱 + 无弧线 |
| Google Auto Albums | 去重 / 多样性 / 代表性 | P9=质量门+配额 | 选「不差」≠ 选「对」 |
| Shutterfly/Mixbook | 设计师手工页型 | 规则网格 mosaic | 模板库=美学天花板 |
| Canva Magic | 单一强制风格 | tone 关 + 两套实现 | 一致性碎片化 |
| Unfold/Mojo | 强制叙事节拍 | arc 为软乘子 | 弧线可被打散 |
| Flipboard/杂志 | 对开+留白硬规则 | folio/breath 仅 hint | hint≠约束 |
| Adobe 智能裁切 | 显著性+构图 | saliency 关、信号弱 | 能力未进主路径 |
| 学术约束求解 | 全局最小代价 | 匈牙利默认关、无 Cassowary | 局部贪心 |

## 3. 新优先级（替换「先开 LSE」）

| 优先级 | 方向 | 本质问题 | 预期观感杠杆 |
|--------|------|----------|--------------|
| **P0** | 感知评估闭环 | 不知道什么叫「变好」 | 没有它，后面全是盲飞 |
| **P1** | 选片升级 | 进排版的是「不差」而非「该出现」 | **最大** · 对标 Apple/Google |
| **P2** | 模板 + 硬编辑约束 | 规则网格 + hint 装饰 | 对标 Shutterfly / 杂志感 |
| **P3** | 结构级编排 | 高光/节拍进章节结构，非打分加成 | 对标 Memories 弧线 |
| **P4** | Solver / LSE | 槽位怎么填 | **最后** · dogfood 已证边际极薄 |

> **P4 处置**：与 [P17-LSE-处置建议](./P17-LSE-处置建议.md) 一致——冻结权重调参与上量，除非 P0–P3 盲评已系统性胜出且满足 LSE 复评门槛。

## 4. P0 · 感知评估闭环（先建裁判）

### 4.1 现状

- Golden / layout metrics 测代理分（`patternDiversity`、`subjectRunScore` 等）；指标微涨而观感不变 = 典型过拟合信号。
- 封面有 `scripts/phase6_cover_blind_review.py`；**整本 layout 盲评**尚无成体系 harness。
- `docs/acceptance-records/p17-dogfood-blind-review.template.json` 仍为模板级。

### 4.2 目标

任何选片 / 模板 / 排版改动，**不以 golden 指标通过为发布条件**，以 **人工 pairwise 盲评胜率** 为准。

### 4.3 最小可行（MVP）

1. **代表 trip 集**（8 本）：竖图为主、横竖混排、大集 mosaic 多 —— 覆盖东澳岛 / 川藏 / 林芝 / 年会等已有 dogfood 样本。
2. **Layout pairwise 盲评**：复用 `scripts/lse_flags_preview_ablate.py` 并排 HTML；每版成稿 A/B，≥3 人投票「哪本更像成品相册」。
3. **分维度标注**（可选）：故事是否清楚 / 节奏 / 版式美感 —— 避免「整体还行但说不清」。
4. **基线打分板**：对当前 P16 默认路径跑一轮，固化 winrate 基线，供 P1–P3 对照。

### 4.4 验收门槛

- 单次改动相对基线：**盲评胜率 ≥ 60%**（与 P17 复评 §5 一致）。
- **禁止**仅凭 proxy 指标合并（除非盲评不可行且仅作 smoke）。

### 4.5 可复用代码

| 模块 | 路径 |
|------|------|
| 并排预览 | `.cache/lse-flags-compare/<tripId>/preview/compare.html` |
| 封面盲评范式 | `scripts/phase6_cover_blind_review.py`、`scripts/cover_selection_blind_review.py` |
| A/B 成稿生成 | `scripts/lse_flags_curate_compare.py` |

## 5. P1 · 选片：从「质量门」到「讲故事的 subset」（最大 ROI）

### 5.1 现状（代码事实）

| 模块 | 行为 | 差距 |
|------|------|------|
| `travelogue/curation/photo_cull.py` | Pass 1 硬剔；Pass 2 组内留 sharpness/aesthetic **最高**；Pass 3 配额截断 | 选「不差」≠ 选「对」 |
| Pass 2 默认 | material 组 **跳过**（ingest dedupe 权威） | 无场景级代表性 |
| 聚类 | `run_clustering_layer` 在 curate 内跑 | **cull 不用 embedding 做 subset** |
| `highlight_windows` | mosaic 内 ×1.25 软 boost | 不改变进 trip / 进章的资产集 |

### 5.2 目标

回答：**这本相册要代表哪些时刻、场景、人物**——再交给排版器。

### 5.3 可落地三步

#### 5.3.1 场景代表性选片（Cull v2 · 聚类后、排版前）

在 `run_clustering_layer` 之后、`plan_screens` 之前增加 **subset planner**：

- 每个 scene cluster：留 **1～3 张 medoid**（embedding 彼此最远 + 质量下限）。
- 全局约束：**地点 / 人物 / 时段覆盖率**（如每天 ≥1 人物 + ≥1 landscape hero）；简单 knapsack，目标=coverage，非 sum(sharpness)。
- 硬上限：进 `plan_screens` 的资产数再减 **20～40%**，强迫「少而准」。

**验收**：盲评「故事是否更清楚」上升；不追求屏数增多。

#### 5.3.2 高光：从「加权」升级为「结构」

将 `travelogue/layout_engine/highlight_windows.py` 的消费方式从 mosaic boost 改为：

- 检测到 top window → **强制**章首 hero / mosaic-6 / Dedicated opener（改 `screen_planner` 的 `preferred_hero_id`、章首 slot）。
- 与封面候选链联动（复用封面盲评 infra）。

#### 5.3.3 封面 / 章首 = 选片的一部分

封面不是排版副产品：**5 候选 + rubric + 盲评**，与章内选片同一标准。

### 5.4 关联 PRD

- [PRD-PHASE9-A](./PRD-PHASE9-A-quality-gate-algorithm.md) · Quality Gate 四段 Pass — 扩展为「质量门 + 代表性 subset」，而非仅替换 Pass 语义。

## 6. P2 · 模板库 + 硬约束：突破「算法味 grid」

### 6.1 现状

- 版式以 `landscape-N`、`mosaic-5/6/8` 等**对称网格**为主。
- `travelogue/layout_engine/editorial_hints.py`：`build_editorial_hints` **不 mutate screens**；PRD 明确 hint ≠ 强制。
- `breath-pause` pattern 存在，但 planner 在约束不满足时常 **回退 unfiltered candidates**（日志已多次出现 `no plan satisfies consecutive pattern`）。
- folio 多在渲染层（`folio_lite`），非规划硬约束。

### 6.2 目标

即使 solver 完美填槽，页型本身也要像「设计师做过版」，而不是「算法拼贴」。

### 6.3 可落地动作

#### 6.3.1 少而精的设计师页型（先 3 个）

| 页型 | 意图 |
|------|------|
| 非对称 hero + 侧栏条 | 大图 ~70% + 竖条 2 小图 |
| 对开 spread | 两 landscape hero 成组；mobile 降级 |
| 大留白单图 | 有意 scale-down，非 full-bleed landscape-1 |

每个页型绑定 **CSS token**（gutter、bleed、max-fill-ratio），非纯 slot 计数。

#### 6.3.2 hint → 硬约束

在 `screen_planner_stages` / mosaic search 中：

- **硬规则**：连续 ≥3 多槽屏 → **必须**插入 `breath-pause`；违反则 plan **丢弃**，禁止 silent fallback 到 unfiltered。
- **硬规则**：相邻 landscape hero 且 tone ΔE \< 阈值 → **优先 / 强制** folio 页型，而非仅写 `curation.editorialHints`。

### 6.4 验收

- 盲评「杂志感 / 呼吸感」维度提升。
- Proxy：`layoutRepeatStreak` 下降（辅助，非门禁）。

---

## 7. P3 · 结构级编排：节拍进「章节目录」

### 7.1 现状

- `beat_profile` / arc 仅在 beam **权重**中；章划分 largely 按 day/run。
- 无 trip 级「节奏曲线」：opener → build → peak → breath → closer。

### 7.2 最小可行（不必 Cassowary / 全 trip DP）

#### 7.2.1 Trip arc planner（轻量）

章划分后，为每章标注 `paceRole`：

| Role | pattern 池约束 |
|------|----------------|
| opener / peak | 允许多槽、mosaic、hero |
| breath / closer | 仅单图、留白、低信息密度 |

#### 7.2.2 相邻屏 swap pass（单遍）

成稿后对相邻 3～5 屏做 **只允许 swap 的局部搜索**；目标 = 盲评结果或轻量美学模型，**非** `default.yaml` 加权和。

### 7.3 与 P18 / cross-page re-rank 关系

PRD 中规划的 cross-page re-ranker 未进主路径；P3 的 swap pass 可作为 **最小插入点**，验证「打破章内贪心」是否带来盲评增益，再决定是否投入全局编排。

## 8. P4 · Solver / LSE（冻结）

| 事实 | 处置 |
|------|------|
| 全开 LSE 真实 trip 观感几乎不变 | 不作产品卖点 |
| 单能力消融仅 hungarian 偶发 1 屏 | 边际 ROI 极低 |
| P1–P3 未做前优化 solver | 优化弱信号 + 平庸模板，优雅无解 |

**复评条件**：见 [P17-LSE-处置建议 §5](./P17-LSE-处置建议.md#5-复评门槛满足任一才考虑重新上量或路线-b)。

## 9. 建议节奏（6～8 周）

```text
W1–2   P0  盲评 harness + 8 代表 trip 基线打分板
W2–4   P1  场景 medoid subset + 进排版数量 −30%
W4–5   P2  breath/folio 硬约束 + 1 个 asymmetric designer pattern
W5–6   P1  highlight → 章首/hero 结构（非 boost）
W6–8   P3  trip paceRole + 相邻屏 swap pass
```

**每阶段合并条件**：盲评胜率 ≥ 基线 **+5%**（或达到 60% 绝对门槛）；否则回滚。

可并行：P0 harness 与 P1 原型可 overlap（W1 起）。

## 10. 有效 / 无效信号对照

| 不要作为主要依据 | 要看 |
|------------------|------|
| golden proxy 涨 0.02 | 盲评 pairwise 胜率 |
| 屏级 diff %（尤其屏数不一致时） | 「故事是否更清楚」「是否像成品书」 |
| mosaic 决策日志条数 | 是否愿意分享 / 二次打开 preview |
| LSE capabilityFlags 全 true | 并排 preview 肉眼差异 |
