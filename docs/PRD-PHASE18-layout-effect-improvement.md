| 属性 | 内容 |

| **产品代号** | Travelogue |

| **前置条件** | Phase 17 LSE Core 已上线并稳定运行；`ScreenLayoutPlannerState`、P3 聚类、P9 筛选、P17 决策日志可用 |

| **更新日期** | 2026-06-08 |

> **定位**
>
> Phase 17 解决了「策略可治理、决策可观测、能力可扩展」问题，但成片观感仍存在「每页都对、全册不惊艳」差距。Phase 18 目标不是再做单点算法叠加，而是把排版系统升级为**全局叙事优化系统**：从局部可行，走向序列审美最优。

---

## 1. 背景与问题

### 1.1 现状诊断（为什么算法类似、效果差距仍大）

| ID | 问题 | 现象 | 根因 |
|----|------|------|------|
| **P18-P-01** | 优化目标偏局部 | 单屏质量高但整册平 | 目标函数偏 Page-level，Trip-level 权重不足 |
| **P18-P-02** | 序列节拍弱 | 缺开场/高潮/收尾感 | 缺稳定叙事角色与章节节拍模板 |
| **P18-P-03** | 跨页编辑层不足 | 相邻页视觉重量不均、呼吸断裂 | 候选后缺 editorial re-rank |
| **P18-P-04** | 裁切与槽位弱耦合 | 人物/视线方向与版槽冲突 | focal 有值但未做 slot 级联合优化 |
| **P18-P-05** | 指标与感知脱节 | 离线分数升，主观观感一般 | 缺叙事与跨页指标，评价体系偏工程可测 |
| **P18-P-06** | 反馈回流弱监督不足 | 手动改版多，但权重更新慢 | 隐式反馈未形成稳定偏好学习闭环 |

### 1.2 核心判断

- Travelogue 当前短板不是「缺算法名词」，而是「缺端到端叙事目标协同」。
- Phase 18 需从“单窗最优”迁移到“全册叙事 + 编辑层平衡 + 局部裁切联合”的多层优化。

## 3. 方案总览（四阶段架构）

### 3.1 阶段 A：叙事编排器（Story Sequencer）

**输入**：事件簇、时间、地点、人物、质量特征  
**输出**：`story_role` + `chapter_tempo` + 章节骨架

- 新增叙事角色：`cover/setup/build/peak/cooldown/ending`
- 每章至少 1 个 peak，避免高潮扎堆
- 把节拍模板（封面→展开→高潮→收尾）参数化配置

### 3.2 阶段 B：版式候选生成器（Layout Candidate Generator）

**输入**：章节骨架 + 素材池 + LTE pattern  
**输出**：每页 N 个可行候选（含解释特征）

- 延续 P17 约束求解与配额机制
- 增加 slot 语义：`hero/support/breath`
- 每个候选输出结构化特征向量，供后续重排

### 3.3 阶段 C：编辑重排器（Editorial Re-ranker）

**输入**：全册候选序列（非单页）  
**输出**：最终页面序列

- 优化目标升级为全局：
  - 节奏曲线连贯
  - 峰值可感知
  - 相邻页视觉重量平衡
  - 模板重复惩罚
- 首版算法：启发式 + beam search；后续升级学习排序

### 3.4 阶段 D：裁切-版槽联合器（Crop-Layout Joint Tuner）

**输入**：最终槽位 + 图片  
**输出**：slot 级裁切结果

- 在 focalPoint 之外加入：
  - 人脸完整性
  - 视线方向一致性
  - 文本/留白保护
- 仅做局部微调，不回退重跑全册，控制时延

## 4. 评分函数升级

`TotalScore = α*PageQuality + β*NarrativeFlow + γ*CrossPageEditorial + δ*Variety - λ*Repetition - μ*HardViolation`

### 4.1 初始权重建议（可灰度学习）

| 组件 | 建议权重 |
|------|----------|
| `PageQuality` | 0.30 |
| `NarrativeFlow` | 0.30 |
| `CrossPageEditorial` | 0.20 |
| `Variety` | 0.10 |
| `RepetitionPenalty` | 0.10（惩罚项） |

> 约束：`NarrativeFlow + CrossPageEditorial >= 0.50`，确保系统不再回到局部最优。

---

## 5. 指标体系与门禁

### 5.1 新增核心指标（必须进 gate）

| 指标 | 定义 |
|------|------|
| `NarrativeRhythmScore` | 章节节拍符合目标叙事骨架程度 |
| `CrossPageBalanceScore` | 相邻页视觉重量与色调平衡程度 |
| `TemplateVarietyScore` | 章内/册内模板多样性且不过度跳变 |
| `PeakMomentCoverage` | 高光时刻在合适位置被放大的覆盖率 |
| `RepetitionPenalty` | 主体、构图、模板重复惩罚 |

### 5.2 离线门槛（Phase 18 Alpha）

- `NarrativeRhythmScore` 提升 >= 15%
- `RepetitionPenalty` 下降 >= 20%
- `PeakMomentCoverage` 提升 >= 10%
- 局部清晰度与裁切指标不下降（波动 <= 1%）

### 5.3 在线门槛（Phase 18 Beta）

- 导出率/下单率显著提升（统计显著）
- 手动改版次数显著下降
- 生成时延增量 <= 12%，失败率不回归

## 6. 数据与学习闭环

### 6.1 监督信号构建

- 样本来源：用户最终采用版本、replan 与改版行为
- 标注层级：
  - 叙事角色标签
  - 峰值页标签
  - 跨页平衡偏好对
  - 重复感评分

### 6.2 训练策略

- 首期：规则重排 + 人工校准权重
- 二期：pairwise 偏好学习 re-ranker
- 三期：分场景权重自动校准（人像/风景/夜景）

### 6.3 治理策略

- 学习结果只产出“提案 patch”，仍走双人审批
- 新模型灰度发布，保留规则回退开关

## 7. 分阶段里程碑

### 7.1 P18-W0（1 周）：诊断与基线冻结

- 冻结 benchmark trip 集（50~100）
- 完成新指标计算与看板
- 输出现状雷达图（局部 vs 全局）

### 7.2 P18-W1~W2（2 周）：低风险高收益

- 上线 `story_role` + `chapter_tempo`（规则版）
- 上线重复惩罚与峰值覆盖约束
- 不改核心求解器，仅新增重排阶段

### 7.3 P18-W3~W5（2~3 周）：结构升级

- 上线 Editorial Re-ranker（启发式 + beam）
- 上线跨页视觉重量平衡
- 完成 slot 级裁切联合优化

### 7.4 P18-W6~W8（3 周）：学习化闭环

- 接入偏好学习排序
- 分场景权重自动校准
- 建立持续回流训练与灰度机制

## 9. 风险与缓解

| 风险 | 影响 | 缓解 |
|------|------|------|
| 全局优化导致时延上升 | 影响交互与转化 | 两段式缓存、早停、低端机降档 |
| 多目标冲突导致结果不稳 | 线上波动 | 场景分权重 + 守护指标门禁 |
| 偏好学习过拟合 | 风格单一 | 规则混合、人工抽检、灰度开关 |
| 编辑层重排破坏局部质量 | 视觉回退 | 局部质量下限约束，触发 fail-open |
