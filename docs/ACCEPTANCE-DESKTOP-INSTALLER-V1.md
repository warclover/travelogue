## 0. 怎么用这份文档

1. **工程冒烟**（M-INS-0 退出条件）：执行 §1 冒烟清单，全部 PASS 才允许约 Gate A 用户。  
2. **Gate A**：按 §2 用例矩阵执行；5 人定向，**≥4 完成**成功定义。  
3. **Gate B / C**：分别执行 §3 / §4；未过前一闸不得进入下一闸。  
4. 每条 AC 记录：环境、产物版本、`VERSION.txt`、结果（PASS/FAIL/BLOCKED）、证据链接（截图/日志路径/录屏）、备注。  
5. 验收记录建议落盘：`docs/acceptance-records/desktop-installer-v1-{gate}-{YYYY-MM-DD}.md`。

## 1. 工程冒烟（M-INS-0 Exit · 干净机）

> **环境硬条件**：无 Python、无 Playwright、无仓库源码树；产物解压到全新目录（非开发机源码旁）。

| ID | 检查项 | 期望 | 优先级 |
|----|--------|------|--------|
| **SM-01** | 解压便携 zip，目录含 `TravelogueStudio.exe`、`_internal/`、`portable.flag`、`VERSION.txt`、`SHA256SUMS`、`使用说明.txt` | 结构符合 ADR-018 D1/D3 | P0 |
| **SM-02** | SHA256 与 `SHA256SUMS` 一致 | 校验通过 | P0 |
| **SM-03** | 双击启动：无控制台黑窗；浏览器打开 Studio | HTTP 可达；UI 可交互 | P0 |
| **SM-04** | 日志写入便携 `./logs/`（或等价），含启动成功行 | 可定位 | P0 |
| **SM-05** | 试用示例相册可打开并完成至少一次预览 | demo 可用 | P0 |
| **SM-06** | 导入本地文件夹（含中文路径）→ 导入成功 | 无 pip 文案；无闪退 | P0 |
| **SM-07** | 无 Playwright：导出长图 → 自动轨 2 → PNG 落在 trip 输出目录 | Task Dock 成功；「在文件夹中显示」可用 | P0 |
| **SM-08** | 第二次启动：打开已有实例，不启第二套写进程 | 单实例 | P0 |
| **SM-09** | 「退出 Studio」后端口释放、进程退出 | 可再正常启动 | P0 |
| **SM-10** | 杀进程/崩溃后再启：不永久锁死 mutex/端口 | 可恢复 | P1 |

**冒烟出口**：SM-01～SM-09 全部 PASS → 允许约 Gate A；任一 P0 FAIL → 回 M-INS-0，禁止外发。

## 2. Gate A · 便携包定向验收（5 人 · ≥4 完成）

### 2.1 环境矩阵（每人至少覆盖一行主环境）

| 环境 ID | OS | 路径/特殊条件 | 必测 |
|---------|-----|---------------|------|
| **E-A1** | Win10 x64 | 普通用户目录 | ✓ |
| **E-A2** | Win11 x64 | 普通用户目录 | ✓ |
| **E-A3** | Win10/11 | 中文用户名或中文解压路径 | ✓（至少 1 人） |
| **E-A4** | Win10/11 | OneDrive / 受控文件夹访问（若可得） | 尽量 1 人 |
| **E-A5** | 干净机 | 无 Python / 无 Playwright / 无源码 | 冒烟机 + ≥1 用户机 |

### 2.2 用例矩阵

| AC ID | 步骤 | 通过标准 | 失败即 |
|-------|------|----------|--------|
| **AC-INS-A01** | 收到 zip → 解压 → 阅读 `使用说明.txt`（可选）→ 双击 exe | ≤2 分钟内看到 Studio；无黑窗 | P0 |
| **AC-INS-A02** | 首次进入首页 | 可见「试用示例相册」与导入入口；无开发术语 | P0 |
| **AC-INS-A03** | （可选）跑通示例相册到预览 | 能理解「成品长什么样」；**不计入成功定义** | P1 |
| **AC-INS-A04** | 导入**自己的** 20–100 张照片（可含中文路径） | 导入成功；无 pip；无崩溃 | P0 |
| **AC-INS-A05** | 生成预览 → 导出长图（无 Playwright） | PNG 写入本机 trip 输出目录；Task Dock「长图已保存」；发群三要素可见；「在文件夹中显示」打开正确目录 | P0 |
| **AC-INS-A06** | 关闭浏览器后再次双击 exe | 恢复可用；trips 仍在便携目录 | P0 |
| **AC-INS-A07** | 用户口述：文件在哪、如何发微信 | 能指出文件夹或「在文件夹中显示」；能说出发微信步骤（复制/发送） | P0 · **成功定义核心** |
| **AC-INS-A08** | 退出 Studio 后再启动 | 正常；端口未残留占用导致失败 | P0 |
| **AC-INS-A09** | 已运行时再开一次 exe | 打开已有实例；无第二写进程 | P0 |
| **AC-INS-A10** | 选文件夹流程（系统对话框） | 能选中相册；worker 不闪退 | P0 |
| **AC-INS-A11** | 故意制造一次失败（如空文件夹） | 中文失败结论 + 可重试/反馈；**无** pip / traceback 主文案 | P0 |

### 2.3 Gate A 通过判据（冻结）

| 指标 | 阈值 |
|------|------|
| 定向用户数 | 5 |
| 完成成功定义（A04+A05+A07） | **≥4** |
| 工程冒烟 | SM-01～SM-09 PASS |
| 公开下载 / 官网 CTA | **禁止** |

**不通过**：≥2 人卡在导入、长图、找文件或发微信路径 → 回产品/工程，不进 Gate B。

## 3. Gate B · 安装包 · 邀请制（N≥15）

### 3.1 量化门禁（冻结）

| 指标 | 阈值 |
|------|------|
| 有效样本 N | ≥15（邀请制，非公开下载） |
| 安装成功率 | ≥90% |
| 完成成功率（成功定义） | ≥60% |
| 中位完成时间 | ≤30 分钟（从安装到拿到 PNG 并知道发微信） |
| SmartScreen / 杀软误报 | 有记录与缓解文案；阻断性误报需修复或改分发策略 |

### 3.2 用例矩阵

| AC ID | 步骤 | 通过标准 | 优先级 |
|-------|------|----------|--------|
| **AC-INS-B01** | 运行 Setup（每用户、免管理员优先） | 安装到 `%LOCALAPPDATA%\Programs\Travelogue\`；开始菜单有「Travelogue Studio」 | P0 |
| **AC-INS-B02** | 安装结束勾选「立即打开」 | Studio 启动成功 | P0 |
| **AC-INS-B03** | 首启生成用户数据 | `%LOCALAPPDATA%\Travelogue\` 含 trips/config/logs 与 ownership marker | P0 |
| **AC-INS-B04** | 完成一次成功定义流程 | 同 A04+A05+A07；数据在 LocalAppData | P0 |
| **AC-INS-B05** | 卸载（不勾选删除数据） | 程序与快捷方式移除；用户数据保留 | P0 |
| **AC-INS-B06** | 卸载（勾选删除数据） | 显示绝对路径 + 二次确认；仅删带 marker 的默认目录；不跟 symlink | P0 |
| **AC-INS-B07** | 覆盖升级 | 用户 trips/配置保留；版本号更新 | P0 |
| **AC-INS-B08** | 安装/升级/卸载时检测到运行中 | 提示退出后继续；不静默覆盖运行文件 | P0 |
| **AC-INS-B09** | 安装器属性 | 版本号 / Publisher / AppId 与冻结表一致 | P0 |
| **AC-INS-B10** | 环境变量指向外部目录时卸载勾选删除 | **不**删除外部目录 | P0 |
| **AC-INS-B11** | 桌面快捷方式 | 默认不勾选；勾选后可用 | P1 |
| **AC-INS-B12** | 旧便携 trips 提示（若检测到） | 帮助文案可理解；不自动迁移 | P1 |

### 3.3 Gate B 出口

量化门禁全部满足 + B01–B10 P0 PASS → 允许准备 Gate C 签名与公开页，**仍禁止**未签名公开下载主 CTA。

## 4. Gate C · 签名公开下载

| AC ID | 步骤 | 通过标准 | 优先级 |
|-------|------|----------|--------|
| **AC-INS-C01** | 代码签名证书签署 Setup / 关键 exe | 签名有效；发布者名称正确 | P0 |
| **AC-INS-C02** | 干净机首次下载安装 | SmartScreen 可接受（或有官方缓解说明）；安装成功率不显著劣化 | P0 |
| **AC-INS-C03** | 官网 `/install`（或等价）上线「立即下载」 | **仅**此门后出现主 CTA；下载指向已签名产物 | P0 |
| **AC-INS-C04** | Release 资产 | Setup + Portable zip + `VERSION.txt` + `SHA256SUMS` + 发行说明 | P0 |
| **AC-INS-C05** | 许可与定价文案 | 与官网/README 一致；无「MIT 永久免费」与「待定」冲突 | P0 |
| **AC-INS-C06** | 反馈通道 | 安装失败/误报可提交；含版本与日志指引 | P0 |

**Gate C 出口**：C01–C05 PASS → 允许公开下载主路径。

## 5. 非功能验收（贯穿）

| ID | 检查 | 期望 | 适用门 |
|----|------|------|--------|
