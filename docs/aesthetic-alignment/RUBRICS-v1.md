## 统一量表（1–5）

| 分数 | 含义 |
|------|------|
| **1** | 废片 / 明显不该进精选 |
| **2** | 偏弱，仅作记录 |
| **3** | 可用，不突出 |
| **4** | 好，可进重点位候选 |
| **5** | 很好，封面 / 主视觉级 |

打分问句：**「若只能在这本游记里重点展示少量照片，你愿意把这张放进候选吗？」**

## 分类补充说明

### person（单人照）

| 分数 | 说明 |
|------|------|
| 5 | 表情自然、主体清晰、光线舒服 |
| 3 | 能看，但平淡或略有瑕疵 |
| 1 | 糊、闭眼、构图严重失误 |

### group（合影）

| 分数 | 说明 |
|------|------|
| 5 | 关键人物清晰、表情可接受、构图稳定 |
| 3 | 能用，但有人略糊或表情一般 |
| 1 | 多人闭眼、关键人糊、明显废片 |

### landscape（风景 / 建筑 / 自然）

| 分数 | 说明 |
|------|------|
| 5 | 构图与光线舒服、有代表性、层次好 |
| 3 | 普通记录照 |
| 1 | 平淡无味或明显技术问题 |

### food（美食）

| 分数 | 说明 |
|------|------|
| 5 | 诱人、主体清楚、色彩自然 |
| 3 | 能辨认，食欲感一般 |
| 1 | 难辨认、灰暗、无食欲 |

### general（混合 / 不确定）

按 **「是否值得在这本游记里重点展示」** 打 1–5；若可判断类型，请先在 UI 中改 stratum 再打分。

---

## 盲评操作

1. 先看图，**确认或修改** stratum 标签。
2. 按该类 rubric 打 1–5（键盘 `1`–`5`）。
3. 不要参考算法分数（盲评页已隐藏）。
4. 完成后导出 JSON，合并进 `aesthetic-human-labels.*.json`。
