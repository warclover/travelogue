## 你要做的（仅 2 步）

### 1. 打开盲评页打分

1. 确保 Studio 在跑（能打开上面的游记链接即可）：
   ```powershell
   python -m travelogue studio --no-open
   ```
2. 浏览器打开：**http://127.0.0.1:8766/demo-2025-6/blind-review.html**
3. 对每张图按 **1–5** 打分（键盘 `1`–`5` 最快，`←` `→` 切换）
4. 进度会自动保存在浏览器；可随时关闭再续
5. 全部完成后点 **「下载标签 JSON」**，保存为：
   ```
   docs/acceptance-records/aesthetic-human-labels.demo-2025-6.json
   ```
   （覆盖仓库里同名模板即可）

### 2. 计算 SRCC 基线

在项目根目录：

```powershell
python scripts/aesthetic_blind_review.py --srcc docs/acceptance-records/aesthetic-human-labels.demo-2025-6.json --compare-purposes
```

把输出的 `srcc` 数字告诉我，或自行写入 acceptance record。
