本页是索引，不是第五份规格。每条只记录：决策是什么、当前类别、详细定义在哪份权威文档、取代了什么、将来如何修改。阈值、字段公式、验收步骤仍以权威文档为准。

下游 PRD、任务和验收记录只能引用 `RD-*`，不得建立平行决策。**「不得再讨论」= 不得在其他文档平行重开**；证据驱动的修订必须在本账本追加记录，不得静默改写历史。

## 类别

| 类别 | 含义 |
|------|------|
| **保留** | 现行有效结论 |
| **冻结** | 现有能力保留；允许变更范围见权威文档，不扩规格 |
| **退役** | 叙事或路径失效（可附退役前提） |
| **待验证** | 尚未闭合。内部分：**待决策**（结果未拍板）/ **待取证**（目标与阈值不得再讨论，只等实现与验收） |

## 修改纪律

1. 需要改变既有结论时，在「修订记录」追加一行，注明理由、证据、受影响文档和替代关系（例如 `RD-019` 拍板后仍用同一编号，改类别与正文）。
2. 不得把规格细节复制进本页后再在权威文档改一版、本页留旧版。
3. 改 [v1.0发布门槛.md](./v1.0发布门槛.md) 必须同时在本页留下修订，并说明触及哪条 `RD-*`。
