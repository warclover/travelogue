## 0. 一句话

临时库上的创建、微缩、标星、拖拽成册、真图试印，是模板引擎升级的一部分，但**不该整包并进现网**。应升格为长期存在的**后台设计工坊**：与现网机器隔离、词汇表统一，只通过**升格包**把试好的页型和角色系列交给现网。

---

## 1. 第一轮：要不要正式集成

### 1.1 产品原意

创建模板、模板缩略图可视化、标记星级、拖拽编排成册、图片填充测试，都已在临时库 HTML 上做成。这些是模板引擎升级的一部分，应当正式集成到现有项目。先讨论，不看代码。

### 1.2 对照事实

| 已做成（临时库 / RSC） | TSU 合同要的 | 差在哪 |
|------------------------|--------------|--------|
| 本夹静态服 + `gallery.html` | 首页「版式」进已落地功能 | 按钮已挂 `/templates-admin`，后面仍是旧五态平铺表 |
| 新夹 + `packet.yaml` 建脸 | 正式页型必须带数据包 | 创建流程对；准入漏斗没有 |
| 微缩按数据包算 | 图标是数据包投影，CI 重出 | 手感已验证，缺正式 glyph |
| `stars.yaml` 点星落盘 | **合同里没有星** | 临时库多出来的产品信号 |
| 拖**脸**进轨，多本草稿柜 | 拖**角色**，脸只换 `faceHint` | 落盘字段像，心智不像 |
| 本机选夹铺图 | 预演是 N+P → 系列 / 落选原因；不要填图器 | 测脸 ≠ 测编排 |
| 引擎不读 | 匹配器只读正式系列 | 这道墙必须留 |

`folio-16-standard` 证明「这批脸配成一本好看」，**还不是** TSU B7（角色芯片写 8/16×疏正密 + 20 页正）。金样锁了附录 A 没有的脸、对照表没有的细角色。

七席：A7 线框未签、B7 金样未交之前，不批编排器合码、不批匹配器合码。

### 1.3 当时建议（后被第二轮修正）

五项能力不该一起搬：

- **创建**：转正收件箱，不要画框器。
- **缩略图**：第一件该进 Studio。
- **星级**：策展笔记，不当选型权重。
- **编排**：进 Studio 的是柜 + 轨，主拖改为角色。
- **试印**：必须留实验室；升级成「一组一页」审匹配。

三层地图：收件箱 → Studio 资产面 → 运行时（最后一刀，可关旗）。

不该一起搬：`page-*` 顶岗现网长图；接到画册跨页；把临时库 HTML 当成 `/series-editor`。

五句待拍：集成是工作流还是引擎消费脸；星是门槛还是分数；16 页金样怎么用；创建是填包还是画框；试印先几何还是先组锁定。

## 2. 第二轮：工坊独立，现网只借鉴

### 2.1 产品新建议

把临时库做成后台管理工具，专门做模板设计、模板测试、编排成册设计。与现网代码完全隔离，或留某种接口，让测好的模板和成册能被现网直接复制使用。现网模板库和管线升级可以借鉴这个工具，但完全隔离、代码独立。

### 2.2 收口判断

**同意**做成长期设计工坊，而不是临时 HTML，也不是整包并进现网。

**不同意**「完全隔离 + 现网再独立做一套相同工具」。那会变成两套后台、两套微缩、两套编排手感；或 Studio「版式」变成空壳。

正确拆法：

| | 设计工坊 | 现网资产柜（Studio「版式」） |
|--|----------|------------------------------|
| 干什么 | 画脸、试几何、标常用度、手编样例、真图审匹配 | 登记谁可以进新册、改正式系列、预演、关旗回退 |
| 页数 | 任意 | 只收档位本 |
| 失败代价 | 难看、装错 | 旧游记花、长图气质变 |
| 和引擎 | **永远不读** | 只读这里 |

工坊回答「好不好看」；现网回答「许不许可用」。中间不是活接口，是**升格仪式**。

### 2.3 隔离什么

> **机器隔离，词汇表统一。**

隔离：引擎、拼图、CI、`trip.json` 当工坊不存在。实现两套，互不引用。

统一：数据包字段、角色名、`program`（`opener | hero | mosaic | grid | breath | journal | peak`）。工坊可以超前（多脸、任意页数、星、铺图），不许另起一套身份语言。

现网「借鉴」= 学工作方式（分柜、微缩、拖轨、红灯），不是搬页面，也不是共用实现。

### 2.4 升格门：三种里只留一种

| 门 | 处置 |
|----|------|
| 现网直接读工坊目录 / 一键写入引擎 | **否**。隔离是假的，关旗关不干净 |
| 微缩 / 拖拽抽成两边共用模块 | **本波否**。工坊一改手感，现网回归全动 |
| **升格包**（给人看、给现网收） | **是**。没有运行时联通 |

包裹只两样：

1. 一张页型：数据包 + 示意图 + 何时用 / 何时不用  
2. 一本正式系列：按**角色**写的页序；脸只是默认提示  

不进包裹：星级表、本机照片、未保存草稿、任意页数试刊本、工坊打开脚本。

三道人检：身份诚实（名=槽数）；角色能对上附录 B；现网收得下（能出微缩，归档脸不冒充新脸）。

16 页金样留工坊当精致对照本；进现网先改写成角色序列。

### 2.5 现网还要不要后台

要，但可以比 TSU W4 **更薄**——前提是工坊长期活着。

工坊承担后，现网不必再做：真图铺页、点星、任意页数试刊、从零画新脸。

现网仍必须做：五入口、轻编正式系列、N+P 预演、关旗回贪心。否则「版式」按钮是空的。

隐蔽风险：工坊太好用，升格被无限推迟。精致观感只存在于本机试印。正式柜要有配额（页型 12–18、系列先金样）。

### 2.6 对第一轮五句的预答

| 问题 | 在「工坊独立」下的答案 |
|------|------------------------|
| 集成是工作流还是引擎消费脸？ | 工作流进工坊并转正；引擎只消费升格后的正式柜 |
| 星级是门槛还是分数？ | 只活在工坊，当门槛；现网不认星 |
| 16 页金样怎么用？ | 留工坊当对照本；进现网先改写成角色金样 |
| 创建是填数据包还是画框？ | 只在工坊；现网只收已经填好的包 |
| 试印下一步？ | 永远在工坊；现网预演是另一件事 |

还要另拍的三句（写入 TDV 时已按此落锤）：

1. 现网「版式」进柜，不进工坊。两个入口，两句人话。  
2. 升格只交页型包和角色系列。现网可有收件动作，但绝不扫工坊文件夹。  
3. 正式系列权威在现网那一份；工坊同名本只是设计稿。

## 4. 与旧备忘的关系

[临时模板库管线讨论备忘录](./templates/reserve/临时模板库管线讨论备忘录.md)（2026-08-17）仍有效，且被本轮吸收：

- 星只认 `stars.yaml`，不进数据包 / 引擎。  
- 试印测几何，不是编辑匹配；不要把脸画软。  
- 快分享 / 精致 Web / 印刷画册三条管线分开。  
- 引擎不读 `reserve/`。  

本轮新增、旧备忘未立项的部分：工坊是**长期产品**，不是「精致路线进引擎」的过渡夹；与现网的关系是升格包，不是合码。

RSC 仍是成册柜细则。TDV 是工坊总合同，不废止 RSC。

TSU 仍是现网资产面 + 成册层合同。TDV 不代替 `/series-editor`、不代替匹配器、不改 D-U-09 双舞台。
