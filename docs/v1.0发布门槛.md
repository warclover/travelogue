本页是 v1.0 的**发布合同**：八类门槛全部二元判定。**全部 PASS 才允许发布**。任何一类为 FAIL 或 **NOT RUN，均不得发布**。

`scripts/quality_gate.py` 目前覆盖 schema 夹具、部分布局 / Studio 回归与 curate replay，**不等于**本页八类门槛。它可以成为自动门的总入口，但干净 Windows 安装、手机实看和真实分享必须另有验收记录。

## 0. 纪律

1. **门槛必须在修复前冻结。** 看到失败结果后，不得为了让当前实现通过而降低阈值。
2. **门槛正文只定义判据。** 执行结果另存 acceptance record。修改本页必须进入 [收敛决策记录.md](./收敛决策记录.md) 修订记录，写明触及的 `RD-*`（通常 `RD-008` / `RD-007` / `RD-021` / `RD-022`）。账本只记决策与替代关系，**不复制本页阈值**。
3. **状态只允许 `PASS` / `FAIL` / `NOT RUN`。** `NOT RUN` 等同于不能发布。
4. **发布门槛 vs 观察指标。** 只有本章 QG-01～QG-08 阻断发布。density、页数、耗时排名、模板是否「还能更精致」、win/tie/loss、macro/micro coverage 对比，只作诊断，不进门槛。
5. **不写总体 coverage 下限。** 超量旅行可以合法 `overflowCapped`。必须归零的是容量内 `placementGap`，不是强迫所有照片入册。

### 0.1 观察指标（不阻断发布）

| 指标 | 用途 |
|------|------|
| coverage / micro / macro | 诊断装填，不设发布阈值 |
| density、页数、emptySlotRate | 只记录 |
| planMs / 耗时排名 | 诊断性能，不排名打分 |
| win/tie/loss vs mosaic | EA-02a 对照，不是发布门 |
| 「还能更精致」的节奏、留白、审美 | post-1.0 台账 |

### 0.2 当前证据快照（不是改门槛）

[EA-02a](./acceptance-records/ea-02a-shadow-compare-2026-09-01.md) `comparisonRunId=ea02a-20260901-203246` 上，目标主路径 series 的 `placementGap` 合计 **221**。按 QG-01，**series 明确不通过**。该缺口由 `SE-00a` 收敛，不能靠降低阈值消化。mosaic 的 `outputInvalid` 也不构成 mosaic 质量通过。

## QG-01 · 成册完整性

| 字段 | 内容 |
|------|------|
| 产品承诺 | 目标主路径把该入册的照片入册；失败、重复填图、容量内空洞和静默丢失均为 0 |
| 语料 | 上表 20 趟真实旅行；哈希见当次记录 |
| 环境 | 开发机可跑采集；口径 EA-00；目标主路径 = series |
| 执行 | `python scripts/ea02a_shadow_compare.py` 的 **series 臂**（或其后继只跑目标主路径的采集器）。必须输出 EA-00 字段；`mustInclude` 静默丢失数未接入前本门槛为 **NOT RUN** |
| 自动 / 人工 | 自动（守恒与计数） |
| 验收记录 | `docs/acceptance-records/qg-01-folio-integrity-*.md`（尚未建立） |

**唯一通过条件（逐趟且合计，任一非 0 即 FAIL）：**

- `tripFailRate = 0`
- `pipelineFailureRate = 0`
- `outputInvalid = 0`
- `intakeLoss = 0`
- `duplicatePlacements = 0`
- `foreignPlaced = 0`
- `placementGap = 0`
- `mustInclude` 照片静默丢失数 = 0（eligible 且标记 mustInclude，却未入内容屏、也未进入可见 `overflowCapped` 清单）

## QG-02 · 确定性

| 字段 | 内容 |
|------|------|
| 产品承诺 | 同输入可复现；渲染器不改计划 |
| 语料 | 至少 1 趟稀疏 + 1 趟常规（从 20 趟中固定，哈希写入记录）；另用 catalog 变更夹具测版本戳 |
| 环境 | 固定配置、固定 `codeRevision`、固定 `templateCatalogHash` |
| 执行 | 连续 3 次 compose + 导出；字段级 diff LayoutPlan；`LP-05` / `LP-06` 测试为自动部分。未接通前 **NOT RUN** |
| 自动 / 人工 | 自动为主 |
| 验收记录 | `docs/acceptance-records/qg-02-determinism-*.md` |

**唯一通过条件：**

- LayoutPlan 除显式时间戳等声明的易变字段外，三次字段级一致
- 页序、分章、选图、模板、槽位映射、`crop`、`fit` 完全一致
- 导出文件的页数、顺序、文件名和尺寸一致
- 渲染器没有重新选图、换模板或重算 crop（`LP-06`）
- 输入或 `templateCatalogHash` 改变时，版本戳准确反映变化

**不要求** PNG 原始字节完全一致。结构用精确比较；视觉用 QG-03 感知差异门。

**几何 · 唯一通过条件：**

**人工实看 · 唯一通过条件：**

- 稀疏 / 常规 / 超量各一趟真实旅行（从 20 趟固定，写入记录）

- 破版、正文不可读、图注不可读、主体被灾难性裁掉、空页等严重问题 = 0
- 一般性节奏、留白、审美建议只记 post-1.0，不得无限阻止发布

## QG-04 · 长图导出与分享

| 字段 | 内容 |
|------|------|
| 产品承诺 | 第一交付物可直接分享；分享动作确实完成 |
| 语料 | 20 趟真实旅行生成；至少 2 张真实作品外发 |
| 环境 | 本机导出；Windows 图片查看器；一种常用手机打开方式；外发不要求对方安装本产品 |
| 执行 | 目标主路径导出竖版长图（`EX-03` 接通后）。未接通竖版长图前本门槛 **NOT RUN** |
| 自动 / 人工 | 可解码 / 页序自动；外发与手机打开为人工 |
| 验收记录 | `docs/acceptance-records/qg-04-longshot-share-*.md` |

**唯一通过条件：**

- 20 趟均能生成可解码的竖版长图
- 页序与 LayoutPlan 一致
- 无缺页、重复页、截断页和空白尾部

- 导出失败时不得残留一个被误认为成功的半成品

不要求对方评价「非常漂亮」。验收的是分享动作完成。

| 验收记录 | `docs/acceptance-records/qg-05-derived-outputs-*.md` |

**唯一通过条件：**

| 字段 | 内容 |
