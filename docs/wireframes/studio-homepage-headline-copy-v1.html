⑤ CSS 变更规格（方案 D · 仅内部）

选择器变更说明
.v2-bento__headline + display: grid
grid-template-columns: 1fr auto
grid-template-areas: "eyebrow tags" "title title" "lead lead"
height: 88px（或 min-height 锁定现网计算值）		 外框尺寸锁定；内部三分区
.v2-bento__eyebrow grid-area: eyebrow · mb 6px 不变 左顶
.v2-auto-tags grid-area: tags
justify-content: flex-end
align-self: end · mb 6px（与 eyebrow 底对齐）		 右顶 · 与品牌行同带
.v2-bento__title grid-area: title · 去掉 flex 属性 独占一行 · 全宽
.v2-bento__lead grid-area: lead · mt 8px · max-width 520px 不变 通栏底行
.v2-bento__headline-row 删除 不再需要

⑥ 备选方案 C · 若希望 Tags 仍与 H1 同行

不改 DOM 顺序，仅把 headline-row 换成 Grid 定列 — 同样 88×100%。

grid-template-areas:
  "eyebrow eyebrow"
  "title   tags"
  "lead    lead";
grid-template-columns: minmax(0, 1fr) auto;

.title  → grid-area: title;  去掉 flex: 1 1 240px
.tags   → grid-area: tags;   max-width: 240px; align-self: center
