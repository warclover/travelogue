设计目标

封底应与封面 cover-opening 形成书本闭合感：独立占满一屏（100dvh − toolbar）， 用一张「收尾图」+ 叠字层完成旅途总结，而不是在浅色正文流里突然结束。 现状 epilogue-screen 仅 inline 排版 + 下方 footer-cta，缺少与首屏对等的仪式感。

封面 ↔ 封底 · 信息对称

封底不是封面的简单复制，而是叙事收束：开场给「为何读」，封底给「读完了什么」。

★ 推荐方案

设计要点

  • 信息层级：Label → Stats → Epilogue → Title echo → Brand
  • 对齐：panel 左对齐，与 cover-opening 一致
  • 渐变：同封面 to-top 94%→8%，保证浅/深图可读
  • 标题回响：Brush 弱化 55% 白，可配置隐藏
  • 空态：无 epilogue 时仍显示 stats + brand

与封面差异

  • 无「向下滚动」提示 · 已是终点
  • 动效方向：滚入时 reveal，而非首屏 eager
  • 可选顶部 THE END 微标（分享态）

footer-cta 处置

  • Web：footer-cta 品牌行并入 panel · 块本身隐藏
  • Studio 草稿：「← 返回 Studio」保留在 toolbar / 或 panel 链接
  • Mobile：维持现有 inline epilogue（不强制全屏）
