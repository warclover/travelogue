F3 · 作品集预览 · 导出门面 已改 · 待重签

F8 · 禁止形态 · 红线 已签 · 加两条

下列任一出现，本主题不算过门。请在侧栏勾「同意红线」。
禁止为什么正确
第三张大卡与快速/精细并列「作品集」用户以为那是更细的游记身份分段 + 原两卡
六平台旁第七个圆点身份不是发行平台作品集主路径 = 这一本 + 页图
作品集主钮仍写「导出长图」会把密页塞进微信竖条导出作品集
作品集精修仍出 LVP「杂志成册」两套杂志撞名只出成册类型 + 页数
对外说「画册已经按页用 page-*」印刷跨页还是 3:4 卡作品集 / 印刷跨页 分说
默认身份改成作品集破坏两击发群默认游记
首页主 CTA 改成做作品集抢 80% 路径弱链即可
新增 · 正式系列没到位就对外称「作品集」 顶岗排出来的其实还是游记版式，用户会以为作品集就长这样 W1 内部只说「版式试验」；次链保持不露
新增 · 照片装不下时静默丢弃 游记是全收，用户默认「我的精选都在里面」，第一次被打破必须说 先升档；仍装不下则明示「本册收录 N / M 张」+ 改用游记出口
新增 · 导入阶段问页数 用户还没看过照片，猜不出 8 页还是 24 页 导入一律自动；页数只在精修（F6）
工程侧同级红线（不上界面但同样挡门）：不得新增第三个 layoutEngine 值；不得用 folio / surface 当本主题标识符； 作品集的 items[] 必须与 screens[] 实收集合同源。
