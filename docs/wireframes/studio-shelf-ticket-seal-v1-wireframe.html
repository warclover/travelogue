审核备注

印样来源：reelsalon-seal-b-round 裁成纯圆印叠在现网满票根上。

推荐

① 封面钤印 朱砂 · seal-B

  • 成册印记，不抢 stub 信息
  • 与撕边形成「盖完再撕」的物件感
  • 网格扫描时品牌可辨、不噪
票根上只用圆印，不要带下方 reelsalon 字标——脚区太矮，字会糊。

请拍板

  • 落位：① / ② / ③ / 不加印
  • 尺寸：偏小（28px）还是现示意（32–36px）
  • 旋转：保留 −8° 钤印感，还是水平端正
  • 是否所有册统一同印（建议是）

工程备注（审核后）

  • 资产：透明圆印 SVG/PNG → templates/studio/assets/
  • DOM：封面 wrap 内绝对定位 img.v2-shelf__seal
  • aria-hidden；不进点击热区逻辑
