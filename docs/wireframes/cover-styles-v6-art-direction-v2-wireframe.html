为什么这次会不一样

上一版是「做减法」，减完只剩干净，没剩下感染力。这版在减法之上补了六条工艺，每条都能在生产 CSS 里落。

  1. 照片先调色：分色暗角 + 银盐颗粒 + 缓慢推移，让素材从「贴图」变成「印品」。
  2. 题字是图形不是标签：镂空、叠印、断字、竖排——字要参与画面，不是浮在上面。
  3. 只留一个动作：每款一句话能说清「它做了什么」，说不清就砍。
  4. 编辑元数据当纹理：日期 / 坐标 / 天数 / 卷号，极小极淡，撑起摄影书的可信度。
  5. 负空间是构图的一部分：留白、天地头、纸缝，不是「没排满」。
  6. 缺陷即质感：套印偏移、裁切十字、书脊阴影、纸纹——工业痕迹带来温度。
