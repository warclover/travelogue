不受现有 PRD 约束 重新假设首页角色：证明输出美感 > 解释产品功能。教程、路径栏、页脚 checklist 均后置到导入 sheet。
推荐主方向 ① 样张即首页 — 真实长图占主视觉，Dock 单一 CTA。适合首次来访者。

与 v3 的关键差异

  • 去掉全幅暗色 Hero + 大标题：文案压到 Dock 或分屏顶栏一行
  • 样张可滚动：用户首屏就在「看成品」，不是「读介绍」
  • 回访态独立布局：④ 书架无 Hero，不再 hybrid 左右分栏
  • 认知支架后置：「文件夹怎么选」进 sheet / 链接，不进首屏
  • 主色改为森林绿：区别于 v3 金色 SaaS 感（可再调）

状态策略（建议）

  • 首次打开 → 默认 ① 或 ③（取决于是否强调场景）
  • 有历史游记 → 直接 ④ 书架
  • 导入中 → ⑤ 叠加在上一屏之上
  • ① 与 ② 可 A/B：一个偏「审美冲击」，一个偏「功能理解」

待你拍板

  • 主推荐：① 样张 vs ② 分屏 vs ③ 场景 — 哪个作默认空态？
  • 样张来源：固定 3–4 套 demo trip vs 随机轮换
  • ④ 书架：是否需要置顶「继续编辑」条，还是卡片 badge 就够
  • Dock CTA 文案：「做一本」vs「选择文件夹」vs「制作我的杂志」
  • 色调：森林绿（本稿）vs 回归金色 vs 纯纸感无 accent
  • ① + ③ 能否合并：首屏样张 + 底部横滑换场景
