精修

情境默认（建议） 点预览封面图 → 「封面 · 照片」；点封面书名/贴纸 → 「封面 · 杂志名」； 从版式入口进 → 「封面 · 版式」。正文页 → 「页面」。

现行 vs 推荐

同一信息架构容量，推荐只把封面内三件事抬到二级导航。

现行 封面｜页面｜画册

封面页面画册
  • 封面 Tab = 长页：照片 + 版式 + 装帧标题（常需下滚）
  • 改杂志名在「画册」，生成艺术字在「封面」——链路断开
  • 封底用封面内分段切换

推荐 同三区 + 二级分段

封面页面画册
照片版式杂志名
  • 三件事始终可见；「杂志名」= 改名 + 生成字体
  • 画册去掉杂志名表单；留一句话 / 成册风格 / 署名 / 进阶
  • 成册风格 ≠ 封面版式（两边文案写清）
画册去重对照 删除：杂志名输入、与封面重复的「改名字」主引导。 保留：一句话、成册风格、作品署名、进阶。弱链：去改杂志名/字体、去换封面照片。

备选 · 四一级 Tab（不推荐为首选）

若你坚持「全部抬到顶栏」，用 4 个而不是 5 个。

代价 顶栏更挤；换图与换版式跨 Tab；「画册」整本设定可能被挤到「更多」或二级。
封面图版式杂志名页面
  • 「画册」可并入页面底部或「⋯」
  • 命名宜短：照片 / 版式 / 杂志名 / 页面
  • 仍建议封底挂在「封面图」内；杂志名段仍含改名+艺术字

已拍板 / 待确认

已拍板 · 二级文案 照片｜版式｜杂志名（副文案：封面/封底 · 样式 · 改名·字体）。 不用单字「名称」或「标题」；不用「装帧字」（用户难懂）。
已拍板 · 画册去重 画册不再放杂志名输入框。骨架：一句话 → 成册风格 → 作品署名 → 进阶（折叠）→ 底栏弱链回「封面 · 杂志名」。成册风格文案标明「影响整本页面，不是封面样式」。
仍可确认 · 一级三区 推荐保持封面｜页面｜画册。否 → 走四 Tab 备选。
仍可确认 · 封底 / 顶栏「封面」是否改「装帧」 封底挂「照片」；顶栏默认仍叫「封面」。

审核清单

  1. 画册去掉杂志名后是否干净？
  2. 一句话 / 成册风格 / 署名是否够用？
  3. 弱链回封面是否好找？
  4. 成册风格 vs 封面版式是否分得清？
