精修 · 频次 / 文案 / 导出合并 · 线框 v1.2（评审稿）

v1.2 定案：精修三区 = 这页 | 封面 | 这本；「封面」Tab 内用分段切换封面/封底（不作两个顶栏 Tab）。 导出决策完整迁入保存长图 ▾（F6）。情境默认见 F2。

F0 · As-Is 诊断 卡死感

用户在封底打开精修 → 默认落在「这页」→ 满屏告诉你「这里不能干那些事」→ 主按钮却是「收起面板」。

三层错位 ① 情境错：封底任务是换图，却停在「这页」； ② 频次错：主按钮是关面板，真正想做的「换封面/封底」变成次要； ③ 文案错：「正文屏 / 拼图改判」像内部术语。

F1 · 设计原则 定案候选

按「打开精修时用户最可能要做什么」排路径；文案只用分享者听得懂的词。

极高不进精修：Dock「发微信群 / 长图」（本轮不改） 高换封面/封底 · 改杂志名 · 正文点 ★（画面上，可收起面板） 中本页锚点/短词 · 导出偏好（范围/清晰度） 低拼图切换 · 按精选重排 · 章意图重写 极低模板 / 同框 / 分章 / zip·LLM（保持折叠）
#原则落地
P1 三区 IA 精修 = 这页 | 封面 | 这本。禁止顶栏再拆「封底」第四 Tab；封底在「封面」区内切换
P2 情境默认 Tab 看封面/封底 → 默认进「封面」并选对分段；看正文 → 默认「这页」
P3 空态主按钮 = 真实任务 若仍停在「这页」且在封面/封底：主按钮「去换封面」→ 跳「封面」Tab；「收起面板」降为次要
P4 人话优先 禁「正文屏 / 拼图改判 / 记忆锚点」裸露；见 F5
P5 导出决策单源 去掉精修「导出」Tab；文案范围/图注/导语完整迁入保存长图 ▾（F6）
P6 「这本」变轻 首尾装帧迁出后，「这本」只留杂志名 / 一句话 / 进阶
已拍板（2026-07-17） 采纳「封面」独立 Tab + 区内「封面 | 封底」分段；不采纳顶栏双 Tab「封面 + 封底」。

F6 · 导出合并定案 必审不弱化

精修「导出」Tab 全部能力已盘点（源码 renderAdvancedPanel）。 长图文案范围 / 图注 / 导语会同步预览 DOM 并写入 longshot 请求（copyDisplay），必须完整迁入保存长图 ▾ 首屏，禁止降级为「更多」。

禁止 只留「打开导出设置」桥接、却不把文案范围迁进 ▾ · 或把图注/导语塞进折叠「更多」· 或两处仍可改 prefs（双源漂移）。
