Cover Styles V6 · 八款封面概念线框 · 设计评审（待拍板）

目标：替换/扩充现网三款（card-br / split-mat / magazine-head）中缺乏感染力的版式。 约束继承 V5：一块 DOM（cover-hero + panel）、100dvh、title/hook ≤2 行、Icon Dock 保留、<1024px 可回落。 批次一（A–E）偏画册/编辑；批次二（F–H）更大胆：圆窗、巨字、斜切。线框仅评审构图与气质。

对现网三款的诊断（设计视角）

  1. card-br：右下实心卡像 UI 浮层，摄影被「说明框」压住，缺少画册开篇的仪式感。
  2. split-mat：奶油衬纸 + 深棕侧栏偏商务画册模板，暖棕配色易显廉价，竖题区与摄影关系生硬。
  3. magazine-head：白顶 + 下大图结构正确，但顶区过「空」、字重与分隔线缺乏编辑部气质，像网页头图而非杂志封面。
