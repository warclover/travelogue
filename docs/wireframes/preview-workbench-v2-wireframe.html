卷轴预览
  • 「阅读视图」无专属样式（preview-toolbar__reader-view 无 CSS）→ 系统默认灰按钮，与工具栏风格脱节；点击后文案变「编辑预览」，像切换了另一个模式但没有选中外观。
  • 金色 overload：主 CTA「保存长图」、stale 提示（#ffd89a）、精选星标（#d2a657）、focus 高亮（#ffd89a 描边）共用相近色相 → 用户以为「变黄 = 已选中」或「变黄 = 出错了」。
  • 保存长图三态外观接近：金色可点 → 金色半透明 disabled → 金色 + 外发光 focus；旁边再出现灰绿状态字，主按钮究竟处于 idle / running / done 不清晰。
  • 反馈分散三处：顶栏 inline 文案 + 底部居中 toast + 右下角成功卡片 → 眼睛要跳三个区域才能确认「保存成功」。
  • 「应用排版」藏在 ⋯ 菜单，改拼图/精选后只 toast 提示，主栏无持续可见的「待应用」状态。

交互规范摘要（实现前评审）

供研发与你对齐「什么颜色代表什么」——避免再出现金色多义。

语义颜色 / 组件禁止
唯一主操作（导出长图 idle） 金色实心 export-zone__cta--idle 不用于状态提示、选中、disabled
进行中 灰蓝底 + spinner + 按钮内文案 不用半透明金色
成功 绿色勾 + 抽屉；按钮变 --done 绿色 不用 toast 替代主确认
需用户行动（stale / pending） 琥珀 banner / 标签 不用 #ffd89a 与 CTA 金相邻
模式选中（编辑/阅读） 分段控件白底块 不用切换按钮文案
画面上精选 ★ 保持金色，但加 aria-pressed + 标题提示 不与顶栏 CTA 同色相邻出现
