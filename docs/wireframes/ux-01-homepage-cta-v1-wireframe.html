本轮范围

  • 只改一个视觉主按钮和一条次入口。
  • 文案跟术语表：动作用「导出」，对象按长图 / 画册说，不用「分享图」「验货」。
  • 最近一本按「最近打开」取；示例相册不参与判定。
  • journal 与 portfolio 用 chip 区分，点击不串导出面。

明确不动

  • Bento 双预览、书架网格、设置、主题。
  • 不把最近项目收成 3 本，不重做首页。
  • 不在首页直接弹出导出设置。

请拍板

1. 已交付回访：主按钮用方案 A「选择照片文件夹」，还是方案 B「打开上一本」？

2. 「待导出」是否包含「导出后内容已改」（现网 stale）？建议包含。

3. 次按钮「选择照片文件夹」是否仍打开现有导入向导，并默认跟最近一本相同身份？建议：默认游记，作品集走向导内切换。

4. 空态「试用示例」是否继续进入现有示例相册？建议是。
