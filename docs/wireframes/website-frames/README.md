# 官网截帧规格（映像高保真）

| 属性 | 内容 |
|------|------|
| **用途** | 把官网换成「本机成册」画面 |
| **原则** | 作品先于功能；标示例 / 本机成册，不假装 UGC |
| **本批册** | `trips/demo-e52494839a` · 斯里兰卡风光精选 · 2018.07.22–08.18 |
| **采集** | `python capture_lanka.py`（需本机 Studio：`python -m travelogue studio` → `127.0.0.1:8766`） |

## 画幅

| 槽 | 画幅 | 裁切 | 不要 |
|----|------|------|------|
| 首屏 Hero | 全幅横图，约 16:9～2.3:1 | 封面同图原片，网站自叠标题 | Studio 顶栏、浏览器壳 |
| 接触印样 · 成屏 | 16:9 横卡 | 只切 `layout-screen` / 封面 | 把 16:9 成屏塞进 3:4 竖卡 |
| 接触印样 · 长图 | 9:16 竖卡 | 册内 `preview.jpg` | 把 9:16 长图塞进扁槽 |
| 跨页 / 拼版 | 16:9 屏或左右对页 | 完整一屏 | 半截滚动 |
| 暗场 / 收束 | 横图原片 | 油灯、晚霞等可叠字 | 可辨认路人作全幅主图 |
| 宁缺格 | — | 空位 | 库存旅拍、AI 生图充数 |
