设计原则

影像即价值证明 不用 stock 图。空态背景 = 真实示例游记的最美一帧；回访态背景 = 你最近一篇游记的封面。
最少 chrome 所有 UI 浮在影像上：顶栏透明、按钮圆角胶囊、文字链替代次级卡片。第一屏只为「看图 + 点 CTA」服务。
状态切换不切布局 空态/回访态/导入中都是同一个全幅 Hero，只换图、文案、CTA，不重排版块，减少视觉断裂。
主 CTA 唯一 每个状态只有 1 个实心按钮（选文件夹 / 继续编辑），其余都做文字链；避免「我该点哪个」。

三态对照

状态背景主 CTA
空态示例游记封面选择照片文件夹
回访你最近游记封面继续编辑
导入同上 + 模糊取消

关键设计决策

  • 大字 H1（72px）：第一眼就传达价值，「你的照片是一本还没装帧的杂志」
  • 杂志衬线：Georgia / Songti SC，不引 Web Font
  • 金色点缀：仅 eyebrow / 强调词，避免泛滥
  • 「向下 · 看看别人做的」：滚动暗示，第二屏是示例画廊
  • 回访态封面优先：第一屏只 1 篇（最近），全部游记在第二屏
  • 导入中保留 Hero：不全屏切换，让用户知道「我还在这」

响应式

宽度布局

481–900Hero 紧凑 · 画廊 1–2 列
901–1280Hero 横排 · 画廊 3 列 · trips 4 列
≥1281同上，内容居中 max 1440

与 v2 的差异

  • 取消多卡片 Bento 布局，回归全幅 Hero
  • 取消拍立得、mini 卡、次级 link 行
  • 背景图升级为「真实精选样例」，非 stock 图占位
  • 导入中保留 Hero 背景，不全屏切到进度卡片
  • 第二屏只放价值证明：示例画廊（空态）/ 全部游记（回访）

待你拍板

  • H1 文案：「你的照片是一本还没装帧的杂志」 vs 其它
  • 空态画廊：3 张精选 vs 滚动瀑布流
  • 样例游记是否真的可点开看完整长图（需要后端 demo trips）
  • 暗色 vs 亮色：现在 Hero 暗、画廊亮，是否统一
