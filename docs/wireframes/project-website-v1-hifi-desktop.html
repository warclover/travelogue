HOW IT IS MADE

一次制作怎么走

Studio 在你自己的电脑上运行。网站只介绍路径，不会让你在这里上传照片。

01

打开工作台

Windows 双击打开。请用 Chrome 或 Edge。手机浏览器不是完整工坊。

02

选这一趟的照片

一次一趟。大约 20～150 张，上限约 250。JPG / PNG / WebP，HEIC 通常可用。

03

等它做完

去重、按时间和地点分章、选封面、杂志排版。默认不必配置模型。

04

预览，而不是立刻重做

先翻一遍。可以删图、改几个字、换封面气质。

05

保存，并确认文件在哪

用「在文件夹中显示」确认落盘。产品不替你发到任何平台。

FAQ

常见问题

照片会上传吗？要注册吗？

默认不上传，也不要注册。处理发生在你的电脑上。

一定要联网吗？

导入、排版、预览、出长图，默认都可以本机完成。

会不会把我的照片变得很「AI」？

不改像素，也不默认生成假风景封面。它做的是编辑。

成品可以给没装这个软件的朋友看吗？

可以。把长图发出去即可。

能导入 RAW / 视频吗？

RAW 请先导出成片。少量短视频可以带，主线仍是照片成册。

收费吗？

当前是种子试用，许可证未对外发布。没有账号墙，也没有试用续费。

ABOUT

旅行记忆的编辑，不是旅行内容的工厂。

它处在相册整理之后、发朋友圈之前。做成之后，你得到的是自己电脑上的文件，不是锁在某个 App 里的帖子。

1. 这一趟做完

旅行结束，照片还在——游记一次做完。

2. 照片留在本机

无需注册。密钥如果以后你自己配，也只存在本机。

3. 先敢发长图

先做出一张敢发的长图，再谈更多能力。

4. 不卖人生系统

我们卖的是这一趟的完工，不是一套要维护的操作系统。

对外介绍能力，只用六条亮点：本机成册、珍贵汇总、一卷一长图、封面像一本、做完再分发、先敢发再谈 AI。可用的本地工具，仍处于种子验证。还不是应用商店里的成熟商品。Windows 优先；默认不推 AI 文案；许可证尚未对外发布。
