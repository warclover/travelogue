产品原则（2026-07-19 拍板）：主路径一次做成——创建→预览→导出；首次生成不主动弹分章确认； Dock 增加「分章」按需入口；分章/精修服务极少数用户。 范围：Dock / 管道状态 / 分章入口 / Task Strip / Help。不改 Sheet 内页、导出 ▾ 内容、Share 栏、长图 job。 纪要：docs/acceptance-records/preview-chrome-unify-v1-product-note-2026-07-19.md
