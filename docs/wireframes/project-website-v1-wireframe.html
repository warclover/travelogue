一次制作怎么走

Studio 在你自己的电脑上运行。网站只介绍路径，不会让你在这里上传照片。

1

打开工作台

Windows 用户双击打开；开发者在本机启动 Studio。请用 Chrome 或 Edge。手机浏览器不是完整工坊。

2

选这一趟的照片

一次一趟，不要把好几年混在一起。大约 20～150 张；上限约 250 张。JPG / PNG / WebP，HEIC 通常可用。RAW 请先导出成片。

3

等它做完

去重、按时间和地点分章、选封面、杂志排版。可以离开，稍后再回来。默认不必配置任何模型或 Key。

4

预览，而不是立刻重做

先翻一遍，看顺不顺、敢不敢发。可以删图、改几个字、换封面气质。不建议第一次打开全部开关。

5

保存，并确认文件在哪

保存长图后，用「在文件夹中显示」确认落盘。产品不替你发到任何社交平台。

常见问题

照片会上传吗？要注册吗？

默认不上传，也不要注册。处理发生在你的电脑上。

一定要联网吗？

导入、排版、预览、出长图，默认都可以本机完成。只有你以后自己配置外部模型时，文案步骤才会访问对应服务。

会不会把我的照片变得很「AI」？

不改像素，也不默认生成假风景封面。它做的是编辑：挑哪些图、怎么分组、怎么排。

成品可以给没装这个软件的朋友看吗？

可以。把长图或导出的图片发出去即可。

能导入 RAW / 视频吗？

RAW 会被拦截，请先导出成片。少量短视频可以带，主线仍是照片成册。

收费吗？

当前是自用与种子试用，许可证未对外发布。没有账号墙，也没有试用续费。

和美图、剪映、Lightroom 有什么不同？

那些工具修单张、剪视频或调色。Travelogue 把一整趟照片做成有章节的册子，并导出能发的长图。

项目自述

旅行记忆的编辑，
不是旅行内容的工厂。

它处在「相册整理之后、发朋友圈之前」。做成之后，你得到的是自己电脑上的文件，不是锁在某个 App 里的帖子。

1. 这一趟做完

旅行结束，照片还在——游记一次做完。

2. 照片留在本机

无需注册。密钥如果以后你自己配，也只存在本机。

3. 先敢发长图

先做出一张敢发的长图，再谈更多能力。

4. 不卖人生系统

我们卖的是这一趟的完工，不是一套要维护的操作系统。
