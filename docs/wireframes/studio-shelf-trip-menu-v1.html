交互规格

DOM 结构调整（实现前置）

  • 网格卡从单一 <button> 改为 <article class="v2-shelf__card">
  • 封面 + 标题区：<button class="v2-shelf__open"> → 打开预览
  • ⋯ + 菜单：独立 <button> + role="menu"，阻止冒泡
  • 新建卡：无菜单 · 保持现有行为

状态机

状态进入退出
idle默认hover / focus-within
menu-visiblehover 封面mouseleave 且 menu 关闭
menu-open点击 ⋯Esc / 外部点击 / 选菜单项
confirm点「删除画册」取消 / 确认完成
deleting点 Modal「删除」API 返回

文案（冻结 v1）

位置文案
菜单项删除画册
Modal 标题删除这本画册？
Modal 正文将移除画册「{title}」及其排版与预览记录。
Modal 说明你电脑上的原始照片不会被删除。之后可以用同一文件夹重新导入。
主按钮删除 / 删除中…
次按钮取消
Toast已删除「{title}」
示例 disabled示例画册无法删除

键盘 / a11y

  • ⋯：aria-label="更多操作" · aria-haspopup="menu"
  • 菜单：role="menu" · 项 role="menuitem"
  • ↑↓ 在菜单项间移动 · Enter 选中 · Esc 关闭
  • Modal：role="alertdialog" · 焦点陷阱 · 默认焦点「取消」
  • Toast：role="status" · aria-live="polite"

Telemetry（建议）

事件触发属性
shelf_menu_open点击 ⋯trip_id, surface (grid|resume)
shelf_delete_confirmModal 点删除trip_id
shelf_delete_success删除成功trip_id, remaining_count
shelf_delete_cancelModal 取消 / Esctrip_id

API（待实现 · M13）

  • DELETE /__travelogue/trips/{tripId}
  • 成功 → 204 · 前端移除卡片 + 刷新 total
  • 失败 → Toast「删除失败，请重试」· Modal 保持可关
  • 仅删 trips/{id}/ 工作区 · 不删用户源照片目录

边界情况

  • 删至 0 本 → hideShelf() · Bento 占满
  • 删 Resume 对应 trip → 重建 Resume 为下一本
  • 网格与 Resume 同一 trip 重复展示 → 删一次两处同步消失
  • 导入进行中（activeJob）→ 该 trip 菜单 disabled「导入进行中」
  • Touch / 无 hover 设备 → ⋯ 常显（低透明度），或 long-press 备选（v1.1）

明确不做（v1）

  • 右下角常驻垃圾桶
  • 批量删除
  • 撤销（Undo）
  • 重命名（留 v2 scope）
  • Mobile / 小程序（归各自 PRD）
