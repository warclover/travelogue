副文替换（定案建议） As-Is：「调整平台与清晰度；点左侧按钮开始导出。」→ To-Be：「选好后点「确定」，再点上方金色按钮开始导出。」
尺寸 Popover min-width：280 → 360；卡片区 grid 1fr 1fr；按钮文案 white-space: nowrap 仅用于 2 段 segmented。
禁止
  • 继续把 4 平台塞进同一条 pill 轨道
  • 靠缩小字号 / 旋转文字「硬塞」
  • 新开平行 Modal 替代 popover（与成功面「禁止第二栈」同精神）
验收（人工）
  • 四平台标签均横排可读，无一字竖排
  • 微信群默认选中；切平台后范围/预期显隐正确
  • 确定后金色 CTA 文案随平台变化（现网行为保留）
  • 窄窗（≈360 视口）卡片不溢出、不裁切中文

F4 · 承接精修「导出」· 完整决策面 必审

精修导出 Tab 中的长图文案范围 / 图注 / 导语控制 AI 文案是否出现在预览与长图成片中， 必须迁入本 Popover 首屏必显，不得弱化进折叠。完整迁出表见精修线框 F6。

现网缺口 当前 ▾（longshot-export-panel.js）只有平台 / 范围 / 清晰度 / 小红书选项； copyDisplay 仅精修导出 Tab（及预览 chip 条）可改 → 合并后 ▾ 必须成为唯一可写决策面。
合并后 Popover 信息架构（自上而下）
  1. 发到哪里 · 2×2 平台卡（方案 A）

  6. 更多输出（折叠）· zip · 文件夹
