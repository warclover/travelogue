v1.1 变更摘要

艺术感升级 全幅摄影 + Ken Burns + 胶片颗粒 + 暗角；左编辑文案 / 右浮起杂志；大衬线 + ISSUE 序号 — 接近 Kinfolk / 摄影展刊首屏。
Web / Mobile 分轨 不是同一布局缩窄，而是不同主路径、不同信息架构：Web 选文件夹；Mobile 上传。

艺术化手段（① 方向）

  • 情绪摄影背景：样张场景图全幅铺底，而非 beige 工具页
  • 编辑式排版：ISSUE 序号、大衬线地名、italic 强调
  • 杂志实体隐喻：透视浮起 + 深阴影 + 可滚动长图
  • 电影感：慢速 Ken Burns、颗粒、暗角、cream 方角 CTA
  • 样张切换：底部缩略条换场景，不换整体布局

结构保留（v1.0 共识）

  • 输出优先：首屏即成品预览
  • 单一主 CTA + 认知支架后置
  • 回访态：书架无 Hero
  • 导入中：背景上下文 + 前景进度

待你拍板

  • Web 左文案是否再缩短？（现在约 2 行 deck）
  • Mobile 封面：样张图 vs 真实长图封面帧
  • 色调：cream/gold 编辑风 vs 回归森林绿
  • Web 路径栏：Dock 常驻 vs 点 CTA 后进 sheet
  • 样张切换：换背景 + 换杂志内容是否要做联动动画
  • 是否需要补 Web/Mobile 导入 sheet 线框衔接 Dock CTA
