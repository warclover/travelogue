Web 预览页封面 · 线框稿 v1.0

对象：data-layout="web" 游记预览 · 示例 trip「雨后京都」· 灰斜纹 = 封面图占位 · 黑标 = data-block

设计目标

Web 预览页的第一屏应像「翻开一本摄影集」——封面图建立情绪，文字层给出语境（去哪、何时、叫什么、为何值得读）。 现状将标题藏在 cover-hero--photo-only、元信息散落在 trip-meta / hook-line，首屏信息断裂。 以下四个方向均在 不新增 data-block 前提下，通过排版组合实现。

方案 首屏完整度 与 manifest 契合 宽屏表现 实现成本 备注
现状 低 · 三截分离 是 图大文小 — screens 模板默认 photo-only
B · 开场 spread ★ 高 · 一屏读完 是 16:9 舞台 + 居中版心 低 推荐：延续 Web「标题在图下」决策
A · 分栏杂志 高 是 ≥1024 最佳 中 编辑感强；窄屏需回退为 B
C · 轻遮罩剧场 高 · 图内收字 部分叠字 电影感 中 接近 mobile 逻辑，Web 略破格
D · 全视窗首屏 最高 需定 100vh 规则 超高屏留白 中 分享态友好；Studio 预览需扣 toolbar 高

数据契约（不变）

cover-hero · 1 张 coverAsset · title ≤24 字 · 禁止正文/视频
trip-meta · 日期 · 地点 · 天数 · 同行（可选）
hook-line · ≤56 字 · 可空
首屏视觉组合 = 上述三块的 CSS 编排；DOM 顺序保持渲染契约。

问题清单

★ 推荐方案

设计要点

  • 信息层级：Place (accent) → Meta → Title → Hook
  • 封面高度：52vh，为文字区留足首屏空间
  • 饰线：48×2px accent，衔接图/文
  • 滚动提示：「进入正文 ⌄」替代空白
  • 编辑态：hook / title 仍走 inline-edit 路径

与 golden 对齐

  • 延续 PRD：Web 标题在图下、浅色底
  • 复用 --font-brush / --font-serif
  • 不破坏 cover-hero--photo-only 语义，仅 Web 显示标题层

方案 A · 分栏杂志

宽屏（≥1024px）左图右文，像杂志跨页。图片抵左出血，文字在右侧竖排居中。窄屏回退为方案 B。
