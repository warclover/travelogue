预览工具栏 v3 · 单栏 + 任务舱 新方案 · 待审核

相对 v1（顶栏堆按钮）、v2 方案 D（双行分区顶栏）、助理式重设计（底部 Tab / FAB）的第三条路： 顶栏永远只有 1 行 · 2 个操作；进度 / 成功 / 待应用排版 → 底部任务舱（按需出现）； 所有编辑能力 → 一个 ⋯ Sheet（4 Tab），不再 3 个独立 drawer。

为何 v1 / v2 / 助理式方案未通过 · v3 设计约束

从现有线框与用户路径反推：80% 用户 = 改标题 → 看一遍 → 导出长图；工具栏不应像 Lightroom 顶栏。

历史方案 做法 未通过原因（推断） v3 对策
现状 / v1 顶栏 8+ 控件 + 多 drawer + 页内 FAB 同屏信息过载；金色语义混乱；反馈分散三处 顶栏 ≤2 操作；金色只绑「导出长图」
v2 方案 D 双行顶栏：模式切换 + 导出区 + 第二行 pending 条 仍占 80px+ 垂直空间；仍像「专业软件」 取消第二行顶栏；pending 进任务舱
助理式 v2 底部 Tab 坞 / FAB 辐射 / 侧栏 Copilot 与桌面 Studio 语境不符；与卷轴阅读冲突；开发面大 保留顶栏返回；任务舱仅临时出现

v3 三条铁律（评审请重点看）

  • 顶栏恒定 48px · 单行：← 返回 · 可编辑标题 · [导出长图] · [⋯] —— 无阅读视图、无文件夹、无放映、无模板名
  • 任务舱 ≠ 工具栏：仅 export running / export done / layout pending 时出现；完成后 8s 自动收起或用户 dismiss
  • 一个 Sheet 收拢全部编辑：文字 · 结构 · 排版 · 高级 —— 替代 edit / structure / cohort 三个 drawer
