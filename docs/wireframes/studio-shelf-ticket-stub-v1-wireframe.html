从参考里借什么

  • 撕边锯齿 — 封面与信息区的物件分界（书架必留）。
  • 纸质票根脚 — 承载地名/年月，替代普通 meta 行。
  • 编号感 — NO.xxxxx 制造「孤本收藏」；可用短 hash。
  • 装饰条码 / 凹口 — 满剂量可选；网格里易脏，默认建议关掉或极淡。

刻意不搬

  • 整卡做成独立纪念票比例（书架要 4 列回访效率）。
  • 锁死米色 + 深棕复古（需跟 --v2-* 主题走）。
  • 可扫真条码 / 过多字母噪音。

审核备注

目标：把书架卡从「文件夹封面」升成「可收藏票根物件」，但不牺牲 4 列回访扫描。

推荐默认

C · 满票根 已定生产

  • 底凹口保留；「新建」仍用虚线空卡

  • Name ← 画册名（单行截断）
  • Meta ← 旅行年月优先；无则用更新月 · N 张
  • NO. ← 旅程短 id / hash（装饰）
