专家推荐结论

  1. 采纳你的构图：全幅摄影 + 右下书名卡 + 右上 Dock（不改为上下分屏）
  2. 优化书名卡：内缩、限宽限高、左边线、实心 A 为默认
  3. Dock：与 PRD-COVER-OPTIMIZATION-V4 Icon Dock 一致
  4. 一屏保障：title/hook 各 2 行 + 卡 max 38vh
  5. 「进入正文」：建议左下全局提示，避免书名卡过高

请你审核的 4 项

  1. 书名卡默认：A 实心 / B 磨砂 / C 贴边？
  2. 「进入正文」放左下还是留在卡内底部？
  3. 右下渐变衬底（corner grad）是否需要？（建议保留，亮图可读性更好）
  4. 宽屏 ≥1280px：书名卡宽度维持 420px 上限，还是略放大？
