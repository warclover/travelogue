> **定位**
>
> V1 已完成「验货默认 + 三区精修 + 更新版面」骨架，但狗粮暴露：**精修模式与精修面板绑死**，导致 ★ / 拼图主能力在真实点击路径上不可达；「这本」把整本与章级意图混装；导出区信息过载；封面候选暴露工程 ID。
>
> 本 PRD **不推翻 V1 铁律**，只做一次**可用性加固**：
>
> 1. **模式 ≠ 面板** — 进入精修后可收起面板，页内 ★ / 拼图仍可用。  
> 2. **情境对齐** — 「这页」管本章与页内；「这本」只管整本与首尾。  
> 3. **导出门面收敛** — 「导出与更多」主区只留导出相关；其余进折叠。  
> 4. **可读性** — 封面缩略图、去工程 ID、减少重复说教。

### 0.1 状态机（MF-01～03 · 已拍板）

| 动作 | 结果 |
|------|------|
| 点 Dock「精修」（验货） | 开面板 + `refine=on` |
| 点 Dock「精修」（面板已开） | **关面板**，`refine` 保持 `on`（toggle panel，**不是**退出模式） |
| Esc / × / 遮罩（面板开） | 关面板，保模式 |
| Esc（面板已关） | **无操作**（不退出模式；退出只走「完成」） |
| 点 Dock「完成」 | `refine=off` + 关面板；若 layoutPending → **一次性非阻断 toast**：「版面还没更新，可稍后在下方更新」；Task Dock **保留** |
| 返回 Studio 首页 | 强制 `refine=off` |

**分词（SF-02）**：「完成」= 退出精修模式；「更新版面」= 消化 layoutPending。二者不得做成同一按钮或同义文案。

mode-chip（MF-04）：默认 **「精修中」**（深底半透明、11px、无脉冲）；「可点 ★」仅 **首次收起面板后** 一次性 tip。验货默认态 **零 chip**。

### 0.2 缩略图视觉规格（MF-05 · 已拍板）

- 比例 **3:4**；圆角 8px；选中：2px accent 描边 +「当前」角标  
- 封面栅格约 3 列；封底 4–5 列；实装用真实候选图 URL（非色块）  
- 默认 UI **无** `asset-` 明文；`title` 可保留 id 供开发者悬停  
- Dock「完成」用 folio 浅描边，**禁止**第二颗金色主按钮；精修态 **禁止**整页暗角/磨砂遮罩  

### 0.3 主题 Go 门禁（MF-06 · 已拍板）

| 里程碑 | Go | No-Go |
|--------|-----|-------|
| **M1** | AC-REFUX-01～03、13～15；**S1 新手脚本**（建议 N≥5，禁止旁白「先关面板」）可标精选；V1 导出拦截不回归；Share 无壳 | 关面板后 ★ 不可见/不可点；或 Esc 误退出模式 |
| **M2** | AC-REFUX-04～08、12、16；UI 无 `asset-` 明文；导出首屏无 zip/LLM | 「这本」仍有章锚点；封面仍是 id 按钮 |

M1 **可独立合入**，不得被缩略图 / 导出收敛阻塞。

## 1. 背景与问题

### 1.1 与 V1 的关系

| | V1（已落地） | V1.1（本主题） |
|--|-------------|----------------|
| 目标 | 重命名、三区 IA、统一「更新版面」、导出拦截 | 修掉落地后不可达路径与情境错位 |
| 不改 | Share 无壳；80% 零精修导出；功能等价 | 同左 |
| 新增铁律 | — | **精修模式可独立于面板存在** |

### 1.2 狗粮摘要（2026-07-14）

| Persona | 关键发现 |
|---------|----------|
| **分享者** | 文案像标签堆砌；引号乱码；「导出与更多」过载；电脑≠手机提示增加不确定 |
| **轻度编辑** | ★ **死胡同**：开面板挡住、关面板隐藏；封面候选显示 `asset-007` |
| **重度编辑** | 「整本故事」混入章锚点/意图；「写给编辑的一句话」黑话；重写文案风险感强 |
| **首次用户** | 三种保存语义仍靠说明书；版式名无缩略预览 |

### 1.3 问题陈述（P-REFUX-*）

| ID | 问题 | 严重度 | 证据 |
|----|------|--------|------|
| **P-REFUX-01** | `onSheetOpened → refine=on` 且 `onSheetClosed → refine=off`；Sheet 拦截 pointer | **P0** | 关面板后 ★ `display:none`；开面板时 `.preview-sheet__body` 挡住点击 |
| **P-REFUX-02** | 「这页」引导用户去点画面控件，但面板盖住画面 | **P0** | 「滚动到正文屏」后仍不可点 ★ |
| **P-REFUX-03** | 章级意图/锚点放在「整本故事」 | **P1** | 封面态「当前章：—」；整本/本章心智冲突 |
| **P-REFUX-04** | 封面/封底候选按钮文案为 `asset-xxx` | **P1** | 无视觉辨识 |
| **P-REFUX-05** | 「导出与更多」堆叠 zip / 放映 / LLM / 阅读视图 | **P1** | 分享者认知过载 |
| **P-REFUX-06** | 「更新版面」说明在同一面板重复 3 次，Task Dock 不醒目 | **P1** | 说教 > 行动 |
| **P-REFUX-07** | 「写给编辑的一句话」等工程/内部措辞 | **P2** | 非开发者不懂对象是谁 |
| **P-REFUX-08** | 封面版式名无预览；电脑/手机差异只警告不提供对照 | **P2** | 不敢定稿 |
| **P-REFUX-09** | 引号乱码 / 标签式导语伤害验货第一印象 | **P2** | 内容质量，跨主题 |

### 1.4 核心判断

> **精修是一种模式，面板是模式里的工具箱。**  
> 用户需要「看得见改、改得了、收得起工具箱继续改」，而不是「打开工具箱才能看见改的控件，但工具箱又挡住要改的东西」。

## 2. 目标与非目标

### 2.1 产品目标

| ID | 目标 | 验收口径 |
|----|------|----------|
| **G-REFUX-01** | ★ / 拼图可达 | 进入精修后收起面板，可完成标精选；无需开发者强制点击 |
| **G-REFUX-02** | 模式可感知 | Dock 显示「完成」退出；chip「精修中」；验货默认无 chip |
| **G-REFUX-03** | 情境对齐 | 章锚点/意图只在「这页」（有当前章时）；「这本」无「当前章：—」 |
| **G-REFUX-04** | 封面可读 | 候选为缩略图；默认 UI 无 `asset-` 字样 |
| **G-REFUX-05** | 导出区收敛 | 「导出与更多」首屏 ≤ 1 屏关键导出控件；其余折叠 |
| **G-REFUX-06** | 待办收敛 | layoutPending 时 Task Dock 一条主 CTA「更新版面」；Sheet 内不再三连说教 |
| **G-REFUX-07** | 不回归 V1 | AC-REF-01～12、Share、零精修导出仍通过 |

### 2.2 非目标

- 不重做排版 / narrate / bookends 算法  
- 不在本主题全面治理文案质量（P-REFUX-09 单独立项或并入 Copy Gate）  
- 不把阅读视图上 Dock（沿用 V1 PK-03）  
- 不合并首页「导入偏好」进预览精修  
- 不引入全新富文本编辑器  
- 不做移动端独立 App；仅保证桌面预览可用 + 保留手机差异诚实提示（可增强对照入口）

### 2.3 成功指标（建议）

| 指标 | 目标 |
|------|------|
| 标精选任务完成率（新手脚本） | ≥90% 无需帮助文档 |
| 「找不到 ★」可用性访谈 | → 0（样本 ≥5） |
| 打开「导出」Tab 后 5 秒内找到清晰度 | ≥80% |
| V1 回归 AC | 100% |

## 3. 用户与任务

### 3.1 Persona（沿用 + 细化）

| Persona | 占比 | V1.1 主路径 |
|---------|------|-------------|
| **分享者** | ~80% | 不进精修；点字微调；长图导出 |
| **轻度编辑** | ~15% | 进精修 → 收起面板 → ★ / 换封面 → 更新版面 → 导出 |
| **重度编辑** | ~5% | 这页改意图 → 重写文案 → 进阶模板/分章 |

### 3.2 关键任务脚本（评审用）

| 脚本 | 步骤 | 失败即 No-Go |
|------|------|--------------|
| **S1 标一张精选** | 打开精修 → 收起/完成前可操作 → 点 ★ → Task Dock 出现更新版面 | ★ 不可点 |
| **S2 换封面** | 这本 → 首尾装帧 → 点缩略图 → 封面变化 | 只能靠 `asset-id` 猜 |
| **S3 改本章感觉** | 滚到某章 → 这页 → 填锚点/情绪 → 重写（确认） | 必须在「整本」里找章字段 |
| **S4 分享者导出** | 不开精修 → 长图 | 被逼进「导出与更多」 |

## 4. 设计原则

1. **模式持久，面板可收** — 工具箱不能挡住工件。  
2. **一种保存语义不变** — 字立即生效；版面类进「更新版面」。  
3. **行动优于说明书** — 少重复 hint，多固定 CTA。  
4. **对人说人话** — 禁止默认暴露 `asset-id`、内部角色称呼。  
5. **主路径不膨胀** — 80% 仍可不打开精修。  
6. **诚实差异** — 电脑/手机版式不同可以说，但要给「看手机效果」出口（若已有则强化发现性）。

## 5. 信息架构

### 5.1 Dock（精修相关）· 已拍板

| 状态 | Dock 按钮文案 | `aria-*` | 点击行为 |
|------|---------------|----------|----------|
| 验货（默认） | 「精修」 | `aria-expanded=false`；模式 off | 开面板 + `refine=on` |
| 精修中 · 面板开 | 「精修」 | `aria-expanded=true`；建议另用 `aria-pressed=true` 表示模式 on（SF-04） | **关面板**，保模式 |
| 精修中 · 面板关 | **「完成」**（folio 浅描边，非金色） | `aria-expanded=false`；`aria-pressed=true` | `refine=off` + 关面板 |
| 有 layoutPending 时点「完成」 | 同上 | — | 允许退出；一次性 toast（§0.1）；Task Dock 保留 |

退出文案 **已拍板**：「完成」（不用「退出精修」）。

**a11y（SF-04）**：模式开闭用 `aria-pressed`（或等价）；面板开闭用 `aria-expanded`——二者不得混用同一语义。

### 5.2 侧栏三区（重组）

| Tab | 管什么 | 不管什么 |
|-----|--------|----------|
| **这页** | 当前屏情境：封面空态引导；正文屏：本章名、锚点、章意图、★/拼图镜像与说明 | 杂志名、封面版式、模板 |
| **这本** | 杂志名、给游记的一句话（原 userNotes）、首尾装帧、封面版式、进阶（模板/同框/分章） | 章锚点、章意图 |
| **导出** | 导出设置入口、长图文案范围、清晰度、范围（章/完整） | zip / 文件夹 / LLM / 放映 → 「更多工具」折叠 |

Tab 显示名（**已拍板 D4**）：

- 保持「这页 / 这本」  
- 「导出与更多」→ **「导出」**（折叠区标题用「更多工具」）  
- 「打开导出设置」与 Dock ▾ **必须同 prefs 单源**（SF-03）

### 5.3 「整本故事」字段重命名

| 现文案 | 新文案 | 说明 |
|--------|--------|------|
| 写给编辑的一句话 | **给这本游记的一句话** | 对象是游记，不是「编辑」这个角色 |
| 按新意图重写文案 | 仍用；必须二次确认（V1 已有） | 按钮迁到「这页」章节块底部 |

## 6. 关键交互规格

### 6.1 P0 · 模式与面板解耦（D-REFUX-01）· **已拍板**

**现行（缺陷）**

```
open sheet  → refine=on
close sheet → refine=off   ← ★ 消失死胡同
```

**目标（已拍板）**

```
open sheet / 点「精修」(验货)     → refine=on + panel open
close / Esc / × / 再点「精修」     → panel close, refine 保持 on
Dock「完成」 / 返回首页            → refine=off + panel close
```

**细则（取代原稿「推荐」措辞）**

| 项 | 规格 |
|----|------|
| Esc | 面板开→关面板；**面板已关→无操作**（MF-02） |
| 点击遮罩 | 同 Esc（关面板，保模式） |
| Dock「精修」面板开时再点 | 关面板保模式（MF-01） |
| ★ / 拼图可见性 | 仅看 `data-preview-refine=on`，与 panel open 无关 |
| 面板形态 | **方案 A（已选）**：现有 Sheet，关后全画面可点；半高面板 **Park（PK-01）** |
| 模式提示 | chip「精修中」；首次收起后一次性「可点 ★」tip（MF-04）；验货默认零 chip |

**线框**：面板 ②③。

### 6.2 P0 · 「这页」可达路径（D-REFUX-02）

| 当前屏 | 「这页」内容 |
|--------|--------------|
| 封面/封底 | 保留空态：「你在看封面」+「滚动到正文」+「去调封面与封底」；**增加**「收起面板，在画面上标精选」主按钮（执行关面板、保模式） |
| 正文屏 | 显示本章名；锚点 0–3；章意图折叠；「按新意图重写文案」；★/拼图操作说明改为：「直接在照片上点 ★；需要改设置时再打开本面板」 |

### 6.3 P1 · 「这本」净化（D-REFUX-03）· **已拍板 D2/D3**

「整本故事」仅保留：

1. 杂志名  
2. 给这本游记的一句话  
3. （可选）一键「同步杂志名到封面」若有需要  

移除：当前章、锚点、章意图、★ 说明书三连。

**迁移提示（SF-01 / D2）**：字段迁出后，用户首次打开「这本」时（localStorage 一次）：提示「章节锚点与意图已移到「这页」」。

「首尾装帧」：

- 候选：**缩略图按钮**（规格 §0.2）；`aria-label` 可用友好名或「候选 1」；`asset-id` 仅 `title`  
- 「看封面 / 看封底」必须有明确按钮样式（pointer + 主/次层级）  
- 版式切换：保留文案说明；迷你预览 **Park（PK-02）**

### 6.4 P1 · 导出 Tab 收敛（D-REFUX-04）· **已拍板 D4**

**首屏（默认展开）**

1. 打开导出设置（与 Dock ▾ **同 prefs 单源** · SF-03）  
2. 长图文案范围：纯照片 / 完整文案 · 图注 · 导语  
3. 导出范围：按章 / 完整  
4. 清晰度：标准 2× / 高清 3×  

**折叠「更多工具」**

- 预览显示：编辑预览 / 阅读视图  
- 在文件夹中显示  
- 导出 zip  
- 放映精选  
- 生成杂志感文案（LLM 不可用时：**禁用 + 原因**「当前未配置写作引擎」）

### 6.5 P1 · Task Dock 与说教收敛（D-REFUX-05）

| 场景 | UI |
|------|----|
| layoutPending | Task Dock 固定一条：「版面有改动」主按钮「更新版面」 |
| 点「完成」且仍 pending | 一次性 toast：「版面还没更新，可稍后在下方更新」（MF-03）；**不**清 pending |
| Sheet 内 | 全局脚注最多 **1** 句；删除「整本故事」内三连 hint |
| 成功更新 | 短 toast 或 Task Dock 消失；不刷屏 |

### 6.6 P2 · 手机对照（D-REFUX-06）

- 封面「手机封面」折叠默认打开一次（首次）或提供「预览手机效果」按钮滚到已有手机预览区  
- 双栏实时对照 **Park（PK-03）**

### 6.7 P2 · 文案乱码（D5 · 已拍板可顺带）

- 修复 pull quote 引号编码（`\x81C`）可随 M3 小 PR 带上  
- 标签式导语 / 内容质量全面治理 **Park（PK-04）** → Copy Gate 另项

## 7. 状态机（已拍板）

```
[验货 refine=off]
    │ 点「精修」
    ▼
[精修中 · 面板开] ──Esc / × / 再点「精修」──► [精修中 · 面板关] ──点「完成」──► [验货]
    ▲                                         │ Esc
    └──────────── 点「精修」──────────────────┘ （无操作）
```

- 返回首页：任意精修子态 → 验货（强制 `refine=off`）  
- layoutPending 可存在于精修中任意子态；导出拦截逻辑沿用 V1  
- G1 > layoutPending > longshotStale 优先级栈沿用 V1（D-REF-18）
