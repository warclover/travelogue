## 0. 一句话

在**不拆掉现有游记版式统一感**的前提下，仅把算法/AI 选出的**高光时刻**（含「决定性瞬间」）做成克制的布展呈现，使观者仍觉得自己在读同一本游记，同时认同：**这一张是旅程中最好的纪念之一**。

---

## 1. 背景与意图

### 1.1 我们要同时满足的两种期待

| 期待 | 含义 |
|------|------|
| **照片小说（廊道态）** | 连续叙事、时间往前、版面统一和谐 |
| **摄影展（展室态）** | 少数画面被郑重对待，值得停顿凝视 |

### 1.2 已验证的教训（来自装裱分级试验）

对全书屏做多级装裱（换底、缩宽、黑匣、角标）时，主观感受是：

- 变化不一定更动人；
- **统一和谐被破坏**，往往不如原版。

结论：**展室感不能靠给每屏换皮肤**；特权必须稀疏，且必须长在「同一种纸面」上。

### 1.3 本需求的核心转向

| 旧思路（已降级） | 新思路（本说明） |
|------------------|------------------|
| 为多数屏分配装裱等级 | **只有高光集合**进入展室态 |
| 用样式制造「作品感」 | 用**选得准 + 出现得少 + 轻布展**制造认同 |
| 廊道/展室 = 两套视觉语言 | 廊道/展室 = **同一游记语法上的能量差** |

---

## 2. 产品原则

| ID | 原则 | 说明 |
|----|------|------|
| **HGM-PR-01** | 游记为底 | 非高光屏 **100% 保持现有游记样式**，不借机改全局间距体系 |
| **HGM-PR-02** | 高光才布展 | 展室态 ⊆ 高光系统产出（签名时刻 / 高光池）；禁止「想布展就强行加冕」 |
| **HGM-PR-03** | 同纸面加重 | 布展只做留白、独屏、题签、EXIF、前后缓冲；**不换材质家族**（无默认黑匣、无大相框、无卡片阴影） |
| **HGM-PR-04** | 稀缺即权威 | 签名全书 ≤1；厅内高光严格配额；连续高光禁止 |
| **HGM-PR-05** | 三层证据 | 认同来自「选得对 → 放得对 → 看得重」；样式只是第三层 |
| **HGM-PR-06** | 两种音色 | 签名可略郑重；厅内高光更克制，避免张张像营销角标 |
| **HGM-PR-07** | 结构复用 | 沿用「章=展厅，屏=墙面作品，组=连作」；不新增平行信息架构 |

---

## 3. 结构隐喻（沿用三级）

```text
游记整卷
├── 章 = 展厅
│   ├── 组（连作）     → 现有样式 · 廊道推进
│   ├── 普通墙面屏     → 现有样式 · 廊道推进
│   ├── 厅内高光屏     → 现有样式 + 轻布展 · 展室态（稀）
│   └── 章门 plate     → 现有章首（默认不是高光）
└── 决定性瞬间         → 轻布展最强档 · 全书唯一镇厅之作
```

**廊道态**：连作 + 普通屏（主体篇幅）。  
**展室态**：仅高光屏（含签名）；仍在展厅叙事动线之内，不是外挂画廊页。

---

## 4. 范围与依赖

### 4.1 本需求负责

- 定义谁有资格进入展室态（与 P23 高光模型对齐）；
- 定义「轻布展」的视觉/编辑变量与禁区；
- 定义配额、位置、前后缓冲、读者认同目标；
- 定义与封面 / 章门 / 封底的职责边界。

### 4.2 本需求不负责（但强依赖）

| 依赖 | 说明 |
|------|------|
| **P23 选型与池** | 高光池、签名 `moment`、次高光 `peak`、EXIF 数据 |
| **高光能力完善** | 选得准、可解释、Studio 可换；**弱选型时不应先上重样式** |
| **现有游记渲染** | 非高光路径行为保持不变 |

### 4.3 非目标

- 不为全书引入多级装裱皮肤（L0–L3 读者面默认语言）；
- 不把章门 plate、封面、封底改造成高光布展；
- 不要求每章必须有高光；
- 不做「另一套网格/模板系统」专供高光；
- 不在 V1 强制凝视交互（可作为后续增强）。

---

## 5. 角色定义

### 5.1 谁可以进入展室态

| 角色 | 来源（P23） | 布展档 | 配额 |
|------|-------------|--------|------|
| **签名时刻** | `data-role="moment"` / `momentAssetId` | **A · 签名布展** | 全书 0–1 |
| **厅内高光** | `data-role="peak"` 或高光池内非签名项 | **B · 厅内轻布展** | 建议每章 0–1；全书稀疏 |
| **非高光** | 其余所有正文屏 | **无布展** | — |

> 若某屏「看起来很适合布展」但不在高光集合：应回到选型，不在本需求开后门。

### 5.2 与其它图位的边界

| 图位 | 职责 | 与高光布展关系 |
|------|------|----------------|
| 封面 | 邀请进门 | 不做展室态；资产尽量与签名去重 |
| 章门 plate | 进入展厅 | 默认廊道语法；不自动升为高光 |
| 签名时刻 | 全书纪念锚点 | 展室态 A |
| 厅内高光 | 厅内值得停的一张 | 展室态 B |
| 封底 | 辞别收束 | 不做展室态 |

## 6. 轻布展规格（讨论基线）

> 原则：读者应感到「还在读这本游记，但这页被多看重了一点」。

### 6.1 允许的变量（V1 候选）

| 变量 | 签名（A） | 厅内高光（B） | 说明 |
|------|-----------|---------------|------|
| **V1 舞台** | **必须独屏** | **默认独屏**；[HPPL](./PRD-HIGHLIGHT-POOL-PORTRAIT-LAYOUT-V1.md) 开启时，**次要竖版**允许整屏 `screen-portrait-2/3` 作为厅内舞台 | 签名禁止进拼图；厅内竖拼仍属高光管线成屏，**禁止**塞进非高光 mosaic/组图主槽（HPPL D-HPPL-10） |
| **V2 额外气口** | 中–强 | 弱–中 | 同色纸面上下多留白；不改全局非高光间距 |
| **V3 题签/角标** | 「决定性瞬间」可保留 | 默认无口号；可极淡地点/日期 | 避免张张营销腔 |
| **V4 EXIF** | 展示 | 展示（随 P23） | 专业纪念感的一部分 |
| **V5 前后缓冲** | 需要 | 需要 | 前：连作尾或轻停；后：廊道余波；禁止两高光相连 |

### 6.2 明确禁止（默认）

- 黑场切页 / 黑匣作为默认签名样式；
- 大相框、厚描边、卡片投影、圆角海报化；
- 高光使用与正文不同的网格体系；
- 非高光屏被连带改底色或缩宽；
- 连续两屏均为展室态。

### 6.3 「不突兀」的验收语感

观者应能说出类似：

- 「这还是同一本游记。」
- 「但这一张明显更被看重。」
- 「我愿意相信这是旅途里最好的纪念之一。」

不应说出：

- 「突然进了另一个模板网站。」
- 「每张好图都在喊口号。」

## 7. 编辑与动线要求

### 7.1 放得对（位置）

| 偏好 | 回避 |
|------|------|
| 章中后段、情绪峰、发现之后的定格 | 章门凑数、纯说明性组图位 |
| 签名承担全书句号感之一 | 签名紧贴另一高光 |
| 厅内高光被连作母题轻轻托住（回声） | 高光前后视觉完全断裂、像硬插入广告 |

### 7.2 章内示意（非强制模板）

```text
厅门 plate（现有）
→ 连作 / 普通墙面（廊道）
→ 厅内高光（轻布展 B，可选）
→ 廊道余波
→ …（可有换气）
→ （全书某处）签名时刻（布展 A）
```

### 7.3 配额纪律（提案）

| 项 | 提案 |
|----|------|
| 签名 | ≤1 / trip；无 moment 则不为了布展而人造签名 |
| 厅内高光 | ≤1 / chapter；小册可 0 |
| 相邻 | 任意两展室态之间至少隔 1 个廊道屏（或等价缓冲） |
| 总密度 | 展室态屏数建议 ≤ 内容屏约 15%（讨论用，可调） |

## 8. 目标与成功标准

### 8.1 目标

| ID | 目标 |
|----|------|
| **G-HGM-01** | 非高光阅读体验与现版游记观感一致（和谐不回退） |
| **G-HGM-02** | 高光屏在无调试角标时可被多数观者识别为「更被看重」 |
| **G-HGM-03** | 观者认同签名/高光「像旅途最好的纪念之一」的比例高于现版弱化呈现 |
| **G-HGM-04** | 不出现「PPT/卡片网站/换肤」主诉 |
| **G-HGM-05** | 与 P23 字段/角色一一对应，Studio 可解释「为何这张被布展」 |

### 8.2 定性验收（讨论用）

| ID | 口径 |
|----|------|
| **AC-HGM-01** | 并排 现版 vs 本方案：非高光段「统一和谐」不下降 |
| **AC-HGM-02** | 盲指「哪一张最像被单独布展」：命中签名或厅内高光 ≥ 70% |
| **AC-HGM-03** | 「是否仍像连续游记」均分不低于现版 |
| **AC-HGM-04** | 「是否突兀」负向提及 < 20% |

## 10. 开放问题（供下一轮讨论）

| ID | 问题 | 备选倾向 |
|----|------|----------|
| **OQ-HGM-01** | 厅内高光是否必须来自 P23 池？ | 倾向：必须，保持「选得准」 |
| **OQ-HGM-02** | 签名是否允许极克制暗场？ | 倾向：V1 默认否；作可选实验开关 |
| **OQ-HGM-03** | 气口数值多少才「重」而不「跳」？ | 待并排小样（仅高光加减气口） |
| **OQ-HGM-04** | 厅内高光要不要一行题签？ | 倾向：默认无；签名保留决定性瞬间 |
| **OQ-HGM-05** | 高光能力未完善前，是否上线轻布展？ | 倾向：否，或仅签名 + 极弱气口 |
| **OQ-HGM-06** | 凝视模式（停驻再加重）是否进范围？ | 倾向：V1 不做，记为增强 |
| **OQ-HGM-07** | 微信长图导出时高光气口是否加大？ | 倾向：可略增，仍同纸面 |

## 11. 建议的讨论顺序

1. 认可本说明的原则与范围（§2–§4）  
2. 拍板角色与配额（§5、§7.3）  
3. 收敛轻布展变量：A/B 各启用哪几项（§6）  
4. 再决定是否做静默小样（只动高光，不动其余屏）  
5. 高光选型强化与呈现强化的优先级排序

## 12. 多方评审摘要（2026-07-20）

完整纪要：[acceptance-records/hgm-multi-persona-review-2026-07-20.md](./acceptance-records/hgm-multi-persona-review-2026-07-20.md)

**五方一致倾向**：方向成立；同纸面；选型先行；OQ-01 必须来自池；OQ-02 暗场默认否；OQ-04 厅内无口号；OQ-05 选型弱不上重样式；OQ-06 凝视不做；OQ-07 长图略增气口。

**跨角色最大风险**：选错图仍郑重布展；EXIF/「决定性瞬间」对家庭用户偏矫情；黑底 EXIF 与同纸面冲突。

**MVP 倾向**：先修 breath → 仅签名 A 档小样 → 池达标后再开厅内 B。
