> **定位**
>
> RCI **不推翻**精修顶栏三区（封面｜页面｜画册），只做一次封面侧信息架构升档：  
> 把「换封面/封底照片 · 换封面版式 · 改杂志名并生成字体」从长滚动抬到**封面 Tab 内醒目二级分段**，并**去掉画册 Tab 与封面的重复入口**。
>
> **一句话目标**：用户打开精修看封面时，三件事一眼可见、一键可达；先改名再出字体在同一段完成；画册只留整本叙事与气质。

### 0.1 术语

| 术语 | 含义 |
|------|------|
| **顶栏三区** | 精修 Sheet 一级 Tab：`封面`｜`页面`｜`画册`（现行已落地，本主题保持） |
| **二级分段** | 仅在「封面」Tab 内展示的子导航：`照片`｜`版式`｜`杂志名` |
| **封面版式** | Opening 风格（雾底题签 / 对页叠印 / 断带题签等），**不是**成册风格 |
| **成册风格** | Layout vibe（整本页面气质），留在「画册」 |
| **杂志名** | `meta.title`（展示名合同见 CAL）；用户可见字段名统一用「杂志名」 |
| **字体 / 生成字体** | 封面艺术字贴纸（title-art · 路线 B 字库 / 路线 C AI 手写体）；**用户文案禁用「装帧字」** |
| **弱链** | 非主入口的跳转按钮/文案，用于从画册回到封面 · 杂志名 |

### 0.2 相邻边界

| 主题 | RCI 拥有 | RCI 不碰 |
|------|----------|----------|
| **Refine V1 / V1.1** | 封面 Tab 内 IA 与画册去重；情境默认子段 | 不改模式≠面板；不改 Dock「完成」；不恢复导出 Tab |
| **CCF** | 版式分段承载主菜 Opening 切换 UX | 不改主菜集合、CSS craft、选图策略 |
| **CAL** | 把「生成字体」与改名并入同一子段；文案用人话 | 不改路线 B/C 算法、OCR、白名单 |
| **Bookends** | 「照片」分段内保留封面/封底切换与候选栅格 | 不改 repick API / 冲突确认语义 |

### 0.3 评审拍板摘要（2026-08-11 · 线框 v1.2）

| 议题 | 结论 |
|------|------|
| 是否拆成 5 个一级 Tab | **否**。保持三区；封面内二级分段 |
| 二级文案 | **照片｜版式｜杂志名**（副文案：封面/封底 · 样式 · 改名·字体） |
| 「标题」vs「名称」vs「杂志名」 | 用 **杂志名**；不用单字「名称」或「标题」 |
| 「装帧字」 | **禁用**；用户侧改称 **字体**（按钮「生成字体」） |
| 杂志名段能力 | **改名 + 生成字体**一条流；主入口在封面 |
| 画册去重 | **删除**杂志名输入；保留一句话 / 成册风格 / 署名 / 进阶；底栏弱链 |
| 成册风格 vs 封面版式 | **不合并**；两边文案互相指明差异 |
| 封底 | 仍挂在「照片」内封面/封底切换，不占一级或二级 |
| 顶栏「封面」是否改「装帧」 | **暂不改**（OQ-RCI-01） |

## 1. 背景与问题

### 1.1 现行结构（改前）

| 一级 Tab | 内容（摘要） |
|----------|----------------|
| **封面** | 封面/封底分段 + Bookends 合页候选 + 封面版式卡片 + 装帧标题（title-art）——**长页下滚** |
| **页面** | 本页精选 / 拼图 / 章字段等 |
| **画册** | 成册风格 + 整本信息（**含杂志名** · 一句话 · 文案）+ 作品署名 + 进阶 |

### 1.2 问题陈述（P-RCI-*）

| ID | 问题 | 严重度 | 证据 / 说明 |
|----|------|--------|-------------|
| **P-RCI-01** | 封面三件事埋在长滚动，装帧字体发现率弱 | **P0** | 产品 2026-08-11 反馈；需下滚才见「生成装帧标题」 |
| **P-RCI-02** | 改杂志名在「画册」、生成字体在「封面」，任务链断裂 | **P0** | 用户期望先改名再出字体；两 Tab 往返 |
| **P-RCI-03** | 若直接拆 5 个一级 Tab，窄栏拥挤且拆碎连做任务 | **P1** | 线框评审否决五 Tab；推荐二级分段 |
| **P-RCI-04** | 「装帧字 / Opening」等词用户难懂 | **P1** | 评审改为「字体」「样式」 |
| **P-RCI-05** | 画册与封面在杂志名上双入口，维护与心智重复 | **P1** | 去重后画册不再放杂志名表单 |
| **P-RCI-06** | 「成册风格」与「封面版式」易被当成一回事 | **P2** | 需双向文案边界，不合并控件 |

### 1.3 与换封面忙态的关系

同日已落地 **Companion 修复**（非本 PRD 主范围，但同属精修封面体验）：换封面/换版式时封面脸遮罩 + chip「更新中」+ 版式卡「更新中」，忙态保持到 rerender 完成（见 §8）。RCI 实施时应复用该忙态，避免版式分段切换时再次「点了没反应」。

## 3. 冻结决策（D-RCI-*）

| 编号 | 决策 | 说明 |
|------|------|------|
| **D-RCI-01** | 顶栏保持 **封面｜页面｜画册** | 不采纳五一级 Tab；四 Tab 备选不作为 V1 默认 |
| **D-RCI-02** | 封面内二级分段：**照片｜版式｜杂志名** | 分段控件始终钉在封面 Tab 内容区顶部（随一级切走而隐藏） |
| **D-RCI-03** | 副文案：**封面/封底** · **样式** · **改名·字体** | 短词优先；禁用「装帧字」「Opening」对用户文案 |
| **D-RCI-04** | 「杂志名」= 改名主入口 + 生成字体 | 字段仍写 `meta.title`；生成仍走既有 `/title-art/resolve` |
| **D-RCI-05** | 用户按钮文案：**生成字体** / **重新生成字体** | 替代「生成装帧标题」；勾选仍可用「优先 AI 手写体」 |
| **D-RCI-06** | 改名后若已有贴纸：标 `titleArt.stale`（沿用 CAL），UI 提示「杂志名已改 · 旧字体已过期，请重新生成」 | 禁止继续展示旧文案贴纸而不提示 |
| **D-RCI-07** | 画册 **删除**杂志名输入框与「改名字」主引导 | 引导改为「改一句话与成册风格。杂志名与封面字体在「封面」。」 |
| **D-RCI-08** | 画册保留：一句话、成册风格、作品署名、进阶（折叠） | 底栏弱链「去改杂志名 / 字体」→ `封面` + 子段 `杂志名` |
| **D-RCI-09** | 成册风格文案必须写清「影响整本页面气质，不是封面第一眼样式」；封面版式文案写清「不是成册风格」 | 双向互指 |
| **D-RCI-10** | 封底继续用「照片」内封面｜封底切换 | 与 Bookends 现网一致 |
| **D-RCI-11** | 版式切换须接入既有换封面忙态（遮罩 / chip「更新中」/ 卡片「更新中」） | Companion 已落地；RCI 接线时不得回退 |
| **D-RCI-12** | 线框 SSOT：`preview-refine-cover-subseg-v1-wireframe.html` v1.2+ | 实现以线框 + 本文为准 |

## 5. 「杂志名」段：改名 → 生成字体

### 5.1 用户流

```
打开 封面 · 杂志名
  → 编辑杂志名（≤20 字；提示字体效果宜更短）
  → 保存名称（写 meta.title；若有旧贴纸 → stale 黄条）
  → （可选）勾选「优先 AI 手写体」
  → 点「生成字体」
  → 状态：字库合成 / AI 手写体 / 失败回退说明（沿用 CAL 归因）
```

若点击「生成字体」时输入相对已保存值有未保存改动：先保存再生成（线框行为；实现应一致，避免生成旧名）。

### 5.2 字段与 API

| 项 | 规格 |
|----|------|
| 字段 | `meta.title`（与画册原「杂志名」同源） |
| 保存 | 既有 `save-copy` / `saveMagazineTitle*` 路径；须继续触发 `mark_title_art_stale`（AC-CAL-09） |
| 生成 | `POST .../title-art/resolve`；`routeC` 仅当勾选且 config 允许 |
| 展示 | 成功后预览 reload / 局部刷新与现网一致 |

### 5.3 文案对照（改前 → 改后）

| 位置 | 改前 | 改后 |
|------|------|------|
| 二级标签 | （无；埋在长页） | **杂志名** |
| 副文案 | — | **改名·字体** |
| 主按钮 | 生成装帧标题 | **生成字体** / **重新生成字体** |
| 说明 | 装帧标题 / 艺术字贴纸… | 先改名再生成封面字体；不生成风景图 |
| stale | （弱或无独立黄条） | **杂志名已改 · 旧字体已过期，请重新生成** |
| 工程词 | Opening / 装帧字 | **不对用户展示** |

### 5.4 与 AI Sheet 的关系

若 AI Sheet 仍有「装帧标题」入口：本主题实施时应 **同步文案为「字体」**，并优先深链到精修「封面 · 杂志名」（OQ-RCI-03：是否保留 AI Sheet 重复入口）。

## 6. 「画册」去重规格

### 6.1 删除

| 删除项 | 原因 |
|--------|------|
| 杂志名输入框（`openEmbed("edit")` 中的杂志名，或等价字段） | 主入口迁至封面 · 杂志名，避免双写 |
| 引导「改名字与一句话」 | 改为不再强调改名 |
| 「整本信息」摘要里把杂志名列为画册主能力 | 摘要改为「一句话 · 文案」等 |

> **实现注意**：若 `edit` embed 杂志名与一句话耦合在同一抽屉模板，须拆分或参数化，使画册只嵌「一句话」相关控件，杂志名只在封面 · 杂志名挂载。

### 6.2 保留（顺序）

1. **引导**：改一句话与成册风格。杂志名与封面字体在「封面」。  
2. **给这本画册的一句话**  
3. **成册风格**（文案：影响整本页面气质，不是封面第一眼样式；互指「封面 · 版式」）  
4. **作品署名**  
5. **进阶**（折叠：阅读视图、放映、换模板、同框、分章说明等）  
6. **底栏弱链**：`去改杂志名 / 字体` → 切换到封面 + 杂志名子段  
7. 辅文：换封面/封底 → 「封面 · 照片」

### 6.3 成册风格 ↔ 封面版式边界文案（必现）

| 位置 | 必含语义 |
|------|----------|
| 画册 · 成册风格 | 「不是封面第一眼样式」+ 指向「封面 · 版式」 |
| 封面 · 版式 | 「不是成册风格」+ 指向「画册 · 成册风格」 |

## 7. 情境默认与深链

| 触发 | 打开精修后落点 |
|------|----------------|
| 预览焦点在封面图 / 用户点封面英雄区 | `封面` + `照片`（opening） |
| 预览焦点在封底 | `封面` + `照片`（closing） |
| 点封面书名区 / 标题贴纸 | `封面` + `杂志名` |
| 从「经典提示 / 版式」类入口进入 | `封面` + `版式` |
| 正文页 | `页面`（不变） |
| 画册弱链「去改杂志名 / 字体」 | `封面` + `杂志名` |

深链 API 建议（实现期）：Sheet `open({ tab: "cover", coverSeg: "photo"|"style"|"name", bookendsFocus?: "opening"|"closing" })`。
