## 0. 一句话结论

现网画册会「把合格照片装进合格拼图」，还不会「这一本为什么这样翻」。按 4 的倍数预编册型，是把用量均衡的拼图序列升成有章法的杂志。真正拉开差距的不是表里写了哪些模板 ID，而是**纲领配额、对页关系、密度呼吸，以及补页绝不能随机**。

拼图 / 朝向硬门 / 书衣 / 裁切失败链不动。主编层只负责选页任务与排序。

---

## 1. 现网缺口（As-Is）

画册出口已是可用的 ECC 管线：28 套封闭 3:4 卡 + 供给感知 CardGrouper + 两卡成跨页 + ABE 书衣。

| 维度 | 现网 | 缺什么 |
|------|------|--------|
| 页数 | UI 预设 4/8/12/16 跨页；自动 `~photos/8` 后向上取 4 的倍数，clamp 到 28（profile max 30） | 无 20/24/32 档；无「选档 → 填内容」orchestrator |
| 选型 | 朝向硬门 + 供给比例 + `target_per_card` 软偏置 + 用量均衡 + 相邻禁同模板 | 无 opener/hero/grid/breath 配额与顺序 |
| 成册 | 线性卡序列两两切开；不再按章分页 | 无跨页叙事、无密度曲线 |
| 角色 / 裁切 | AEL L1 SSC 已合码但默认 off；L2 角色未入场 | 先定模板再塞图的倒序仍在 |
| 全书主编 | EDC 有 `program` 合同，零实现；且 **不** 在 EDC 实施 `album_spread` | 画册侧页纲领需自己挂，枚举与 EDC 对齐以免两套文法 |

多样性靠「相邻不重复 + usage_counts」，不是杂志式页纲领。

## 2. 产品提案与总判断

**提案**：模板按 4–8–12–16–20–24–28–32 编成册；每档模板类型、数量、顺序不同；非档位输出（如 19）以最近编好的一册为底，从模板库补页；拼图规则不变。目的：排版更有逻辑，同一类型重复得到控制，整体更有杂志感。

**判断**：方向对，且正好打在现网最大缺口上。与 EDC「页纲领」和智能模板建议「成册节奏」是同一条产品线，不是另起炉灶。

## 4. 组合表写成页纲领配方，不要写成模板 ID 清单

若 16 跨写成 `card-1-full → card-6-brick → card-8-grid…`，库一扩、某套被降权，整张表就碎。杂志感来自**页的任务**，不是某一套几何。

与 EDC 已定枚举对齐（可先落画册，日后全书共用）：

`opener | hero | mosaic | grid | breath | journal | peak`

每档配方只锁三件事：

1. **配额**：几个英雄、几个密网、几个呼吸、几个满版
2. **顺序骨架**：开篇、中段高潮、收束落在哪几跨
3. **密度曲线**：哪几跨故意少图（这比换模板更决定杂志感）

具体哪套 `card-*` 仍由现有拼图规则在纲领约束内选。「重复使用同一类型得到控制」控的是 hero/grid/满版的**次数与间距**，不是死锁模板 ID。相邻禁同模板保留；另加连续同一纲领 ≤ 2（对齐 D-EDC-16）。

---

## 5. 签名嵌套：共享文法，禁止「复制一倍」

独立维护 8 套互不相关的组合，会节奏互打、难评。印刷签名本来可嵌套：**共享起承转合，不共享页清单**。

最小文法（跨页角色，不是卡 ID）：

- **开**：英雄或满版，建立这本的脸
- **承**：拼图 / 序列，把故事铺开
- **转**：密网或第二个高潮，改变密度
- **合**：呼吸或收束英雄

**禁止**把 8 跨做成两个一模一样的 4 跨，把 16 跨做成两个一模一样的 8 跨。大本是更长的叙事弧（第二段发展、中段 peak），不是小本的复读。展开时必须重算密度——见 §10。

20–32 档用同一文法拉长，不要为 24 另发明第三种文法。先只做 8 和 16 两档，确认能扩再开其余。

---

## 6. 按对页想，不要只排单卡序列

杂志感有一半发生在左右对视。配方的原子单位是**跨页角色对**，例如：

| 位置 | 跨页角色对（左 \| 右） |
|------|------------------------|
| 开篇跨 | `hero \| mosaic` |
| 发展跨 | `grid \| grid`（允许一对，下一跨必须换密度） |
| 高潮跨 | `hero \| breath` 或双满版 |
| 收束跨 | `mosaic \| closer` |

拼图规则仍负责每张卡内部怎么填；主编层只决定左右两张卡彼此是什么任务。这是画册相对 16:9 网页独有的杠杆。

---

## 7. 非档位补页：随机从库里抽是默认政策里最弱的一环

「19 = 16 + 随机 3 张」容易把刚编好的节奏拆掉。随机补库只适合**供给失败兜底**，不适合当默认生成。

按优先级：

1. **能靠档就靠档**：软页数 19 优先落到 16 或 20，用槽数/密度吃掉差额（现网本就是朝向正确优先于精确页数）。
2. **必须 19**：以 16 签名为脊，多出的跨页走固定「尾声槽」（呼吸 / 细节拼贴 / 收束英雄），禁止与倒数第二跨同纲领。
3. **从 20 减 1**：丢掉优先级最低的一跨（通常是第二个 breath 或最密宫格），往往比从 16 往后乱加更安全。

用户手填跨页 vs 自动软算出来的非档位数，补齐策略分开写，勿混用。

## 9. 配方必须看照片池成分，否则会回到「先定模板再硬塞」

同一套 16 跨剧本，40 张竖人像和 40 张横风景不该选出同一串模板族。每档建议 2～3 个变体，由池子成分选：

| 池子倾向 | 配方偏置 |
|----------|----------|
| 竖人像多 | 满版/竖英雄多，宽英雄少 |
| 横风景多 | 宽英雄 + 三带，少 16 宫格 |
| 序列/过程多 | 等权网格配额上调 |
| 细节/食物多 | 小槽拼贴多，满版少（美食继续走 FRP，不当 hero） |

页数决定骨架长度，池子成分决定用哪条变体。拼图继续做朝向硬门。

## 10. 讨论续篇 · 签名展开必须跟照片量挂钩（2026-08-14）

产品认同 §5 的「共享文法、不对页复制」，并明确：**不建议把大档做成小档的一倍复读**；成册必须关联用户照片数量。20 张与 250 张（画册池上限）是完全不同的编辑问题。

### 10.1 为什么「8 = 两个 4」会坏

页数（跨页档）和照片量是**两根独立轴**。只沿页数轴翻倍，等于假设照片量也刚好翻倍、密度不变。现网并不是这样：

- 自动跨页约 `ceil(photos / 8)` 再取 4 的倍数，小本（估算 < 3 跨）不强制凑 4。
- 画册正文吃光 kept 池（每张恰好一次），上限 250。
- 28 跨 × 2 卡 = 56 卡；250 张时平均每卡约 4.5 槽。20 张自动约 4 跨，平均每卡约 2.5 槽。

因此：同一档 8 跨，20 张是「奢侈小册」（几乎不该出现 8+ 宫格），120 张是「消化册」（密网是劳动力）。把 4 跨稀疏配方复制两遍，既吃不掉 120 张，也会让 20 张的 8 跨变成空翻。

### 10.2 真正该锁的是密度带，不是「大本 = 小本 × 2」

定义 **每卡槽预算** `PPC = ceil(photos / (spreads × 2))`（与现网 `target_per_card` 同构，仍是软目标，朝向优先）。

| 密度带 | PPC（约） | 编辑性格 | 20 张典型 | 250 张典型 |
|--------|-----------|----------|-----------|------------|
| **疏** | ≤ 2 | 满版/hero/breath 主导；重型 grid 基本禁用 | 用户手填偏多跨页时 | 几乎不出现（吃不完） |
| **正** | 3–5 | 经典杂志配比：英雄奢侈、密网有节制 | 自动 4 跨附近 | 自动 28 跨附近的下限 |
| **密** | ≥ 6 | 密网是劳动力；hero 更少但必须卡在高潮位 | 用户手填偏少跨页时 | 用户手填 8/16 跨、或自动仍偏密时 |

查表应是 **档位 × 密度带**，不是只查档位：

```
8 跨 × 疏（~20 张）  ≠  8 跨 × 密（~120 张）
16 跨 × 正           ≠  2 × (8 跨 × 正)
```

8 → 16 的合法展开：

1. 加**新的幕**（第二段发展、约 60% 处 peak），不复读第一幕的跨页对。
2. 用新的 `photos` 重算 PPC，升降纲领（疏则升满版/呼吸，密则升 grid/mosaic）。
3. 配额的槽数总和必须与照片量闭合：`Σ slots ≈ photos`。闭合失败先改密度带，再改档，最后才允许受约束补页。

### 10.3 两极对照（便于设计 8/16 草表时记得）

**约 20 张**

- 每张都有机会当英雄；敌人是「一页吃掉太多」和「为凑档而空翻」。
- 自动应停在 4 跨附近；8 跨是奢侈小册，不是把 4 跨复制两遍。
- 单张 8+ 槽会一次吃掉池子的 40%，后面只剩边角料——重型宫格应视为禁令或极例外。
- 呼吸可以多：留白是结构，不是算法没填满。

**约 250 张**

- 现网 keep-all：每张都要出场。敌人是「照片墙」和「英雄被稀释」。
- 不能把 4 跨奢侈签名连贴 7 遍。必须有能力消化的 mosaic/grid，同时把满版/hero **囤在高潮位**（建议全书 1～2 个 peak 跨，不要按比例随页数线性加）。
- 呼吸仍要：密册没有疏页会变成目录。但 breath 是「密度跌一档」，不是空白废页。
- 若用户强行只要 8/16 跨：PPC 会冲到 8–16，配方必须切到密带，而不是硬套 8 跨正带草表。

### 10.4 对 §8 草表的含义

产品回写 8/16 配额时，建议每档至少三列密度带（疏/正/密），而不是每档一行。池子成分变体（§9）是第三轴，可第二刀再加；第一刀先把**照片量 → 密度带 → 配额**钉住。

Hero / 满版 / peak **不要**随跨页数线性翻倍。密网和 mosaic 才随照片量（密度）涨。这是「不像复制一倍」在配额数字上的落点。

## 11. 重复控制要分层

| 层 | 规则 | 现网 |
|----|------|------|
| 相邻 | 同模板 ID 禁止（唯一候选除外） | 已有 `avoid_immediate_repeat` |
| 连续纲领 | 同 `hero/grid/满版` ≤ 2 | EDC 已写，画册未接 |
| 全书配额 | 重型宫格（如 16 槽）每档有上限 | 无 |
| 密度节拍 | 密—疏—密，避免半本全是 8–16 槽、半本全是 1–2 槽 | 无 |

人翻纸时感知的是「这一页突然变空/变满」，不是槽线长得不一样。

## 13. 建议落地切法

1. 先只做 **8 和 16** 两档，且每档先按密度带（疏/正/密）出配额，盲评「像不像一本」而不是「模板多不多」。
2. 用共享文法嵌出 8/16，确认能扩，再开 20–32。
3. 非档位先做「靠档 + 受约束尾声」，再决定要不要开放任意跨页。
4. 拼图、朝向、书衣、裁切失败链一律不动。

## 14. 成册编排引擎（2026-08-14 · 对照 40 卡参考册深化）

参考对象：手工册「风景经过的时候」约 40 卡总谱（用户确认整体非常受欢迎）。借鉴其**编辑语法**，不抄工作流、不抄纸书坐标、不在运行时发明模板。目标：按照片量延伸出各数量级的**系列（Series）**；引擎负责编译；设计师可对某一个系列做对页 / 顺序的增删改查，而不动算法。

### 14.1 从 40 卡里真正该借的，不是 40 套版式

把总谱按 8 行 × 5 列读下来，受欢迎的不是「每页长得不一样」，而是四条可复述的纪律：

1. **幕的标点**：约每 8～10 卡一个巨字扉页（出发 / 遇见 / 停留 / 回望），加书名页与收束页。密度被定期清零。
2. **疏密振荡**：满版/英雄之后接 2～4 图有机页；6+ 密网极少，且前后几乎总是英雄或扉页。密页是调味，不是主食。
3. **对页意识**：有的卡明显成双（双竖、双横、末段疑似跨页全景）。左右在对话，不是两张独立海报。
4. **字是建筑**：扉页和收束把中文标题当结构，照片退成条带或点缀。这是杂志感的来源之一，现网画册内页几乎还没有。

粗算这本 40 卡的页型比例（不是精确点表，是设计校准）：

| 页型角色 | 约占比 | 每卡槽数带 | 在总谱里干什么 |
|----------|--------|------------|----------------|
| 书名 / 章扉 / 收束 | ~12% | 0–2 | 把一本切成四幕，给呼吸 |
| 英雄 / 满版 | ~30% | 1 | 锚点；高质量单图 |
| 对幅 / 2–4 图有机页 | ~45% | 2–4 | 叙事展开，主体量 |
| 6+ 密网 | ~6% | 6–9 | 过程/细节，全书仅两三次 |
| 图文 journal | ~7% | 1–3 | 字多图少，不是图说 |

槽数加总大约 **70–110 张照片** 才能填满这本而不空、不胀。它校准的是「20 跨页 × 正密度」这一个单元格，不是所有档的母版。40 卡 = 20 跨页（D-ABE-01）。

现网 28 套 3:4 卡已经能覆盖英雄/对幅/2–4/6–16 密网；**缺的是扉页/收束 SKU 与成册顺序**，不是再画 40 套几何。胶带/微倾/印章仍是工艺层，不进 V1 编排引擎。

### 14.2 三层资产 + 一个编译器

系列是产品资产，引擎是编译器。改一本的对页顺序 = 改一份系列文件，不发新算法。

```
词汇表 vocab     页型角色 → program + 槽数带 + 允许的模板族
文法 grammar     一幕怎么写；连续禁令；合法对页对
系列 series      某一 (跨页档 × 密度带) 的具体跨页清单   ← 增删改查落在这里
编译器 compiler  照片量 → 选系列 → 校验 → 纲领内走 CardGrouper → 填图
```

| 层 | 谁改 | 改了影响谁 | 不改什么 |
|----|------|------------|----------|
| 词汇表 | 设计 + 工程，低频 | 所有系列里同名角色的绑定 | 不改拼图漏斗 |
| 文法 | 设计，中频 | 校验规则、幕的默认骨架 | 不改某一本的具体顺序 |
| 系列 | 设计，高频 CRUD | **只有这一个系列** | 不改其它系列、不改引擎 |
| 编译器 | 工程 | 选系列 / 靠档 / 降级 | 不内置 40 卡硬编码顺序 |

V1 系列必须是**写死的跨页清单**（像这本 40 卡总谱），不要一上来做成生成式文法。用户喜欢的是「被设计过的一本」，不是「合法随机」。文法只用来：校验 CRUD 没有写坏；从金样系列**派生**短册/密册时给设计师一个骨架，派生结果仍落成新的系列文件，再手调。

### 14.3 词汇表（从 40 卡收成约 10 个角色）

角色是编排引擎的稳定 API。系列只写角色，不写 `card-*` ID。CardGrouper 在角色的槽数带 + 朝向硬门内选具体模板。

| 角色 `role` | 映射 `program` | 槽数带 | 现网可落 | V1 策略 |
|-------------|----------------|--------|----------|---------|
| `title-opener` | opener | 0–1 | 无巨字 SKU | 先降级为满版+书衣标题；扉页 YAML 随后 |
| `chapter-opener` | opener | 1–2 | 同上 | 每幕 ≤1；短册可删整幕只留书名 |
| `hero-portrait` | hero | 1 | `card-1-full-frame` | 竖英雄 |
| `hero-bleed` | peak / hero | 1 | `card-1-full-frame` | 幕末满版，全书 peak 仍 1～2 |
| `pair` | mosaic | 2 | `card-2-stack-equal` 等 | 对幅/序列 |
| `organic-3` | mosaic | 3–4 | `card-3-*` / `card-4-*` | 有机展开，40 卡主体 |
| `grid-4` | grid | 4 | `card-4-grid-equal` | 整齐四宫，少用 |
| `grid-dense` | grid | 6–9 | `card-6/7/8/9-*` | 每幕最多 1；疏带禁用 |
| `journal` | journal | 1–3 | 现有 editorial 卡近似 | V1 可映射少图卡 |
| `closer` | breath / journal | 0–2 | 无 | 全书 ≤1，禁止密网收束 |
| `panorama-spread` | peak | 1+1 跨两卡 | 无真跨页图 | V1 用双满版对视近似 |

`grid-dense` 的上限随密度带变：疏 = 0，正 = 全书 2～3，密 = 每幕可 1 但不连续。`card-12/13/16` 只进密带，不进金样系列。

### 14.4 幕文法（金样是四幕，不是四十个单页）

40 卡 ≈ 四幕 × 约 10 卡（5 跨页）：

```
书名跨
幕「出发」：章扉 → 英雄 → 有机/对幅 ×2 → 满版
幕「遇见」：章扉 → 英雄 → 有机 ×2 → 满版
幕「停留」：章扉 → 密网（首次）→ 有机 → 满版
幕「回望」：章扉 → 密网 → 有机/对幅 → 满版 → 收束
```

后两幕才出现密网——前半本建立气质，后半本才消化量。这是「不像复制一倍」在金样里的证据：四幕同构但**配比递进**。

跨页档决定**幕数**，密度带决定**幕内配比**：

| 正文跨页 | 建议幕数 | 相对金样怎么变 |
|----------|----------|----------------|
| 4 | 1（可无章扉，只留气质） | 开–承–转–合压进 4 跨；禁止密网 |
| 8 | 1～2 | 两幕则第二幕才允许 1 个密网（正/密带） |
| 12 | 2～3 | 加一幕发展，不复读出发 |
| 16 | 3 | 中段约 60% 处 peak |
| 20 | 4 | **金样校准点** |
| 24–32 | 4～5 | 加「余韵」幕，peak 仍 1～2，不按页数加英雄 |

幕内配比随密度带改，不随幕数复制：

| | 疏（PPC≤2） | 正（3–5） | 密（≥6） |
|--|-------------|-----------|----------|
| 章扉 | 可保留 1 个全书 | 每幕 1 | 每幕 1，但槽数带取下限 |
| 英雄/满版 | 升 | 金样比例 | 降，只囤高潮位 |
| 有机 2–4 | 降 | 主体 | 主体，槽数带取上限 |
| 密网 | 禁 | 全书 2～3 | 每幕 ≤1，前后必须疏页 |
| 收束 | 要 | 要 | 要（密度跌一档） |

### 14.5 系列文件：CRUD 的落点

一个系列 = 一个 YAML。改「停留」里某一跨的左右角色，只动这一个文件。

```yaml
id: scenery-passing
version: 1
spreads: 20
density: standard
photo_span: [70, 110]     # 槽预算闭合带；选系列的硬门
acts: [title, depart, meet, stay, lookback]
sequence:
  - id: s01
    act: title
    left:  { role: title-opener }
    right: { role: hero-portrait }
  - id: s08
    act: stay
    left:  { role: chapter-opener, label: 停留 }
    right: { role: grid-dense }
  # …
rules_ref: album-grammar-v1
```

CRUD 合同：

| 操作 | 做法 | 引擎要拦的 |
|------|------|------------|
| 增一跨 | 在 `sequence` 插入，赋新 `id` | 跨页总数偏离档位；`photo_span` 不再闭合 |
| 删一跨 | 删一项 | 幕失去唯一章扉或收束；连续纲领破门 |
| 改左右角色 | 改 `left.role` / `right.role` | 非法对页对（见下）；密网与密网对视 |
| 改先后 | 调列表顺序 | 连续同一 `program` > 2；密网前后不是疏页 |
| 派生新系列 | 复制文件，改 `id` / `density` / `photo_span` | 与已有系列 `photo_span` 重叠过大（选系列歧义） |

合法对页对（V1 白名单，可随金样修订）：

- 开篇：`opener | hero`、`opener | journal`
- 发展：`hero | mosaic`、`mosaic | mosaic`（下一跨必须换密度）、`pair | organic-3`
- 高潮：`hero | breath`、`hero-bleed | hero-bleed`、`panorama-spread`
- 消化：`grid-dense | hero`、`chapter-opener | grid-dense`
- 禁止：`grid-dense | grid-dense`、`closer` 不在中段、连续三跨同一角色

系列里允许少量 **flex 位**：`role: [organic-3, pair]`，编译时按剩余照片量与朝向二选一。这是「同一系列消化 ±15% 照片」的阀门，避免为 78 张和 92 张各做一本。flex 位必须标在文件里，不能运行时随便换。

### 14.6 编译器：照片量怎么选到系列

```
照片 N + 可选用户跨页 S
  → 若无 S：沿用现网 resolve_album_slide_count（4 的倍数，小本不强制）
  → PPC = ceil(N / (S × 2)) → 密度带
  → 在 series 库中筛：spreads==S 且 density 匹配 且 N ∈ photo_span
  → 命中唯一：编译该系列
  → 命中多个：取 version 最新；或池子成分变体（§9，第二刀）
  → 零命中：靠档（§7）→ 仍零命中则「最近系列 + 受约束尾声/删低优先级跨」
  → 对 sequence 每卡：角色.槽数带 ∩ 朝向 → CardGrouper（拼图规则不变）
  → 槽预算闭合校验；失败先消耗 flex，再降级同纲领兄弟模板
  → AEL SSC / 书衣
```

选系列是查表，不是现场生成 40 卡。金样 `scenery-passing`（20 跨 × 正 × 70–110 张）是第一本要手写的系列；8/16 的疏/正/密是派生系列，派生后必须手调，禁止自动「×2」。

数量级与系列的对应（设计校准，不是现网公式）：

| 照片量 | 更像哪本 | 不要做成 |
|--------|----------|----------|
| ~20 | 4 跨疏，或 8 跨疏奢侈小册 | 20 跨金样（空翻） |
| ~40 | 8 跨正 / 12 跨疏 | 金样四幕（章扉比内容还多） |
| ~80 | **20 跨正 = 金样**，或 16 跨正 | 8 跨密（变成目录） |
| ~160 | 20–28 跨正偏密 | 把金样四幕贴两遍 |
| ~250 | 28 跨密；用户强行 8/16 则切密带系列 | 金样比例的英雄线性加倍 |

### 14.7 与现网、与「字/工艺」的边界

| 现在就能挂 | 必须另立、不进 V1 引擎 |
|------------|------------------------|
| 角色 → 槽数带 → 28 套卡 | 巨字扉页 3～5 YAML（EDC/AEL 已规划，引擎先占 `opener` 位） |
| 系列 YAML + 校验 | 胶带/微倾/印章（工艺层 W4） |
| 对页角色对 + 连续禁令 | 真跨页全景、异形叠压槽 |
| flex 位消化 ±15% | 运行时生成新模板 |
| 父开关回退现网贪心 CardGrouper | 人手选图主路径 |

引擎挂在 `plan_cards` 之前：输出的是「每张卡的 program + 槽数带 + 可选模板族」，CardGrouper 继续做朝向与供给。关旗 ≡ 现网。

### 14.8 建议的落地顺序

1. **收词汇表**：把 40 卡点成角色表（一卡一行：role / 槽数 / 左右是否成对）。这是金样系列的输入，也是 8/16 配额草表的校准尺。
2. **手写金样系列** `scenery-passing`（20 跨 × 正），用现网 28 套填进去做一册对照，只评节奏，不评字和胶带。
3. **编译器只读系列 + 校验 + CardGrouper 约束**；先能关旗回退。
4. **派生 8/16 × 疏正密** 六份系列：从文法出骨架，设计师改对页，写入 `photo_span`。
5. 扉页 SKU 与工艺层按 AEL/EDC 原节奏另波进入，不阻塞编排引擎。

## 17. 画册专用跨页 SKU（2026-08-14）

产品补充：杂志感要上台阶，必须有**一张图跨两页**的模板；仅适用 `album_spread`。样张：一图横切中缝，上约 2/3 为跨页主图（左半/右半同一张），下为 PROLOGUE + 中文标题（左）与正文（右），页码 02/03，中缝仍在。

### 17.1 判断

**该做，而且是杂志感里杠杆最高的缺页。** 40 卡点表里的 `panorama-spread`、样张里的「去看没有见过的天色」，都不是两张 3:4 卡并排能冒充的。现网 `render_spread` 是左卡+48px gutter+右卡（2208×1440），中缝是为了读成「两页打开」（ADR-021 D2.2），不是为了让一张图过去。

但**不要做成第 29 套卡**。跨页的原子单位是**整跨**，一张图、一个宽幅裁切窗、可选跨页文案区。必须独立 registry（建议 `SPREAD_TEMPLATES`），禁止写入 `_ALL_TEMPLATES` / `CARD_TEMPLATES` / `AVAILABLE_SLOT_COUNTS`，禁止泄漏到小红书/海报。隔离方式对齐 AEL 探针，舞台更宽。

中缝要保留为折线（样张也有中线）。禁止为了「无缝」取消 gutter，那会退回已被否决的 2.8:1 大海报。

### 17.2 硬约束（比满版卡严）

| 门 | 为什么 |
|----|--------|
| 中缝禁区 | 人脸、地标、地平线焦点不得落在中缝左右约 8–12%（含装订吃进） |
| 必须够宽、够清 | 画布约 2208×上 2/3 高，窄图硬拉会糊 |
| 角色 | 优先 `vista`；群像/食物默认不进 |
| 失败必降级 | 过不了门 → 改走 `hero \| journal` 两卡，禁止硬切中缝 |

准入应对齐 MTSO「六图英雄」那种两段资格，而不是「有横图就跨」。

### 17.3 SKU 要少，配额要奢侈

V1 只建议 2～3 个跨页 SKU，不要按 28 套卡的密度扩：

| id（草案） | 结构 | 用在 |
|------------|------|------|
| `spread-span-prologue` | 一图跨缝 + 底栏标题/正文（样张） | 开篇或一幕之首 |
| `spread-span-bleed` | 一图近满幅，无字或仅页码 | 全书 1 个 peak |
| `spread-span-caption-left` | 一图跨缝 + 仅左下标题 | 非开篇的英雄跨 |

系列里：20 跨正带 **1～2 个**；8 跨疏带最多 1；密带仍 1～2（不随照片量加）。禁止连续两跨都是 spanning。`sequence` 里占 **一条**（整跨），不是左右两个 role。

### 17.4 字和图谁先

样张一半的杂志感来自底栏字。V1 建议先做**过门的跨页图 + 中缝禁区裁切**（观感已经跳一档）；底栏文案做同一 SKU 的第二变体，文案先复用行程/章标题，空则只留图（像干净章首）。不把跨页做成写作引擎，也不等 AIR 80%。

书衣（ABE）不管正文跨页。页码、纸色、外白边应是画册**共用页框**，跨页 SKU 与普通两卡跨共用，否则一本里两套印刷系统。

### 17.5 挂点

`plan_cards` 之前：系列点到 `panorama-spread` → 产出 `SpreadPlan(kind=spanning, template, photo)`，不经 CardGrouper 拆两卡。`render_spread` 认 `kind` 走新画布。关旗 ≡ 现网两卡+gutter。拼图规则对 spanning 不适用（没有槽可拼），只适用普通跨。

## 18. 社交卡线 vs 印刷页线（2026-08-14）

产品提问：当初四出口共用 3:4 是为了兼顾；画册实际面向打印/印刷，受纸面制约。是否为画册**单独建库**（按 A4 长宽比设计），拼图/装配算法复制现网，把画册做成独立管线；小红书 / 公众号 / 海报继续共享一条。

### 18.1 判断

**分库、分舞台 — 赞成。整条管线复制一份 — 不赞成。A4 可以是首选纸面，但必须先钉「印什么本」，不能把 3:4 卡拉伸成 A4。**

ADR-021 v0.1 其实已经分过：海报 A4、画册 2.8:1 跨页。v0.2 为了**共用模板库和渲染内核**收成 3:4（D2.1/D2.2）。那是工程收敛，不是印刷真理。现在跨页 SKU、页框、装订中缝都在逼画册离开手机卡。OQ-ECC-03 也问过「小红书 3:4 与画册 3:4 要不要不同留白」，当时 28 套已到位就搁下了。

社交三出口继续 3:4 一条线，正确。画册应升成**印刷页线**：自己的页库 + 跨页 SKU + 页框（出血/页码/内白），主编/系列只挂在这一条。

「算法可以复制」对的是**算法形态**（槽数贪心、朝向硬门、用量多样性、失败降级），不是再 fork 一份 `card_grouper` / `collage_pack`。两周后两套规则会分叉。正确粒度：内核参数化（registry + 画布 + 配对策略），画册分支换库、换舞台、加上系列编译与 spanning。

### 18.2 先钉纸面，再画库

A4 竖页 = 210×297 ≈ **1:1.414**，比 3:4（1:1.333）更高一截，正好给样张那种底栏标题留位置。两页打开 = A3 横 = **√2:1 ≈ 1.414**，现网跨页是 2208×1440 ≈ **1.53:1**（两张 3:4 + gutter），更像两部手机并排，不是一本打开的 A4。

国内印书常见还有方册（20×20 / 21×21）。方册会吃掉底栏字带，和 40 卡金样、prologue 样张更不合。若产品要的是「杂志画册」而不是「影楼方册」，**A4 竖开本**是更贴的一档。

未钉纸面就建第二套库，会重演 2.8:1 → 3:4 的返工。建议先锁一个印刷 SKU（V1 只做一个开本）。

### 18.3 拆什么、不拆什么

| | 社交卡线（小红书 / 公众号 / 海报） | 印刷页线（画册） |
|--|-----------------------------------|------------------|
| 舞台 | 3:4 卡 1080×1440 | 单页 A4 竖（或已钉开本）；跨页 = 两页+物理中缝 |
| 模板库 | 现网 28 套，不动 | **新库**，按纸面原生设计，禁止 3:4 拉伸 |
| 一等公民 | Card | Page + Spread（跨页 SKU 是整跨） |
| 页框 | 无出血 | 出血 / 安全区 / 页码 / 内外边不对称 |
| 编排 | 贪心 + 开篇宫格（xhs） | 系列编译器 + 密度带 |
| 拼图/裁切 | CardGrouper + SSC | **同一套内核**，换槽 AR 与 registry |
| 导出壳 | `collage_pack` / Writer | 同一壳，不同 `kind` |

禁止：把 28 套 `displayAspect` 改个数当 A4 库；跨页 SKU 写进 `_ALL_TEMPLATES`；为画册复制一份 Grouper 源码。

### 18.4 建议路径（不冻结现网画册）

1. **纸面合同**：V1 开本（建议 A4 竖页 / A3 打开）+ 出血与中缝毫米数。  
2. **社交冻结 3:4**：28 套只服务 xhs/mp/poster；画册不再往这库加卡。  
3. **印刷页库从金样长**：先少套（满版、对幅、有机 3、四宫、一个密网）+ 2～3 个跨页 SKU，按 A4/A3 画，带页框。  
4. **内核抽参数**：`Grouper(templates, canvas)`；album 走新库 + `SpreadPlan`；关旗可暂回现网两卡 3:4（迁移期）。  
5. **系列/主编只挂印刷页线**。AEL 的选图×裁切继续在画册验，但舞台改为纸面后要重算槽 AR，不要默认 3:4 通行证自动成立。

手编金样：若已决定分库，用现网 28 套排的是**节奏草图**，不是印刷金样。纸面锁定后，同一套角色顺序要按纸面重画一版。

## 19. A4 横过来 = √2:1 跨页画布（2026-08-14）

产品决定：画册专用库按 **A4 横置** 设计，长宽比 **√2:1**（ISO 216）。社交 3:4 库不动。

### 19.1 先钉单位：√2:1 是「打开的一跨」，不是「横着的一页再对贴」

同一比例有两本完全不同的书：

| | 推荐：√2:1 = **整跨画布** | 不推荐先做：每页都是 A4 横 |
|--|---------------------------|----------------------------|
| 物理 | 一张 A4 横纸对折 = A5 竖页；或按比例放大到 A3 打开 = A4 竖页 | 每页 297×210，打开 ≈ **2.83:1** |
| 半页 | 1:√2 ≈ 0.707（略瘦于 3:4） | 每页本身就是宽屏 |
| 跨页主图 | 正好铺满一张 A4 横 / A3 横 | 接近 3:1，人像很难用 |
| 与 4 的倍数 | 骑马钉一张纸 = 4 页，和册型档咬合 | 对折签名对不上 |
| 与样张 | prologue 左右页是竖的，整跨是横的 | 单页太扁，底栏字带很挤 |

**已钉（D-ABE-04/05）：√2:1 = 一张 A4 横页的整版画布**，左侧胶装，页心不骑缝、不画中折线。先前「左右半页是竖开本 / 一张纸四页骑马钉」作废。

打开书时两页并排 ≈ **2.83:1**，那是可选的跨页 SKU 画布，不是默认页。默认模板按一整张 √2:1 画完。

### 19.2 画的时候用毫米，导出再落像素

| 项 | V1 建议 |
|----|---------|
| 比例 | 精确 √2:1，不要 1.5:1 或 3:4 对贴 |
| 成品（小） | 297×210 mm（A4 横张 = 一跨） |
| 成品（大） | 420×297 mm（A3 横张 = 一跨，页是 A4 竖） |
| 出血 | 四周各 3 mm |
| 裁切安全 | 成品边内 5 mm |
| 印刷工艺 | **不管**（D-ABE-06）：装订边 / 出血 / 页码由印厂处理 |
| 预览像素 | 高 1440 时宽 ≈ 2036（√2）；或 A4@150dpi ≈ 1754×1240 |
| 印刷像素 | A4@300dpi = **3508×2480**；A3@300dpi = 4961×3508 |

页框（页码、纸色、内外边）全库共用，不要每张模板自画一套。内侧留白 ≥ 外侧，给装订。

### 19.3 共用网格，不要 40 张互不相关的灵感

单页建议 **12 栏 × 8～12 行**，不要预留中缝栏。角色落在格子上。横图吃满 √2:1 是这开本的本业；竖图用窄栏或一侧大图，不要默认切成左右两个 3:4。

印刷最小图：短边建议 ≥ **40 mm**。整页 3×3 可以；**4×4 / 16 宫不要进 V1**。不要把社交卡的 12/13/16 槽搬过来。

正文字不要拉通整跨：一行超过约 35–40 个中文会难读。标题在左、正文在右（样张）是对的。

### 19.4 V1 先画的跨页 SKU（建议 10～14 个，不是 28）

按角色画「一整跨」，不要先画半页再胶水：

| 优先级 | 角色对 | 备注 |
|--------|--------|------|
| P0 | `spread-span-prologue` | 样张：一图跨缝 + 底栏字 |
| P0 | `spread-span-bleed` | 近满幅，仅页码 |
| P0 | `chapter-opener \| hero` | 巨字扉页对英雄 |
| P0 | `hero \| organic-3` | 疏密振荡的基本句 |
| P0 | `pair \| pair` | 对幅对话 |
| P1 | `hero-portrait \| journal` | 字是建筑 |
| P1 | `grid-4 \| hero` | 四宫后必须疏 |
| P1 | `grid-dense \| hero` | 全书 1～2；禁 dense\|dense |
| P1 | `closer`（可半跨字 + 半跨小图） | 全书 1 |
| P2 | `spread-span-caption-left` | 非开篇英雄跨 |

槽位写清：横/竖/主图、是否跨缝、文案区。拼图内核只消费半页内的矩形槽；跨缝图走独立准入（§17.2）。

### 19.5 和册型、社交线的关系

- 系列的一条默认 = 一个 √2:1 **单页**模板。跨页 SKU 一条占 **两页**。  
- 胶装按页序胶，没有「一纸四页」折手；设计师按阅读序画即可。  
- 28 套 3:4 **不要改比例复用**。现有手编只当节奏草图。  
- 现网 1.53:1 两卡跨页仅作迁移期关旗退路，不是新库画幅。

## 21. 示意图字段合同（2026-08-14）

> **2026-08-15**：字段仍可作画示意图的检查单。舞台改为 **16:9**（D-U-06），不再用本节 √2 / `spread-*`。已画 6 张的机器数据包见 [PAGE-PACKET-CATALOG.md](./templates/PAGE-PACKET-CATALOG.md)。档位单位是**页**，不是跨页。

首张范例：`page-1-hero-land`（单图 · 横版英雄）。后续稿按同一套字段写，几何画在框里，文字可写在框内（单槽）或框下（多槽）。

### 21.1 每张必写

| 字段 | 范例 | 给谁用 |
|------|------|--------|
| 模板 ID | `page-1-hero-land` | 文件名、选型、系列 |
| 中文名 | 单图 · 横版英雄 | 人读；改中文不改 ID |
| 纸面 | A4 横 √2:1（`spread-` 则写两页打开 ≈2.83:1） | 画布 |
| 槽位数 | 1 | 拼图切块 |
| 横版槽 / 竖版槽 | 1 / 0 | 朝向硬门（与现网 Grouper 同构） |
| 每槽：比例 + 位置 + 角色 | 4:3 · 居中 · `main` | 裁切与填槽 |
| 准入 | 竖版禁入 / 横版禁入 | 硬门 |
| 裁切通则 | 见 §21.2 | 横槽、竖槽同一套相对规则 |
| 用途 | 高光池横图；风光/合影优先 | 系列软约束 |
| 文案区（可选） | 无 / 底栏单行、可空 | **不算**槽数 |

### 21.2 裁切通则（不要按相机比例逐条写）

相对**该槽**的长宽比：

| 照片 vs 槽 | 做法 |
|------------|------|
| 同比例（含很小误差） | 铺满 |
| 比槽更宽（宽高比更大，如 16:9 / 3:2 进 4:3 横槽） | **以宽对齐，上下留白** |
| 比槽更高（宽高比更小，如 9:16 进 3:4 竖槽） | **以高对齐，左右留白** |
| 朝向与槽不符（竖进横槽 / 横进竖槽） | 禁入，不硬裁 |

与「宁留白，不毁构图」一致。按相对该槽的宽高比判断，不按相机型号逐条写。

### 21.3 不写

毫米、装订边、出血、页码。印厂缩放整张导出图。文案区若画了：绿框、可空、**不计入**横/竖槽数。

### 21.4 画几何时

槽的**图形比例要等于所标比例**。4:3 横槽在 √2 纸上，左右留白应宽于上下。示意图约定：黑=纸，红=照片槽，绿=文案（可选）。

### 21.5 已收录目录

见 §22。后续新稿按本表字段画即可追加。
