# Travelogue · 游记智能体

**一句话**：把旅行照片自动整理成杂志风游记，并一键导出可发微信群的竖版长图。

> 给陌生人和用户的完整说明见 **[项目说明手册.md](./项目说明手册.md)**。本文只保留一页纸定位。

---

**Travelogue** 是一款面向旅行者的本地智能编辑工具。用户选择电脑上的旅行照片文件夹后，系统自动完成导入、智能策展、杂志风排版与短文案生成，输出可预览的 HTML 游记，并导出适合微信群传播的 PNG 长图。

产品定位是「旅行记忆的编辑」——不做重视频剪辑，也不做内容托管，而是帮助用户在旅行结束后的 1–3 天内，把散乱相册做成可直接分享的游记：**旅行结束，照片还在——游记一次做完。**（成册完工，而非旅行 OS；见 [CHARTER §7.2](./CHARTER.md) · [FTT PRD](./PRD-FINISH-THIS-TRIP-V1.md)）交付物归用户所有，默认本地处理、无需注册。

## 核心能力

- **导入与挑片**：选文件夹、去重连拍、质量闸口、拦 RAW；可全部保留
- **分章成册**：按时间地点切开、场景收束、杂志排版；默认游记，可选作品集
- **封面与阅读**：开场装帧、短文案、大屏卷轴、全屏放映、竖版长图（同一屏序）
- **精修**：删图、改字、换封面气质；先验货再导出
- **导出**：微信群长图、朋友圈 6～9 张、小红书 / 公众号 3:4、画册跨页、单张海报
- **工作台**：本机 Studio，无需注册；Windows 可双击打开

完整能力表见 [项目说明手册 §7–§9](./项目说明手册.md)。

## 亮点

1. **本机成册** — 照片不上传、不用注册
2. **珍贵汇总** — 去重、分章、选片，不是把相册倒出去
3. **一卷一长图** — 自己翻卷轴，朋友看长图，对方不用安装
4. **封面像一本** — 开场有装帧，不是第一张随手照
5. **做完再分发** — 同一本再出多平台，不必重做
6. **先敢发，再谈 AI** — 默认就能出纯照片长图

## 技术要点

Python 多 Agent 管线驱动，`trip.json` 为单一数据源，Handlebars 模板渲染，Playwright 导出高清长图；可选 LLM 增强文案，视觉侧使用 CLIP 等模型。

## 当前阶段

MVP 与「可分享体验」已闭环；正持续优化成书质量、导出体验与首访引导。目标用户是希望快速把旅行相册变成可发群作品的普通旅行者，以及追求杂志感的进阶创作者。
