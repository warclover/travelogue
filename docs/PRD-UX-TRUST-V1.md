> **定位**
>
> 精修体验 V1 与导出门面 V1 已分别解决「半生效导出」与「导出旅程规格」。  
> **2026-07-11 试用会议**表明：主路径工程上已能出长图，但多 Persona 仍**不敢发群 / 不敢交稿**——信任断在验货壳不纯、分享态工程感、续跑可靠性、标题难改、平台话术错位。
>
> 本 PRD 以试用反馈为需求源，定义一次 **跨层体验加固**，北极星从「能导出」推进到「**愿发出去**」。
>
> **样本澄清（v1.1）**
>
> 试用 trip 标题「贵州+州兴义」为 **演示数据人工笔误**（用户把名称写错），**不是** OCR/地名拼接/narrate 系统故障。  
> 由此引出的产品含义是：**改名主路径必须好用**（发现错了能立刻改对并落盘），而非「算法生成了乱码要门禁兜底」。可读性门禁仍保留为空标题/乱码等兜底，**不以该笔误作为「孤立 `+` = 系统缺陷」的证据**。
>
> **与既有主题的关系**
>
> | 主题 | 解决什么 | 与本文关系 |
> |------|----------|------------|
> | **精修体验 V1** | 验货默认 IA · 更新版面 · 导出拦截 | 本文 **补齐落地缺口**（验货壳仍露编辑控件） |
> | **导出门面 V1** | 续跑可靠 · 发群引导 · 漏斗埋点 | 本文 **试用加严项** 以 Facade **增量补丁**落地（**D-TRU-12**）；冲突见 §7.4 矩阵 |
> | **Longshot 2.0** | 平台切分算法与 Profile | 本文只改 **进度/成功话术** |
> | **Copy Optimization** | narrate / fact 文案质量 | 正文复读等 = Park；本主题不背算法根因 |
> | **小程序 P1** | 云端长图 | 附录 B 回写；不实施代码 |
>
> **产品共识（五条铁律）**
>
> 1. **愿发出去是终点** — 长图落盘 ≠ 成功；用户须相信「标题能见人、文件是新版、知道怎么发」。  
> 2. **80% 验货不被编辑壳打扰** — 默认预览禁止露出 ★ / 拼图 / 工程标注；编辑控件仅在精修模式（点字例外见 **C4 / D-TRU-13**）。  
> 3. **Share 真只读** — `?share=1` 零编辑暗示、零 Plate 工程元信息。  
> 4. **不破坏三条导出合同** — 无 pending 一键长图；有 pending 禁静默旧图；用户可见词仅一套。  
> 5. **不借试用开新能力面** — 不加新 Dock 控件、不做系统级一键发群、不扩平台算法。

## 1. 背景与问题

### 1.1 试用会议摘要

| 项 | 内容 |
|----|------|
| **时间** | 2026-07-11 |
| **样本** | Studio `http://127.0.0.1:8766` · 主 trip `demo-043e46a4d0` |
| **方法** | 多 Persona 模拟试用 + Playwright 实机；小程序为文档讨论 |
| **局限** | **不能替代真人可用性测试** |
| **标题样本** | 「贵州+州兴义」= **人工笔误**，非系统生成缺陷（产品方确认 2026-07-11） |

| Persona | 推荐分 | 核心情绪 |
|---------|--------|----------|
| 分享者 · 零编辑 | **4 / 5** | 能出图；错标题难改 + 成功后又「过期」→ 不敢发 |
| 编辑者 · 精修 | **3 / 5** | pending 拦截买账；改标题难 + 更新中「服务已停止」 |
| 创作者 · 平台导出 | **3 / 5** | 平台选项清楚；进度像微信群 + 续跑卡住 |
| 接收方 · `share=1` | **≈3 / 5** | 像后台预览，不像电子相册 |
| 回访 · 书架 | **≈3.8 / 5** | 找得到，但像进工具台 |
| 小程序潜在 | **4 / 5** | 路径 A 够用；怕上传久等 / 80 张 / 电脑存不出 |

**会议一句话结论**：零编辑发群主路径工程已通；**验货壳、分享态、续跑可靠性、标题难改**是当前最伤信任的事（文案「乱码感」在本样本中归因为笔误 + 改名路径弱）。

### 1.2 问题陈述（P-TRU-*）

| ID | 问题 | 严重度 | 主要 Persona | 说明 |
|----|------|--------|--------------|------|
| **P-TRU-01** | 标题写错或不宜发群时，**改名路径不通顺**（难发现、难改、不落盘） | 严重 | 分享者、编辑者 | 试用中「贵州+州兴义」为笔误；产品要解决的是**改得过来**，不是算法拼错 |
| **P-TRU-01b** | 正文/图说复读、模板感强 | 中等 · **Park** | 接收方 | **不在 Trust P0** → Copy Optimization（**MF-TRU-05**） |
| **P-TRU-02** | 「更新并导出」续跑失败/卡住；「服务已停止」/疑似跳首页 | 阻塞 | 编辑者、平台 | Facade 增量 |
| **P-TRU-03** | 默认预览仍露 ★ / 拼图 / 媒资改判 | 严重 | 分享者 | 验货壳缺口 |
| **P-TRU-04** | 长图成功后很快又弹「预览产物已过期」 | 严重 | 分享者 | stale 误伤 |
| **P-TRU-05** | 封面/杂志名内联改名难用或不落盘 | 严重 · **写路径升 P0** | 编辑者 | 与门禁共用（**MF-TRU-01 / D-TRU-08**） |
| **P-TRU-06** | `share=1` 仍露 Plate / 「可编辑」 | 严重 | 接收方 | |
| **P-TRU-07** | share 不稳定：易掉回编辑壳 / 与 Studio 顶栏不一致 / 精修误入 share | 中等 | 多角色 | **补全需求**（**MF-TRU-04**） |
| **P-TRU-08** | 平台导出进度/成功仍像「按章长图」 | 中等 | 平台创作者 | P1 |
| **P-TRU-09** | 首页内部词；气质偏工具台 | 中等 | 回访 | P2 |
| **P-TRU-10** | 预览露 Plate / 雾底题签等工程词 | 轻微 | 分享者、接收方 | |

### 1.3 核心判断

> **信任 ≠ 功能清单。**  
> 用户已经会点长图；卡住的是怕丢人（含**自己写错名却改不顺**）、怕导旧版、怕半路失败、怕朋友看到工程页。

### 1.4 用户分层与策略

| Persona | 策略 |
|---------|------|
| **分享者 ~80%** | 验货壳纯净 + 错题易改 + 成功不被 stale 泼冷水 |
| **编辑者 ~20%** | 杂志名写路径 P0；续跑可感知；图说 happy path P1 |
| **平台创作者** | 进度/成功话术按平台（P1） |
| **接收方** | Share 真只读 |
| **回访** | 首页降噪（P2） |
| **小程序** | 附录 B；本迭代不实施 |

## 2. 目标与非目标

### 2.1 产品目标

| ID | 目标 | 衡量 |
|----|------|------|
| **G-TRU-01** | 标题写错时能在导出发群前**顺利改对并落盘** | AC-TRU-01～03、16（写路径）；种子「改标题并导出」 |
| **G-TRU-02** | 「更新并导出」全程可感知；禁止静默失败 | AC-TRU-04～07；Facade 加严 |
| **G-TRU-03** | 默认预览 = 纯验货壳（按修订 C4） | AC-TRU-08～10 |
| **G-TRU-04** | 导出成功态与 stale 互不误伤 | AC-TRU-11～12 |
| **G-TRU-05** | Share 真只读 + 路由稳定（含 P-TRU-07） | AC-TRU-13～15、13b～13d |
| **G-TRU-06** | 杂志名写路径 P0；图说 happy path P1 | AC-TRU-16～18 |
| **G-TRU-07** | 平台话术一致 | AC-TRU-19～21 |
| **G-TRU-08** | 首页对外文案降噪 | AC-TRU-22～23 |
| **G-TRU-09** | UX-P5-80-01 / C1～C3 **不回归** | 回归套件 |

### 2.2 非目标

- 不重做 narrate / 聚类 / 排版引擎；**不把试用笔误当 OCR 故障立项**  
- 不加第四 Dock 主钮；不做一键发群；不实施小程序  
- 不增加「仍导出旧版」逃生舱  
- 不改朋友圈/小红书切分算法  
- 正文/图说可读性门禁 → **PK-TRU-01**  

### 2.3 成功指标

| 指标 | 目标 |
|------|------|
| 改标题并导出后封面/书架/产物一致 | **100%**（门禁或精修路径） |
| 「更新并导出」→ `longshot_export_start` | ≥85%（失败须明确错误） |
| 成功后 60s 内误报「产物过期」主警告 | **= 0** |
| 默认预览可点的 ★/拼图/媒资控件 | **= 0** |
| `share=1` 工程元信息 / 可编辑提示 | **= 0** |
| UX-P5-80-01 | **不回归** |
| 敢发自评（模拟） | Soft-Go；**不**挡 Reliability（**O-TRU-03**） |
| 主题 Complete 真人敢发 | 建议中位数 ≥4.0；正式 ≥4.5（另立计划） |

## 4. 标题改名与可读性门禁（P0）· P-TRU-01 / P-TRU-05

### 4.1 问题边界（v1.1）

| 是 | 否 |
|----|-----|
| 用户写错/想改杂志名时，路径可达、落盘、三处一致 | 把「贵州+州兴义」归因于系统 OCR/拼接并立项修算法 |
| 空标题、明显乱码等 **可选** 导出前提醒 | P0 全文图说扫描；正文复读门禁 |

### 4.2 杂志名写路径（P0 · **MF-TRU-01 / D-TRU-08**）

| ID | 需求 | 优先级 |
|----|------|--------|
| **F-TRU-EDIT-NAME-01** | 封面主标题在精修模式可点进编辑；不得因实现 `hidden` 不可达 | **P0** |
| **F-TRU-EDIT-NAME-02** | 「这本」杂志名输入：改值后 **≤1s** 反映到封面与 `document.title`；刷新保持 | **P0** |
| **F-TRU-EDIT-NAME-03** | 写路径与门禁「改标题并导出」**共用同一落盘 API**；失败则不得继续当导出成功 | **P0** |
| **F-TRU-EDIT-NAME-04** | 文案类变更 **不**置 `layoutPending` | **P0** |
| **F-TRU-EDIT-NAME-05** | 书架卡片 · 预览封面 · 门禁展示标题同源（**F-TRU-COPY-08**） | **P0** |

### 4.3 可读性门禁（P0 · 兜底，非笔误主因）

| ID | 需求 | 优先级 |
|----|------|--------|
| **F-TRU-COPY-01** | 启发式见 **附录 D**（正例/负例冻结；**MF-TRU-07**） | P0 |
| **F-TRU-COPY-02** | 点「长图」且命中 → 轻量软拦门禁（非系统错误风） | P0 |
| **F-TRU-COPY-03** | 文案见附录 C；对外称「现在的标题」不称「杂志名」 | P0 |
| **F-TRU-COPY-04** | 动作：主「改标题并导出」· 次「暂时不改，继续导出」· 幽灵「取消」 | P0 |
| **F-TRU-COPY-05** | 「改标题并导出」：同卡内联输入 → 落盘（共用写路径）→ 继续导出；**无需更新版面** | P0 |
| **F-TRU-COPY-06** | bypass 允许；打点 `copy_gate_bypass`；**成功态回声当前标题**（**MF-TRU-14**） | P0 |
| **F-TRU-COPY-06b** | **严重档**（空标题 / 明显乱码）：同 trip **首次**偏强制走改标题（仍可取消）；再次同 trip 才放宽 bypass | P0 |
| **F-TRU-COPY-07** | 与 `layoutPending` 并存：**一律先完成 C2（成功或失败终止）→ 再出门禁**；禁止双 Modal 叠层；第二次打断优先非全屏（顶栏/Checklist）（**D-TRU-11 / MF-TRU-06**） | P0 |
| **F-TRU-COPY-08** | 三处标题一致 | P0 |
| **F-TRU-COPY-09** | 门禁 UI 展示 **当前标题**（建议附封面缩略）；软拦视觉与 layout 硬拦可辨（**SF-TRU-01**） | P0 |

### 4.4 决策

| ID | 决策 |
|----|------|
| **D-TRU-02** | 门禁可 bypass；主钮引导改名；bypass + 成功回声 |
| **D-TRU-03** | P0 仅封面主标题；正文复读 = Park |
| **D-TRU-08** | 杂志名**写路径 P0**；图说 happy path 仍 P1 |

## 6. Share 真只读（P0）· P-TRU-06 / P-TRU-07

### 6.1 需求（F-TRU-SHARE-*）

| ID | 需求 | 优先级 |

## 附录 D · 可读性启发式最小表（**MF-TRU-07**）

> 用途：空/乱码/异常短长兜底；**不以「贵州+州兴义」作为系统缺陷正例**（该串为人工笔误）。含 `+` 的标题 **可以** 作门禁候选，但须有艺术书名负例，且可 bypass。

### 正例（应出门禁或严重档）

| ID | 标题示例 | 规则 |
|----|----------|------|
| H+ | （空） | 空标题 → 严重档 |
| H+ | `�` / 大量替换符 | 乱码类 → 严重档 |
| H+ | 单字 `啊` | 过短（建议 &lt; 2 字） |
| H+ | 超长重复堆砌（&gt; 40 字且重复地名） | 长度/复读异常 |
| H~ | `贵州+州兴义` | **可选**命中「孤立 `+`」；用户笔误场景，**主路径仍是改名**，非证明系统坏了 |

| ID | 标题示例 | 说明 |
|----|----------|------|
| H− | `A+B 旅行手记` | 艺术/品牌含 `+` |
| H− | `京都三日` | 正常短标题 |
| H− | `兴义夏天` | 正常地名 |
