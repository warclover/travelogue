## 30 秒看懂

**Travelogue（游记智能体）** 是一款装在自己电脑上的照片成册工具。

你选一次旅行的照片文件夹，它自动分章、选片、排版，做成一本杂志风画册。你可以在电脑上翻着看，也可以一键导出长图，直接发微信群、朋友圈、小红书或公众号。

**一句话：照片导进来，画册自动出来。**

它不是云相册，不是修图软件，也不是旅行攻略 App。它做的是旅行结束后那一件事——把还堆在文件夹里的照片，一次做成可以翻、可以发的游记。

> 照片留在本机 · 无需注册 · 交付物归你所有。

---

## 1. 它解决什么问题

旅行常有三次快乐：决定出发、身在路上、回家整理回味。

Travelogue 只负责第三次。很多人回家后会遇到同一件事：

- 相册里几百张，重复、糊掉、顺序乱，不知道从哪讲起
- 想写一篇游记，一拖再拖，最后只发了九宫格
- 专业排版软件太重，云端「一键生成」又不想把原片传上去
- 羡慕完整的旅行日志系统，却常常只搭了空架子就停了

我们的判断是：**大多数人要的不是一套终身旅行操作系统，而是这一趟能做完。**

所以默认路径只有三步：

**选相册 → 出游记 → 分享。**

成功的标准不是「功能很多」，而是：你愿意把做出来的东西发给朋友，并且下一趟还愿意再来一次。

## 2. 适合谁，不适合谁

### 适合

| 你是谁 | 你在意什么 | Travelogue 怎么帮你 |
|--------|------------|---------------------|
| **刚结束旅行的人** | 1～3 天内把相册变成能发的东西 | 选文件夹就能出一本，不必先学软件 |
| **爱拍照、在意观感的人** | 比九宫格更有故事，但不想自己排版 | 自动选片、分章、杂志排版，再微调即可 |
| **摄影爱好者 / 自媒体** | 同一趟内容要发群、发笔记、发公众号 | 做完一本后，按平台导出，不必重做 |
| **在意原片与隐私的人** | 照片不要上传、不要注册、不要锁在平台里 | 全程本机处理，文件在你自己的电脑上 |

### 不太适合

- 想做行前攻略、行程规划、终身旅行数据库——那不是我们的主职
- 想剪完整 Vlog、做时间线视频——我们最多带几段短视频，不是剪辑台
- 想在手机上直接选片成册——当前工作台是电脑端；手机主要用来看和发已经导出的图
- 想把 RAW 原片直接导入——请先转成 JPG / PNG / WebP（或 HEIC）
- 一次要扔进上千张——当前建议单次不超过 250 张

## 3. 它是什么，不是什么

### 它是

**旅行记忆的编辑，不是旅行内容的工厂。**

更具体一点：它处在「相册整理之后、发朋友圈之前」。你已经拍完了，Lightroom 或手机相册也整理过了（也可以不整理），接下来需要的是：有人帮你做成一本还能拿得出手的册子。

做成之后，你得到的是自己电脑上的文件，不是锁在某个 App 里的帖子。

### 它不是

| 容易误会成 | 实际不是 |
|------------|----------|
| 云相册 / 网盘 | 不托管、不同步、不建账号 |
| AI 修图 / AI 生图 | 不改你的照片内容，只做选片与排版 |
| 朋友圈九宫格替代品 | 做的是策展后的成册，不是把全部照片倒出去 |
| Notion 旅行系统 | 不卖愿望清单、路线图、终身知识库 |
| 多平台内容工厂 | 主叙事仍是「这一趟做成一本」；多平台只是做完之后随你发哪儿 |

## 4. 你会得到什么

做完一本，通常有两样主交付，外加若干分享格式。

### 4.1 大屏卷轴（给自己看、给电脑看）

一本可以上下翻的杂志风 HTML 游记：封面、分章、拼图、短文案、尾声。适合在宽屏上慢慢看，也适合以后自己收藏。

### 4.2 竖版长图（给微信群看）

一张（或按章几张）竖版 PNG。发给群里，朋友不用点开链接、不用装 App，就能把这一趟看完。

**这是当前最重要的分享物。** 做完一本，首先要能敢发这张长图。

### 4.3 做完之后，也可以按平台再出一份

同一趟照片，不必重做，可以再导出：

| 要发到 | 你会拿到 |
|--------|----------|
| 微信群 | 竖版杂志长图 |
| 朋友圈 | 大约 6～9 张、按故事切开的图 |
| 小红书 | 一组 3:4 卡片，适合轮播笔记 |
| 公众号 | 一组 3:4 图，可插入图文 |
| 画册 / 印刷参考 | 左右成对的跨页图 |
| 单张海报 | 一张有主图的封面感海报 |

这些是「做完之后随你发哪儿」，不是产品改名叫「自媒体生成器」。默认仍然先做一本游记。

## 5. 两种成册（默认是游记）

| | **游记**（默认） | **作品集**（可选） |
|--|------------------|-------------------|
| 适合 | 旅行刚结束，想尽快发群 | 想做一本更像杂志的卷轴，慢慢看 |
| 气质 | 快、完整、敢发 | 更讲究页序与装帧 |

绝大多数人第一次走游记就够了。作品集不会自动替你选；两条线也不会混成「又快又精」的一个按钮。

## 6. 一次制作怎么走

不需要先配置、先填愿望清单、先学模板。标准路径如下。

```text
打开 Studio
  → 开始制作
  → 选这一趟的照片文件夹（或先试用示例相册）
  → 等待自动导入 / 选片 / 分章 / 排版
  → 在预览里翻一遍，确认敢发
  → 保存长图
  → 在文件夹里找到文件，发给朋友
```

### 第一步：打开工作台

Travelogue 的工作台叫 **Studio**，在你自己的电脑上运行，浏览器打开本地页面即可。不需要注册，照片也不会上传到我们的服务器。

- **一般用户**：解压或安装 Windows 版，双击打开，浏览器会自动出现首页
- **开发者 / 本机源码**：`python -m travelogue studio`，访问 `http://127.0.0.1:8766/`

请用 **Chrome 或 Edge**（Windows）。手机浏览器不是完整工坊。

### 第二步：选这一趟的照片

点「开始制作」，选一个文件夹。建议：

- 一次一趟旅行，不要把好几年的相册混在一起
- 大约 20～150 张最舒服；上限约 250 张
- 至少 4 张；格式优先 JPG / PNG / WebP；HEIC 通常可用
- RAW 会被拦住——请用已经导出的成片
- 短视频可以带一点，但主体仍是照片

第一次也可以先点「用示例照片试一次」，看成品长什么样，再导入自己的相册。

### 第三步：等它做完

导入期间可以离开，稍后再回来看。系统会在本机完成这些事（你不必逐项操作）：

1. **摄入**：看朝向、去重、拦 RAW、去掉明显太糊或太小的图
2. **聚类**：按时间和地点切成几段故事，再按场景收束
3. **选片与分章**：挑封面、压低连拍和杂物、给每一段排版
4. **成册**：套上杂志模板，生成可以预览的画册

当前默认不要求你配置任何「写作引擎」或 API Key。先把照片长图做出来，才是这一版的完成定义。

### 第四步：预览，而不是立刻重做

预览页的默认动作是**验货**：翻一遍，看顺不顺、敢不敢发。

你可以：

- 删掉不想出现的照片
- 改几个字
- 换封面气质，或在「杂志成册 / 更贴比例」之间选一种风格
- 需要时再微调某一屏

不建议第一次就把所有开关都打开。先出一本，再决定要不要精修。

### 第五步：保存，并确认文件在哪

点保存长图。成功之后，请用「在文件夹中显示」确认文件已经落在你的电脑上。

**文件保存了，才算做完。** 知道怎么发到微信，是下一步；产品不会替你发，也不会上传到任何社交平台。

## 7. 完整能力

对外仍是「自动分章 · 配文 · 排版」。下面按用户能碰到的能力写全，不写内部工程名。

### 7.1 导入与挑片

| 能力 | 你能感受到的 |
|------|----------------|
| **选这一趟的文件夹** | 不用一张张上传；一次一趟，大约 20～150 张最舒服，上限约 250 张 |
| **读照片自己的信息** | 用拍摄时间、朝向、地点把顺序理顺 |
| **去重与连拍收束** | 同一下快门连拍不会整组堆上册 |
| **质量闸口** | 明显太糊、太小的图会少出现；也可以选「全部保留」 |
| **拦 RAW** | 原片请先导出成 JPG / PNG / WebP（HEIC 通常可用） |
| **少量短视频** | 可以带，主体仍是照片，不是剪辑台 |
| **示例相册** | 第一次可以先走一遍示例，再导入自己的照片 |

### 7.2 分章、选片、成册

| 能力 | 你能感受到的 |
|------|----------------|
| **按旅程切开** | 不是 200 张平铺，而是「第一天 / 那家店 / 回程」这样的章节 |
| **按场景收束** | 同一处风景、同一桌饭会收成一组 |
| **分镜** | 同一动作的几张，会收在一起讲，而不是拆散 |
| **精选与高光** | 更好的一张会靠前；值得停一下的瞬间会被看见 |
| **杂物降权** | 菜单、地面、重复餐盘不会占满一屏 |
| **杂志排版** | 横竖搭配、该拼才拼；等权宫格默认可用 |
| **两种气质** | 「杂志成册」或「更贴照片比例」，一句话选，不必调一堆开关 |
| **两种成册** | 默认游记（快、敢发）；可选作品集（更讲究页序），由你主动选 |

### 7.3 封面、文案、阅读

| 能力 | 你能感受到的 |
|------|----------------|
| **封面装帧** | 开篇像「这一本」，不是文件夹里的第一张 |
| **封面与封底成对** | 开头和收束互相认得，不像两张随便拼的图 |
| **短文案** | 有章节名和少量说明；当前默认本机朴素配文，不必先配模型 |
| **可选杂志文案** | 你以后自己在本机配置模型，可以加强句子和封面字体 |
| **大屏卷轴** | 16:9 杂志风 HTML，封面、分章、拼图、尾声，可收藏 |
| **全屏放映** | 同一屏序可以一张张放，适合自己回看 |
| **竖版长图** | 同一屏序导出 9:16，发给群里，对方不用安装 |

### 7.4 预览与精修

| 能力 | 你能感受到的 |
|------|----------------|
| **先验货** | 默认动作是翻一遍，看顺不顺、敢不敢发 |
| **删图、改字** | 不想出现的拿掉，几个字可以改 |
| **换封面气质** | 开场皮肤可换，不必重做整本 |
| **书架回访** | 做过的本子留在本机首页，下次还能打开 |
| **进度可离开** | 导入或导出时可以离开，稍后再回来看 |

### 7.5 导出与分享

同一本做完之后，按你要发的地方再出一份，不必重做。

| 出口 | 你会拿到 |
|------|----------|
| **微信群** | 竖版杂志长图（当前最重要的分享物） |
| **朋友圈** | 大约 6～9 张，按故事切开，尽量不在单张照片中间切断 |
| **小红书** | 一组 3:4 卡片，适合轮播笔记 |
| **公众号** | 一组 3:4 图，可插入图文 |
| **画册 / 印刷参考** | 左右成对的跨页图 |
| **单张海报** | 一张有主图的封面感海报 |
| **批量勾选** | 可以一次勾几个平台，一起出 |

产品不会替你发到任何社交平台。文件在文件夹里，才算做完。

### 7.6 工作台与形态

| 能力 | 你能感受到的 |
|------|----------------|
| **Studio 工作台** | 装在自己电脑上，浏览器打开本地页；无需注册 |
| **Windows 桌面版** | 绿色便携包 / 安装包，不必先装 Python |
| **开发者命令行** | 同一套管线可以分步跑，便于自己排查 |
| **帮助按需出现** | 不打断验货；卡住再问，没有连环新手引导 |

## 8. 产品特点

能力是「能做什么」。特点是「它和别的工具不像什么」。

1. **成册完工，不是旅行 OS。** 主职是这一趟做成可翻、可发的游记。不要求先建库、先填愿望清单、先学模板。
2. **珍贵汇总，不是全量倾倒。** 该留的留下，该收的收住。不是网盘，也不是九宫格放大。
3. **照片留在本机。** 默认不上传、不注册、不锁在平台里。交付物是你电脑上的文件。
4. **先结构，后句子。** 先分章、选片、排版，再配短文。当前版本先保证敢发长图，不把配模型当主线。
5. **一条主链，两种成册。** 默认游记；作品集要你自己选。不会合成「又快又精」一个按钮。
6. **一次做成，随你发哪儿。** 主叙事是一本游记。群聊、朋友圈、小红书、公众号、画册、海报是做完之后的出口。
7. **人还在环里。** 可以删图、改字、换封面、决定发不发。它是编辑，不是代你审美的黑箱。
8. **读法和导出同一屏序。** 卷轴里翻到的，就是长图里会看到的，不会导出成另一本。

## 10. 隐私、数据与所有权

这是产品最硬的承诺之一。

| 问题 | 答案 |
|------|------|
| 照片会上传吗？ | 默认不会。处理发生在你的电脑上。 |
| 要注册吗？ | 不要。 |
| 成品在哪？ | 在你本机的画册目录里（绿色便携版通常在程序旁边的 `trips` 文件夹）。 |
| 精确定位会公开吗？ | 导出时会剥离精确 GPS；发到哪里由你决定。 |
| API Key 呢？ | 若你以后自己配置模型，密钥只存在本机，不经过我们的云。 |
| 卸载后呢？ | 程序可以删；你的照片原片始终在你原来的文件夹。成品目录请自行备份。 |

长图是你主动保存、自己发送的。产品不对微信群或任何社交平台做访问控制。如果某一趟特别私密，请自己决定发不发、发给谁。

## 13. 常见问题

**Q：一定要联网吗？**  
导入、排版、预览、出长图，默认都可以在本机完成。只有你自己以后选择配置外部模型时，文案相关步骤才会访问对应服务。

**Q：会不会把我的照片变得很「AI」？**  
不会改像素内容，也不会默认生成一张假风景封面。它做的是编辑：挑哪些图、怎么分组、怎么排。

**Q：文案不够杂志怎么办？**  
当前版本先保证照片长图敢发。配文默认朴素。设置里的模型配置是进阶项，不是第一次使用的必经之路。

**Q：能导入 RAW / 视频吗？**  
RAW 会被拦截，请先导出成片。少量短视频可以带，但产品主线仍是照片成册，不是剪辑。

**Q：一张图都不想被丢掉，怎么办？**  
可以走「全部保留」一类选项（界面里按提示选择）。注意：全留不等于更好看，成册仍然会做排版，只是少做质量剔除。

**Q：成品可以给不会装这个软件的朋友看吗？**  
可以。把长图或导出的图片发出去即可。对方不需要安装 Travelogue。

**Q：和美图、醒图、剪映、Lightroom 有什么不同？**  
那些工具帮你修单张、剪视频或调色。Travelogue 帮你把一整趟照片做成一本有章节的册子，并导出能发的长图。

**Q：收费吗？**  
当前是自用与种子试用阶段，许可证未对外发布。没有账号，也没有「试用三天后续费」。若以后有桌面安装版或创作者包，会单独说明，不会把阅读和转发变成付费墙。

**Q：我的数据会不会在升级后丢失？**  
绿色便携版的画册一般在程序旁边的 `trips` 目录。升级或移动程序前，请先备份这个目录。原片仍在你原来的相册路径，不受影响。
