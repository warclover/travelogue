## 0. 一句话

在**不新开旅行 OS、不与 Notion/行前系统抢战场**的前提下，把产品主轴收束为：**旅行结束后，用户能一次做完一本可分享的游记**——默认路径按「截取型」设计（选相册 → 出游记 → 分享），成册交付「珍贵汇总」而非倾泻，并以**分层完成口径下的首趟完工 + 14 日行为回流**作为防搁置验收，而非「搭好空系统」或「口头愿再做」。

## 1. 背景与问题

### 1.1 信号来源

| 信号 | 原文摘要 | 产品翻译 |
|------|----------|----------|
| **截取型** | 「P 人只做第一步和最后一步：期待旅行——照片汇总」 | 禁止中间系统工程；要情绪起止 + 成册汇总 |
| **意向搁置型** | 「本来也想这样做，结果只有一趟路线图就搁置了」 | 意向≠习惯；失败在维护成本 |

本产品**主职是第三次快乐的完工**（CHARTER §5.1）：整理回味 → 成册 → 微信向分享。

### 1.2 战略判断

| 判断 | 含义 |
|------|------|
| 竞品不是 Notion | 我们做成册与分享，不做行前 OS |
| 量产用户更轻 | 截取型 / 搁置型是可获客面 |
| 短板在漏斗与可信 | HGM/扩库解决不了做不完、不敢发、发出去不像同一本 |
| 编排既有主线 | 收口 FTUE/FST/Share/LTN，不另起产品线 |

### 1.3 用户可感知问题（P-FTT-*）

| ID | 问题 | 用户体感 |
|----|------|----------|
| **P-FTT-01** | 路径像搭系统 | 要先懂配置才敢开始 |
| **P-FTT-02** | 成稿≠完工 | 预览过了但没导出/发出 |
| **P-FTT-03** | 三模式撒谎 | 网页满意，长图垮掉 |
| **P-FTT-04** | 汇总像倾泻 | 不像可翻画册 |
| **P-FTT-05** | 第二趟无引力 | 首页像仓库；再开始像待办 |
| **P-FTT-06** | 话术绑人设 | Notion/J 人腔排除 P 人 |
| **P-FTT-07** | 已挑子集仍重 | 精选夹被道德施压倒全库 |
| **P-FTT-08**（新） | 最后一公里不清 | 「发哪一份」不明确 |
| **P-FTT-09**（新） | 失败即搁置 | 导入/生成/导出失败无恢复 |

### 1.4 职责切分

```text
第一次快乐（决定出发）  → Out of Scope
第二次快乐（身在旅途）  → Out of Scope
第三次快乐（整理回味）  → ★ FTT
                           ├─ 成册（策展 + 杂志语法 + 节奏）
                           └─ 分享（长图 · 微信向 · 不教操作）
```

## 2. 产品原则与冻结决策

### 2.1 原则

| ID | 原则 | 操作化 |
|----|------|--------|
| **FTT-PR-01** | 成册完工，非旅行 OS | 成功定义不含「系统搭好」 |
| **FTT-PR-02** | 默认截取路径 | `选相册 → 出游记 → 分享`；配置后置 |
| **FTT-PR-03** | 汇总要珍贵 | 禁止张数 KPI |
| **FTT-PR-04** | 防搁置优先 | 只问：首趟完工？第二趟回流？ |
| **FTT-PR-05** | 话术对齐完工 | 「旅行结束，照片还在——游记一次做完。」 |
| **FTT-PR-06** | 编排不造轮 | 相邻 PRD 拥有字段合同 |
| **FTT-PR-07** | HGM/扩库后置 | 可信与防搁置未过线不加戏 |
| **FTT-PR-08**（新） | 完成须分层宣布 | 禁止用「打开文件夹」对外宣称防搁置 |
| **FTT-PR-09**（新） | 默认自动 + 轻控制出口 | 零步成稿；导出前可微调；禁止工作台化 |

### 2.2 冻结决策（D-FTT-*）

| # | 决策 | 结论 |
|---|------|------|
| **D-FTT-01** | 波次 | **W0 → W1（LTN A/B）→ W2（LTN C/D）**；**W3a**（再做一趟入口+埋点）可 **W1 后并行**；**W3b**（COPY/线框 F2–F6/轻控制）为 W3 主体；HGM 后置 |

| **D-FTT-03** | 默认意图 | 复用 L0 / quick_share；不新建意图层 |
| **D-FTT-04** | 否决默认 | Planner / 商城 / 排版工作台 / 人生数据库 → NO；豁免见 §11.4 |
| **D-FTT-05** | LTN | FTT 不改 LTN 合同；消费其 AC 与样本 |
| **D-FTT-06** | 第二趟 | 有作品态一等 CTA = **「再做一趟」**（OQ-02 已关）；= 新建独立 trip 输入选择；与「继续精修」分流；不覆盖首趟 |
| **D-FTT-07** | 已挑子集 | 小集为正常输入；**30–80 张仅为测试代表样本，不是支持下限或质量承诺** |

| **D-FTT-11**（新） | 示例计分 | 示例路径可证 L0 走通；**对外「首趟完工率」分母默认仅计真实本地输入**（示例另列） |
| **D-FTT-12**（新） | COPY 边界 | FTT 拥有**固定主句方向 + 禁区表**；其他触点细则归 COPY/各主题，改主句须点名 FTT |

### 2.3 完成状态机（合同）

```text
NoTrip
→ InputSelected
→ ImportValidated
→ Generating
→ DraftReady                 （成稿可预览）
→ PreviewVerified            （卷轴±长图已可发现；狗粮记录）
→ Exporting
→ ExportSucceeded            （文件真实落盘且可打开）
→ DeliveryLocated            （用户已定位本次交付物）
→ ShareHandoff               （可选：已发出 / 稍后分享 / 仅保存）
→ Completed                  （= ExportSucceeded ∧ DeliveryLocated）

旁路：ImportBlocked | GenerationFailed | ExportFailed | InterruptedRecoverable
```

| 状态 | 出口条件（摘要） | 禁止 |
|------|------------------|------|
| InputSelected | 选定示例或本地路径且系统可读 | 选择后无反馈；强迫全库 |
| ImportValidated | 可生成或人话修复动作 | 静默丢图；重选丢状态 |
| Generating | DraftReady 或可恢复失败 | 无限等待；离开即丢输入 |
| DraftReady | 预览可开 | 把预览当 Completed |
| ExportSucceeded | 文件落盘可打开（非仅 toast） | 假成功 |
| DeliveryLocated | 用户打开**本次**交付位置 | 打开无关旧文件等权计入 |
| Completed | 上两行同时满足 | 「仅预览」「仅打开位置」 |

**InterruptedRecoverable**：须保留输入、任务进度与可重试点。

### 2.4 宣布用语门槛

| 宣布用语 | 最低证据 | 可否对外 |
|----------|----------|----------|
| 可生成 | DraftReady | 对内/狗粮 |
| 可导出 / 技术交付 | ExportSucceeded | 可 |
| 交付物可定位 | DeliveryLocated | 可（勿称完工） |
| **首趟完工** | **Completed** | 可（须样本口径） |
| 愿分享 / 分享交接 | ShareHandoff 有应答 | 可 |
| **防搁置 / 会再来** | **14 日内再次 InputSelected 或新建 trip** | **行为证据齐备前禁止** |

## 3. 目标与非目标

### 3.1 目标

| ID | 目标 | 验收口径 |
|----|------|----------|
| **G-FTT-01** | 截取路径可走完 | 无强制 API/建库；至 DraftReady + 成功面稳定（FST） |
| **G-FTT-02** | 首趟完工 | 跨画像狗粮中达成 **Completed** 的比例见 §10.3；可用性闸门 N 规则见下 |
| **G-FTT-03** | 分享面敢发 | 继承 FST/Share/SFC AC；内容一致性硬化与存量兑现由 **[SFI](./PRD-SHARE-FACE-INTEGRITY-V1.md)** 支线执行（§4.2）；无说明书腔、无系统搭建文案 |
| **G-FTT-04** | 成册不撒谎 | LTN B 关键 AC + FTT 三模式狗粮 |
| **G-FTT-05** | 汇总像画册 | LTN C/D + 用户词盲评（LTN 量表） |
| **G-FTT-06** | 第二趟可启动 | ≤1 点击「再做一趟」→ 新 InputSelected；冷启动可测 |
| **G-FTT-07** | 话术一致 | 主句/禁区抽检零命中 |
| **G-FTT-08** | 失败可恢复 | Import/Generate/Export/Interrupt 均有人话出口（§5.3） |
| **G-FTT-09** | 轻控制不伤截取 | 默认零步；成册者可在导出前轻控（§8.4） |

### 3.2 非目标

| 不做 | 原因 |
|------|------|
| Travel Planner / 愿望清单 | 第一次快乐 |
| Notion 同步 / 人生书架产品化 | OS 化 |
| 重写 FTUE/FST/Share/LTN 全文 | 编排即可 |
| 完整 HGM / 多模板工作台 | 后置 / 否决 |
| 强制微信分步教学 | FST/D-FTT-10 |
| 平台级真实发送埋点 | 用可选 ShareHandoff |

### 3.3 成功指标（修订）

| 指标 | 定义 | 用法 |
|------|------|------|
| **生成率** | DraftReady / InputSelected | 漏斗诊断 |
| **导出率** | ExportSucceeded / DraftReady | 技术交付 |
| **首趟完工率** | Completed / InputSelected（**真实输入**） | 核心；示例另列 |
| **分享交接率** | ShareHandoff 有应答 / Completed | 代理「愿分享」；非强制 |
| **第二趟回流** | 自 Completed 起 14 日内再次 InputSelected 或新 trip | **行为**；「愿再做」仅访谈 |
| **搁置否决数** | 评审引用 §11.3 次数 | **治理指标**，非成功 KPI |

**可用性闸门（非率）**：跨画像狗粮合计 N≥5（配额见 §10.3）中，**≥4** 达成 Completed，才可对内宣布 M-FTT-0 候选；**不足以**对外宣称「防搁置已验证」。

### 3.4 事件字典 v0（语义合同）

| 事件语义 | 触发 | 去重建议 | 归属 |
|----------|------|----------|------|
| `ftt_input_selected` | 选定示例或本地路径 | 每 trip 首次 | FTUE / FTT |
| `ftt_import_validated` / `_blocked` | 校验通过/阻断 | 每尝试 | FTUE |
| `ftt_generate_started` | 进入 Generating | 每 job | 管线 |
| `ftt_draft_ready` / `_failed` | DraftReady / 失败 | 每 job | 管线 |
| `ftt_export_succeeded` / `_failed` | 文件落盘可开 / 失败 | 每导出 | Share / Export |
| `ftt_delivery_located` | 用户打开本次交付位置 | 每 Completed 窗口 | FST / FTT |
| `ftt_share_handoff` | 三选一应答 | 每 Completed | FTT |
| `ftt_again_impression` / `_click` | 「再做一趟」曝光/点击 | 会话级 | FTT W3a |
| `ftt_second_input_selected` | Completed 后再次 InputSelected | 用户+14d | FTT |

### 5.1 需求

| ID | 需求 | 说明 |
