## 1. 纲领（一句话）

> **Travelogue 的核心价值是：用丰富、美观的屏级版式（拼图 + 横单 + 竖单）呈现旅行照片；章节结构、叙事弧与文案服务于版式，而非与之竞争用户注意力。**

对外可简述为：**「像杂志一样摆图」优先于「像作家一样讲故事」。**

---

## 2. 三条产品原则

| ID | 原则 | 说明 |
|----|------|------|
| **P-LAY-01** | **拼图模板足够丰富；单屏拼图上限 9 张** | 单屏 **≤9 张**；**丰富度主战场 = 4 / 5 / 6 张**（可变化形式最多）；**7 / 8 / 9 张维持现状、非重点**；不考虑 10+ 张单屏。 |
| **P-LAY-02** | **拼图、单张横版、单张竖版的排版须合理、美观** | 用户感知主要来自 **哪张图、如何裁切、槽位与留白**；须避免满屏竖墙、别扭混排、主体被切、连环同款 grid。美观是 **第一类产品目标**，不是算法 proxy 的副产品。 |
| **P-LAY-03** | **章节、叙事、文案的重要性低于拼图与排版** | 分章、故事线、LLM 长文案、记忆锚点等 **不得占用主路径的核心研发与验收带宽**；默认体验允许 **轻章节 + 极短 hook**；深度叙事归入可选 / Studio 进阶，**不以「故事更清楚」作为排版阶段的北极星 Gate**。 |

### 2.1 P-LAY-01 的工程边界

- **硬上限**：`photoCount.max ≤ 9`、单屏 slots ≤ 9（与 LTE validator `V-P16-12` 一致）。
- **张数优先级**（产品拍板 2026-06-11）：

| 档位 | 张数 | 研发 / 验收 |
|------|------|-------------|
| **P0 重点** | **4、5、6** | 可变化形式最多；新增模板、探针截图、选版调优 **优先投入此处** |
| **维持** | **7、8、9** | 现有竖/横九宫、八宫格等 **已够用**；不列为丰富度 backlog |
| **基础** | 1–3 | 单张横/竖 + 少量混排；随 P0 迭代即可 |
| **禁止** | >9 | 拆屏或减图 |

- **「丰富」定义**（验收导向）：在 **4–6 张探针集**上，每个 n 具备 **多种构图语义可区分** 的活跃模板（主图位、横竖比、主次、留白），而非仅 slot 坐标微调。
- **明确不做**：10+ 图单屏；为 7–9 张堆同质变体；为凑 SKU 占比而扩模板库。

### 2.1.1 资产 AR 与多图对齐（已拍板 2026-06-11）

详见 [TEMPLATE-USE-CASES.md](./TEMPLATE-USE-CASES.md) §0。

| 规则 | 阈值 / 策略 |
|------|-------------|
| 全景 / 超宽 | 宽高比 **≥ 2.5:1** → UC-2 / UC-3 全景 stack 等 |
| 近正方形 | **0.85–1.15** → UC-3 方图 + 双横版 |
| 多图长宽比不一 | **`contain` + 同高 stage**（较长边对齐，不 cover 硬裁） |
| 5 张构图 | **5A + 5B 均实现** |
| 7 / 8 张用例 | **仅归档，不实现** |

### 2.2 P-LAY-02 的「美观」可操作化

优先用 **可回归护栏** 保障底线，用 **探针截图 + 设计者肉眼** 迭代上限：

| 维度 | 底线（自动化） | 上限（人工） |
|------|----------------|--------------|
| 裁切 | focal 生效、AR 匹配、无 pattern 级 object-position 硬编码 | 主体舒服、无「假竖条横图」 |
| 节奏 | breath / 同 pattern 连发 ≤2 | 单张与拼图交替自然 |
| 单调 | 显式 fallback 率可控 | 同屏主次分明、不像模板 DEMO |

> P19 dogfood 结论：**屏序 / pattern 调度的大幅算法 diff，若未改变版式语言，用户可能无感知**；P-LAY-02 要求动 **模板库与选版**，而非仅动排序。

### 2.3 P-LAY-03 与历史能力的对齐

| 能力 | 定位 |
|------|------|
| ingest / 去重 / 质量门 | **支撑排版**（进槽素材可靠） |
| 拼图 + 横竖单版式 | **核心产品** |
| 分章 / 行程段 | **轻量结构**（时间/地点粗分即可） |
| narrate / 长文案 / 叙事弧 | **后置或可选** |
| 盲评「故事更清楚」 | **非排版阶段北极星**（可作 copy 专项指标） |

Phase 4「杂志心智」、G1 记忆锚点等文档 **仍然有效**，但优先级低于 P-LAY-01～03；冲突时以 **本文** 为准。

## 3. 研发与验收纲领

### 3.1 投入优先级（替换「先叙事 / 先 LSE / 先盲评胜率」）

```text
1. 版式库 P0：4 / 5 / 6 张 mosaic 与混排版（LTE + CSS + 探针截图）
2. 版式库维持：7 / 8 / 9 仅回归不修；1–3 与横竖单随需
3. 选版与像素：图进哪槽、cover/contain、focal、硬约束
4. 选片底线：糊片、重复、明显不该上屏的图（为排版服务）
5. 轻章节：默认规则分章即可
6. 叙事与长文案：可选路径 / 后续 Phase
7. 求解器微调、LSE 上量、屏序-only 优化：默认不做
```

### 3.2 验收口径

| 采纳 | 不采纳（排版阶段） |
|------|-------------------|
| 探针集 badcase 率（裁切/节奏/单调） | 仅凭 `patternDiversity` 等 proxy |
| **4–6 张**探针 badcase 闭合、同 n 多构图可区分 | 7–9 张扩 SKU；designer 占比类机械 Gate |
| 真实 trip 回归（不意外丑屏） | 要求 ≥3 人 × 8 本盲评胜率作合并门槛 |
| 产品负责人对探针成稿的肉眼通过 | 「故事更清楚」≥60% 作排版北极星 |

### 3.3 与 Phase 19 的关系

P19 交付的 **硬约束、像素闭环、Schema v2 基础、可选 subset/highlight（默认关）** 可作为 **护栏** 合入；  
P19 **未证明** 的「盲评胜率 / 屏序调度观感跃迁」**不阻塞** 以 P-LAY 纲领为主导的下一阶段。见 [ACCEPTANCE-PHASE19.md](./ACCEPTANCE-PHASE19.md)。
