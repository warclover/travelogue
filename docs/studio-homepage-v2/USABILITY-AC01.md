---

## 1. 目标

**Then**：5/5 被试在 **10 秒内** 能复述「卷轴演示 + 9:16 长图」两个输出形态。

---

## 2. 被试与场景

| 项 | 要求 |
|----|------|
| 人数 | **5**（+ 1 备用） |
| 画像 | 会用文件夹导入照片；未参与 M20 内部开发 |
| 设备 | Windows/macOS 桌面浏览器 **或** iPad 横屏 Safari |
| 环境 | dogfood URL 或 loopback + 团队 VPN |
| 数据 | 空书架（IdleEmpty）或 Returning 均可；**禁止** 测试员代操作 Import |

---

## 3. 流程（约 15 min / 人）

1. **开场**（1 min）：「这是 Travelogue Studio 新首页，请自由浏览，无需完成任务。」
2. **自由浏览**（3 min）：被试自行滚动 Bento、点 carousel、可选点 ⤢。
3. **复述**（计时）：「这个产品是做什么的？你看到了哪两种作品展示方式？」
   - **通过**：10s 内提到「卷轴/翻页/半页」+「长图/竖图/9:16」各至少一种表述。
4. **可选任务**（5 min）：「如果你想开始做一本游记，你会点哪里？」→ 记录是否找到 CTA。
5. **追问**（2 min）：demo-flag 是否注意到？Unsupported 未测。
