> **一句话目标**：把已能干活的临时库，收成一个与现网**机器隔离**的后台工坊——设计页型、看微缩、标常用度、手编成册、真图验证；试好的页型和角色系列，只以**升格包**交给现网，从不被引擎直接读取。
>
> **产品铁律**
>
> 1. **工坊是长期产品，不是过渡夹。** 试验失败关在这里。  
> 2. **机器隔离，词汇表统一。** 现网不引用工坊实现；数据包字段 / 角色 / `program` 必须同构。  
> 3. **升格包，不是管道。** 禁止现网扫工坊目录，禁止一键写入引擎，本波禁止抽共用模块。  
> 4. **包裹只有两样：页型包 + 角色系列。** 星、真图、草稿、任意页试刊、打开脚本不进包。  
> 5. **工坊回答好不好看；现网回答许不许可用。** Studio「版式」进 TSU 五入口，不进本工坊。

## 1. 问题与 As-Is

### 1.1 要解决的问题

模板引擎升级缺的是成册层 + 诚实的页型资产面。这件事的前半——**把脸画出来、看成册、用真图验几何**——已经在临时库 HTML 上跑通，而且试印结论是：这批脸的杂志感好于现网长图，值得当精致 Web 预览的方向。

缺的是产品身份：

- 临时库没有被承认为长期工具，开发者靠手输地址或双击 HTML。  
- TSU 把治理台 / 编排器写成现网必修，但七席仍挡 A7/B7；若把工坊 HTML 整包并进 Studio，试验床和出册管线会焊死。  
- 若现网再独立做一套相同工具，会得到两套微缩、两套拖轨、两套「真相」。  
- 若留「现网直接读工坊」的活接口，隔离是假的，关旗关不干净。

### 1.2 工坊 As-Is（2026-08-19）

现场：`docs/templates/reserve/`。引擎、MCS、CI **不读**。

| 工作台 | 现状 | 本波 |
|--------|------|------|
| 创建页型 | 新夹 + `packet.yaml` + 总表一行 + `faces.js` 一条 | **收编**。V1 保持填包，不做画框器 |
| 微缩 | `gallery.html` 按数据包画槽；竖红横蓝金方 | **收编**。继续从包投影，不手绘第二套 |
| 星级 | `stars.yaml`；微缩 tab 点星后写入 | **收编**。继续只活在工坊 |
| 成册 | RSC W1：多本 YAML、静态服目录、金样保护、草稿分格 | **收编**。细则不重写 |
| 试印 | `preview.html`：按星级轮转 / 按系列消耗朝向 | **收编**。W2 加一组一页 |
| 升格 | 人口述「抄进附录 A」 | **本波主增量**：升格包 + 检查单 + `promote-ready` |
| 入口文案 | 「备用 / 临时」 | **本波主增量**：改称设计工坊；与 Studio「版式」分家 |

### 1.3 现网 As-Is（对照，不在本波改代码）

- 首页底栏「版式」已链 `/templates-admin`。  
- `/templates-admin` 仍是 P13 五态平铺表，没有五入口、没有成册对象、没有工坊入口。  
- 活目录仍是 `screen-*`；附录 A 六张 `page-*` 是文档合同，未入库。  
- 画册仍是 ECC 3:4 两卡（TSU D-U-09）。

## 2. 目标与非目标

### 2.1 目标（V1 出门）

1. **工坊有身份。** 打开方式、界面用词、README 都叫设计工坊。不再暗示「这只是临时夹，做完就搬走」。  
2. **五块工作台在同一现场可完成日常。** 创建（填包）、看微缩、标星、编样例、真图试印。  
3. **机器继续不读工坊。** 验收能指出：现网路径、MCS、正式系列目录、`trip.json` 没有新增引用。  
4. **升格可执行。** 能导出页型包和角色系列；检查单能拦身份不诚实、角色对不上、把星/照片塞进包。  
5. **两个入口分家。** 工坊自己打开；Studio「版式」只进现网柜（TSU 合同，本波不改链）。

### 2.2 非目标

| 不做 | 说明 |
|------|------|
| 现网五入口 / `/series-editor` | 归 TSU。本波零 Studio 路由 |
| 匹配器 / 父开关 / 出册改脸 | 归 TSU W2。工坊不冒充运行时 |
| 现网再造一套铺图 / 点星 / 任意页试刊 | 那是工坊的工作，禁止重复建设 |
| 活接口或共用模块 | 现网不扫 `reserve/`；不抽共享渲染核 |
| 画框器 / Mixbook 填图 | 创建仍是数据包；试印不是 C 端填槽 |
| 把工坊脸顶岗默认长图 | 快分享继续 `screen-*` |
| 接到 `album_spread` | D-U-09 分波；另立编译合同 |
| 引擎消费星级 | 星不当 MCS 分数 |
| 自动交 B7 七本正式 SKU | 16 页金样留工坊；B7 第一稿由**项目运营**按附录 B 改写，**产品**签核后走 TSU（D-TDV-17） |
| UI 删本 / 重命名 / 并排对照台 | 沿用 RSC：手删 YAML 后刷新 |
| 搬家出现网静态资源目录 | 现场留在 `docs/templates/reserve/` |

### 2.3 完成定义（产品）

日常设计不再需要打开现网治理台。设计师能：加一张脸、看见微缩、标星、编一本任意页数、用本机相册铺上、认为够好时导出升格包。现网可以几天后才收。旧游记与默认长图不因工坊任何操作而改变。

## 3. 冻结决策

| ID | 决策 |
|----|------|
| **D-TDV-01** | 工坊是长期后台产品。禁止再把现场说成「做完就并进引擎的临时夹」。 |
| **D-TDV-02** | 现场路径保持 `docs/templates/reserve/`。改的是身份与合同，不是搬家。 |
| **D-TDV-03** | **机器隔离。** 引擎 / MCS / LTE registry / CI 业务断言 / 现网系列目录 / `trip.json` **不读**本目录。本波零 Python 业务包（静态服 `serve.py` 除外，且只服务工坊）。 |
| **D-TDV-04** | **词汇表统一。** 数据包字段下限 = TSU 设计理由 §5；`program` 引用 EDC 枚举；角色升格时必须能对上 TSU 附录 B 或显式标「试验角色，附录 B 未收」。禁止第三套主编词。 |
| **D-TDV-05** | **实现独立。** 现网管线升级可借鉴工坊手感，禁止引用工坊 HTML/JS/CSS 当依赖。禁止为「少写一遍微缩」抽本波共用模块。 |
| **D-TDV-06** | **升格包，不是管道。** 禁止现网扫描工坊目录。禁止工坊一键写入 `layout_templates` 或现网系列目录。 |
| **D-TDV-07** | 升格包只含：**页型包**和/或**角色系列**。见 §6。 |
| **D-TDV-08** | 不进升格包：`stars.yaml`、本机照片、浏览器草稿、`file://` 种子、`serve.py` / `serve.cmd`、未满目标的试刊本（除非人显式导出并标 sketch）。 |
| **D-TDV-09** | 星级只认工坊 `stars.yaml`。未列出 = 0。镜像不自动继承。数据包 / 附录 A / 现网 YAML **不写星**。 |
| **D-TDV-10** | 星是工坊**门槛信号**，不是选型分数。默认：`promote-ready` 建议 ★★★。**覆盖理由是常态**（当前三星只有少量），不是例外。现网状态机不出现星星。 |
| **D-TDV-11** | 真图试印永远留在工坊。照片只在浏览器本地读。不要导出、不上传、不进 trip。 |
| **D-TDV-12** | 工坊试印 ≠ 现网预演。两个概念、两套界面、两句人话。 |
| **D-TDV-13** | 创建页型 = 填数据包出微缩。V1 **禁止**自由画框、改槽 `rect` 的可视化编辑器。 |
| **D-TDV-14** | 成册工作台沿用 RSC：一本 = 一份 YAML；金样 `folio-16-standard` 不可被新建占用；日常走静态服。 |
| **D-TDV-15** | 工坊成册**允许拖脸**（试验要快）。落盘仍写 `role` + `program` + `faceHint`。**升格用的系列必须能导出角色序**；`faceHint` 若不是附录 A 已有 id，检查单标「脸未准入，只交角色」。 |
| **D-TDV-16** | 工坊样例页数任意，不是正式档位。禁止把「32 页试一本」写成现网第二 SKU。 |
| **D-TDV-17** | `folio-16-standard` 是工坊精致对照本，**不是** TSU B7。B7 角色金样**第一稿由项目运营**用工坊对照本改写成附录 B 角色序；**产品签核**后才算 TSU B7。禁止用未改写的对照本交差。 |
| **D-TDV-18** | 正式系列一旦被现网收下，**权威在现网那一份**。工坊里同名或同源本降为设计稿；再改工坊不会自动改现网。 |
| **D-TDV-19** | Studio 首页「版式」**只进现网 TSU 柜**。禁止链到工坊 HTML 或本夹静态服。 |
| **D-TDV-20** | 工坊自己的打开方式：`serve.cmd` / `python serve.py`。界面品牌「设计工坊」。不进 Studio 底栏。 |
| **D-TDV-21** | 不把脸画软。朝向硬门、组先于脸。装不上就换兄弟或少槽，不改槽比。 |
| **D-TDV-22** | 快分享现网长图继续 `screen-*`。工坊 `page-*` 服务精致 Web 方向，升格后仍由 TSU 决定何时给新册用。 |
| **D-TDV-23** | 画册跨页本波不接。对外禁止说「画册已经按页用 `page-*`」。 |
| **D-TDV-24** | 工坊页型状态：`sketch` → `reviewed` → `promote-ready`。`designed` 只属于 TSU 附录 A。入库代码后的五态属于现网。 |
| **D-TDV-25** | 现网薄柜必须存在（五入口 + 正式系列可登记 + 关旗）。实施归 TSU，不在本 PRD 开门。未建薄柜不得假装升格已闭环。 |
| **D-TDV-26** | 现网收件（TSU 侧）读的是人交过来的升格包，可做校验后写入正式目录。**收件动作扫的不是工坊文件夹。** |
| **D-TDV-27** | 邻页软规则沿用 TSU / RSC：双密网、opener 连 opener、closer 在中段。灯是编辑提示，不挡工坊保存。升格正式系列时灯必须可见。 |
| **D-TDV-28** | 封面封底沿用现网默认 hint，工坊不编书衣砖。升格系列可带 `coverHint` / `backHint`，现网书衣业主仍是 ABE / CAL / V6。 |

## 6. 升格门

### 6.1 何时升格

人认为「这张脸或这本节奏敢给现网新册用」时。不是试印好看的自动下一步。

默认建议：

- 页型：运营标 `reviewed` + 数据包字段齐 + 建议 ★★★（**无三星须写覆盖理由，覆盖是常态**）  
- 系列：目标页数与轨上页数对齐（或人接受软目标并在包里声明）+ 未收角色已映射或声明增收 + 邻页红灯已看过  

机器硬门见 §6.4 / D-TDV-29 / D-TDV-35。过不了硬门不能生成包。琥珀项可导出，现网收件仍可拒。

### 6.2 页型包

一份页型包 = 一个文件夹快照，建议文件名 `promote-<id>-<yyyymmdd>/`：

| 必须 | 说明 |
|------|------|
| `packet.yaml` | 工坊数据包。导出前把 `status` 写成 `promote-ready`（源文件同步） |
| `USAGE.md` | 字段投影，不另写散文 |
| `sketch.png` | **必须有**。没有则工坊导出硬拒（D-TDV-35） |

禁止夹带：`stars.yaml` 片段、试印照片、整库 `faces.js`。

### 6.3 角色系列包

一份系列包 = 一个 YAML，建议文件名 `promote-<id>-roles-<yyyymmdd>.yaml`：

```yaml
id: magazine-16-standard          # 现网将用的正式 id，不要用 folio-* 试刊 id 冒充
kind: series
status: promote-ready
stage: "16:9"
pageCount: 16
density: standard                 # 正式本必须诚实标疏/正/密；不要用试刊默认蒙混
photo_span: [48, 80]
coverHint: veil-footer
backHint: closing-default
sourceAtelier: folio-16-standard  # 工坊对照本 id，仅溯源
sequence:
  - { i: 1, role: hero-land, program: hero, faceHint: page-1-hero-land }
```

导出规则（**W1 即生效**，D-TDV-29）：

1. **主序列按角色。** 每一行必须有 `role` 与 `program`。  
2. **附录 A 白名单（现行六张）：** `page-1-hero-land`、`page-2-pair-port`、`page-3-port`、`page-4-grid-land`、`page-3-2l1p-right`、`page-3-2l1p-left`。`faceHint` 在此名单内可写附录 A id。**以外一律由导出器自动标 `atelier-only`**（或同等字段），不得靠人记。现网收件时：`atelier-only` 不得直接进活目录，只保留角色，顶岗按 TSU 附录 B。  
3. **正式 id 禁止任何 `folio-*`。** 默认 `magazine-{pageCount}-{density}`。人可改，撞试刊前缀则硬拒（不只禁 `folio-16-standard`）。  
4. **未收角色 W1 必须列出。** 附录 B 没有的 `role`：人必须映射到附录 B 某一行，或声明「请附录 B 增收」。未处理则**硬拒导出**，不等 W2、不靠人表漏检。  
5. 写出 `sourceAtelier` = 工坊对照本 id。

### 6.4 检查单（硬拒 / 琥珀）

硬拒（不生成包，或不许标已导出）——**W1 即硬**：

- 页型：`id` 中数字 ≠ `slotCount`；`mix` 与各槽 `orient` 对不上；`program` 不在七词内；**无 `sketch.png`**  
- 系列：无 `role` / 无 `program`；正式 id 为任意 `folio-*`；未收角色未映射且未声明增收；`atelier-only` 未由机器标出  
- 包内出现照片文件或 `stars.yaml`

琥珀（可导出，现网可拒）：

- 建议三星未达（须已写覆盖理由，否则也硬拒）  
- `faceHint` 多数或全部是 `atelier-only`（已标明则过硬门）  
- 邻页红灯仍在  
- `pageCount` ≠ 轨上页数  

完整人检表见附录 B。

### 6.5 现网怎么收（合同，TSU 实施）

1. 人把升格包放到评审区（PR / 指定目录，由 TSU 实施定）。  
2. 现网收件校验附录 A/B 字段，通过则写入正式页型或正式系列。  
3. 收件**不**打开工坊静态服、**不**读 `docs/templates/reserve/series/`。  
4. 收下后工坊源文件仍在，状态保持 `promote-ready`；现网那一份开始过自己的日子（D-TDV-18）。

本波工坊侧只做到「能导出 + 检查单」。现网收件未做，**不得宣称升格已闭环**（D-TDV-34 / AC-TDV-19）。

### 7.5 真图试印（FE-D5）
