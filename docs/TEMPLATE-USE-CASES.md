## 0. 已拍板决策（2026-06-11）

| 项 | 决策 |
|----|------|
| **5 张** | **5A + 5B 两种构图均要实现**（`UC-5A-TOP-HERO-4`、`UC-5B-LEFT3-RIGHT2`） |
| **全景 / 超宽** | 宽高比 **≥ 2.5:1** 视为全景/超宽，用于 UC-2 / UC-3-PANO 等选版 |
| **近方图** | 宽高比 **0.85–1.15** 视为近正方形，用于 UC-3-SQUARE-LEFT-2 |
| **较长边对齐** | 统一 **`object-fit: contain` + 同高 stage**（不用 cover 硬裁对齐） |
| **7 / 8 张** | 用例 **仅归档**，**不进入实现 backlog** |

工程常量建议（实现时写入 `layout` / ingest 配置，与本文一致）：

```yaml
# 拟议 · 实现 Phase 20 时落 config
layout:
  asset_aspect:
    panorama_min: 2.5      # width/height ≥ 2.5
    square_min: 0.85
    square_max: 1.15
  multi_image_stack:
    fit: contain           # 全景 stack、方图混排等
    unify_stage_height: true
```

## 1. 字段说明

| 字段 | 含义 |
|------|------|
| **用例 ID** | 草案编号，便于 backlog 引用 |
| **n** | 单屏照片张数 |
| **横竖构成** | 槽位朝向与排列 |
| **主图位置** | 无 / 上 / 下 / 左 / 右 / 大格 |
| **对齐规则** | 多图长宽比不一致时的统一策略 |
| **典型场景** | 触发条件或素材类型 |
| **优先级** | P0（4–6 重点）/ 基础（2–3）/ 维持（7–8） |
| **现网** | 已有 patternId 或 **待新建** |
