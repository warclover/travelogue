> **定位**
>
> PFO 已经把「生成前定规格 + 满意即导」走通。2026-08-26 狗粮证明闭环能出门，但 **身份话术、票根、页数、选脸** 还没对齐产品对「两本可以同时存在」和「作品集该用最好的页型」的判断。
>
> 本主题只硬化四件事：**同夹双身份怎么说、怎么认、怎么标**；**作品集面上的游记壳用词**；**「页」只有一个数字**；**装填换脸按星、三星优先**。厚度算法、0.67 进选档、首页主 CTA、装填缺口（空 16 张）**不在本文**。
>
> **一句话目标**：同一文件夹可以同时留一本游记和一本作品集；书架票根一眼分得清；再做时说清盖哪一本、不动另一本；作品集从选夹到导出不再说画册/杂志/长图；成功面与导出说同一套页数；能换的页型优先用三星脸。
>
> **产品铁律**
>
> 1. **游记与作品集是两本，不是一本的两种皮肤。** 同夹允许同时存储；覆盖只发生在**同一身份**。  
> 2. **书架靠票根区分，不靠改标题。** 游记票根写「游记」，作品集票根写「作品集 · N 页」。  
> 3. **作品集面上禁止游记壳。** 「画册 / 杂志 / 长图 / 一篇」不得出现在作品集选夹主钮与 hint、确认脚、等待主句与估计、成功面主句、Dock 主 CTA。允许「请改选游记」「页图」。游记路径上述字面**逐字不动**（仅票根补「游记」；409 游记冻结）。  
> 4. **对 C 端「页」= 成册页。** 成功面、书架、导出主句必须同一数字。封面多导的一张不得改写成「多了一页」。  
> 5. **作品集选脸：先几何、后星。** 同槽且朝向/混排不差于计划脸时，更高星优先；三星错混不得压过二星正配；禁用脸永不选用。C 端不画星星。不把星写进 `page-*.yaml`，不在运行时读工坊目录。  
> 6. **游记装配零改。** `mosaic/**`、`screen-*.yaml`、`journal-screens.css`、`chapters.py` 本波不碰。游记 409「该画册已存在」本波不改（BLK-PIS-04）。  
> 7. **PFO 主路径不重开。** 击数、规格一句、打开∥导出、先弹面板再导，全部沿用。

### 0.1 术语

| 术语 | 定义 |
|------|------|
| **身份** | `journal`（游记）或 `portfolio`（作品集）。C 端只说这两个中文词 |
| **同夹双本** | 同一本机相册文件夹下，游记 trip 与作品集 trip **各有独立 `tripId`**，可同时出现在书架 |
| **覆盖** | 仅当用户以**同一身份**再次导入同一文件夹时，写回该身份已有 trip。另一身份的 trip **禁止**被这条导入改写 |
| **票根身份行** | 书架票面主标题下的第一行弱标。游记：`游记`；作品集：`作品集 · N 页`（无页数则 `作品集`） |
| **成册页 X** | `studio.portfolio.pageCount`。系列装出来的页数（封面屏若算进 series 则含在内，以 trip 字段为准） |
| **页图张数 Y** | 导出目录里 `*-portfolio-*.png` 的张数。可以 Y = X 或 Y = X+1（另含封面张） |
| **星** | 工坊对 `page-*` 脸的 0–3 常用度。**3 = 最优**。未列出 = 0。镜像不自动继承 |
| **禁用脸** | `stars.yaml` 的 `disabled:` 名单。工坊与现网选脸都不得用 |
| **堂亲换脸** | 计划脸装不上时，换同槽数/少槽、同朝向家族的另一张 `page-*`。本波在此排序里加入星 |
| **升星换脸** | 计划脸能装上，但存在同槽数、能装上、星更高的堂亲 → 改用更高星。本波要做 |

## 2. 目标 / 非目标 / 成功标准

### 2.1 目标

1. 同一文件夹：**可以**同时拥有游记 + 作品集；再导入只覆盖**当前身份**那一本。  
2. 书架两本并排时，票根第一行就能分清。  
3. 覆盖句必须写出「盖谁、不盖谁」；409 弹窗与确认页用同一套身份词，不互相否定。  
4. 作品集从选夹到导出成功，主路径无「画册 / 杂志 / 长图 / 一篇」（允许「请改选游记」，BLK-PIS-05）。  
5. 成功面、书架、导出主句的「页」是同一个 X。  
6. 作品集换脸：同槽且几何不差于计划脸则更高星优先；三星错混不得赢；禁用脸不出现。

### 2.2 非目标

| 不做 | 原因 |
|------|------|
| 把作品集改成默认首页主 CTA | PFO 未开 |
| 重写 `magazine-*-standard` 全序列为三星 | 属 MSP 升格；本波运行时换脸即可 |
| 运行时读 `docs/templates/reserve/` | DPI / TDV ISO-05 |
| 把星写入 `page-*.yaml` / 附录 A | 守 D-TDV-09 数据包不写星 |
| 游记 MCS 也按星选 `screen-*` | 游记零改 |
| 取消 409 二次确认 | 覆盖不可撤销，二次确认留下 |
| 自动合并/删除同名历史册 | 用户没授权清书架 |
| 装填算法重做 | 另立项 |
| 逐页精修换脸 UI | PFO OQ-PFO-01 |

### 2.3 成功标准（出门即可称 PIS 通）

- 华农：作品集确认页写明覆盖作品集、**不盖游记**；两标题相同时**不复读**书名。  
- 珠海：再导入作品集仍写回同一 `tripId`，游记若存在则不被改。  
- 书架：游记票根可见「游记」，作品集可见「作品集 · N 页」。  
- 作品集等待主句不再含「杂志 / 长图 / 画册」。  
- 导出成功主句的页数 = 成功面 / 票根的成册页；若多一张封面，只在副句说。  
- 单测：同槽且混排相当则选 3 星；错混的 3 星不得赢过正配的 2 星；禁用脸不入堂亲列表。  
- `pytest -m pipeline_isolation` 绿；游记向导/Dock 快照不因作品集用词改写而红。

## 4. 双身份：存储、覆盖、话术

### 4.1 存储模型（已实现，本文锁死）

```
同一 albumPath
  ├─ edition=journal     → tripId_j   （journal slug）
  └─ edition=portfolio   → tripId_p   （portfolio slug；ascii 加 -p / 中文 seed 加 :portfolio）
```

- 无显式 `tripId`、身份为作品集、且 **legacy journal slug 上真实 `edition=portfolio`** → 复用该旧册（现网 `_reuse_legacy_portfolio_dir`）。不得因此改写旁边的真游记。  
- peek 只返回**真实身份匹配**的 trip：`existingJournal` / `existingPortfolio` 分字段。  
- **禁止**用「同夹已有任意 trip」当成「本身份已有」。

### 4.2 覆盖决策

| 当前身份 | 已有本身份 | 已有另一身份 | 导入结果 |
|----------|------------|--------------|----------|
| 作品集 | 无 | 无 | 新建作品集 |
| 作品集 | 无 | 有游记 | **新建**作品集，游记不动 |
| 作品集 | 有 | 任意 | **覆盖**该作品集；409 后 `force`；游记不动 |
| 游记 | 无 | 有作品集 | **新建**游记，作品集不动 |
| 游记 | 有 | 任意 | **覆盖**该游记；作品集不动 |

切换向导「这次做」只改当前身份与上述表，不得把已有另一本的 `tripId` 填进本次 import。

### 4.3 确认页碰撞句（`folderCollisionCopy`）

函数签名保持 `(edition, existingSelf, existingOther)`。`existingOther.edition` 缺失时按「与当前身份相反」推断（现网已有）。

**作品集（edition=portfolio）**

| Self | Other | 书名是否相同 | C 端句（标点可微调） |
|------|-------|--------------|----------------------|
| 有 | 无 | — | 这个文件夹已经做过作品集《{self}》。继续会覆盖这本作品集。 |
| 有 | 有 | 不同 | 这个文件夹已经做过作品集《{self}》。继续会覆盖这本作品集，不会动已有游记《{other}》。 |
| 有 | 有 | **相同**（去空白后相等） | 这个文件夹已经做过作品集。继续会覆盖这本作品集，不会动书架上的游记那一本。 |
| 无 | 有 | — | 将新建一本作品集，不会覆盖已有游记《{other}》。两本可以同时留在书架上。 |
| 无 | 无 | — | （空） |

**游记（edition=journal）** — 对称，把「作品集/游记」对调；同名时同样**禁止**连续两个《同一书名》（BLK-PIS-02）。  
「两本可以同时留在书架上」只在 **无 Self、有 Other** 时出现。

### 4.4 409 二次确认

### 8.3 选用算法（BLK-PIS-01）

对每一页，输入：计划 `patternId`、本组 `asset_ids`、朝向表。

```
1. 禁用脸既不能当计划结果，也不能进堂亲。
2. 候选 = { 计划脸 } ∪ 同槽数堂亲（朝向硬门仍走 _can_admit）。
3. 只保留 take_for_page / take_for_pattern 能装上（非 skip）的脸。
4. 排序键（升序，先比左边）：
   a. 槽数差 planned_n - n
   b. -fine_overlap
   c. mix_dist
   d. -star                         # 几何相当之后，3 最优
   e. 0 if official series 用过 else 1
   f. 0 if "ultra" not in id else 1
   g. tid
5. 升星门槛：候选星更高，且 overlap 与 mix_dist **不差于**计划脸。否则保持计划脸。
6. 取第一名。升星成功 → 遥测 face_star_upgrade；demoted_pages 不因此 +1。
7. 若计划脸 skip → fallback_take，排序同上，可降槽；此路径仍可记 demoted_pages。
```

单张落到 hero：先朝向家族，再 `-star`。正朝向三星优于错朝向三星。

**禁止**：三星错混压过二星正配。官方用过的三星堂亲优先于未用过的三星（OQ-PIS-02 本场改判）。
