## 1. 背景与目标

### 1.1 现状与痛点

Travelogue(MVP+Phase 2~17)已具备 **从本地照片文件夹到杂志风 HTML 游记 + 微信长图 PNG** 的完整本地管线,Studio 工作台、Phase 14 双模式导入、Phase 17 LSE 智能排版均已就绪。**关键资产**:对 EXIF、构图、影调、节奏的处理已经达到「懂摄影」的门槛 —— 但目前这些能力藏在 CLI 和 Studio 工作台里,**官网这一对外门面尚未把「本地 + 摄影感」翻译成视觉语言**。

| 痛点 | 表现 | 摄影圈 + 本地派的真实损失 |
|------|------|--------------------------|
| **没有发现入口** | 潜在用户根本不知道这个产品存在 | 摄影圈/本地派用「GitHub / V2EX / 知乎」找工具,搜不到 = 不存在 |
| **「本地」这件事没说清** | 5 秒内讲不清「**照片会传到哪里**」 | 摄影派第一反应「又是个云端 AI 修图」,直接关页面 |
| **下载路径缺失** | 没有 Windows / macOS / 源码 三种下载入口 | 摄影用户拒绝跳到 GitHub 自助,需要「一键下载 exe」+「一行 pip」 |
| **没有社会证明** | 没有真实样例、没有摄影师证言 | 摄影圈是「作品先于产品」,空喊功能=空气 |
| **品牌资产缺失** | 没有统一视觉与文案 | 散落在仓库 README,无法形成「本地 + 摄影」品牌记忆点 |

### 1.2 立项目目标(摄影艺术 + 桌面软件视角重写 · **D4 修订**)

> **用 1 个站,把「照片导进来,画册自动出来 · 照片留在本机 · 无需注册」讲清楚;让访客安装 Studio、开始制作游记、愿意分享给朋友。**

**【D4】本节所有 KPI 与 §8.3 运营表、§9.3 Stop-Loss 三表口径完全一致,不再有 v0.3 自相矛盾**。

| ID | 目标 | 衡量方式(**90 天内**) | 摄影派 + 本地派验收口径 |
|----|------|----------------------|------------------------|
| **G-WEB-01** | 访客 5 秒内被「**本地交付 + 摄影感**」击中 | 落地页首屏停留 ≥ 12s | 摄影用户「不立刻点叉」= 入门 |
| **G-WEB-02** ★ | 至少 30 位**真实摄影用户**完成首次本地装订 | GA 事件 `first_local_book_bound` 计数 ≥ 30(**【D5】埋点定义:Studio 第一次成功导出 HTML 长图且落盘 ≥ 1 张 `*-ch0X.png` 即视为「首次装订」**) | 其中**非开发者占比 ≥ 80%**(**【D4】口径:官网来路非 github.com/yourname/yourname + 命令行未出现 `pip install` 字样** = 非开发者) |
| **G-WEB-03** | 至少 5 位**真实摄影师**愿意把作品/署名挂在站内 | 站内「视野墙」收录 ≥ 5 位(**【D6】30 天 ≥ 2 / 60 天 ≥ 4 / 90 天 ≥ 5 三段式预警**) | 摄影圈最稀缺的是「被认真对待」 |
| **G-WEB-04** | 至少 5 个摄影垂直社区(500px/图虫/米拍/LOFTER/POCO)出现 UGC | 站内「社区精选」收录 ≥ 10 条 | 摄影圈渠道不可缺 |
| **G-WEB-05** | **下载量**(GitHub Releases + PyPI + 镜像站)**90 天 ≥ 500** | Releases 下载计数 + PyPI stats + 镜像站下载计数 | 桌面软件核心指标 |
| **G-WEB-06** | **GitHub Star ≥ 200**(产品信任锚) | shields.io 实时展示 | 桌面软件开源信任锚(**【B-05】若 60 天 < 50,目标下调到 80**) |
| **G-WEB-07** | **零云端/零账号承诺**被访客记住 | **【A4】** Hero 区互动投票 + 1 元红包激励,正确率 ≥ 80% | 桌面软件最核心心智 |

### 1.3 非目标(本 PRD 明确不做 · 桌面软件 + 摄影视角加强)

#### A. 严格不做(SaaS 化 / 云端化)

- ❌ **不在网站内提供「在线导入照片直接生成」** —— 摄影派「传原图上云」极度敏感
- ❌ **不做账号体系 / 注册 / 登录** —— 桌面软件不需要账号
- ❌ **不做云同步 / 云端存储** —— 一切数据归用户本地
- ❌ **不做付费订阅 / 会员体系** —— 商业化会破坏「创作自由」氛围
- ❌ **不做云端 AI 文案生成** —— 即使使用 LLM,也走**用户自带 API Key**,数据不经过我方
- ❌ **不做 Web 版 / 浏览器内体验** —— 桌面软件形态是产品本质,**Web 版会模糊承诺**

#### B. 不做(范围控制)

- ❌ **多语言 i18n**:首版仅简体中文(国内摄影圈已足够大)
- ❌ **复杂 CMS / 博客系统**:用静态站 + Markdown 即可
- ❌ **电商化变现**:不卖课、不卖滤镜、不卖预设、不挂 Affiliate 链接(**【B-08】**摄影圈对软广极敏感)
- ❌ **强 SEO 黑帽**:不做关键词堆砌,**反对任何「水印党」「预设党」气质**

#### C. 文案红线(摄影派 + 本地派共通)

- ❌ **「AI 一键生成大片」「AI 修图」「AI 生图」**:统一用「**策展 / 编辑意图 / 版面智能**」
- ❌ **「邀请好友得 VIP」「立即注册领取」**:违反本地派美学
- ❌ **「上传到云」「云端备份」「云相册」**:**严格禁用**;改用「**照片留在本机 · 本地处理**」
- ❌ **「免费试用 3 天后续费」**:不存在的概念
- ❌ **「累计装机 5000+」「5000+ 摄影者在用」类用户数 social proof**(**【B-08】摄影圈最反感**):**全站禁出现具体用户数**,仅展示「作品数」「摄影师数」结果性数字
- ❌ **9 宫格/朋友圈自动同步**:不做(摄影用户需要的是「作品集」,不是「一次性分享」)

## 2. 受众与场景

> Persona 详档见 [PRD-MVP.md §3](./PRD-MVP.md)。本节**只列桌面软件 + 摄影圈视角的差异化要点**。

### 2.1 三类核心访客

| Persona | 占比预估 | 进站路径 | 桌面软件 + 摄影圈语境的核心诉求 | 决策时长 |
|---------|----------|----------|------------------------------|----------|
| **P-A 摄影艺术爱好者 · 主力用户** | 55% | 小红书/500px/图虫 看到长图 | 「**这长图怎么做的?我自己的照片也能做成这样吗?会不会让我的照片变俗?要装什么?要钱吗?照片会传到哪里?」** | 30 秒 |
| **P-B 独立摄影师 / 视觉创作者** | 30% | 朋友圈/微博/即刻 看到作品 | 「**是装在本地吗?我的 RAW/EXIF 会被尊重吗?能挂到我的作品集网站吗?卸载后数据怎么办?」** | 2 分钟 |
| **P-C 摄影自媒体 / 博主** | 15% | 微信群/视频号/小红书 看到引流 | 「**粉丝能不能一键保存长图?能挂我的二维码吗?能不能加上我的水印?支持视频号助手吗?」** | 1 分钟 |

### 2.2 三类访客的「黄金 5 秒」

| Persona | 5 秒后必须看到的 |
|---------|-----------------|
| **P-A 摄影艺术爱好者** | 一张**真实全屏摄影长图** + 「**TRAVELOGUE · 智能游记画册 · 照片留在本机 · 无需注册**」+ Lead「自动分章 · 配文 · 排版,生成大屏卷轴 + 微信长图」(**不出现「云」「AI 一键生成」字样**) |
| **P-B 独立摄影师** | 「**本地运行**」「**底片归你**」「**开源可审**」三个徽章 + 真实摄影师作品集入口 |
| **P-C 摄影自媒体** | 「**支持自定义水印**」「**支持视频号二维码**」「**一键保存长图**」三个 badge + 案例 |

### 2.3 摄影派 + 本地派「踩雷点」清单(站内绝不能出现)

| ❌ 雷点 | 真实反应 |
|---------|----------|
| 「AI 一键生成大片」 | 「我的作品不需要 AI 代我审美」 |
| 「10 秒出图」 | 「10 秒能出什么东西?我的快门是按了 1/2000s 都没犹豫的」 |
| 「美颜 / 滤镜 / 一键磨皮」 | 误认为「美图秀秀同类」,直接关页面 |
| 「**上传到云**」「**云端存储**」「**云相册**」 | 误认为「又一个云盘 SaaS」,**直接关页面** |
| 「邀请好友得 VIP」 | 「我不为朋友做营销」 |
| 「免费试用 3 天后续费」 | 「好工具不靠这个」 |
| 「**登录 / 注册 / 账号**」 | 「我只是装个软件,为什么要注册?」 |
| 「**在线一键试用**」 | 「在线 = 云 = 不安全」,直接关页面 |
| 「5000+ 摄影者在用」 | 「刷的吧」「谁信」,**【B-08】**全站禁用户数 |
| 通用 SaaS 渐变紫蓝色 | 「又一个 SaaS,看腻了」 |
| 棚拍模特假脸、合成感大图 | 「一眼假,这是给谁看的?」 |

### 3.4 文案语气(**【v0.6】对齐 Studio §3.2「自动 vs 智能/AI」**)

| 场景 | 允许 | 禁止 |
|------|------|------|

## 7. 技术选型(**【A 类 must_fix】D 类 v0.4 重大修订**)

### 7.1 推荐栈(**【A 类 D2/B 类】v0.4 全面修订**)

| 层级 | 选型 | 理由 |
|------|------|------|
| **框架** | **Astro** | 静态优先 + 岛屿架构,Lighthouse 极易高分,**支持 content collections 直接消费 `docs/*.md`** |
| **样式** | Tailwind CSS + `@tailwindcss/typography` | 配合设计 token,易维护 |
| **图片** | **Astro `<Image />` 组件** + Cloudflare Images / 阿里云 OSS | 长图/高分辨率图自动生成 webp/avif + srcset + lazy load |
| **画廊** | **PhotoSwipe v5** 或 **Lightbox 自研** | 触屏友好 + EXIF 浮层 |
| **部署** ★【技术 A 类】 | **国内主源:阿里云 OSS + CDN(已备案)**,Cloudflare 只做海外兜底 / Vercel 国外镜像 | **国内主分发不能用 Cloudflare,ICP 备案主源必须是国内 CDN** |
| **域名 + DNS** ★【技术 A 类】 | 阿里云 DNS(主) + Cloudflare(海外) 智能解析 | 跨网降级 |
| **下载源** ★【D9】 | **GitHub Releases(主) + Gitee 源码(国内镜像) + PyPI stats**;**腾讯软件中心/360 降 P3(M6 后再申请)** | 桌面软件官网必备 |
| **评论/讨论** | **Giscus(GitHub Discussions)** | 零成本、可持续、可定制暗房主题;**法务 Q8**评估跨境传输风险 |
| **分析** ★【A 类 D2】 | **Plausible cookieless 自托管(默认无 cookie,无个人识别,无跨境)** + **GA4 默认不加载,仅用户主动「接受全部」Cookie 时才注入** | **严格零遥测,优先 Plausible cookieless** |
| **二维码** | 自托管 + cron 提醒 | 见 F-42 |
| **字体加载** ★【A 类 D2】 | **Fontsource 自托管 + 强制 unicode-range 子集化 + 全部 woff2**;**Google Fonts CDN 在国内必超时,绝不能用** | 关键:只加载用到的字符,避免中国大陆访问 Google Fonts 失败 |

| **滚动** | **优先 CSS `scroll-behavior: smooth`**,不达标再 Lenis(不引第三方滚动库) | 性能预算优先 |
