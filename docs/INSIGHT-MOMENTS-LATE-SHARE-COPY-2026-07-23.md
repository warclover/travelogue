## 1. 原文资产（六段）

语气统一：**迟晒 / 虽迟但到 / 快乐不打折**；适合微信朋友圈配文，偏网感 + 轻自嘲。

### 01

虽然迟到但不会缺席的旅行碎片🧩  
这是一条过了时效的朋友圈，但快乐无限期📅  
去年的旅行今年发，这叫沉淀美感🥰

### 02

翻相册才发现这些美景还没晒🌄  
拖延症晚期患者的旅行日记，虽迟但到，快乐不打折⏳  
新鲜出炉的…去年旅行照📷

### 04

旅行过去式，快乐进行时✈️

## 2. 与现有产品的边界

| 表面 | 现状 | 与本资产关系 |
|------|------|----------------|
| 杂志 `meta.hook` / 章 `lead` / `caption` | sparse；「敢发」宁可空，禁说明书腔 | **不要**默认灌入这六段 |
| 小红书 `shareCopyPack` | title + 可选 body + topics | 已有出口包；朋友圈缺对等 |
| Wait Tips（导入等待） | 6 张 Outcome-first：结果/信任/能力/下一步/试用 | **职责不同**，见 §4 |
| 朋友圈九宫格 / 连读 | 导出形态已有 | **最自然的挂载点** |

洞察文已写：朋友圈 / 家庭群 / 个人相册需要 **三种文案**，且忌夸张鸡汤。本资产只覆盖其中一类语气——**迟晒公开晒**。

## 3. 主推用途（产品落点）

### 3.1 朋友圈「配文包」种子库（P0）

- 导出成功面或意图卡旁：**复制朋友圈文案**
- 3～6 条候选，一键换一条，可再编辑
- 扩展现有 `shareCopyPack` 思路，增加 `moments` / `late_share` 通道，而非塞进杂志 narrate

### 3.2 按场景启用，勿当通用默认

仅在以下情况优先露出：

- 行程结束距今 ≥ 14 / 30 天（阈值可调）
- 用户选择「朋友圈 · 九宫格 / 连读」
- 用户明确点「换一条朋友圈配文」

刚回来、家庭群、相册归档 → 换更平实语气包，不混用迟晒腔。

### 3.3 L0 / stub 的出口兜底

- 无 Key：Moments 候选模板，不依赖 LLM  
- 有 Key：作 few-shot / 语气锚仿写「迟晒」句；**禁止编造照片中不存在的情节**  
- 杂志章导语、图注仍走 sparse

### 3.4 刻意不做

- 不当默认 `meta.hook` / 章 `lead`
- 不当首页营销主口号
- 不假装「AI 原创」——宜标「可发模板 / 点一下换」

## 4. Wait Tips 是否合适？

### 结论

**原样六段上 Wait Tips 轮播：不合适。**  
「等待时种下以后好发」的内核可取，但实现应最多 **1 张出口提示卡**，原文仍留给成功面。

### 原因（对照 PRD-WAIT-TIPS-V1）

- Wait Tips 教：会得到什么 / 为何放心 / 做完先干什么 / 怎么试用  
- 禁区：教微信发群步骤、杂志级文案承诺、与 stage 同义复述  
- 现卡语气是产品旁白；六段是用户发出去的社交文案 → **角色串台**  
- 等待时用户焦虑「好了没」，不是在挑配文 → **抢心智**  
- 再塞多张文案卡会稀释 Outcome-first、拉长轮播

### 若仍想沾「文案」——唯一建议形态

最多加 **1 张**「小灵感 / 下一步」卡，讲能力不贴原文，例如：

| 标签 | 标题（例） | 正文（例） |
|------|------------|------------|
| 小灵感 | 发出去时，配文也备好了 | 成稿后可点换几句轻松的；不满意再改两个字就行。 |

- 插在 WT-04（下一步）附近  
- emoji 慎用（现有 Wait Tips 几乎不用）  
- 六段原文 **不**进等待轮播

## 5. 「六张卡片 × 一份文案」形态

### 结论

**可行，但挂在「敢发」时刻，不挂在「还在等」时刻。**

| 场景 | 是否合适 |
|------|----------|
| 导入等待 Wait Tips | 不合适 |
| 导出成功面 / 复制文案 | 合适 |
| 精修旁「灵感」抽屉 | 可做次选 |

### 成功面六卡建议

- 每卡只露 **1～2 行 opener**；选中或展开再看全文  
- 主 CTA：**复制这条**；次要：换一条 / 自己改  
- 横滑或点选即可；**不必**自动轮播抢注意力  
- emoji 可保留；可选「精简版」（去 emoji）开关更稳

## 6. 其它创意用法

### 产品内

1. **语气开关**  
   导出前：`刚回来` / `沉淀一下` / `随便晒晒`。选「沉淀」才启用本六段。

2. **九宫格封面贴纸句**  
   只取 opener 作顶/底一行字（可关），不进长文。

3. **空 hook 时的「人味补丁」**  
   杂志 hook 可空；朋友圈出口用本资产做 channel-only 正文。

4. **「换一句」微互动**  
   Dock 次要入口：点一次随机换一条（轻动效，像抽签）。

5. **行程时间差彩蛋**  
   结束已过 30/90/365 天 → 成功面默认推迟晒包，副标如「这趟已经在相册里住了 N 天」。

### 增长 / 品牌（轻）

6. **示例册固定旁白** — demo「发朋友圈」演示用 1～2 条当人格样片。  
7. **分享海报一句** — 宣传图底部用 opener，偏情绪钩子。  
8. **A/B 文案工坊资产** — 先 JSON 池测复制率 / 改写率 / 直发率，再扩家庭群/相册语气。

### 可后做

9. **「迟晒日历」** — 旅行后第 7/30 天本机提醒「要不要晒了？」+ 随机一条。  
10. **拼一条「三行诗」** — opener / punch / closer 各抽一行组合；仍不编造行程事实。

---

## 7. 优先顺序（建议）

| 优先级 | 事项 |
|--------|------|
| **P0** | 成功面 / 复制链路：`late_share` 配文池 + 六卡或「换一条」 |
| **P1** | 语气开关 + 行程时间差默认推迟晒 |
| **P2** | 扩展 `shareCopyPack` 增加 moments 通道；九宫格贴纸句 |
| **以后** | 迟晒日历、三行诗组合、Wait Tips 单张「配文备好了」提示 |
| **不做** | 原文进 Wait Tips 轮播；原文默认进杂志 hook |
