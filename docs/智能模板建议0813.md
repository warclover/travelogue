## 0. 参考对象与差异

参考设计是一套约 40 张游记页模板：奶油纸底、中文衬线主标题 + 英文无衬线辅文、大量留白。功能类型包括扉页/章节页、单图英雄、网格、手帐拼贴（微倾 + 胶带）、长文页、不对称混排。槽位长宽比不统一，部分叠压，带圆形印章等装饰。

它有两个必须有人的步骤：

1. **人选图**：把照片挑进各个模板。
2. **人裁切**：把照片裁进不规则槽位。

好处是充满艺术感与杂志气息，页面生动，是一本真正的画册。

本项目的设计初衷恰好相反：**无需人类参与，自动出画册**（章程：默认零步，选相册 → 出游记 → 分享）。差异就落在上述两点。

下文回答三个问题：AI 能否自动生成并组合模板；AI 能否智能裁切填槽；作为产品总监，这张图有哪些借鉴。

---

## 1. AI 能否自动生成各式模板并组合使用？

**能「生成」，不该「当场生成」。能「组合」，而且这才是本项目该做的那一半。**

参考图里那约 40 张页，本质是一套**封闭设计系统**，不是 40 个互不相关的灵感。纸色、字体层级、页码、元数据、留白纪律是共用的；变化只发生在：扉页 / 大图 / 网格 / 拼贴 / 长文 / 不对称。

本项目其实已经走在同一条路上：

- 仓库约有 47 份槽位几何说明（`docs/templates/slot-aspect/`）。
- 布局模板引擎（LTE）把 YAML 当唯一权威。
- 拼图选型（MTSO）负责「这组照片该用哪张脸」。
- 章程：**版式由模板与 manifest 决定，Agent 不直出 HTML。**

所以差距不在「模板够不够多」，而在三类能力：

| 他们有、我们弱 | 说明 |
|---|---|
| **成册节奏** | 有「出发」这类纯字扉页、大留白呼吸页、图文对半页。我们更常把每一屏都当成「把照片塞满」。 |
| **不规则语法** | 微倾、胶带、叠压、圆形印章。这是装饰层，不是新拓扑。 |
| **跨页叙事** | 他们按纸书对页想；我们按 16:9 屏 / 9:16 长图想。版式不能 1:1 搬。 |

运行时让模型自由发明模板，会直接打穿三件本项目已经用血换来的东西：品牌一致性、可回归、裁切可预测。拼图槽位自适应（MSA）的非目标里已写过：不做遗传算法搜拓扑树（N-03）。LTE 也明确：理论组合极多，产品只维护 curated 子集（D-P16-03）。

更稳的分工是：

1. **离线**：AI 当设计师助手，按语法提案新 YAML（槽数、横竖比、文案权重、装饰标记）→ 几何审计 → 探针图 → 人工准入。
2. **在线**：AI / 规则当编辑，从现成库里**选页、排顺序、配角色**——这和现有的多候选打分（MCS）、拼图选型（MTSO）、版式评论是同一条产品线。
3. **用户感知的「各式各样」**：主要来自节奏变化（扉页 → 大图 → 密网格 → 留白），不是每趟旅行现场发明 40 套新版式。

**本节结论：** 40 套手工模板的价值，是设计系统，不是数量。本项目要自动化的是「用这套系统的编辑」，不是「再生一套系统」。

## 2. AI 能否智能裁切并填进不规则槽位？

**矩形槽、已知长宽比：可以做到「得体」，而且应作为下一阶段主战场。旋转/异形槽：先降维，再追求杂志级。**

手工填充之所以好看，是因为人同时做了两件事：这张图该进哪个槽（角色），以及裁到哪（构图）。本项目已经有半套机械：

- `crop_solver`：按人脸 / 保护框反推 `object-position`，必要时才从铺满退到留白。
- 封面焦点、标题避让，已经在用「别压到脸」。
- MSA 的产品直觉是对的：**宁留白，不毁构图**。但它默认关闭，盲评未过——说明「跟着照片改槽」在成册节奏上还有副作用。
- 明确不做：入库时把照片统一裁成一种物理比例（D-P16-02）。

技术上应拆成三层，而不是丢给一个多模态模型「看着办」：

1. **感知**：人脸、半身保护框、地平线、显著物。风景保天际线与地标完整性；人像保头、肩、脚，避免「砍头切脚」。
2. **几何求解（权威）**：给定槽位长宽比，求一个可测的裁切窗。这必须确定性、可单测、可回归。
3. **视觉评论（加分）**：在若干合法窗里挑更得体的；过不了就换槽、换模板，或合法留白。禁止「评论推翻几何」。

风景和人像规则不同，不能共用一个中心裁：

- **人像**：脸是硬约束；群像要进同一窗；半身保护框过大时，不要为了保框而破坏铺满合同。
- **风景**：地平线、建筑脚、招牌文字比「画面中心」更重要；宽槽吃 3:2 单反时，上下各砍约 15% 就足以毁掉一张好图（MSA 已量化过这一错配）。

不规则槽建议分档，不要一上来做任意多边形：

| 档 | 例子 | 自动化难度 | 建议 |
|---|---|---|---|
| A | 横/竖/方矩形，AR 不同 | 中，业界已有解 | **现在就该做默认能力** |
| B | 矩形 + CSS 微倾 / 胶带 | 中低（先裁正再变换） | 装饰层，高性价比 |
| C | 真重叠、异形遮罩、圆形戳 | 高（图层顺序、遮挡主体） | 只做少量签名页，不当默认 |

「得体」的最后 20% 最难：切到脚、切到地平线、切到路牌汉字、砍掉合影里的人。所以产品合同应是：**保主体失败 → 换槽或留白，而不是硬裁。** 这和「无需人类参与」不矛盾——编辑决策自动化了，人不用上手。

**本节结论：** 智能裁切可做，且应做；权威在几何求解，AI 只做评论与加分。异形槽降维成「矩形 + 装饰变换」，不要把任意多边形当默认舞台。

## 3. 产品总监视角：看到这张图会产生哪些想法？

先承认：这本手工册证明了一件事——**用户要的「真正的画册」= 编辑过的纸面，不是照片墙。** 然后立刻划清：我们不能变成「先选 40 套模板再手填」的工具，那会回到他们已经付出、而本项目立志省掉的那两步。章程仍是「这一趟做完」，默认零步。

借鉴按优先级排，而不是按「好看得抄」排。

### 3.1 高优先级：抄编辑语法，不抄工作流

**成册节奏，而不是每页都拼满。**  
参考图真正高级的地方，是页与页之间的呼吸：大字扉页、单图英雄、密网格、半页手帐。我们现有算法很会「把合格照片装进合格拼图」，还不大会「这一页故意少图」。这可以直接变成版式序列规则：每章至少一页扉页或大留白，禁止连续三屏同构网格。

**留白是奢侈品，不是算法失败。**  
奶油纸 + 大面积负空间，是杂志感的来源。我们习惯 16:9 铺满。MSA 那句「宁留白不毁构图」方向对，但需要变成用户能懂的气质（接近 LVP「杂志成册 / 更贴照片比例」），而不是工程开关。

**手工感是装饰层，不是新模板库。**  
微倾、胶带、圆形印章，可以做成确定性的 CSS / 贴纸语法，挂在现有槽上。这和封面装帧标题（CAL）、以及 [zine 技能调研](./RESEARCH-PHOTO-ZINE-SKILLS-2026-08.md) 的判断同构：**实拍权威 + 派生装饰**。投入小、观感跳一档，而且不破坏自动裁切。

**字是版式，不只是图说。**  
「出发」那种巨字扉页，说明内页也可以把中文标题当建筑。我们在封面书法上已经走得很深，内页仍偏「图下小字」。章节页、地点页可以先做 3～5 个固定版，不必等生成式排版。

### 3.2 中优先级：把「人填槽」翻译成「角色匹配」

人在那 40 个框里做的，其实是角色分配：

- 大场景 → 宽英雄槽
- 脸 / 全身 → 竖槽
- 食物、材质、局部 → 小方槽
- 序列过程 → 等权网格

本项目的策展和打分已经在做弱版。补强点是：**先定角色，再选模板，再裁切。** 现在容易倒过来——先定模板拓扑，再把图塞进去，于是裁切被动、主体受伤。

### 3.3 明确不抄

- **不把「人手选图 + 手裁」做成主路径。** 那是另一个产品（Canva / 印书工具）。我们的差异化就是省掉这两步。
- **不在运行时让模型发明版式。** 参考图好看，正因为 40 套是同一只手画的。每趟旅行现场发明，品牌会碎，回归会死。
- **不把纸书对页当现网舞台。** 他们是近似书页比例；我们是 16:9 屏和 9:16 长图。要借的是节奏和装饰，不是网格坐标。
- **不规则槽不当默认。** 它是艺术，也是自动裁切的倍增器。默认仍应是矩形槽 + 得体裁切；拼贴只作为可选气质。

### 3.4 若只开一条产品线

**「智能编辑器」而不是「智能模板工厂」。**

```
照片池
  → 策展（已有）
  → 角色标注（风景主图 / 人像 / 细节 / 序列）     ← 补
  → 成册节奏选页（扉页 / 英雄 / 网格 / 留白 / 手帐） ← 补
  → 槽位匹配 + 保主体裁切（几何权威 + 视觉评论）   ← 主战场
  → 可选工艺层（微倾 / 胶带 / 印章）               ← 观感
```

这正好接住参考图的两个「必须有人」的点：选哪张进哪页，用算法角色匹配替代；裁到哪，用保主体求解替代。模板继续人工策展、小步扩库——和他们用设计师画出 40 套，是同一件事，只是发生在发版前，而不是用户做册时。

## 4. 对这张图的最终态度

它证明我们要追的不是「更会生成版式的模型」，而是「更会当杂志编辑的系统」。他们用设计师 + 人手，做出了画册该有的呼吸和得体；我们要用同一套设计纪律，把编辑决策做进管线。

- **模板**保持封闭、可测、可盲评；AI 只在离线提案。
- **AI 在线**用在选页、角色和裁切评论上。
- **裁切**以几何求解为权威，保主体失败则换槽或留白。
- **工艺层**（微倾 / 胶带 / 印章）用确定性装饰，不新开拓扑。

这样既不放弃「无需人类参与」，也才有机会接近那本真正的画册。
