## 1. 会议背景

PRD v0.1 已确立两条核心规则（用户原始诉求）：

- **R-06**：`screen-portrait-2`（双竖并排）连续 ≤2 屏
- **V-08/V-09**：满屏竖单（含 plate 等价类）不连续

本次讨论会目标：**在不推翻 pair-first 主原则的前提下，征集更广泛的排版规则补充**，覆盖观感、版式美学、算法可行性、工程成本四个维度。

参会角色：**用户体验（UX）/ 版式排版专家 / 算法专家 / 前端工程 / 视觉编辑（摄影向）/ 产品**。

## 2. 角色发言与规则候选

### 2.1 用户体验（UX）

**关注点**：滚动阅读疲劳、节奏可预期、首屏与章首的「第一印象」。

| 候选 ID | 建议 | 理由 |
|---------|------|------|
| **WS-UX-01** | **章内同一 pattern 总占比软上限**（如单章 `portrait-2` 不超过该章内容屏的 50%） | demo-2025-2 ch-01 双竖占比过高，即便 ≤2 连仍显单调 |
| **WS-UX-02** | **章首 3 屏不连续同类**：章节开头节奏更需变化，避免「一进章就连续双竖」 | 第一印象决定继续滚动意愿 |
| **WS-UX-03** | **呼吸屏不应替代版式多样性**：呼吸屏后若仍是同 pattern，不算「换了节奏」 | 与 PRD R-07 一致，建议写成显式 UX 验收口径 |
| **WS-UX-04** | **「大图锚点」节奏**：每滚动 N 屏（建议 5–7）至少出现 1 次单张大图/拼图等强视觉屏 | 给读者「停顿—呼吸—惊喜」的节奏感 |

### 2.2 版式 / 排版专家

**关注点**：版面留白、视觉重量、相邻屏的构图呼应、跨页（plate）节奏。

| 候选 ID | 建议 | 理由 |
|---------|------|------|
| **WS-LAY-01** | **相邻屏视觉重量交替**：避免连续「高密度→高密度」（如 mosaic-6 紧接 portrait-2 群） | 版面需要疏密交替 |
| **WS-LAY-02** | **同朝向连续上限**：连续「全竖版屏」（含 portrait-1/2/3）总数设上限，超出应插入横版/全景换气 | demo-2025-2 ch-01 整段竖版墙 |
| **WS-LAY-03** | **plate（跨页大图）间隔**：两张 folio plate 之间至少间隔 K 屏，且 plate 优先横/全景而非竖图 | plate 太密或全竖会削弱「跨页惊喜」 |
| **WS-LAY-04** | **章尾收束**：章节最后一屏避免用「弱兜底」pattern（孤张 portrait-1） | 章尾应有收束感 |
| **WS-LAY-05** | **人物连拍组的「主次」**：同一连拍组优先选 1 张做略大展示，而非全部等权双竖 | 8 连拍全等权双竖缺乏层次 |

### 2.3 算法专家

**关注点**：规则可计算性、确定性、与现有 beam/MCS/state 的耦合、性能。

| 候选 ID | 建议 | 理由 |
|---------|------|------|
| **WS-ALG-01** | **streak 统一抽象**：将「连续上限」收敛为单一 `consecutive_policy`（按 kind / pattern / 朝向三种粒度），避免散落 if 分支 | 当前 `LayoutKind` 粒度不足以表达 WS-LAY-02 |
| **WS-ALG-02** | **规则优先级显式化**：硬禁令 > 全覆盖 > pair-first > 多样性 > force，写成可测的裁决函数 | 与 PRD §5 一致，建议代码层固化 |
| **WS-ALG-03** | **pending 回插窗口**：streak 触顶时把竖版暂存并在「下一个非竖版后」回插，需限定回插最大距离（避免照片漂移过远破坏时间线） | V-07 ③ 的边界条件 |
| **WS-ALG-04** | **确定性保证**：所有新规则必须在 `note_screen` 路径同步 state；deferred carry 不得提前 note | 复现性是回归红线 |
| **WS-ALG-05** | **post-check 安全网**：trip 级 validator 增加 streak 检查，违规打 log/telemetry，便于灰度观测而非直接 fail | 渐进式上线 |
| **WS-ALG-06** | **LSE 与 legacy 双路径一致**：规则需在 `ScreenLayoutPlannerState`（非仅 LSE 策略包）生效，否则未开 LSE 的 trip（如 demo-2025-2）拦不住 | 已在 PRD G-04 体现，强调测试覆盖 |

### 2.4 前端工程

**关注点**：渲染契约、folio/breath 与 pattern 的解耦、CSS 兼容。

| 候选 ID | 建议 | 理由 |
|---------|------|------|
| **WS-FE-01** | **plate 等价类标注**：渲染时为「满屏竖图 plate」加 data 标记，便于 QA/审计统计竖单 streak | 当前 plate 把 portrait-1 掩盖，审计需还原 |
| **WS-FE-02** | **streak 审计可视化**：在 Studio 预览叠加「连续同类」高亮（调试开关），辅助人工验收 | 便于 AC-RHY-03 人工浏览 |
| **WS-FE-03** | **呼吸屏与 streak 解耦**：明确呼吸屏 DOM 不带 `data-pattern` 内容语义，审计脚本统一忽略 | 与 R-07 对齐 |

### 2.5 视觉编辑（摄影向）

**关注点**：照片内容质量、人物表情、连拍择优、时间线真实感。

| 候选 ID | 建议 | 理由 |
|---------|------|------|
| **WS-VIS-01** | **连拍择优而非全收**：同一 burst 组内若已有 cull，组屏阶段仍可对「近重复双竖」进一步抑制 | 8 连拍未必都值得双竖展示 |
| **WS-VIS-02** | **人物成对优先「同场景」**：双竖配对优先选 takenAt 邻近且同场景的两张，避免拼接违和 | 提升 person-pair 观感 |
| **WS-VIS-03** | **时间线不漂移**：pending 回插/ carry 不应让照片跨越明显时间断点（如跨天） | 保持叙事真实 |

### 2.6 产品

**关注点**：规则可解释、灰度可控、与「版面密度」偏好正交。

| 候选 ID | 建议 | 理由 |
|---------|------|------|
| **WS-PM-01** | **规则与版面密度（hero_first/balanced/collage_first）正交**：streak 上限在三档下数值可不同（collage_first 可放宽） | 避免规则与用户偏好冲突 |
| **WS-PM-02** | **可配置而非硬编码**：所有阈值（streak 上限、carry hops、plate 间隔）走策略包 | 便于运营调参 |
| **WS-PM-03** | **灰度先 log 后 enforce**：先上 post-check 观测违规率，再切硬约束 | 降低回归风险 |

## 4. 收敛建议（主持人小结）

按「**对 demo-2025-2 的直接收益 × 工程成本**」分三档：

### 第一批（随 PRD P0–P2 一起做，低成本高收益）

- **R-06 / V-08 / V-09**（PRD 已有）
- **WS-ALG-01** streak 统一抽象 + **WS-ALG-02** 优先级裁决（实现 R-06 的自然产物）
- **WS-ALG-04** 确定性 + **WS-ALG-05** post-check 安全网
- **WS-FE-01** plate 等价类标注（支撑 V-09 审计）
- **WS-ALG-03 / WS-VIS-03** pending 回插限距 + 不跨时间断点

### 第二批（PRD P3 之后，需产品定阈值）

- **WS-LAY-02** 同朝向连续上限（竖版墙换气）
- **WS-UX-02** 章首 3 屏不连续同类
- **WS-LAY-04** 章尾不用弱兜底
- **WS-PM-01 / WS-PM-02** 阈值随密度可配置

### 第三批（探索 / 需更多样本验证）

- **WS-UX-01** 章内占比软上限
- **WS-UX-04** 大图锚点节奏
- **WS-LAY-01** 相邻屏视觉重量交替
- **WS-LAY-03** plate 间隔与朝向偏好
- **WS-LAY-05 / WS-VIS-01/02** 连拍择优与配对质量（涉及 cull/scoring，跨子系统）
